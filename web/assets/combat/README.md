# 金陵雨巷战斗美术

本目录为独立战斗入口 `web/combat.html` 使用的项目内美术素材。图像由内置图像生成工具制作，再转为 WebP；界面文字、血条、单位栏、热点与特效全部由 HTML／CSS 绘制，没有烘焙在图片中。

| 文件 | 用途 | 尺寸 |
| --- | --- | --- |
| `jinling-rain-ambush.webp` | 雨巷多人伏击战场底图 | 941×1672 |
| `portrait-chen-siming.webp` | 陈司命头像 | 512×512 |
| `portrait-masked-blade.webp` | 蒙面刀客头像 | 512×512 |

| `portrait-black-leader.webp` | 黑衣头目头像 | 512×512 |

## 生成提示摘要

- 战场：金陵药铺雨巷，陈司命持三枚银针，蒙面刀客当前逼近，屋脊弩手瞄准，黑衣头目留在后阵；灯笼、檐柱和矮墙清楚可辨；顶部与底部保留界面留白；不含文字、图标或界面。
- 陈司命：年轻求道者，雨湿灰衣、长发、银针，冷静而警觉。
- 蒙面刀客：黑衣、遮面、右手明刀、左袖藏刃，危险但没有超自然特征。
- 屋脊弩手：雨披、传统手弩、屋脊瞄准，轻装远程威胁。
- 黑衣头目：成熟、蓄须、深色武服、佩刀，后阵指挥者。

统一美术方向为半写实水墨数字绘画、冷蓝黑雨夜、暖色纸灯、克制金色与朱红点缀。禁止现代武器、西式甲胄、霓虹科幻和图片内文字。
