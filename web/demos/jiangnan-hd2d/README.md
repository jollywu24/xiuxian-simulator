# 武道 · 临水镇

独立 HD-2D 浏览器切片，完整制作说明见仓库 `docs/hd2d/IMPLEMENTATION.md`。

仓库根目录执行 `npm run serve`，打开 `/demos/jiangnan-hd2d/`。也可在仓库根执行 `python3 -m http.server 8080 --directory web`，访问 `http://127.0.0.1:8080/demos/jiangnan-hd2d/`。需要 WebGL2，不能直接通过 file:// 打开。

WASD／方向键行走，Shift 快走，鼠标点击地面寻路或点击人物走近交谈。E 交互，I 行囊，J 行录，M 地图，Esc 行旅；触屏使用左下方向键或地图导航。

任务路线：茶摊接事 → 渡口断缆及货签 → 客栈程岳 → 过桥到仓院 → 回合战斗 → 取箱 → 客栈交付。仓院每回合先走至多三格，再选择招式和目标、确认行动；数字键 1–4 选招式，Enter 确认。

行旅中可以切换晚照、声响、画质，导入导出行录或另起一程。独立存档键 `wudao-jiangnan-hd2d-v1` 不读取正式游戏记录。

Three.js 0.186.0 使用 MIT 许可证，见 vendor 目录。模型、像素人物、纹理与合成声音为本切片原创程序资产，源文件均在 src 内。没有使用目标参考图充当场景、第三方游戏资产或网络加载的运行依赖。

当前是首版可玩效果切片，完整八向手绘动画、GLB 制作、NPC 生活动作和硬件性能验收尚未完成，不宣称达到方案全部最终美术门槛。
