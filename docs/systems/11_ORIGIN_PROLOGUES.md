# 三出身与独立序章系统

## 1. 文档定位

本文定义《大曜江湖》人物建立阶段的三种出身、三段独立开场和它们汇入“雨夜破庙—龙青鱼—沈家丹房”主线的完整规则。

本文同时是现行设计规格与实现基线。三种出身、十一类容貌与命名、两段新增独立序章、破庙汇流、三种沈家入口、三个第一章个人事件、版本10迁移和浏览器回归已经接入当前网页；后续扩展必须继续同步规则、状态、界面、测试、存档迁移和剧情文档。

本系统解决四个问题：

1. 出身不再只是初始物品和一句人物介绍，而是直接决定开场地点、社会身份与第一项任务；
2. 三种出身在十五至二十五分钟内经历不同内容，但都能自然抵达破庙招牌奇遇；
3. 汇入共同主线后，开场取得的关系、见闻、权限和牵连继续产生实际影响；
4. “逆天改命”、龙青鱼和曹青丹房等核心玩法不被任何单一出身垄断。

## 2. 核心设计结论

第一版只保留三种出身：

| 稳定ID | 玩家可见名称 | 核心身份幻想 | 开场地点 | 第一项任务 |
| --- | --- | --- | --- | --- |
| `shen_branch` | 世家旁支 | 生在高墙里面，却从未被写进嫡脉次序 | 城南族宅西偏院 | 雨夜取回封存药匣 |
| `streetborn` | 市井子弟 | 没有靠山，但知道城中每条活路 | 秦淮外港鱼市 | 替人取回红绳油布包 |
| `mystery` | 身世成谜 | 不知道自己是谁，却有人认得遗物 | 金陵东郊破庙 | 活过今夜并查明随身之物 |

删除原“世家旁支、寒门子弟、身世成谜、江湖遗孤”四分法：

- 原“世家旁支”保留玩家可见名称，内部稳定ID收束为`shen_branch`；选择界面只显示“族宅西偏院”，进入序章后才揭示此处是沈家；
- “寒门子弟”和“江湖遗孤”合并为“市井子弟”；
- 家破人亡、孤儿、逃荒或被收养等具体往事不再占据一个完整出身，可在后续人物往事或初心中表达；
- “身世成谜”继续作为默认正史参考，但界面不得标注“推荐”“主线”或“正史”。

## 3. 设计目标与硬规则

### 3.1 出身必须提供什么

每种出身必须同时提供：

- 一个不同的开场地点；
- 一项可以完成、失败或带着隐患完成的开场任务；
- 一种永久保留的经历标签；
- 两至三件不同的随身物；
- 至少一名提前建立关系或留下印象的人物；
- 一个进入破庙的明确理由；
- 一个汇入沈家丹房的独立入口；
- 一个在第一章内回响的个人悬念；
- 至少三个在开场三十分钟内可见的实际差异。

### 3.2 出身不做什么

- 不直接提供力道、根骨、身法、悟性或福缘加点；
- 不绑定剑、刀、拳掌、暗器等战斗职业；
- 不把三种出身设计成简单、普通、困难三档难度；
- 不让某一出身自动得到最强武学、最多长期属性或唯一主线结局；
- 不为三种出身复制三套完整主线；
- 不让出身专属选项永远正确，它只能提供不同知识、权限或支付方式；
- 不在共同剧情中每句话都写三份变体，只在身份真正改变判断时响应。

### 3.3 公共主线不被出身锁死

以下内容属于所有出身都能进入的公共体验：

- 破庙环境求生与三项固定奇遇；
- “逆天改命”的首次觉醒和三点属性重分教程；
- 青衣妇人入庙、死亡风险、夜话与龙青鱼身份揭示；
- 《鱼跃龙门诀》的获得机会；
- 紫金河水路的第一次能力兑现；
- 沈家入口与曹青丹房主线；
- 命灯死亡回照；
- 三夫人、白栀云、王五、灵猴遗迹和沈福反目等后续篇章。

出身可以改变进入方式、前置见闻、人物态度、行动成本和后续责任，不得把这些内容变成某一出身的专属奖品。

## 4. 总体流程

```text
选择来处
├─ 世家旁支
│  沈家西偏院 → 领取雨夜药匣差事 → 抵达破庙
├─ 市井子弟
│  秦淮外港鱼市 → 接下红绳油布包差事 → 抵达破庙
└─ 身世成谜
   破庙冷醒 → 救火、果腹、查明随身物

共同局面
破庙环境行动 → 逆天改命觉醒 → 青衣妇人入庙
→ 夜话或死亡／错过 → 鱼跃龙门诀 → 紫金河

三种沈家入口
├─ 世家旁支：回府复命 → 旁支试用 → 丹房
├─ 市井子弟：侧门交货 → 药材跑腿 → 丹房
└─ 身世成谜：沈字铜钱 → 四项谋差落选 → 丹房

共同主线
曹青取血 → 炼丹三问 → 青青册 → 五禽戏 → 后续篇章
```

三条独立序章应控制在十五至二十五分钟。共同破庙局面可以复用场景、龙青鱼事件和固定奇遇，但开场旁白、到达状态、局部热点和身份选项不同。

## 5. 公共系统规则

### 5.1 经历标签

三种出身分别赋予一个永久标签：

| 标签 | 代表知识 | 常见用途 |
| --- | --- | --- |
| `[世家旁支]` | 宗族称谓、家宅规矩、印信、账契与沈家人物 | 正式入门、辨认文书、理解家法、调用有限族人身份 |
| `[市井]` | 物价、码头黑话、帮会记号、后门、跑腿规矩与底层人情 | 议价、找路、辨认骗局、从伙计和船夫处打听消息 |
| `[残忆]` | 玉佩、血书、模糊旧梦和与金龙会相关的异常熟悉感 | 辨认隐藏标记、触发身世片段、察觉追查者和假身份 |

标签不是自动成功。选项展开详情时必须说明它提供的是：

- 新见闻；
- 不同交涉身份；
- 更低资源代价；
- 新的风险；
- 或一条替代路径。

不得只显示“出身条件满足”而不解释依据。

### 5.2 开场三点属性

“逆天改命”的第一次三点重分属于公共教程，不再由“身世成谜”的家传玉佩独占。

目标规则：

- 三种出身在破庙遭遇第一次真实生存压力时都能觉醒命格；
- 十六年来已经形成、但尚未固化的三点力量成为首次可重分总量；
- 玩家可将三点分配到任意五维；
- 半块家传玉佩仍是“身世成谜”的线索与人物物件，但不再是其他出身无法使用核心系统的理由；
- 后续由武学、奇遇和物品取得的可重分属性继续遵循现有总量守恒规则。

玩家界面只需要说明“你有三点可以重新安放的力量”，不在开场灌输额外术语。

运行时已经将首次三点重分改为三种出身共有的命灯反应；玉佩只保留为“身世成谜”的线索与触发意象之一。

### 5.3 出身反馈密度

最低反馈标准：

- 独立序章内至少两次；
- 破庙共同局面至少一次；
- 龙青鱼事件至少一次；
- 初入沈家至少两次；
- 曹青丹房至首次炼丹至少两次；
- 第一大章结束前至少一个个人悬念回响。

每个后续核心篇章的制作预算为：

- 一条出身见闻或对话；
- 一种不同的权限、成本或风险；
- 必要时一段个人悬念回响；
- 不强制每个普通日常行动响应出身。

### 5.4 平衡方式

出身采用横向优势，不比较总价值：

| 维度 | 世家旁支 | 市井子弟 | 身世成谜 |
| --- | --- | --- | --- |
| 正式权限 | 高 | 低 | 低 |
| 自由行动 | 低 | 高 | 中 |
| 初始银钱 | 高 | 中 | 无 |
| 底层门路 | 低 | 高 | 低 |
| 隐秘线索 | 中 | 低 | 高 |
| 身份暴露 | 高 | 中 | 未知但危险 |
| 沈家审视 | 家法与利用 | 轻视与差遣 | 猜疑与追查 |

一个出身得到便利时，必须同时让世界更容易以相同身份找到、约束或利用玩家。

## 6. 出身一：世家旁支

### 6.1 玩家幻想

> 你的名字写在沈氏旁谱，却进不了正堂。旁人称你一声沈家人，只因还没到撕破脸的时候。

这是“身在局内”的开场。玩家比另外两种出身更早看见沈家的秩序，但最初没有决定权。

### 6.2 身份事实

- 陈司命十六岁，随母系远支在外生活；
- 外支产业败落后，他带着旁谱证明来到金陵沈家求一份立足之地；
- 沈家承认其旁支身份，但尚未给月例、住处和正式差事；
- 沈福负责观察其是否可用；
- 玩家知道沈家家主、三夫人、外院与内宅的基本称谓，不知道曹青真实身份；
- 玩家来沈家只有三日，不能凭空认识所有人物或掌握宅院秘密。

### 6.3 开场地点

**金陵沈家·西偏院**

场景应表现：

- 能看见正院灯火，却有一道不许旁支跨过的月门；
- 玩家床铺与两个空箱笼挤在旧厢房；
- 桌上放着旁谱副页、未发放的月例签和一面用于认领药匣的木牌；
- 雨声压住远处练武声，先从空间关系解释“有姓无权”。

开场不得一次介绍全部沈家人物。玩家先认识沈福、门房和“内宅规矩”即可。

### 6.4 初始随身物

| 物件 | 类型 | 用途 |
| --- | --- | --- |
| 世家旁支腰牌 | 关键物 | 允许从外院正门出入；不能进入内宅、账房和药库 |
| 《沈氏入门拳》抄页 | 武学线索 | 只开放研习入口，不直接视为已经学会或携带 |
| 银两二两 | 资源 | 可在开场购买干粮、油纸或保留到沈家生活 |
| 沈家取匣木牌 | 任务物 | 用于认领破庙中的封蜡药匣；无法作为普通沈家通行凭证 |

数值在实现前应与现有经济再校准，但相对关系固定：三种出身中银钱最多、食物不额外赠送、自由度最低。

### 6.5 开场任务：雨夜取匣

沈福告诉玩家：

> 沈家采药伙计把一只药匣藏在东郊破庙。天亮前带回来，匣封不能破，人也不必多问。

实际任务结构：

1. **领命**
   - 立刻接下：沈福认为玩家懂规矩；
   - 追问药匣用途：得到内宅正在催药的见闻，但沈福戒心略升；
   - 检查差事签：发现签发时辰比沈福所说早一个时辰。
2. **准备**
   - 买干粮：消耗银钱，降低破庙饥饿压力；
   - 买油纸：保护药匣，暴雨中不会受潮；
   - 直接上路：保留银钱，但到达时寒冷和药匣风险更高。
3. **抵达破庙**
   - 药匣不在沈福所说的旧神龛下，而在无像供桌后；
   - 封蜡有被烘热后重新按合的痕迹；
   - 玩家可以保持原状、只查封蜡、或冒险打开；
   - 冒险打开不会提前揭露曹青全部秘密，只得到药味异常和一张缺角药签。

任务不要求玩家立刻判断沈福善恶。它只建立“沈家差事的表面说法与实际情况并不完全一致”。

### 6.6 破庙中的独特反馈

- `[世家旁支]`认出暗墙砖缝使用了沈家田庄常见的青灰；
- 能看懂沈字铜钱不是钱，而是老太爷一代留下的偿诺信物；
- 青衣妇人看见腰牌后会问“沈家什么时候连孩子也派出来做夜差”；
- 玩家可以隐瞒旁支身份、承认差事或反问她为何知道沈家；
- 承认身份不会令青衣妇人立刻透露自己是谁。

### 6.7 龙青鱼事件中的独特作用

出身选项不直接加好感，而是改变谈话角度：

- 从宗族名分理解她对陆连山的恨；
- 指出“名字写进家谱，也不代表真被当成一家人”；
- 若玩家此前私拆药匣，龙青鱼能看出封蜡痕迹，并评价玩家并不像一个守规矩的沈家人。

正确使用身份能更早触及她对“名分与旧情”的矛盾；用沈家名头压她则会提高杀意。

### 6.8 汇入沈家丹房

获得《鱼跃龙门诀》后，玩家沿紫金河回府，在时限内交还药匣。

回府结果：

| 药匣状态 | 沈福反应 | 长期状态 |
| --- | --- | --- |
| 完好、未拆 | 认为玩家可用 | 外院通行稳定，保留二两银剩余部分 |
| 查封但未拆 | 知道玩家多心 | 获得“药匣被动过”见闻，沈福戒心增加 |
| 已拆且如实交代 | 责罚但暂不逐出 | 知道缺角药签，失去一部分旁支便利 |
| 已拆并掩饰 | 当下可能蒙混 | 后续曹青或沈福能凭封蜡识破，形成延迟风险 |

之后进入“旁支试用”：

- 护院：基础武学未入门；
- 账房：悟性或算术不足；
- 庄务：根骨不足；
- 内宅跑腿：旁支身份敏感，不予安排。

玩家不是“无人可用”，而是“身份尴尬、能力不足，放在哪里都麻烦”。沈福最终把他塞给无人愿意接近的曹青丹房。

### 6.9 第一章个人悬念

**谁提前动过药匣？**

回响节点：

- 曹青取血时闻出药匣里的药味；
- 沈家密会时，缺角药签可对应某一批内宅药材；
- 沈福送钱时，玩家能发现封银手法与药匣封蜡来自同一名账房；
- 曹青离场后，药匣旧事可以成为判断沈福是否说谎的一项证据。

这个悬念提供沈家内部视角，不提前替玩家证明沈福或曹青有罪。

## 7. 出身二：市井子弟

### 7.1 玩家幻想

> 你没有能替你开门的姓氏，却知道哪扇门在什么时候不落闩。金陵不记得你的名字，你却认得这座城的脾气。

这是“活在局外”的开场。玩家缺少正式权限，但拥有最灵活的路线和底层联系。

### 7.2 身份事实

- 陈司命在金陵外城长大，靠搬货、传话、替摊贩看夜维生；
- 是否为孤儿不作硬性规定，界面只说明眼下独自生活；
- 玩家知道鱼市、码头、脚店和小贩之间的规矩；
- 玩家听过漕帮与金龙会的名字，但只知道它们控制不同水路生计；
- 玩家尚未见过龙青鱼、陆连山、沈福和曹青；
- 王五可以在开场作为“不知姓名的老渔人”短暂出现，但不得提前展示其杆法和后续奇遇。

### 7.3 开场地点

**秦淮外港·鱼市尾巷**

场景应表现：

- 收摊后的湿石路、盖着草帘的鱼筐和远处船灯；
- 玩家能从摊位、脚店和河埠三个热点认识市井生活；
- 不一次罗列帮会设定，通过摊贩交保护钱、船夫避开某面旗解释水路权力；
- 一名鱼市牙人正在找愿意冒雨跑东郊的人。

### 7.4 初始随身物

| 物件 | 类型 | 用途 |
| --- | --- | --- |
| 旧火镰 | 工具 | 破庙救火的稳定工具，减少一次环境代价 |
| 粗粮两份 | 消耗品 | 缓解饥饿，也可分给人物或留作赶路 |
| 银两二百文 | 资源 | 可补给、议价或保留 |
| 红绳样结 | 任务物 | 牙人给出的认物凭据，证明玩家接过差事但不能进入沈家 |

三种出身中，市井子弟资源最灵活、正式权限最低。

### 7.5 开场任务：红绳油布包

鱼市牙人提出：

> 东郊破庙东北墙后有一只系红绳的油布包。寅时前取回来，里面是什么与你无关。

任务结构：

1. **谈价**
   - 直接接受：保留牙人基本信任；
   - 追问为何不派熟人：发现前一个跑腿人没有回来；
   - 要求先付一半：通过市井见闻判断牙人急于拿到东西，得到四百文定钱；
   - 假装拒绝后观察：发现牙人身后有人带着沈家货门木签。
2. **选路**
   - 官道：稳妥但耗时；
   - 河堤小路：更快，可能受寒；
   - 货船尾舱：需支付人情或银钱，抵达状态最好；
   - 选路只改变到达状态，不得让玩家在序章永久错过破庙。
3. **取包**
   - 玩家凭市井经验认出新灰、旧砖与墙后空响；
   - 油布包内有沈字铜钱和一张折角货签；东郊残图仍来自独立的“旅人遗物”奇遇；
   - 玩家可以按约交货、藏下铜钱、以别物替换或先查明牙人来路；
   - 设局需要在开场至少发现两项疑点，避免无依据的万能欺骗。

### 7.6 破庙中的独特反馈

- 旧火镰让救火更快，玩家能把节省的时间用于检查暗墙或门外脚印；
- `[市井]`认出墙角不是香客记号，而是跑腿人标记“东西已到、收货未至”；
- 能从青衣妇人的口音、用词和看门方式判断她熟悉水路；
- 能看出她的衣料昂贵，却故意没有佩戴能说明身份的首饰；
- 不能因此直接知道她是漕帮帮主夫人。

### 7.7 龙青鱼事件中的独特作用

- 玩家可以用码头上的旧夫妻、合伙与分账比喻理解她的处境；
- 可以指出“水路上的规矩只认旗号，不认当年是谁陪谁撑船”；
- 若此前收了牙人定钱，龙青鱼会闻到钱袋上的鱼油味，问玩家是不是替人取东西；
- 玩家可向她打听沈家货门木签，但她只会提供判断，不替玩家解决任务。

### 7.8 汇入沈家丹房

市井子弟不使用“所有普通差事都不合格”的完全相同路径。

根据油布包处置，进入沈家的方式不同：

| 处置 | 入门方式 | 初始后果 |
| --- | --- | --- |
| 如约交货 | 牙人给出沈家货门口信 | 得到报酬，牙人知道玩家见过铜钱 |
| 留下铜钱 | 直接持铜钱叩侧门 | 失去牙人信任，但掌握更独立的沈家入口 |
| 替换后交货 | 暂时获得两条门路 | 后续牙人识破时提高追查风险 |
| 查明后拒交 | 凭证据向沈福说明 | 沈福戒心较低，鱼市渠道关闭 |

进入沈家后：

- 市井经验使玩家具备跑腿价值，但身法仍不足以独立承担远差；
- 沈福先让玩家把一批药材送到丹房；
- 曹青发现玩家接触过油布包、暗墙或异常药味，提出取血条件；
- 玩家由一次送药差事被曹青留下，汇入共同丹房主线。

### 7.9 第一章个人悬念

**鱼市牙人替谁寻找沈字铜钱？**

回响节点：

- 沈家密会中，玩家能认出某名伙计使用相同货门木签；
- 沈福给银时，牙人可能再次索要分成或要求玩家传话；
- 紫金河钓鱼时，王五会提到有人沿河打听红绳油布包；
- 沈福反目篇中，鱼市渠道可以成为替代联系人，也可能把玩家行踪卖给毒蛇帮。

这个悬念把市井优势转化为长期联系人与暴露风险。

## 8. 出身三：身世成谜

### 8.1 玩家幻想

> 你记得自己的名字，却想不起是谁替你取的。怀里的半块玉佩尚有余温，血书上的人名却像在等你送命。

这是“被过去追赶”的开场，也是当前已实现路线的连续性基准。

### 8.2 身份事实

- 陈司命十六岁；
- 十六岁以前的记忆支离破碎；
- 知道自己的姓名，不知道父母、籍贯和师承；
- 半块玉佩应当属于自己，但没有可核对的家族标记；
- 血书指向金龙会万鲤堂孙不离，真假未知；
- 玩家不知道是谁把自己带到破庙，也不知道是否有人正在寻找自己。

### 8.3 开场地点

**金陵东郊·无名破庙**

沿用当前已经确认的五比四场景构图：

- 将熄余火；
- 无像供桌和新鲜山桃；
- 新砌暗墙；
- 漏雨庙门；
- 玩家醒来的位置。

### 8.4 初始随身物

| 物件 | 类型 | 用途 |
| --- | --- | --- |
| 半块家传玉佩 | 关键物 | 触发身世残忆与特定人物反应，不再独占三点重分 |
| 血书 | 关键物 | 指向金龙会万鲤堂孙不离，可靠性未知 |
| 旧衣 | 装备 | 仅提供最低防寒，不含额外战斗优势 |
| 银两零 | 资源 | 必须依靠破庙所得解决最初生存 |

### 8.5 开场任务：活过今夜

沿用并强化当前三个环境行动：

1. 扒开炭灰寻找火种；
2. 检查身上还能证明什么；
3. 吃山桃或保留食物。

三项完成后才发现暗墙异常并觉醒“逆天改命”。

顺序产生真实影响：

- 先救火：降低失温，错过观察门外短暂脚印；
- 先查身：得到玉佩与血书，但火势继续下降；
- 先食桃：恢复饥饿，山桃减少；
- 迟迟不救火：需要消耗更多旧布或干粮才能恢复火势。

### 8.6 破庙中的独特反馈

- `[残忆]`让玉佩在靠近暗墙时发热；
- 血书封蜡与沈字铜钱的缺口存在相似形状，但只能形成推测；
- 玩家偶尔想起水声、鱼鳞铜签或一句没有说完的称呼；
- 任何残忆第一次出现时只给一个感官片段，不直接宣布人物、势力和结论。

### 8.7 龙青鱼事件中的独特作用

- 龙青鱼会注意到玉佩，却不能立刻确认来历；
- 玩家说出血书上的“金龙”时，她的反应证明这不是无意义的假名，但不会替玩家确证血书；
- `[残忆]`可以察觉她听到孙不离时短暂停顿；
- 直接把血书交给陌生人会提高她对玩家轻信和求死倾向的判断，不是免费答案。

### 8.8 汇入沈家丹房

沿用现有主线：

1. 取得沈字铜钱；
2. 获得《鱼跃龙门诀》后沿紫金河及时抵达；
3. 铜钱只换来一顿饭和一次谋差机会；
4. 四种普通差事均不合门槛；
5. 沈福把玩家送到曹青丹房；
6. 曹青对玩家的血、玉佩和求生反应产生兴趣。

### 8.9 第一章个人悬念

**血书究竟写给谁？**

回响节点：

- 曹青取血时发现玩家血液或体质存在值得利用之处，但不得直接确证家族；
- 沈家密会揭示金龙会四堂后，玩家能把“孙不离”放入更清晰的势力位置；
- 龙青鱼的临安入口可以验证血书的一部分，却可能令追查者知道玩家仍活着；
- 沈福反目篇中，钱匣水路痕迹可能与血书封蜡形成交叉证据。

## 9. 共同破庙局面的差异化

### 9.1 到达状态

| 状态 | 世家旁支 | 市井子弟 | 身世成谜 |
| --- | --- | --- | --- |
| 时间 | 子时末至丑时初 | 丑时前后 | 已在庙中，不知何时到达 |
| 火势 | 手提灯将熄，庙火近灭 | 有火镰，庙火近灭 | 余火将熄 |
| 饥饿 | 由是否买干粮决定 | 有两份粗粮 | 初始饥饿 |
| 任务物 | 封蜡药匣 | 红绳油布包 | 玉佩与血书 |
| 门外风险 | 时限与药匣受潮 | 雇主与可能的尾随 | 狼、失温与身份未知 |

### 9.2 固定奇遇兼容

三项固定奇遇仍属于地点，不属于某个出身：

| 奇遇 | 三出身共同规则 | 出身差异 |
| --- | --- | --- |
| 旅人遗物 | 正确处理将熄火种 | 沈氏认得行囊缝法；市井知道残图价格；残忆可能认得一段路线 |
| 沈氏承诺 | 发现并打开东北暗墙 | 沈氏理解旧诺；市井更快看出新灰；残忆由玉佩察觉异常 |
| 神秘贡品 | 只记录初一或十五条件 | 三出身都不能在开场提前领取 |

任何出身都能取得沈字铜钱，但它的用途不同：

- 世家旁支：证据与家族旧事，不是进入沈家的必需品；
- 市井子弟：可以换成独立入口，也可以完成雇佣；
- 身世成谜：进入沈家的主要凭证。

### 9.3 青衣妇人揭示规则

无论出身如何：

- 入庙时只显示“青衣妇人”；
- 不显示龙青鱼、漕帮帮主夫人或陆连山；
- 她没有受伤，也没有追兵；
- 身份在夜话接近结束时才揭示；
- 出身只能让玩家看懂她的某一部分，不得提前完成整个人物谜题。

## 10. 沈家与丹房长期回响

### 10.1 初入沈家

| 局面 | 世家旁支 | 市井子弟 | 身世成谜 |
| --- | --- | --- | --- |
| 进入方式 | 旁支腰牌、回府复命 | 货门口信或沈字铜钱 | 沈字铜钱 |
| 沈福最初定义 | 可用但麻烦的族人 | 可替换的跑腿 | 来历不明的机会 |
| 曹青最初兴趣 | 沈家血脉与药匣 | 市井经历与油布包 | 玉佩、血书与身体 |
| 地点权限 | 外院正门、西偏院 | 货门、厨房外廊 | 侧门、临时住处 |
| 主要风险 | 家法、名声、被内宅调用 | 无担保、联系人出卖 | 身份追查、物件暴露 |

### 10.2 曹青取血

三种出身都面对同一残酷事实：曹青强取一碗血后才允许继续留下。

差异只影响玩家理解和后续依据：

- 世家旁支可以指出曹青无权按家法规矩取旁支血，但曹青根本不受这套规矩约束；
- 市井子弟能判断门外没有人会为一个跑腿出头，可预先藏物或留口信；
- 身世成谜能从曹青对血液的反应判断，他关心的并非普通药性。

任何出身反抗或拒绝仍可能死亡，不能把身份标签做成免死金牌。

### 10.3 炼丹三问与悟性重分

三种出身都能使用公共三点属性完成悟性重分，不再要求持有半块家传玉佩。

出身提供不同的补充观察：

- 世家旁支：认识沈家药材封签与内宅用药等级；
- 市井子弟：知道不同药材在鱼市和药铺的真假价格；
- 身世成谜：能把某种药味与血书或残忆联系起来。

三道盘问的正确答案、死亡风险和固定奖励保持一致。

### 10.4 沈家密会与沈福银钱

- 世家旁支更早理解座次、称谓和谁有权发言，但也更难假装局外人；
- 市井子弟能看出货物与银钱如何经过伙计、船夫和货门流动；
- 身世成谜更容易把金龙会四堂与血书人名对应；
- 收下沈福银钱后，三种出身都必须决定是否向曹青如实交代；
- 后续钱匣、毒蛇帮水路与沈福反目继续读取出身联系人和开场悬念。

## 11. 出身个人事件

每种出身在第一大章安排一个十至十五分钟的短事件，不另建长篇主线。

### 11.1 世家旁支：旁谱缺名

触发：进入沈家密会后。

局面：

- 玩家在旁谱副页上看见自己的父辈名字被重新描过；
- 原本应记录母系来处的位置被刮去；
- 沈福声称只是旧谱受潮；
- 玩家可查账房、问老门房、向曹青交换信息或暂时不追。

结果不是立即揭晓身世，而是决定沈家把玩家视为族人、工具还是潜在争产者。

### 11.2 市井子弟：鱼市催信

触发：第一次从沈家回到紫金河或鱼市。

局面：

- 牙人要求玩家交代油布包或铜钱去向；
- 有人沿河询问玩家夜里去了哪里；
- 不知名老渔人提醒玩家，问路者看的是脚印，不是货物。

玩家可还钱断线、继续合作、反查雇主或用沈家身份压住牙人。结果改变后续鱼市联系人、银钱渠道和毒蛇帮追踪。

### 11.3 身世成谜：血书旧字

触发：沈家密会揭示金龙会四堂后。

局面：

- 玩家终于能确认血书中的一个堂口名；
- 血书笔迹与内容并非同一时间写成；
- 有一行像是后来补给“陈司命”看的；
- 龙青鱼、曹青和沈福会从不同立场解释这件事。

玩家可暂信其中一人、继续保密或故意放出假线索。结果改变谁知道血书存在及追查从哪里开始。

## 12. 玩家界面

### 12.1 选择界面

出身选择使用全屏横板界面：

- 选择出身时不显示尚未完成的主角立绘；
- 顶部固定显示“出身／容貌／天赋／属性”四步进度，出身页只点亮“出身”；进入容貌页后，出身标记为完成并点亮“容貌”；
- 标题固定为“你从何处踏入江湖？”，不再追加世界观说明或系统解释；
- 三张卡只使用出身所代表的生活地点与普通人物活动，不出现预设主角脸；
- 卡片横向并列，场景图在上、名称和完整经历描述在下；手机横屏仍完整显示三张且保留描述；
- 默认选中“市井子弟”，选中态使用深青说明底、暖金边框和菱形标记，另外两张保持雾白底与墨色文字；
- 底部只保留居中的“选定出身”，姓名不在本页填写；
- 页面使用雾白、青灰、墨色、少量暖金与深青，禁止回到满屏雨夜、纯黑底、脏污遮罩和发光网格；
- 不显示“车卡、旧债、构筑、难度、推荐、主线、测试”等产品语言；
- 不直接展示未来奖励和完整后果；
- 不列初始物品、未来任务、“今夜身在”或隐藏风声；世界介绍继续放在选择前一页。

目标人物建立顺序：

> 出身 → 容貌（含命名） → 天赋 → 属性 → 入世 → 在破庙死局中首次看见命格

容貌页的交互依据见[《鬼谷八荒》创建角色与捏人系统拆解](../TALE_OF_IMMORTAL_CHARACTER_CREATION_REFERENCE.md)，运行时插槽、遮罩、资源制作和组合验收以[容貌纸娃娃与美术生产管线](12_APPEARANCE_RIG.md)为准。现行版本采用“人物居中、十一类离散部件环绕、左右切换、即时反馈和整组随机”，不采用魅力分数、部件属性加成、连续滑杆或无限刷新开局气运。

出身页与容貌页的现行纵切已经完成。当前容貌页支持姓名、男身／女身、十一类外观状态和一键更换组合；选择写入存档并在继续旅程时恢复。人物预览从同一完整人物母版派生衣服和头部变体，再由固定画布、稳定插槽和 Canvas 合成；当前只有衣服和头饰拥有两个已验收选项，其余类别只有默认项。新旅程十一项全部从编号“1”开始，装备与人物外观解除绑定，服装只由容貌状态决定。天赋与独立属性页尚未实现，“确认容貌”暂时继续承接现有初心与开场纵切。选择出身时不得用预设主角形象代替。命格不是人物建立页上的可选背景或预先说明，而应等到玩家亲手撞见暗墙阻碍后在剧情中显现。

### 12.2 容貌页

- 姓名只在容貌页填写，最长八个字符，任何外部输入都经`escapeHtml()`进入界面；
- 体貌只描述人物外观，不产生属性、境界、战斗或关系优劣；
- 外观维度固定为帽子、前发、后发、眼睛、眉毛、嘴巴、鼻子、脸型、脸饰、后背、衣服，不继续增加妆容、瞳色、身高、体重或局部比例；
- 十一类部件采用顶部帽子、左侧五项、右侧五项的固定结构；左右对应行等宽、等高、等距并镜像对齐，每项只显示名称、序号和上一套／下一套，不打开二级目录，不同时铺开几十个缩略格；
- 男身／女身使用两个明确按钮；除姓名外不增加滑杆、色盘或数值输入；
- 所有部件都是纯外观选择，不建立隐藏魅力数值，也不改变属性、战斗或关系；
- 前发与后发分开选择，首批不出现夸张长辫子；帽子、脸饰和后背都允许选择“无”；
- 衣服切换后立即更新中央完整人物预览；
- 装备不改变角色外观。衣甲、冠帽、护腕、佩饰和兵器只在装备界面显示图标与详情，并继续提供数值、动作、身份和叙事权限；
- 桌面与手机横屏以人物居中、部件环绕为主；手机竖屏改为人物预览在上、十一项紧凑列表在下，不强行保持环绕布局；
- 人物预览不得使用含完整五官、发型与服装的单张角色立绘；运行时由男／女固定母版附件、当前脸型、五官、前后发、衣服与装饰按稳定插槽解析，再由Canvas一次合成；新旅程十一项初始值全部为“1”，切换一项只替换对应附件；
- 出身完成状态、当前容貌步骤、未完成天赋与属性不能只靠颜色，进度节点同时使用勾记与文字。

#### 组件美术生产规范

- 正式画布统一为`1024×1536`透明WebP，人物中轴`x=512`、脚底线`y=1460`；附件保留完整画布，禁止trim、自动居中和逐图缩放；
- 运行时固定使用后背、后发、帽后、身体、衣服、脸型、眼睛、眉毛、鼻子、嘴巴、前发、脸饰和帽前插槽；跨层部件必须提供多个附件，不得靠DOM顺序碰运气；
- 帽子必须同时声明帽前附件和头发遮罩；遮罩只裁掉被帽冠包住的前后发，不得擦除脸、衣服或帽子；
- 不允许为某个编号增加`top`、`left`、`scale`或`clip-path`特例。结构不对时返回母版、插槽或遮罩修正；
- AI图像只可作为完整母版候选，不能把多张独立生成图直接当作运行时组件；所有附件必须在共同母版上重绘、拆分并经过组合验收；
- 当前只开放双体貌、两套同源衣服和无头饰／旧布额巾；其它外观类别暂时只有从完整母版确定的默认项。八种正式组合见[容貌组合矩阵 v2](../assets/appearance-rig-v2-matrix.webp)，旧版九十六格错位资源已经撤回；
- 可重复生成与校验脚本为`scripts/build-appearance-rig-v2.py`，完整契约、成熟方案取舍和扩充条件见[容貌纸娃娃与美术生产管线](12_APPEARANCE_RIG.md)。

### 12.3 卡片文案

#### 世家旁支

> 你生在世家旁支。小时候读过书，也跟族中教习练过几手拳脚。只是家里的田产一年少过一年，到了十六岁，该轮到你自己找出路了。

#### 市井子弟

> 你在金陵外城长大，给鱼贩看过摊，也跟码头伙计搬过货。你认得几条省脚程的小路，也知道城里哪些人不能轻易招惹。

#### 身世成谜

> 十六岁以前的事，你只记得零碎几段。偶尔见到某些笔迹、听见某些名字，会觉得自己以前遇见过。除此之外，没人能说清你的来历。

### 12.4 剧情内标识

与出身相关的选项直接标识：

- `[世家旁支] 查验封蜡上的家印`
- `[市井] 沿鱼市脚夫留下的记号找后门`
- `[残忆] 让玉佩靠近墙缝`

不可用时保留选项并置灰，在同一行说明缺少的不是抽象出身ID，而是玩家未取得的实际依据。

例：

> `[世家旁支] 要求查看内宅药册`
>
> 不可用：你的腰牌只准进入外院。

## 15. 验收与测试

### 15.1 规则测试

每种出身必须验证：

- 初始物品只领取一次；
- 初始银钱与任务物正确；
- 三点属性总量一致；
- 经历标签不直接修改五维；
- 序章失败仍能进入破庙；
- 至少一种选择改变关系、权限、见闻或资源；
- 共同固定奇遇不会重复领取；
- 龙青鱼身份不会提前显示；
- 可以获得鱼跃龙门诀并进入沈家；
- 三种路径都能抵达曹青取血；
- 出身专属见闻不会在其他出身中凭空出现。

### 15.2 浏览器流程

浏览器回归覆盖三条完整冒烟流程：

1. 世家旁支：西偏院领命 → 药匣状态 → 破庙 → 夜话 → 回府 → 旁支试用 → 丹房；
2. 市井子弟：鱼市谈价 → 选路 → 油布包处置 → 破庙 → 夜话 → 货门／铜钱 → 丹房；
3. 身世成谜：冷醒 → 三项生存行动 → 暗墙 → 夜话 → 铜钱 → 丹房。

共同检查：

- 1672×941、1280×720、844×390与390×844无横向溢出；
- 横屏三张出身卡首屏可辨；
- 未完成容貌前不显示人物形象；
