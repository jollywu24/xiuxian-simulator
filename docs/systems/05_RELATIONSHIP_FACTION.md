# SYS-05 人物关系、势力与身份系统

## 1. 系统目标

让人物因玩家长期行为改变身份和立场，而不是达到好感门槛后交出奖励。系统需要表达喜欢但不信任、欠命但仍会利用、害怕却不愿背叛势力等复杂关系。

## 2. 当前基础与缺口

已有：

- 龙青鱼、曹青、王五好感；
- 莫逆之交等关系称谓；
- 沈福联系人；
- 选择日志和部分提前收束；
- 身份延迟揭示。

缺口：

- 单一好感无法解释曹青的危险性；
- 没有救命债、利益、恐惧、把柄和忠诚；
- NPC不知道玩家做过什么，只看最终数值；
- 关系阶段不能因事件反转；
- 沈家、漕帮、毒蛇帮和官府没有系统状态；
- 通行权限、监视、通缉和假身份没有统一规则。

## 3. 人物关系维度

```js
{
  npcId: "bai_zhiyun",
  favor: 0,
  trust: 0,
  fear: 0,
  debtToPlayer: 0,
  playerDebt: 0,
  leverage: 0,
  suspicion: 0,
  bond: "stranger",
  knownFacts: [],
  witnessedActs: [],
  promises: []
}
```

各维度职责：

| 维度 | 决定内容 |
| --- | --- |
| 好感 | 愿不愿亲近、宽容或主动帮助 |
| 信任 | 是否相信说法、交出秘密或托付任务 |
| 恐惧 | 是否服从、逃避、先下手或求援 |
| 救命／利益债 | 是否必须回报，以及回报边界 |
| 玩家债务 | NPC可以合理要求什么 |
| 把柄 | 是否能胁迫，但会损害信任 |
| 怀疑 | 是否监视、试探、封锁权限 |

任何奖励条件最多读取三项关键维度，避免把关系做成不可理解的公式。

## 4. 关系阶段

关系阶段不是由好感单独计算，而由事件结果确认：

```text
陌生 → 认识 → 可往来 → 同盟／师徒／知己
                ↘ 利用关系
                ↘ 敌对
                ↘ 被迫合作
```

关系可以并存标签，例如：`师徒＋互相隐瞒`、`救命恩人＋政治风险`。

## 5. 人物记忆

NPC必须记住影响其判断的行为：

- 是否说过实话；
- 是否守约；
- 是否在危险时留下；
- 是否独吞利益；
- 是否杀死其亲友或帮众；
- 是否泄露秘密；
- 是否使用胁迫；
- 是否在对方不知情时帮助。

记忆条目带来源、日期、是否亲见和是否被证伪。NPC不应凭空知道玩家私下行动。

## 6. 秘密与身份揭示

秘密采用阶段：

- 未知；
- 怀疑；
- 被告知；
- 亲眼确认；
- 可公开使用；
- 已泄露。

例子：

- 龙青鱼身份在夜话结束前不得显示；
- 曹青本名和药王谷旧账可被命格看见，但直接说出会提高怀疑；
- 白栀云练功病因需要医术和信任共同打开；
- 黑衣人身份需要多条证据，不由单次好感揭示。

## 7. 人物多重身份

每名核心NPC至少有三种剧情位置：

| 人物 | 可能身份变化 |
| --- | --- |
| 龙青鱼 | 危险陌生人 → 知己 → 漕帮权力人物／潜在冲突方 |
| 曹青 | 取血者 → 传授者 → 师父 → 可能牺牲弟子的自保者 |
| 白栀云 | 病危者 → 欠命者 → 传武者 → 沈家秘密操盘者 |
| 沈福 | 管事 → 联系人 → 利益同盟 → 威胁者／死敌／受控证人 |
| 燕惊鸿 | 神捕 → 病人 → 官面同盟 → 必须依法审视主角的人 |
| 王五 | 普通渔翁 → 传功者 → 水路联系人 → 被主角名声波及的人 |

交出线索或武学后，人物仍应保留欲望、风险和未来选择。

## 8. 势力模型

```js
{
  factionId: "shen_family",
  standing: 0,
  suspicion: 0,
  alarm: 0,
  access: ["outer_court"],
  knownIdentity: "cao_apprentice",
  warrants: [],
  debts: []
}
```

关键维度：

- 声望：成员普遍态度；
- 怀疑：是否调查主角；
- 警戒：地点和行动难度；
- 权限：可以进入哪里、接触谁；
- 身份：势力如何定义主角；
- 通缉／追杀：公开或秘密敌对；
- 债务：势力承诺与玩家义务。

## 9. 宗门食物链式身份

在大曜江湖中，成长也表现为势力如何定义陈司命：

1. 无名外人；
2. 沈家旧诺带来的无用少年；
3. 曹青药童；
4. 曹青对外联络人；
5. 曹青弟子／白栀云救命恩人；
6. 值得监视的年轻武者；
7. 官面可用之人；
8. 能影响帮会计划的危险变量。

身份越高，权限越多，也越容易进入强者视野。

## 10. P0白栀云关系闭环

至少产生四种结果：

- 救活且保守秘密：信任和救命债高；
- 救活但索取过度：救命债高、信任低；
- 只稳定病情：可以往来，但后续仍需治疗；
- 失败或错过：沈家关系改变，白栀云路线关闭或转为遗留债务。

“以身相许”改写为报恩试探、亲近压力和沈家政治关系，不以成人奖励结算。

存档版本5让夜袭后手第一次读取关系维度：把鱼鳞铜签与暗语交给白栀云会增加信任与人情债，但放弃利用敌人渠道；伪报和设局不会自动增加她的关系值，因为她并未亲眼看见玩家私下做过什么。

## 11. P1沈福与燕惊鸿

沈福：

- 贪念、恐惧和把柄逐步增长；
- 主角可收买、警告、揭发、控制、放走或杀死；
- 每种处理改变沈家渠道和后续证人状态；
- 不能突然强制进入唯一杀人结局。

燕惊鸿：

- 好感不等于信任；
- 医治建立私人债，神捕职责建立官面压力；
- 主角若使用毒术或隐藏尸体，她会根据证据而非好感反应；
- 她可以帮助主角，也可以依法限制主角。

## 12. P2势力与身份

- 毒蛇帮警戒和清剿；
- 漕帮卧底身份、口令和暴露度；
- 归墟秘密组织成员资格；
- 人榜和打虎名声；
- 崔大人官面审视；
- 七杀刀带来的沈家内部立场；
- 公开英雄、危险毒师或隐秘医者等不同社会身份。

## 13. 建议纯规则接口

```js
getRelationship(npcId, state)
changeRelationship(npcId, changes, reason, state)
recordNpcMemory(npcId, memory, state)
canRevealSecret(secretId, npcId, state)
revealSecret(secretId, method, state)
getFactionState(factionId, state)
changeFactionState(factionId, changes, reason, state)
getAccess(locationId, identityId, state)
resolvePromise(promiseId, outcome, state)
getNpcResponse(npcId, actionContext, state)
```

## 14. UI要求

- 不向玩家展示所有关系数值；
- 只显示可被人物行为感知的称谓、态度和关键债务；
- 重大变化用“他开始相信你”“沈家已派人盯梢”等世界内反馈；
- 人物卡记录共同经历、承诺和已知秘密；
- 势力卡显示权限、公开身份和警戒，不显示隐藏脚本；
- 同一人物在不同身份下使用一致头像或视觉标记，避免像新NPC。

## 15. 测试矩阵

- 高好感低信任不能交出核心秘密；
- 救命债不会自动转化为爱情；
- NPC只根据亲见或被告知事实反应；
- 泄密会同时改变人物和势力状态；
- 沈福死亡后所有依赖其本人的渠道关闭；
- 燕惊鸿不会因好感忽略明确罪证；
- 回照恢复关系状态，但玩家保留上一世记忆；
- 旧存档好感正确迁移到新结构。

## 16. 完成标准

P0完成要求白栀云和曹青各自能在相同好感下因信任、债务、怀疑不同给出不同选择；P1完成要求沈福的至少三种长期结局会真实改变沈家渠道。
