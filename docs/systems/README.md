## 当前唯一施工焦点

下一阶段不并行建设完整经济、势力、日程或新战斗系统。先完成第五十五至六十八章“曹青离场—沈福反目—七杀秘密”：用一个局面盒同时验证人物权限、沈家身份、不义之财、联系人生命周期、分段追踪、至少三种沈福长期结局和章末江湖留痕。任何新增通用结构都必须在该闭环的下一场景产生可见差异。

系统文档共同遵守：

- `AGENTS.md`的纯高武、单人叙事边界；
- `STORY_BIBLE.md`的剧情顺序和揭示规则；
- `GAME_DESIGN.md`的玩家体验与界面规则；
- `SYSTEM_ROADMAP.md`的依赖和优先级。

具体实现与文档冲突时，先确认剧情基线是否变化，再同步修改规则、状态、测试和文档。
