M4第一条闭环和SYS-09纵切已经完成，不并行建设完整经济或全NPC日程。人物页、装备状态、双方判定、伤害反馈和存档迁移已经以雨巷与王卓战接通。当前剧情生产继续把M4已经验证的人物权限、身份、联系人、证据传播和地点状态带入M5“戒严金陵”。任何新增通用结构都必须在当前局面的下一场景产生可见差异。
