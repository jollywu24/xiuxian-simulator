## 当前施工焦点

M4第一条闭环、SYS-02完整武学纵切、SYS-09装备战斗纵切和SYS-11三出身／容貌入场均已完成，不并行建设完整经济或全NPC日程。人物页、武学页、装备状态、双方判定、伤害反馈和存档迁移已经以雨巷与王卓战接通；三种开场也已在曹青取血前稳定汇流。人物建立下一步只补天赋与独立属性页；剧情继续把现有出身联系人、暴露、身份权限，以及M4已经验证的证据传播和地点状态带入M5“戒严金陵”。任何新增通用结构都必须在当前局面的下一场景产生可见差异。

系统文档共同遵守：

- `AGENTS.md`的纯高武、单人叙事边界；
- `STORY_BIBLE.md`的剧情顺序和揭示规则；
- `GAME_DESIGN.md`的玩家体验与界面规则；
- `SYSTEM_ROADMAP.md`的依赖和优先级。

具体实现与文档冲突时，先确认剧情基线是否变化，再同步修改规则、状态、测试和文档。

工程流程不写入单个系统规格：自动化测试见[`docs/TESTING.md`](../TESTING.md)，调试协议见[`docs/DEBUGGING.md`](../DEBUGGING.md)，发布与线上冒烟见[`docs/RELEASE.md`](../RELEASE.md)。
