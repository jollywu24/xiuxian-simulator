# SYS-09 装备系统与统一战斗公式

## 1. 文档状态

状态：**第一阶段已完整接入运行时（2026-07-24）**。

当前事实来源为`web/character-system.mjs`、`web/martial-system.mjs`、`web/combat-engine.mjs`与`web/combat-encounters.mjs`。人物五维、境界、当前携带武学、装备、伤势、敌方防御和减伤已经进入同一套判定；装备栏与当前气血／真气从版本6起保存，版本7新增完整武学状态，版本8增加出身状态，当前版本9继续保留这些字段并新增人物容貌状态。人物页的装备操作必须经过详情提示确认。旧的分档伤害字段仍作为非武器效果与剧情兼容数据保留，但凡标记`formulaDamage`的招式只由本文公式决定实际伤害。

2026-08-03新增目标决定：装备不再改变人物外观，服装改由容貌状态独立控制。下文标明的纸娃娃透明层是当前版本的已发布旧实现，不再是后续目标；在状态迁移和人物页解耦完成前，必须继续区分“当前能玩”与“目标规则”。战斗公式、装备数值、动作、身份和叙事权限不受此决定影响。

本次统一只引入四个玩家必须理解的战斗量：

| 名称 | 回答的问题 | 主要来源 |
| --- | --- | --- |
| 伤害 | 打中后可能扣多少气血 | 武器、招式、威力属性、境界 |
| 防御 | 对方是否容易打中你 | 身法、招架／闪避姿态、遮挡、条件装备 |
| 减伤 | 打中后少扣多少气血 | 衣甲、护腕、临时护体 |
| 气血 | 还能承受多少伤害 | 根骨、境界、伤势 |

一句话规则：

> **防御决定能不能打中，减伤决定打中以后扣多少气血。**

“攻势、守势、防守、护身、远手、贴身／适中／远离”等旧界面词不再作为玩家术语。统一使用“伤害、防御、减伤、近战、远程、近距／中距／远距”。

聚气境以后另外出现两种资源，但它们不进入新的命中公式：

| 资源 | 作用 |
| --- | --- |
| 行动 | 本轮还能做几件事，每轮恢复 |
| 真气 | 还能把招式催动到多深，跨战斗保存 |

玩家界面已经把每轮额度统一称为“三点行动”；“真气”是由内功和境界推导、在战斗间保存的小型资源，两者不再混称。

## 2. 设计目标

### 2.1 必须做到

- 玩家换上一件兵器后，立刻看见伤害区间、适用距离、持握方式和可用招式变化；
- 玩家换上衣甲后，立刻看见减伤变化，并能在下一次受击中看到实际抵扣；
- 属性、境界、武学、装备、伤势、距离和环境进入同一套判定；
- 玩家和敌人使用同一底层公式；
- 一次行动仍只掷一枚固定因果骰，不新增命中骰、伤害骰和暴击骰；
- 聚气境后的真气只强化现有招式、护体和身法，不增加另一套法术战斗；
- 默认按钮仍只显示胜算、依据、结果与风险，详细公式点击后再展开；
- 数值服务叙事选择，不把游戏变成刷装、堆装等或比较战力数字。

### 2.2 不做

- 不复制《博德之门3》的D20、护甲等级、豁免、分级法术位和多层伤害骰；真气只保留一个共享的小型资源池；
- 不做随机词缀、套装、强化加十、洗炼、宝石孔和装备评分；
- 不做普通耐久损耗和战后逐件修理；
- 不让品质颜色直接决定一件物品必然优于另一件；
- 不为斩、刺、钝、毒分别建立一套复杂抗性面板；
- 不用装备替代人物关系、身份、见闻和场景解法。

## 3. 装备栏结构

人物共有九个等大装备位置：

| 分组 | 位置 | 主要职责 |
| --- | --- | --- |
| 护具 | 冠 | 轻量减伤、识破、身份或环境效果 |
| 护具 | 衣 | 主要减伤来源 |
| 护具 | 腕 | 招架、暗器、医术或兵器动作 |
| 护具 | 履 | 换距、追逐、地形适应 |
| 佩饰 | 佩 | 条件、关系、身份、奇遇或少量特殊规则 |
| 兵器 | 近战主手 | 当前近战伤害与主要武器动作 |
| 兵器 | 近战副手 | 副兵器、格挡器具或空手收益 |
| 兵器 | 远程主手 | 弓弩、飞刀袋、针匣等远程手段 |
| 兵器 | 远程副手 | 配套箭囊、暗器准备或副远程器具 |

装备页不是独立的大背包。右侧“装备行囊”是现有二十四格行囊的筛选视图，只显示可以穿戴或装备的物品，数量、容量和银两与行囊系统共用。

### 3.1 主手、副手与远程

- 单持兵器占主手，副手仍可装备轻兵器或器具；
- 双持要求两件允许双持的轻兵器，并由对应武学开放双持动作；
- 双手兵器同时占用主手与副手；
- 远程位置独立保存弓弩、飞刀袋或针匣；
- 战斗外切换已装备兵器不消耗资源；
- 战斗中从近战切到远程，通常消耗一点行动；
- 被贴近、手臂重伤或弹药耗尽时，远程动作会受限或关闭。

### 3.2 空副手也有意义

空着副手不是“少穿一件装备”：

- 部分拳掌、擒拿、点穴和灵巧刀法要求一只手空闲；
- 可开放抓取、攀援、救人或快速使用物品；
- 某些单持兵器在副手为空时获得专属动作；
- 是否空手由招式条件决定，不统一提供数值加成。

### 3.3 穿戴条件

装备条件只从以下类别选择必要项：

- 属性，如力道三；
- 境界，如锻体；
- 武器门类熟练，如刀法入门；
- 身份或关系，如沈家内院腰牌；
- 身体状态，如双臂可用。

不满足条件时仍显示物品和完整说明，但穿戴按钮置灰，并直接写明缺少的条件。

## 4. 兵器数据

每件兵器只保留能改变实际选择的字段：

```js
{
  id: "goosewing_short_saber",
  name: "雁翎短刀",
  quality: "fine",
  slot: "mainHand",
  weaponFamily: "saber",
  grip: "single",
  range: ["near"],
  damage: { min: 3, max: 5 },
  powerAttribute: "strength",
  requirements: [
    { type: "attribute", id: "strength", value: 3 }
  ],
  actions: ["saber_press", "saber_disarm"],
  passives: ["empty_offhand_counter"],
  tags: ["刀", "单持", "灵巧"],
  weight: 0.9,
  price: 1300
}
```

### 4.1 兵器门类

第一批只制作四类：

| 门类 | 主要距离 | 核心差异 |
| --- | --- | --- |
| 拳掌／短兵 | 近距 | 贴近后稳定，容易擒拿、点穴或藏兵 |
| 刀剑 | 近距／中距 | 伤害和招架均衡，武学选择最多 |
| 长兵 | 中距 | 控距、扫击、缠兵；近距受限 |
| 远程／暗器 | 远距 | 先手和追击强；受遮挡、弹药与近身压制 |

第一版每类只需三至四件有明确身份和用途的手工装备，不用大量换皮数值填满格子。

### 4.2 持握方式

| 持握 | 规则 |
| --- | --- |
| 单持 | 占主手；副手可空、可持轻兵器或器具 |
| 双持 | 主副手各一件允许双持的兵器；动作由武学开放 |
| 双手 | 同时占主副手；通常伤害或控距更强 |

持握方式不直接生成通用加成。它只改变可装备位置、动作条件和少数兵器被动。

### 4.3 距离

统一采用三档：

| 距离 | 常见手段 |
| --- | --- |
| 近距 | 拳脚、短刃、擒拿、点穴 |
| 中距 | 刀剑、长兵、飞针和大多数正式交锋 |
| 远距 | 弓弩、追逐、撤离和远程压制 |

兵器距离匹配时正常判定；距离不合时获得不利，完全无法施展时直接关闭动作并说明原因。距离只影响能否使用与有利／不利，不另设命中率乘区。

## 5. 护具与佩饰数据

```js
{
  id: "patched_leather_coat",
  name: "旧皮护衣",
  quality: "common",
  slot: "body",
  reduction: 1,
  conditionalDefense: [],
  passives: ["rain_cold_resist"],
  requirements: [],
  tags: ["衣甲", "轻甲"],
  weight: 2.4,
  price: 420
}
```

### 5.1 减伤

- 衣是稳定减伤的主要来源；
- 冠、腕、履只在物品本身有充分理由时提供一点减伤；
- 多件装备的减伤直接相加；
- 第一阶段常态总减伤控制在 `0～3`；
- 临时护体、掩体或同伴挡招产生“临时减伤”，单独写入本次受击；
- 减伤不能把所有危险磨成零伤害，强招仍可附带推倒、缴械、毒或部位伤。

### 5.2 防御

装备通常不直接增加常驻防御。只有轻便、招架或遮挡特征明确的物品，才提供带条件的防御，例如：

- 轻履：换距后的下一次闪避防御 `+1`；
- 护腕：持刀剑招架时防御 `+1`；
- 斗笠：远程攻击穿过雨幕时防御 `+1`。

重甲不等于高防御。它主要提高减伤，也可能让翻越、追逐或轻功行动处于不利。

### 5.3 佩饰

佩饰优先改变江湖条件，而不是稳定加战斗数字：

- 身份腰牌开放地点和对话；
- 信物改变人物态度或求援权限；
- 药囊允许战斗中快速用药；
- 特殊护符才可能抵消一次明确状态。

## 6. 统一行动判定

### 6.1 行动总值

```text
行动修正 =
  行动属性
  + 武学熟练
  + 境界差
  + 有利／不利
  - 相关伤势
  + 动作特殊修正

行动总值 = 固定因果骰1D10 + 行动修正
```

约束：

- 每次行动只读取一项属性和一门主要武学；
- 有利统一为 `+2`，不利统一为 `-2`，各自最多计算一次；
- 有利和不利同时存在时互相抵消；
- 同一状态、轮次、对象和行动使用固定骰点，不能靠读取进度刷新；
- 装备通过开放动作、改变距离、提供被动或进入伤害／防御／减伤发挥作用，不再额外堆一串“装备命中修正”。

### 6.2 目标值

非攻击行动：

```text
目标值 = 4 + 行动难度
```

攻击、擒拿、点穴、缴械等直接针对敌人的行动：

```text
命中目标 = 4 + 行动难度 + 目标防御
```

“行动难度”表示招式本身和当下任务有多难；“目标防御”表示对方有多难被命中。两者职责不得混用。

### 6.3 防御

```text
防御 =
  floor(身法 ÷ 2)
  + 当前招架／闪避姿态
  + 遮挡
  + 条件装备防御
  - 防守者相关伤势
```

建议数值：

| 来源 | 常见值 |
| --- | --- |
| 身法 | `0～2` |
| 招架／闪避姿态 | `0～2` |
| 遮挡 | `0～1` |
| 条件装备 | `0～1` |
| 伤势扣减 | `0～2` |

防御正常控制在 `0～4`。它不是另一条气血，也不消耗到零。防御的每一项来源必须能用一句世界内文字解释。

### 6.4 四档结果

| 行动总值与目标值 | 结果 | 规则 |
| --- | --- | --- |
| 高出 `3+` | 大成 | 完成目标，并取得动作写明的额外收益 |
| 达到目标 | 得手 | 完整完成目标 |
| 只差 `1` | 得手有损 | 完成主要目标，同时承受预告代价 |
| 低于 `2+` | 失手 | 没有完成主要目标，局面继续或敌招兑现 |

统一使用“大成、得手、得手有损、失手”。旧文档中的“出色、苦成”在实现迁移时一并替换。

## 7. 统一伤害公式

### 7.1 伤害区间

```text
伤害下限／上限 =
  武器伤害下限／上限
  + 招式威力
  + floor(威力属性 ÷ 2)
  + 境界伤害加值
  + 本次催动伤害加值
```

没有兵器的拳脚使用对应武学写明的徒手基础伤害，不把空手视为零伤害。

境界伤害加值：

| 境界 | 加值 |
| --- | --- |
| 未入门 | `0` |
| 锻体 | `+1` |
| 聚气 | `+2` |
| 通脉 | `+3` |
| 宗师 | `+4` |

境界同时已经参与行动修正，因此这里只给缓慢增长的伤害加值，不再按境界倍乘。

### 7.2 结果档位取值

一次因果骰同时决定是否命中和命中质量，不再掷伤害骰：

| 结果 | 采用伤害 |
| --- | --- |
| 大成 | 伤害上限 |
| 得手 | 上下限的向上取整平均值 |
| 得手有损 | 伤害下限，同时承受按钮预告代价 |
| 失手 | `0`，除非动作明确写有擦伤或环境余波 |

“大成”承担暴击的爽点，不再另设暴击率和暴击倍数。

### 7.3 最终伤害

```text
有效减伤 = max(0, 常驻减伤 - 穿透)

最终伤害 =
  档位伤害为0时取0；
  否则 max(1, 档位伤害 - 有效减伤 - 本次临时减伤)
```

穿透只允许出现在少数明确的破甲招式、真气催动、内劲或剧情兵器上；默认不在人物页显示独立穿透属性。按钮或物品说明直接写“忽略一点减伤”。

### 7.4 伤势触发

伤势不是每次受击的随机附赠：

- 动作必须带有割伤、骨折、穴位、毒等伤势标签；
- 单次最终伤害达到最大气血的 `25%`，可造成一级相关伤势；
- 单次最终伤害达到最大气血的 `40%`，可造成二级相关伤势；
- 三级致命伤只由已预告的杀招、剧情机关或气血归零产生；
- 防住大部分伤害仍可能承受被推开、失衡或武器脱手，但按钮必须提前说明。

## 8. 敌人使用同一公式

敌招不再只写死扣血。每名敌人的动作同样拥有：

- 使用属性；
- 武学熟练；
- 境界；
- 行动难度；
- 武器或徒手伤害；
- 当前真气与允许的催动层级；
- 适用距离；
- 伤势标签；
- 四档结果。

敌方阶段按已公开意图依次结算：

```text
敌方行动总值 = 固定因果骰1D10 + 敌方行动修正
敌方命中目标 = 4 + 动作难度 + 玩家防御
玩家承伤 = 档位伤害 - 玩家减伤 - 本次临时减伤
```

玩家默认只看见：

```text
刀客：压身横斩
目标：你
威胁：可能造成4～7点伤害
依据：近距 · 你无处遮挡
```

点击后再展开自己的防御、减伤以及可改变结果的条件，不公开敌人整张属性表。

## 9. 属性、武学、境界与装备的职责

| 系统 | 主要影响 | 不负责 |
| --- | --- | --- |
| 属性 | 行动修正、基础防御、伤害小幅成长、气血 | 直接开放没学过的招式 |
| 武学 | 动作、招式威力、熟练修正、特殊被动 | 提供无限叠加的百分比乘区 |
| 内功／真气 | 催动方向、有限爆发、护体、换距和恢复方式 | 另建一套法术命中、法术防御或内功生命条 |
| 境界 | 越阶难度、高武权限、气血和小幅伤害 | 让低境界所有手段自动失效 |
| 兵器 | 基础伤害、距离、持握、武器动作 | 决定人物全部战斗力 |
| 护具 | 减伤与少量条件防御 | 让攻击必然打不中 |
| 伤势 | 降低相关行动、防御或禁用动作 | 另建一套部位生命条 |
| 见闻／环境 | 有利、不利、遮挡、新行动和后手揭示 | 永久堆数值 |

示例：

> 陈司命以雁翎短刀施展“压刀夺门”。力道决定行动修正，刀法熟练提供加值，雁翎短刀给出基础伤害和近距条件，锻体境提供境界修正与一点伤害，左臂伤降低行动，檐柱遮挡只在敌人反击时提高防御。所有来源都能在一个展开面板里讲清楚。

## 10. 真气如何接入统一公式

### 10.1 催动类似升环，但不是新法术

真气催动采用“同一个动作、更深一层效果”的结构。它与升环施法的共同点是玩家用更高资源成本强化熟悉能力；不同点是本项目没有不同等级的真气槽，也不产生独立法术列表。

```js
{
  id: "saber_crosscut",
  label: "雁翎刀·横截",
  actionCost: 2,
  baseDamage: { min: 6, max: 8 },
  qiVariants: [
    {
      id: "normal",
      qiCost: 0
    },
    {
      id: "surge",
      label: "催劲",
      qiCost: 1,
      damageBonus: 2,
      ignoreReduction: 1
    },
    {
      id: "penetrating",
      label: "贯劲",
      qiCost: 2,
      damageBonus: 2,
      ignoreReduction: 1,
      addStatus: "off_balance",
      requires: ["stage:qi", "mastery:skilled"]
    }
  ]
}
```

选择催动层级不会另掷骰。它只在提交行动前改变同一动作的资源成本、伤害、忽略减伤、身位或状态效果：

```text
行动总值仍只结算一次
催动伤害进入原伤害区间
忽略减伤进入原最终伤害公式
状态只在动作已经命中时产生
```

### 10.2 三种首批用途

第一批只需要三类真气用途：

| 用途 | 消耗 | 效果边界 |
| --- | --- | --- |
| 催劲 | 真气 `1` | 增加伤害、忽略一点减伤或强化已有破绽，三选一 |
| 运气护体 | 真气 `1` | 在敌方阶段获得一次或一轮临时减伤 |
| 爆发身法 | 真气 `1` | 无视一次追击、跨越额外身位或获得临时防御 |

一项催动通常只取得一个主要强化，不能同时增加命中、伤害、防御、减伤和控制。两点真气的深度催动只给少数标志性招式。

### 10.3 真气与行动卡

真气不生成多个重复按钮。行动卡内部提供“常式／催动”切换：

```text
雁翎刀·横截
[常式] [催劲·真气1]

行动2｜真气1
伤害8～10
忽略一点减伤
```

- 切换后即时更新消耗、结果预览和条件；
- 真气不足时保留常式，只把催动置灰；
- 不满足境界或熟练时显示具体缺口；
- 默认仍只推荐三项最相关行动；
- 只有当前局面能产生不同用途的催动才进入推荐区。

### 10.4 真气、装备与内功

装备负责兵器基础伤害、距离、持握和护具减伤；内功决定真气怎样强化这些已有规则：

- 刚猛内功可以让刀剑催劲增加伤害或忽略减伤；
- 鱼跃龙门诀可以让身法催动改变换距、追击和临水恢复；
- 枯木类内功可以把真气转为临时减伤、压伤或抗毒；
- 针法催动可以把封腕深入为封穴，但仍使用针法原本的命中判定；
- 少数佩饰可以改变恢复条件或保存一点真气，不能普遍堆高真气上限。

真气不建立法术防御、内功伤害条或第二套气血。内劲造成的特殊伤害仍通过“忽略减伤、附加伤势或改变状态”表达。

### 10.5 敌人的真气

聚气境以上敌人使用同一规则。敌方意图必须提前暴露正在运气以及可能强化的结果：

```text
王卓正在贯劲
下一击将忽略一点减伤，并可能震退你
```

玩家可以通过封穴、逼迫换招、撤离适用距离或消耗其真气来应对。界面不必公开敌人完整真气公式，但敌人不能拥有不受资源约束的无限催动。

### 10.6 不让催动成为必选

为了避免玩家每次有真气就无脑选择最高档：

- 真气在战斗之间保存，不自动补满；
- 常式必须足以处理普通局面；
- 催动优先提供控距、破甲、护人和状态变化，而不是统一加伤；
- 同一点真气应当在进攻、防御和脱身之间形成竞争；
- 高阶催动效率不按消耗成倍增长；
- 战斗内吐纳会占用行动并让敌招继续推进。

玩家常用少数招式是预期体验。大量武学负责形成不同打法和特殊解法，真气负责决定何时把当前常用招式推得更深。

## 11. 人物界面

界面参考：[人物效果图-v10](../../web/assets/UI_Renderings/人物效果图-v10.png)。

### 11.1 布局

- 顶部一级入口保持“人物、行囊、武学”等；
- 人物页左侧为小号姓名、出身、境界、气血、真气、五维、伤势和特性，不显示命灯与潜能；

- 左侧战斗摘要只显示“防御”和“减伤”，不显示总战力；
- 左侧二级入口固定为“人物、江湖关系、江湖百艺”，使用与确认稿一致的连续竖排纸签；已学招式和心法统一归入顶层“武学”；
- 中央人物保持视觉居中，并围绕人物显示九个相同尺寸的装备位置；
- 中央人物读取容貌状态中的体貌、面容、发式、肤色和服装；人物页装备变化不替换人物立绘；
- 装备位置仍围绕人物展示，品质、图标、详情、替换关系和有效数值继续即时更新；
- 当前已发布的兜帽、斗笠、短甲和护腕透明层属于待解耦的旧实现，不能继续作为新装备的美术生产标准；
- 右侧显示二十四格装备行囊与兵刃／衣甲／佩饰纯图标筛选；格子保持略高于宽的固定比例，内部图标使用正方形裁切，不随格子拉伸；
- 点击行囊物品或已装备部位只打开浮动详情，不改变装备状态；玩家必须在详情底部再次点击“装备”“替换”或“卸下”；若新装备会移除任一已有装备，包括双手兵刃清空副手，按钮必须显示“替换”并说明被替换物；
- 特性只显示名称，点击后再弹说明。

### 11.2 装备详情规格

详情浮层已经成为人物页换装的必经交互。当前先显示名称、品质、类别、位置、基础伤害、主属性、穿透、装备效果、穿戴条件、物品描述和操作按钮；后续装备具有武器动作与熟练解锁时，继续按以下顺序扩展：

1. 名称、品质、类别；
2. 当前有效伤害或减伤；
3. 与已装备物的差值；
4. 持握和适用距离；
5. 装备被动；
6. 武器动作；
7. 熟练后解锁内容；
8. 穿戴条件；
9. 标签、重量和价值；
10. 穿戴／卸下按钮。

颜色只传达稳定语义：

| 颜色 | 含义 |
| --- | --- |
| 金色 | 名称、品质和重要规则 |
| 绿色 | 比当前装备提高或已满足条件 |
| 赤色 | 比当前装备降低、风险或未满足条件 |
| 灰色 | 无变化、说明文字或不可用操作 |

同一装备的品质文字、装备名称、详情顶边和品质底边必须读取同一个品质色变量，不允许各组件维护错位的颜色表。

目标版本中，装备目录不再声明人物外观资源；`paperDoll`元数据与`paperdoll-system.mjs`只作为旧档和旧界面的迁移对象。人物页始终显示玩家在容貌页选定的服装，装备操作只更新装备槽、详情、派生数值、动作与叙事权限。这样新增装备不再产生人物合成和遮挡资源，新增服装也不会改变战斗最优解。

详情不可依赖鼠标悬停。桌面与手机横屏都通过点击打开，点击空白处、关闭按钮或按Escape关闭；浮层超出视口时允许自身滚动，不能裁掉穿戴条件和操作按钮。打开详情和关闭详情都不得改变装备状态。

### 11.3 战斗中的反馈

装备必须在实际结果中留下可见证据：

```text
雁翎短刀：伤害 7
旧皮护衣：减伤 1
最终失血：6
```

只显示本次有贡献的来源。没有生效的装备不进入战报。

## 12. 品质与掉落

品质只表示稀有程度、工艺和规则复杂度：

| 品质 | 设计边界 |
| --- | --- |
| 凡品 | 一个基础用途 |
| 良品 | 数值可靠，或带一个清楚被动 |
| 珍品 | 一个能改变行动的独特规则 |
| 稀有 | 与人物、势力或武学形成明确联动 |
| 奇珍 | 能改变局面，但必有身份、代价或长期因果 |

高品质不保证全面更强。例如漕帮信物可能没有减伤，却能叫停一次水路冲突；轻巧旧刀可能伤害低，却允许空副手点穴。装备选择应当回答“这一局我准备怎么打、以什么身份做事”，而不是只比较绿箭头。

取得装备的主要来源：

- 人物传授或赠予；
- 事件取舍；
- 敌人遗留；
- 势力权限；
- 少量购买。

每件珍品以上装备必须记录来源和相关人物，失去、转赠或被认出时可以触发后续内容。

## 15. 验收标准

- 人物页装备、属性、境界和武学能共同推导出战斗详情；
- 更换装备后无需开始战斗即可看到有效伤害、防御或减伤变化，人物外观保持为当前服装；
- 同一敌招在不同防御下可能改变四档结果；
- 同一命中在不同减伤下产生不同实际失血；
- 玩家和敌人使用相同的目标、防御与伤害规则；
- 取得内功后显示小型真气池，境界继续提高其上限；
- 同一招式的常式和催动共用一次固定因果判定，推荐区不会同时出现两个版本；
- 真气在战斗间保存，且进攻、防御和脱身会竞争同一资源；
- 玩家界面使用“行动”和“真气”，不同时显示“气机”和“真气”；
- 固定因果骰仍不能通过读取进度刷新；
- 默认行动按钮不展示长公式，点击依据才能查看构成；
- 不出现攻势、防守、护身、远手等废弃玩家术语；
- 844×390横屏可完整打开装备详情并执行穿戴；
- 人物、行囊和战斗页没有两套不同的装备数量或银两；
- 旧存档迁移后取得安全的初始装备行囊与人物当前状态，流程可以继续；
- 规则测试、内容校验与浏览器回归全部通过。
