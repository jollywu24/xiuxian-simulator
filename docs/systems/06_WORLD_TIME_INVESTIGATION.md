# SYS-06 世界、时间、旅行与调查系统

## 1. 系统目标

让大曜江湖成为会随时间和选择变化的地方。玩家需要安排日程、赶赴窗口、选择路线、调查证据、察觉跟踪和利用制度，而不是从一个剧情按钮瞬移到下一个剧情按钮。

## 2. 当前基础与缺口

已有：

- 破庙、紫金河、沈家和东门药铺等地点；
- 官道与水路选择；
- 丹房三时段日常；
- 篝火时间、饥饿和部分限时奇遇；
- 钓鱼准备和第三段河湾；
- 场景中的自然线索；
- 破庙、紫金河、沈家侧门和丹房的2D空间视图；
- 根据亲历、信物和关系逐步显形的已知行路图；
- 连续日期、旅行时段、四条八月十五路线、地点状态与限时结果；
- 病例见闻／确证、雨痕追踪与四项回报秘密链的最小调查样板。

缺口：

- 连续日期尚未成为所有旧章的统一事实来源；
- 当前行路图只负责已知地点揭示，尚未统一人物权限和旅行成本；
- 戒严和宵禁尚未改变行动；天气只在具体事件中有叙事作用，暂不制作通用随机天气；
- 调查样板尚未支持错误推测、证据冲突和跨篇章流转；
- 跟踪与潜入只有单段样板，无法复用为发现尾巴、断踪、设局和反查；
- 地点变化尚未稳定写回后续篇章；
- 无法同时推进多个有期限的事件。

## 3. 世界时钟

建议使用离散时段，不模拟分钟：

```js
clock: {
  year: 1,
  month: 8,
  day: 14,
  segment: "evening",
  weather: "clear"
}
```

时段：黎明、上午、午后、黄昏、夜、深夜。特殊事件可以使用更细的“辰时前”标签，但玩家操作仍按时段推进。

每个行动声明耗时：瞬时、半时段、一时段、多日。旅行、炼丹、医治和等待都真实推进时间。

## 4. 地图模型

```js
{
  id: "ruined_temple",
  region: "jinling_east",
  discovered: true,
  access: [/* 权限条件 */],
  routes: ["purple_river", "east_road", "monkey_trail"],
  services: ["shelter", "fire"],
  events: ["temple_offering", "monkey_map"],
  state: "abandoned"
}
```

路线记录：

- 出发地与目的地；
- 所需时段；
- 体力、饱腹和银钱；
- 水路、官道、山路等标签；
- 天气与宵禁修正；
- 所需能力或权限；
- 途中事件；
- 被跟踪和暴露风险。

## 5. 地点状态

地点可以因剧情改变：

- 破庙：普通废庙 → 发现贡品 → 打开猴道；
- 沈家：外院可进 → 内宅获准 → 提高警戒 → 失去沈福渠道；
- 药铺：曹青在场 → 曹青离开 → 被人监视；
- 金陵：开放 → 戒严 → 部分城门封锁；
- 毒蛇帮据点：活跃 → 警觉 → 被清剿／被接管。

地点状态影响行动和文案，不另造重复场景ID掩盖变化。

## 6. 时间窗口

窗口包含：

```js
{
  id: "mid_autumn_temple",
  opensAt: {/* 八月十五黎明 */},
  closesAt: {/* 八月十五午后 */},
  requiredLocation: "ruined_temple",
  warningAt: {/* 八月十四黄昏 */},
  missOutcome: "offering_taken"
}
```

界面提前提供世界内提醒，例如月相、节令、人物约定和路程，不显示后台倒计时。

## 7. 多事件日程

玩家可以同时有：

- 三夫人病危倒计时；
- 曹青要求的差事；
- 八月十五破庙窗口；
- 沈家或漕帮约见；
- 自身伤势恢复时间。

日程板按“今日必须处理、将近窗口、无期限”排序。错过是合法结果，不自动暂停其他事件。

## 8. 调查与证据

证据对象：

```js
{
  id: "third_lady_burned_meridian",
  kind: "medical_trace",
  source: "pulse_exam",
  reliability: "confirmed",
  pointsTo: ["deviation"],
  contradicts: ["ordinary_illness"],
  freshness: "current"
}
```

调查行动可以：观察、询问、检查物品、跟踪、对照记录、试药、设局验证。

结论分见闻、推测、确证和过期。错误推测允许存在，并影响行动选项。

## 9. 跟踪与反跟踪

跟踪由四项决定：

- 目标警觉；
- 跟踪者身法与隐藏；
- 地形人流；
- 已暴露次数。

过程分段：发现目标、保持距离、穿过风险点、确认落脚点、撤离。

反跟踪允许：

- 改换路线；
- 借水路断踪；
- 进入人群；
- 设置假目的地；
- 反过来确认跟踪者；
- 引入燕惊鸿或沈家守卫。

失败不一定立刻开战，可以增加对方警觉或留下假情报。

存档版本5已有第一个最小跟踪样板：若蒙面刀客从长街脱身，玩家不直接追刀光，而是以身法沿檐下断续雨痕保持距离；成功取得回报暗语、鱼鳞铜签和交接时辰，失败则被反身察觉并使旧渠道作废。完整的分段跟踪和反跟踪在P1-A由沈福反目局面首次补齐。

### 9.1 M4分段追踪与逃亡

第五十五至六十八章只实现服务沈福反目的必要分段：

```text
察觉尾巴 → 决定是否保持距离 → 穿过风险点 → 设假目的地／反查 → 确认落脚点 → 撤离或转入冲突
```

每段都要允许至少两种意图，例如继续观察、护送同伴、断踪、诱入伏点或主动退出。固定因果骰只决定暴露、耗时、伤势和情报完整度，不替玩家决定要不要杀人或交出沈福。

失败推进优先写入以下后果：

- 对方警觉提高，后续路线缩短但不会立刻死亡；
- 玩家得到一条可能错误的去向，需要第二证据验证；
- 假目的地反被利用，某处地点进入受监视状态；
- 为护人或保住证据而主动放弃追踪；
- 被迫进入既有战斗引擎配置的遭遇。

地点只保存能影响后续选择的变化，例如沈家侧门封闭、药铺受监视、藏身处暴露和紫金河水路仍可用。不要为M4先建立通用路网、随机天气或全NPC作息。

## 10. 潜入与权限

进入地点有多条路线：

- 正式身份；
- 人情引见；
- 伪造口令；
- 趁换岗潜入；
- 水道、屋顶或暗门；
- 制造合法差事；
- 被押入内。

制度漏洞必须成为正式解法。例如借沈家药材交接进入内宅，或利用戒严公文获得短期通行。

## 11. P0八月十五闭环

1. 在拜师阶段获知具体日期；
2. 估算药铺到破庙的路程；
3. 处理伤势、师命和物资；
4. 选择水路、官道或提前出发；
5. 天气和夜路改变成本；
6. 正确窗口看见贡品来源；
7. 跟随灵猴打开隐藏路线；
8. 错过则记录贡品已被取走，并留下下一次更高代价机会或永久关闭。

## 12. P1戒严金陵

戒严金陵属于M5。它必须复用M4已经验证的身份权限、联系人、地点状态和分段追踪，而不是另起一套城市模拟。

- 城门、宵禁和盘查；
- 身份玉牌或通行文书；
- 黑市价格和藏身处；
- 燕惊鸿官面权限；
- 王卓尾随；
- 东湖奇珍与伏击同时推进；
- 城市警戒会因战斗、尸体和谣言变化。

## 13. P2组织暗局

- 毒蛇帮据点侦查；
- 漕帮卧底和暴露度；
- 归墟联络点与假身份；
- 多事件融合；
- 黑衣人反侦察；
- 官面议程和崔大人约见；
- 名声改变城市随机反应。

## 15. UI要求

- 场景顶部只显示世界内日期、时段、天气和地点；
- 日程板用“今夜前”“明日辰时”等自然语言；
- 地图只显示已知地点和路线，未知目的地使用世界内称呼，不显示内部锁定条件；
- 路线卡说明时段、体力和可见风险；
- 证据册分见闻、推测、确证，不显示内部可靠度数值；
- 戒严时先呈现盘查压力，再提供路线；
- 手机端使用收纳在场景内的紧凑示意图和地点说明，不允许地图撑宽页面；后续地点增多时切换为纵向地点列表。

## 16. 测试矩阵

- 所有行动真实推进时钟；
- 旅行成本不足时给出世界内原因；
- 八月十五窗口按到达时间而非点击顺序判断；
- 地点状态改变后旧行动不再出现；
- 错误推测不会被系统自动修正；
- NPC不知道未公开证据；
- 跟踪失败可进入警觉而非直接战斗；
- 追踪过程中可以为护人、保住证据或隐藏身份而主动退出；
- 追踪得到的错误去向不会自动标为错误，必须由第二证据验证；
- 沈家侧门、药铺与藏身处的持久状态会改变下一场景行动；
- 沈福死亡后依赖其引见的路线关闭；
- 戒严会改变路线、价格和盘查；
- 旧首章固定流程在无连续时钟时迁移到合理日期。

## 17. 完成标准

P0完成要求玩家能够因不同出发时间和路线得到准时、迟到、重伤到达或错过四种八月十五结果。P1-A完成要求M4追踪可以被察觉、继续、断踪、反查、主动放弃或引入冲突，失败会推进警觉、错误情报或地点状态；P1-B再要求这些规则与戒严、官面身份和跨篇章证据联动。
