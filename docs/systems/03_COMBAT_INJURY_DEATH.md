# SYS-03 简明战斗、伤势与死亡系统

## 1. 一页规则

玩家只需要理解七件事：

1. 每回合敌人会露出一个意图；
2. 玩家选择一个行动；
3. 每个行动只使用一项属性和一门功法；
4. 境界、优势、劣势和伤势共同形成行动修正；
5. 仍有不确定性的行动掷一枚固定因果骰，同一战况不能靠读取进度刷新点数；
6. 双方气血公开显示，行动结果会直接增减气血；
7. 气血归零会死亡或击杀，但制伏、逃离、护人和追查仍是独立目的。

展开选项详情后可以查看：

```text
行动值 = 对应属性 + 功法熟练 + 境界差 + 优势／劣势 - 伤势
判定总值 = 固定因果骰1D10 + 行动值
玩家最大气血 = 12 + 根骨×2 + 境界阶数×4
```

选项默认只显示：

```text
春风针·封腕
胜算：可行
依据：悟性 · 春风针熟练 · 已看破左袖
结果：封住持刀手 · 敌方气血 -3～5
风险：失败会损失自身气血并被短刃擦伤
```

点击条件行后才显示行动修正、目标值和构成；执行后显示骰面、修正、合计与四档结果。相同存档、相同轮次、相同战况和相同行动得到相同骰点。想改变结果，必须先改变见闻、伤势、武学、属性或环境。

一场普通战斗控制在三至五回合，每回合提供三至五个按钮。

这就是玩家必须学习的全部核心规则。

## 2. 参考与取舍

完整的参考拆解、统一战斗循环和王卓战落地样板见 [《武道》战斗系统参考与转化](../COMBAT_DESIGN_REFERENCE.md)。本节只保留直接影响规则层的取舍。

第二轮参考补充六个体验支点：

| 参考 | 采用 | 压缩或舍弃 |
| --- | --- | --- |
| 《Into the Breach》 | 敌招目标、兑现顺序、已知后手和行动预览 | 不做棋盘，也不让初见敌人的全部秘密透明 |
| 《A Legionary’s Life》 | 距离、武器长度、地形与身体状态改变打法 | 疲劳、士气、架势只转为按需出现的临时标签 |
| 《Sifu》 | 死亡保留死因、杀招、破绽和针对性行动 | 不因死亡直接增加属性、境界或熟练 |
| 《Fights in Tight Spaces》 | “动作＋对象”、位置变化和环境兑现 | 不做卡组、抽牌和格子战场 |
| 《Roadwarden》 | 场景负责空间，文字负责条件、行动和结果 | 不以长战报或动画隐藏关键风险 |
| 《Wildermyth》 | 伤势、关系、牺牲和战斗选择形成长期后果 | 不让所有小战斗都产生随机永久改造 |

### 《博德之门3》

采用：

- 一回合有明确的行动额度；
- 每个动作说明消耗、目标、成功机会与效果；
- 属性、熟练、优势／劣势和环境共同影响结果；
- 武器熟练会开放少量具有明确用途的特殊动作；
- 击倒、缴械、推动、沉默等状态比单纯伤害更有战术价值。

官方更新曾明确介绍：熟练武器可提供最多三种标志性动作，例如打手降低攻击能力、重击造成眩晕；界面也直接显示优势与劣势。[Larian 武器行动说明](https://baldursgate3.game/news/community-update-14-forging-the-arcane_44)

不采用：

- 主行动、附赠行动、反应、法术位等多套行动资源；
- 护甲等级、豁免、独立命中骰和伤害骰；第一版只保留每次关键行动的一枚因果骰；
- 大量持续时间与叠层状态。

### 《太吾绘卷》

采用：

- 功法与距离必须匹配；
- 不同功法形成不同战斗方式；
- 内功、身法和具体招式各自承担不同职责；
- 武学不是换皮伤害按钮。

《太吾绘卷》的官方介绍强调搭配功法、运转内力、磨炼技艺和策略。[Steam 官方商店页](https://store.steampowered.com/app/838350/_/?l=schinese)

不采用：

- 连续距离数轴；
- 内外伤、破体、破气、护体、御气等多组对照数值；
- 复杂架势、提气、脚力和功法运转条。

本项目只保留三档距离：贴身、适中、远离。

### 《鬼谷八荒》

本次把用户所写“硅谷八荒”按《鬼谷八荒》理解。

采用：

- 心法提供根基；
- 常用招式负责稳定应对；
- 身法负责脱险和创造机会；
- 绝技负责扩大已经形成的优势；
- 少量技能组成清晰战斗套路。

官方商店页把其结构概括为“心法筑根基，武技／灵技探深浅，身法创机会，绝技造优势，神通定乾坤”。[《鬼谷八荒》官方商店页](https://store.steampowered.com/app/1468810/_/?l=schinese)

不采用：

- 即时弹幕和走位操作；
- 大量词条、冷却缩减和伤害乘区；
- 一屏同时装载许多主动技能。

### 最终取舍

本项目采用：

> **以《Into the Breach》的意图公开为入口，用《博德之门3》的清楚按钮承载选择，以《太吾绘卷》和《A Legionary’s Life》的距离、功法与身体状态构成战局，再用《Sifu》的死亡学习、《Fights in Tight Spaces》的位置环境、《Roadwarden》的图文分工和《Wildermyth》的长期后果完成闭环；《鬼谷八荒》的少量技能分工继续控制复杂度。**

## 3. 当前问题

现有春风针夜战已经拥有：

- 可读敌人意图；
- 观察、灭灯、出针与撤离；
- 制伏、杀死、负伤和死亡；
- 双方气血、敌招顺序、三档距离与环境对象；
- 部位伤势与命灯回照。

存档版本5已经把这场夜战改为第一份完整样板：行动读取对应五维、武学熟练、境界差、一次优势／劣势、相关伤势和当前气血，并向玩家显示“稳妥、可行、凶险、必死”、气血预估与简短依据。执行关键行动时使用固定因果骰，并把骰面、修正、气血变化、合计和结果写入战斗履历与右侧叙事栏。杀死、制伏和脱身还会分别进入搜尸、盘问和追踪雨痕，不再只更换战后文案。

上一版设计又走向另一个极端，同时暴露：

- 把握、效力、险势三轴；
- 四道对抗门；
- 攻守之势、破绽类型和气血负荷；
- 主属性、辅属性与多层境界抵消。

这些内容适合设计师内部推演，不适合作为玩家要学习的规则。本版全部压缩为“一次行动、一个属性、一门功法、一次胜算判断”。

## 4. 回合结构

玩家每回合仍只执行三步；界面则按“敌招—战局—选择—预测—兑现—余波”展示信息。

### 4.1 敌人露出意图

敌人显示一句主要动作：

> 刀客右肩微沉，正向你逼来。

悟性、旧见闻或特定功法足够时，追加一句：

> 你看出右手只是诱饵，左袖中还藏着短刃。

玩家不需要阅读完整战报才能知道危险。

### 4.2 玩家选择一个行动

每轮提供三至五项：

- 一项常用攻击或招式；
- 一项防守、观察或身法；
- 一项环境、物品或同伴行动；
- 一项当前功法产生的特殊行动；
- 必要时提供撤离。

玩家每回合只选一个，不区分主行动、附赠行动和反应。

### 4.3 立即结算

结算后只告诉玩家三件事：

- 你做成了什么；
- 你付出了什么；
- 敌人下一步发生了什么变化。

随后进入下一回合或结束战斗。

## 5. 唯一战斗判定

### 5.1 行动值

```text
行动值 = 对应属性 + 功法熟练 + 境界差修正 + 优势修正 - 劣势修正 - 伤势修正
```

每项只计算一次。

### 5.2 结果

行动与该选项的难度比较：

| 行动值 | 结果 | 含义 |
| --- | --- | --- |
| 高出难度 `2+` | 出色 | 做成目标，并获得该招式写明的额外效果 |
| 达到难度 | 得手 | 完整做成目标 |
| 只差 `1` | 苦成 | 做成目标，但承受按钮提前说明的代价 |
| 低于难度 `2+` | 失手 | 没做成，敌人意图兑现 |

结果档位直接映射到行动预先写明的固定气血变化。不存在独立命中骰、伤害骰、穿透计算或部位生命计算。

### 5.3 气血

- 玩家最大气血为 `12 + 根骨×2 + 境界阶数×4`；
- 每级既有伤势令入场气血减少二；
- 观察、借势与撤离通常不伤敌，但失手会损失自身气血；
- 夺械与强攻会削减敌方气血，得手有损会同时扣减自身气血；
- 自身气血归零进入命灯死局；
- 击杀令敌方气血归零，制伏令敌方气血停在一；
- 敌方失血过半可以提供优势，但不能替代看破杀招和满足行动条件。

### 5.4 玩家看到的胜算

系统把结果预告压成四档：

| 显示 | 对应结果 |
| --- | --- |
| 稳妥 | 出色或得手，且没有未知后手 |
| 可行 | 得手，或已经明确知道苦成代价 |
| 凶险 | 可能苦成、失手，或仍有一个未看破后手 |
| 必死 | 已经亲历并确认的死亡行动 |

点击“为何”才展开简短来源，例如：

```text
悟性 3
春风针熟练 +1
手腕破绽：优势 +2
高一境：-2
左臂伤：-1
```

默认界面不展示公式面板。

## 6. 五维如何影响战斗

每个行动只使用一项属性，不设辅属性。

| 属性 | 战斗中负责什么 | 行动例子 |
| --- | --- | --- |
| 力道 | 正面强攻、格挡、推开、夺械 | 翻桌撞开刀客、强拉钓竿 |
| 根骨 | 忍伤、抗毒、运功、护住他人 | 硬撑一击、压住毒性 |
| 身法 | 抢先、闪避、换距、撤离 | 灭灯绕后、跃入河中 |
| 悟性 | 观察、识招、精确使用武学 | 看破左袖、春风针封穴 |
| 福缘 | 战斗开始时出现额外环境机会 | 松动船索、经过的巡船 |

规则限制：

- 一个按钮只标一项属性；
- 不让玩家在点击后再选择属性做法；
- 同一场战斗至少提供两种属性路线；
- 高属性提高胜算，不会自动解锁没有学过的功法；
- 福缘只在入场时生成一次机会，临战改点不会重复刷新。

### 6.1 逆天改命

战斗前可以自由重分已有五维。

战斗开始后，玩家仍可选择“改命换势”重新分配，但这会占用本回合，敌人的意图照常推进。

不再计算攻守之势或呼吸窗口。代价只有一个：用掉这回合。

## 7. 境界如何影响战斗

境界只提供一个清楚的差值修正：

| 双方境界 | 玩家行动修正 |
| --- | --- |
| 玩家高一境以上 | `+2` |
| 同境 | `0` |
| 玩家低一境 | `-2` |
| 玩家低两境 | `-4` |
| 玩家低三境以上 | 不能正面击败，只能逃离、拖延、谈判或使用剧情机关 |

境界差修正只算一次，不再额外修改伤势、效果和负荷。

境界仍然开放高武权限：

| 武境 | 新权限 |
| --- | --- |
| 未入门 | 使用凡俗兵器和已经入门的基础招式 |
| 锻体 | 可稳定使用正式战斗武学，轻伤不会立刻中断行动 |
| 聚气 | 可使用带内劲的招式，攻击经脉或隔甲发力 |
| 通脉 | 可使用隔空劲力、踏水和连续内息招式 |
| 宗师 | 可以个人力量影响多人或一片战场 |

### 7.1 越阶

克制功法、已知弱点、敌人重伤或极有利地形统一称为“优势”。

只要有一项，就得到 `+2`；拥有多项也不继续叠加。优势和劣势同时存在时互相抵消。

因此锻体对聚气时：

- 正面交手：境界差 `-2`；
- 看破穴位或在水边发挥鱼跃龙门诀：优势 `+2`；
- 两者抵消后按正常行动结算。

不再逐层计算“破阶优势”。

## 8. 功法如何影响战斗

### 8.1 每门功法最多三件事

一门战斗功法只设计：

1. 一个常用动作；
2. 一个满足条件后出现的特殊动作；
3. 一个容易记住的被动特点。

例：《春风化雨针》

- 常用动作：封腕；
- 特殊动作：看破要穴后可以封穴制伏；
- 被动特点：观察经脉、出血和暗器动作时获得优势。

### 8.2 熟练度

只保留三档：

| 熟练度 | 作用 |
| --- | --- |
| 入门 | 可以使用常用动作，修正 `0` |
| 熟练 | 修正 `+1`，解锁特殊动作 |
| 精通 | 修正 `+2`，强化被动特点 |

“知道名称”和“持有秘籍”不是战斗熟练度，不能使用正式动作。

第一版不制作大成、化境、突破等额外熟练层级。

### 8.3 功法分工

玩家同时只需要关注四个位置：

| 位置 | 作用 | 当前例子 |
| --- | --- | --- |
| 根基 | 提供常驻规则 | 鱼跃龙门诀 |
| 常用招式 | 每回合稳定使用 | 春风针、打鱼杆法 |
| 身法／防守 | 脱险或制造优势 | 海桩、枯木桩 |
| 绝招 | 有条件地结束阶段 | 封穴制伏、致命出针 |

这不是装备栏限制，而是战斗页面的展示限制。其他已学功法只有在符合场景时才出现。

### 8.4 当前功法实例

#### 春风化雨针

- 使用属性：悟性；
- 合适距离：适中；
- 入门：钢针封腕；
- 熟练：看破穴位后可封穴制伏；
- 精通：观察暗器、经脉和失血时自动获得优势；
- 限制：没有银针、手臂重伤或贴身缠斗时不可使用。

#### 打鱼杆法

- 使用属性：力道；
- 合适距离：适中；
- 入门：缠住兵器或物件；
- 熟练：敌人前冲时可借力使其失衡；
- 精通：成功缠住后可以选择夺械或拉回同伴；
- 限制：贴身时长杆难以展开。

#### 鱼跃龙门诀

- 类型：根基；
- 水中、水边、逆流和船战时提供优势；
- 不直接提高所有战斗行动；
- 战胜高境界敌人后可推进心法剧情。

#### 沧澜定海桩

- 使用属性：根骨；
- 水边抵抗推挤、失衡和冲撞时提供优势；
- 可以选择“稳住下盘”保护自己或同伴；
- 不增加春风针在普通旱地的胜算。

#### 神农枯木桩

- 使用属性：根骨；
- 忍伤、压毒和强撑行动时提供优势；
- 重伤时可以用一回合把伤势暂时压住；
- 战斗结束后仍需医治。

## 9. 距离与环境

### 9.1 三档距离

| 距离 | 常见行动 |
| --- | --- |
| 贴身 | 拳脚、短刃、擒拿；长杆和飞针受限 |
| 适中 | 刀剑、钢针、钓竿和大多数武学 |
| 远离 | 弓弩、追逐、逃跑；近战招式不可用 |

移动本身是一个行动。部分身法可以在移动后附带闪避或制造优势，但仍只结算一次。

### 9.2 环境

环境只产生两类效果：

- 开放一个新按钮；
- 为一个行动提供优势或劣势。

例子：

- 扑灭灯火：开放“借黑暗绕后”；
- 湿滑河岸：普通换位有劣势，海桩抵消；
- 松动船索：福缘足够时开放“放船撤离”；
- 狭窄门洞：阻止多人同时围攻。

不再维护落脚、掩体、出口控制权和攻守之势四套状态。

## 10. 伤势

伤势保留部位，但只分三档：

| 伤势 | 后果 |
| --- | --- |
| 轻伤 | 对相关行动 `-1`；锻体角色可忽略一次中断 |
| 重伤 | 对相关行动 `-2`，并禁用需要该部位完整发力的招式 |
| 致命 | 必须立即止血、撤离或求助，否则下一轮死亡 |

例子：

- 左臂轻伤：发针与持杆 `-1`；
- 腿部重伤：不能追击，撤离为凶险；
- 腹部致命伤：下一轮前必须处理。

不设置每个部位的生命值、疼痛值、失血值和感染值。感染、残损等长期后果在战后事件处理。

### 10.1 战后处理

- 包扎：解除致命倒计时，伤势仍在；
- 春风针或回春丹：满足条件时移除轻伤或重伤；
- 运功压制：暂时忽略修正，战后伤势不消失；
- 求医：支付时间、银钱或人情；
- 放任：进入恶化事件。

## 11. 同伴与多人敌人

### 11.1 同伴

同伴不拥有独立操作面板。

每轮最多出现一个与同伴有关的按钮，例如：

- 让燕惊鸿先走；
- 请她牵制刀客；
- 替她挡下一击；
- 合力制伏王卓。

关系足够时，该行动获得优势；关系不足时按钮说明她为什么拒绝。

### 11.2 多人敌人

多人敌人按一个整体威胁处理：

- 两人夹击：玩家行动处于劣势；
- 狭门、灭灯或同伴牵制：抵消劣势；
- 首领被制伏或帮众失去目的：整组敌人可能溃退。

不为每个杂兵提供独立回合和完整伤势表。

## 12. 首领战

首领最多两至三个阶段，每阶段只增加一条新规则。

例：王卓河岸战。

### 第一阶段：柳巷尾随

- 目的：护住燕惊鸿并确认跟踪者；
- 特殊规则：王卓身份未明，第一次攻击带未知后手；
- 解法：悟性观察、身法诱敌、关系路线让燕惊鸿先走。

### 第二阶段：河岸截命

- 王卓为聚气境，玩家锻体时承受 `-2`；
- 河岸让普通换位处于劣势；
- 鱼跃龙门诀或海桩提供优势，抵消境界或地形中的一个不利因素；
- 春风针熟练且看破左腕时可以尝试制伏；
- 致命出针可以快速结束，但失去活口并改变人物关系；
- 放王卓逃走可跟踪令牌去向，但后续敌人提高戒备。

玩家面对的仍然是三至五个清楚按钮，不需要理解首领内部公式。

## 13. 命灯与死亡

### 13.1 只有真正死亡才熄灯

以下结果不消耗命灯：

- 轻伤、重伤；
- 昏迷；
- 被俘；
- 丢失物品；
- 同伴离开；
- 任务失败。

### 13.2 回照保留

死亡后保留：

- 直接死因；
- 亲眼看见的隐藏招式；
- 已确认的敌人身份与场景规则。

回到战斗前因果节点后，这些信息可能：

- 把“未知后手”变为可见；
- 让观察行动直接得到优势；
- 开放新的防守或撤离按钮。

不直接增加属性、境界或功法熟练。

同一死因不会反复产生奖励。只剩一盏命灯时，不再显示已经确认的重复必死按钮。

## 14. 手机界面

战斗页固定顺序：

1. 敌方单位栏：当前目标完整显示，其他敌人显示头像、小气血和简化意图；
2. 场景中的当前交锋、远程／后阵威胁及环境热点；
3. 玩家气血、战斗目的、当前目标、距离和关键伤势；
4. 三项根据敌招、目标和环境筛出的推荐行动；
5. 承载其余招式、身法、物品和退路的“全部手段”；
6. 最近一次结果；
7. 可折叠的命盘和更早战报。

手机竖屏中，标题、敌方单位栏和战场各占独立纵向区域，单位栏不得悬浮盖住人物、敌招或环境热点。三名敌人必须在一行内完整出现；远程与后阵敌人的详细标签由单位栏承担，场景只保留可点击站位。390×844首屏需在浏览器底栏上方完整露出三项推荐行动，剩余手段再向下滚动。

示例：

```text
河岸截命 · 第二轮
护住燕惊鸿，离开河岸

王卓：聚气
意图：佯攻你的面门，左袖藏着后手

你：锻体｜适中｜左臂轻伤

[海桩稳身]
胜算：稳妥｜根骨
挡住逼近，并抵消湿滑劣势

[春风针·封腕]
胜算：可行｜悟性 · 针法熟练
制伏持刀手；失败会被短刃擦伤

[让燕惊鸿先走]
胜算：稳妥｜关系
你独自留下，下一轮被夹击

[翻入河中撤离]
胜算：可行｜身法 · 鱼跃龙门诀
放弃活捉王卓
```

不在默认页面显示：

- 行动公式；
- 敌人完整属性；
- 多个防御值；
- 独立伤害骰与穿透值；
- 攻守之势条；
- 气血之外的负荷条；
- 破绽标签列表。

数字键 `1～3` 触发推荐行动；展开“全部手段”时，数字键按抽屉中的行动顺序触发。

### 14.1 多敌人呈现

- 单人游戏中的多名敌人共享一个横向单位栏；
- 当前交锋显示完整头像、气血、敌招与场景高亮；
- 其他敌人只显示小头像、小气血和“瞄准、蓄势、包抄”等意图；
- 点击单位可以切换关注目标，但不能绕过当前阻挡者直接执行不合法攻击；
- 群攻或环境效果应同时高亮所有受影响单位；
- 友军不提供另一套完整操作面板，每轮至多出现一个关系或协助行动。

### 14.2 环境对象

环境对象使用两段确认：

1. 点击灯笼、檐柱或矮墙，只选中对象并切换行动区；
2. 玩家从三项情境行动中确认一项后，才消耗本轮并写入规则结果。

对象使用后必须改变可见状态。例如灯笼熄灭、弩手失去视线、檐柱提供遮挡或矮墙成为脱身落点。敌人也可以破坏或利用同一对象。

### 14.3 动画事件

规则层仍只输出 JSON 可序列化事件。界面按顺序表现：

`锁定目标 → 轨迹／位移 → 命中停顿 → 飘字／状态 → 气血变化 → 下一敌招`

- 普通伤害合并为一个数字，不连续刷屏；
- 当前气血先变化，浅色延迟段随后追上；
- “破绽、失衡、制伏、死局”等结果使用短促笔触提示；
- 银针、刀光、雨水和灯火属于独立特效层，不写入规则；
- 动效期间禁止重复提交；
- `prefers-reduced-motion` 下缩短或取消位移、震动和粒子。

## 17. 测试矩阵

### 17.1 规则测试

- 同一行动更换对应属性后，胜算发生变化；
- 非对应属性不会进入结算；
- 入门、熟练、精通分别提供 `0／1／2` 修正；
- 未入门功法不能使用正式行动；
- 高一境、低一境分别得到 `+2／-2`；
- 优势和劣势最多各计算一次，并互相抵消；
- 多个优势不会继续叠加；
- 轻伤与重伤只影响对应部位行动；
- 福缘机会不会因战中重分刷新；
- 改命换势消耗一回合；
- 非死亡失败不消耗命灯；
- 死亡回照保留见闻，不重复保留物品和关系结果；
- 相同状态和选择得到可重复结果。
- 相同因果键得到相同骰点，单纯读取进度不能刷新；
- 大成、得手、得手有损和失手四档均有可达测试；
- 大成产生的完整活口、凭证或退路会成为后续追查优势；
- 得手有损完成目标但保留真实伤势；
- 普通失手仍保留可执行行动，不强制读档。

### 17.2 浏览器流程

- 春风针夜战至少支持悟性、身法、力道三种路线；
- 每回合只有三至五个主要按钮；
- 每个按钮显示胜算、对应属性、功法、结果和主要风险；
- 默认页面不显示内部公式和多余战斗数值，展开条件后才显示因果骰、修正和目标；
- 执行后显示骰面、修正、合计和四档结果，并写入叙事记录；
- 读取同一战前进度再次选择同一行动，骰点完全相同；
- 至少覆盖一次失手后仍留在夜战并出现下一组行动；
- 一次死亡后左袖后手变为已知；
- 王卓战支持撤离、制伏和击杀；
- 同伴结果与伤势进入战后场景；
- `390×844` 和 `1280×720` 无横向溢出；
- 页面无运行异常，动态姓名经过 `escapeHtml()`。

## 19. 完成定义

简明战斗系统只有同时满足以下条件才算完成：

- 玩家只需理解“一回合一个行动”和“一条行动值公式”；
- 默认战斗页没有把握、效力、险势、对抗门、负荷或破阶层数；
- 每个行动只读取一项属性和至多一门功法；
- 属性、境界、功法、优势和伤势都真实改变胜算；
- 双方气血会随行动真实变化，且不另掷伤害骰；
- 一门功法最多提供一个常用动作、一个特殊动作和一个被动特点；
- 距离只有贴身、适中、远离三档；
- 优势和劣势不叠层；
- 伤势只有轻伤、重伤、致命三档；
- 普通战斗三至五回合，每轮三至五个按钮；
- 战斗至少支持一种非杀戮结果；
- 规则测试、浏览器流程和手机布局全部通过。
