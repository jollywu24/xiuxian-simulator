# SYS-03 战斗、伤势与死亡系统

## 1. 系统目标

提供适合文字冒险的可复用战斗：玩家阅读敌人意图，利用招式、环境、物品、关系和已经掌握的情报作出选择。系统不追求棋盘或大量数值，而要让每回合都回答“我看懂了什么，以及我愿意承担什么风险”。

## 2. 当前基础与缺口

当前死亡选择和宝鱼挣扎已经证明：

- 明确危险可以通过命灯回照；
- 只剩一盏灯时可隐藏必死重复选项；
- 环境知识能改变正确行动；
- 非死亡失败可以重试而不熄灯。

但当前没有：

- 通用敌人、意图、回合和招式；
- 距离、位置、水域、遮挡和撤退；
- 部位伤势、失血、毒素、疼痛和濒死；
- 同伴援助、控制、逃脱和俘虏；
- 第一次杀人的心性后果；
- 首领阶段和机制变化。

## 3. 战斗原则

1. 战斗是高风险事件的一种，不是独立小游戏；
2. 敌人强弱先通过动作、装备和环境表现；
3. 大多数回合显示可读意图，但隐藏一部分后手；
4. 属性决定深度和容错，不直接自动胜利；
5. 逃跑、投降、拖延、谈判和设局都是有效目标；
6. 伤势会进入战斗后的旅行、医治和关系；
7. 死亡提供死因见闻，但不能免费增加战力。

## 4. 战斗状态

```js
{
  battleId: "first_needle_kill",
  round: 1,
  phase: "choose",
  range: "mid",
  terrain: ["alley", "rain", "low_light"],
  participants: [/* 主角、敌人、同伴 */],
  intents: [/* 当前可读意图 */],
  opportunities: [/* 环境机会 */],
  escape: {/* 逃脱进度与封锁 */},
  log: []
}
```

战斗状态只在战斗期间存在；持久后果写回角色伤势、物品、关系和世界状态。

## 5. 回合结构

```text
观察 → 选择目标 → 选择行动 → 同时结算 → 伤势与位置变化 → 新意图
```

每回合界面应提供：

- 当前最危险的敌人动作；
- 自身可用招式、物品和环境行动；
- 行动的世界内风险说明；
- 逃脱或结束战斗的条件；
- 上回合造成的明确变化。

## 6. 行动类别

| 类别 | 示例 |
| --- | --- |
| 攻击 | 钢针穿穴、鱼竿拍腕、近身重击 |
| 防御 | 格挡、闪避、定海稳身、以伤换位 |
| 控制 | 封穴、绊倒、压制兵器、逼入水中 |
| 观察 | 看步法、辨毒、寻找首领暗号 |
| 环境 | 灭灯、翻桌、割船绳、借水流 |
| 物品 | 回春丹、毒粉、绳索、烟火 |
| 关系 | 呼唤援手、劝降、用债务拖延 |
| 撤退 | 拉开距离、抢路、潜水、投降 |

行动可有准备时间和冷却，但不使用复杂能量条。

## 7. 敌人意图与情报

敌人意图分三层：

- 表面动作：任何人可见；
- 武学判断：相关能力达到门槛后可见；
- 因果后手：拥有确证情报或曾死于此招后可见。

例如王卓战：

- 表面：右肩下沉，准备扑近；
- 武学判断：真正发力来自左腿，右手只是诱饵；
- 死亡见闻：第一次闪避后会有藏在袖中的第二击。

## 8. 伤势模型

伤势至少记录：

```js
{
  id: "left_forearm_cut",
  type: "cut",
  bodyPart: "left_arm",
  severity: 2,
  bleeding: 1,
  pain: 1,
  infectionRisk: 0,
  tags: ["limits_needles"],
  source: "snake_gang_blade"
}
```

伤势类型：割裂、钝击、骨伤、内伤、失血、烧伤、毒、穴位阻塞、精神震荡。

严重度建议为一至四：

1. 轻伤：降低少量容错；
2. 明显伤：限制部分行动；
3. 重伤：需要撤退或立即治疗；
4. 致命：进入濒死倒计时。

## 9. 毒与心神状态

毒素由SYS-04定义物质，本系统负责战斗表现：

- 潜伏回合；
- 发作强度；
- 影响属性或行动；
- 可观察症状；
- 解毒、压制和耐受。

心神状态包括恐惧、杀意、迷惑、执念和震慑。它们应减少或改变行动，而不是直接剥夺玩家整场控制权。

## 10. 战斗结束类型

- 击败：敌人失去战斗能力；
- 杀死：明确承担死亡和后续；
- 逼退：敌人撤走，可能再次出现；
- 逃脱：保住性命但失去目标；
- 投降／被俘：进入新的事件；
- 谈判：以情报、物品或关系结束；
- 两败俱伤：完成目标但留下重伤；
- 主角死亡：进入命灯判定。

每场战斗必须声明允许哪些结束类型，不能默认“清空生命值”。

## 11. 命灯与检查点

- SYS-01创建进入战斗前的因果检查点；
- SYS-03确认死亡是否真实致命；
- 有命灯时熄灭一盏并恢复业务状态；
- 保留本次死亡的敌人后手、死因和场景见闻；
- 只剩一盏灯时隐藏已经确证必死且无新信息的重复行动；
- 两灯皆灭进入本局终结，不自动重置所有进度；
- 非致命败北不消耗命灯。

## 12. P0三场验证战

### 第一次钢针杀敌

验证意图、距离、封穴、致命选择和第一次杀人后果。

### 拜师前考验

验证曹青观察、非致命战斗、招式教学和多种结束方式。

### 灵猴冲突

验证不杀目标、食物交换、环境互动和关系结果。

## 13. P1与P2升级

P1增加：

- 多敌人和首领；
- 同伴援助；
- 追逐转战斗；
- 水域和戒严城巷环境；
- 王卓两阶段战；
- 俘虏与审问。

P2增加：

- 帮会据点连续战；
- 名声和敌方准备；
- 毒、金刚、止杀多路线；
- 心神控制和净魂；
- 卧底暴露后的逃亡战；
- 机制接管和非杀清剿。

## 15. 测试矩阵

- 同一敌人意图因武学和死亡见闻显示不同层级；
- 钢针既能止血又能致命，不能同时无代价执行；
- 手臂伤会限制针法但不影响所有行动；
- 逃脱保留伤势并改变事件结果；
- 非致命败北不熄灯；
- 死亡回照不重复消耗物品或奖励；
- 只剩一灯时不显示已确证的必死重复选择；
- 手机端一屏先显示威胁和当前行动。

## 16. 完成标准

P0完成要求至少三场战斗共用同一套规则，且每场都支持攻击以外的结束方式；伤势能被SYS-04治疗，并在后续场景真实限制行动。
