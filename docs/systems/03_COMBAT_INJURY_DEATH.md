# SYS-03 战斗、伤势与死亡系统

## 1. 设计结论

战斗不是脱离剧情的数值小游戏，而是一场可以被读懂、利用和改写的高风险事件。

玩家每回合面对的核心问题不是“用哪招伤害最高”，而是：

> **敌人下一步想做什么，我能否用武学、位置、环境和关系把他的杀招变成自己的机会？**

完整战斗循环为：

> **读势 → 定策 → 出手 → 对招 → 留伤 → 改势 → 达成目的或付出代价离场。**

系统必须支持五种同等有效的解法：

1. 击杀敌人；
2. 制伏、逼退或俘虏敌人；
3. 保护目标并拖到援手到来；
4. 带着情报、同伴或物品撤离；
5. 夺取敌人的武器、位置、暗号或机关，反过来接管战局。

第一阶段不采用棋盘、复杂命中率或长血条。战斗深度主要来自敌人意图、距离、攻守之势、破绽、部位伤势和场景条件。

## 2. 当前可玩基础

现有流程已经实现一段可以作为规则基准的春风针夜战，以及一段灵猴冲突：

- 敌人的持刀逼近和后续动作可以提前观察；
- 玩家可通过灭灯、观察、出针等方式改变交锋条件；
- 同一场战斗包含两轮以上的局势变化；
- 结果包括封穴制伏、致命出针、负伤撤离和死亡；
- 伤势记录部位、严重度与效果标签，并进入后续医治；
- 死亡会熄灭命灯，保留死因记忆并返回最近因果节点；
- 灵猴冲突允许玩家用不同筹码换取不同的脱身路径。

这些内容证明了“可读意图 + 条件行动 + 长期后果”能够成立，但尚未抽成通用规则。当前缺口是：

- 战斗数据仍与具体剧情绑定；
- 五维没有进入行动结算，同一选择不会因力道、根骨、身法、悟性或福缘不同而变化；
- 武境只在突破剧情中出现，未入门与锻体角色在战斗规则中没有本质区别；
- 武学目前主要作为动作开关，入门、熟练、精通没有形成不同把握与效果；
- 没有统一的距离、攻守之势和破绽模型；
- 伤势尚未完整影响招式、移动和旅行；
- 缺少同伴、多人敌手、毒物、追逐与连续战斗；
- 缺少首领阶段转换和战场机关；
- 缺少供后续内容复用的战斗视图与结算接口。

下一步应先在不改变现有夜战结果的前提下抽出通用规则，再用王卓两阶段战验证同伴、首领和水边环境。

### 2.1 成熟系统参考与取舍

本系统不直接复制任何一套规则，只吸收下列已经长期验证的结构：

| 参考 | 成熟做法 | 本项目采用 | 本项目不采用 |
| --- | --- | --- | --- |
| [Pathfinder 2e 规则总览](https://2e.aonprd.com/Rules.aspx?ID=2266) | 一次检定同时加入属性与熟练；结果分为大成功、成功、失败、大失败 | 把“五维天赋”和“武学掌握”作为两个独立来源，并使用四档结果 | 不采用二十面骰，也不把人物等级直接加进所有检定 |
| [Pathfinder 2e 技能规则](https://2e.aonprd.com/Rules.aspx?ID=171) | 原始天赋和训练经验职责不同；更高熟练还会开放普通人不能使用的行动 | 属性决定做法，熟练决定稳定性并开放高阶招式 | 不让单一高属性替代正式传承 |
| [Blades in the Dark 行动规则](https://bladesinthedark.com/action-roll) 与 [效果规则](https://bladesinthedark.com/effect) | 把“成功机会”“行动风险”“产生多大效果”拆开；效果受质量、强度与规模影响 | 把“把握、效力、险势”分开，境界差主要改变效力和受伤严重度 | 不采用压力条、骰池或主持人临场裁定作为核心依赖 |
| [Mythras Imperative SRD](https://srd.mythras.net/) | 身体属性派生先手、伤害、恢复等战斗能力；战斗流派决定技能；优势成功可换缴械、绊倒等特殊效果；伤害落到具体部位 | 五维派生不同战斗职责，优势结果用于制造破绽、封穴、夺械和改位，继续使用部位伤势 | 不采用逐部位生命值和大量动作点 |
| [Pillars of Eternity 攻击结算](https://eternity.obsidian.net/eternity/news/update-39-non-core-classes-cooldowns-attack-resolution-damage-vs-armor-and-a-tileset) | 不同攻击分别对抗偏斜、强韧、反射和意志；结果有落空、擦中、命中、重击 | 不设万能防御值；强攻、暗器、毒和心神招式分别攻不同的“门” | 不采用百分骰和持续削减总生命值 |

从这些参考得到四条明确结论：

1. **属性不能只是伤害加成**：它要决定玩家适合用什么方法破局；
2. **熟练不能只是解锁按钮**：它要决定同一招有多稳定、能否追加战术效果；
3. **境界不能只是更大的命中数字**：它要决定力量能否真正穿透、能承受多少爆发，以及失败会有多严重；
4. **功法不能只是属性包**：每门功法至少要改写一条行动、克制、环境或破境规则。

## 3. 战斗的三层目标

每场战斗必须同时声明三层目标，避免所有遭遇都退化为清空敌人。

### 3.1 眼前目的

玩家进入战斗时明确知道的任务，例如：

- 活过三轮；
- 护住燕惊鸿；
- 夺回账册；
- 阻止敌人敲响铜锣；
- 在官差赶到前离开；
- 逼问出接头地点。

### 3.2 可选成果

玩家通过额外观察或承担风险才能取得：

- 看清敌人武学来路；
- 夺走暗器、令牌或船钥；
- 留下活口；
- 不杀人完成脱身；
- 让某位同伴亲眼看到真相；
- 借敌人的招式毁掉机关。

### 3.3 失败底线

战斗失败不等于死亡。每场遭遇需提前定义可能的底线：

- 带伤逃离；
- 丢失物品；
- 同伴受伤或关系下降；
- 被俘并进入新场景；
- 敌人完成部分目的；
- 真正死亡并触发命灯。

只有满足明确致死条件时才进入死亡结算。

## 4. 核心战斗状态

建议通用战斗状态保持 JSON 可序列化：

```js
{
  battleId: "wang-zhuo-riverside",
  round: 1,
  phase: "tailing",
  objective: {
    primary: "protect-yan-and-leave",
    optional: ["identify-style", "capture-wang"],
    failed: []
  },
  position: {
    range: "near",
    footing: "stable",
    cover: "willow-shadow",
    exits: ["alley", "river"],
    controlledBy: null
  },
  momentum: 0,
  combatLoad: 0,
  fortuneOpenings: [],
  profileSnapshot: {},
  participants: [],
  intents: [],
  openings: [],
  terrain: [],
  statuses: [],
  knownFacts: [],
  roundLog: [],
  outcome: null
}
```

关键字段说明：

| 字段 | 作用 |
| --- | --- |
| `phase` | 当前首领阶段或剧情阶段，决定意图、环境和结束条件 |
| `position` | 不使用格子地图，以距离、落脚、掩体、出口和控制权描述空间 |
| `momentum` | 攻守之势，范围 `-2` 至 `2`，不作为可囤积的法力 |
| `combatLoad` | 本场已经积累的气血与经脉负荷，超过承载后会透支或受伤 |
| `profileSnapshot` | 入场时根据五维、境界、武学、伤势派生的角色战斗档案 |
| `fortuneOpenings` | 入场时由福缘确定的偶合机会，生成后不因临战改点反复刷新 |
| `intents` | 玩家本轮已经看见或推测出的敌方行动 |
| `openings` | 有时限的破绽、机会和可利用条件 |
| `knownFacts` | 已经看破的招式、习惯、毒性与场景规则，死亡回照后可保留 |
| `outcome` | 击杀、制伏、逼退、撤离、被俘、目的达成或死亡等结局 |

### 4.1 人物能力进入战斗的五层职责

同一个行动依次读取五层人物能力，任何一层都不能被另一个总战力数字替代：

| 层级 | 回答的问题 | 规则职责 |
| --- | --- | --- |
| 五维 | 角色用什么办法做这件事？ | 提供行动把握、防御门、读势深度和特殊机会 |
| 武学掌握 | 这套办法练得有多熟？ | 开放招式、增加稳定性、允许选择优势效果 |
| 武境 | 这股力量到达什么层次？ | 决定效力上限、境界压制、负荷承载和受伤严重度 |
| 具体功法 | 这一门传承违反了哪条常规？ | 改变距离、属性用法、克制、环境或结束条件 |
| 情报与场景 | 如何让弱者有机会破阶？ | 制造破绽、针对弱点、取消特定境界差 |

最重要的职责边界是：

> **五维与熟练决定“能不能做好”，境界决定“做好以后有多大用”，功法决定“是否能用不同规则做到”。**

### 4.2 五维的战斗职责

五维不是五种攻击力。每项属性要同时影响至少一种主动做法和一种被动承受：

| 五维 | 主动作用 | 被动作用 | 不负责的内容 |
| --- | --- | --- | --- |
| 力道 | 强攻、压制、格开重兵、夺械、破门 | 抵抗擒抱和正面推挤 | 不自动提高暗器精度 |
| 根骨 | 运劲、强行续招、压毒、带伤护人 | 承受冲击、毒性、失血和经脉负荷 | 不自动识破虚招 |
| 身法 | 抢先、闪避、换位、追击、撤离 | 对抗暗器、夹击和落脚变化 | 不自动穿透护体 |
| 悟性 | 识招、精确封穴、临阵变式、寻找克制 | 抵抗佯攻、心神诱导和错误判断 | 不替代身体承载 |
| 福缘 | 在入场时发现偶合条件、意外出口或可借之物 | 在致命后果发生前提供一次有代价的转机 | 不提供随机命中，也不能每回合重掷 |

福缘按入场时的有效值生成并锁定：

| 有效福缘 | 战斗表现 |
| --- | --- |
| `0～2` | 只使用场景本来公开的机会 |
| `3～4` | 额外揭示一项合理的偶合机会，如松动船索、未熄药炉、经过的巡船 |
| `5～6` | 除偶合机会外，首次进入危急险势时可选择付出物品、关系或伤势换取生路 |
| `7+` | 可在一项偶合机会出现时二选一，但仍不能凭空令敌人暴毙或自动获胜 |

### 4.3 四道对抗门

行动不能都对抗同一个“防御值”。根据做法选择目标的对抗门：

| 对抗门 | 主要来源 | 被什么行动针对 |
| --- | --- | --- |
| 护架 | 力道、根骨、兵器和防守武学 | 正面刀剑、重击、擒拿、推挤 |
| 机先 | 身法、轻功、落脚和警觉 | 暗器、抢位、绕后、追逃 |
| 定元 | 根骨、境界、桩功和抗性 | 毒、点穴、内伤、震劲和持久消耗 |
| 守神 | 悟性、见闻、心神法和关系 | 虚招、威吓、魅惑、杀意与误导 |

例如春风针封腕通常以“悟性主、身法辅”对抗敌人的机先；力灌银针破护体则以“力道主、悟性辅”对抗定元。两种做法使用同一门武学，却要求不同人物配置并承担不同风险。

第一版建议按下式派生，所有武学修正只取与当前对抗门直接相关的一项：

```text
护架 = max(有效力道, 有效根骨) + 防守武学修正 + 兵器或掩体
机先 = 有效身法 + floor(有效悟性 / 2) + 轻功或身法修正
定元 = 有效根骨 + 境界掌控 + 桩功或抗性修正
守神 = 有效悟性 + floor(有效根骨 / 2) + 心神法或已知情报
```

`境界掌控`依次为未入门 `0`、锻体 `1`、聚气 `2`、通脉 `3`、宗师 `4`。它只进入身体与内息相关的定元，不作为所有检定的通用加值。

### 4.4 武境的四项实际作用

武境不能只显示在人物卡上。每一境至少提供四类规则变化：

| 武境 | 权限 | 境界效力 | 基础承载 | 典型威胁 |
| --- | --- | --- | --- | --- |
| 未入门 | 通用动作与已入门的基础招式 | 只能稳定发挥凡俗兵器和身体力量 | `0` | 一次重伤即可终止连续作战 |
| 锻体 | 完整发力、桩功护体、连续使用正式招式 | 对凡俗目标可造成标准效力 | `2` | 正面击破门板、受创后仍能行动 |
| 聚气 | 招式附带内劲，可攻经脉与隔甲伤身 | 对无内劲防护者提高一档效力 | `4` | 普通格挡只能减伤，难以完全化解 |
| 通脉 | 内息连续运转，可隔空发劲、踏水疾行 | 可跨越部分距离和护具限制 | `6` | 战场空间规则开始被武者改写 |
| 宗师 | 精神与气机影响一片战场 | 以个人力量对抗多人和大型机制 | `8` | 普通遭遇不再以正面对战为合理目标 |

实际承载为：

```text
承载 = 境界基础承载 + floor(有效根骨 / 2) + 桩功与身体特征修正
```

高承诺招式产生 `1～3` 点负荷。负荷达到承载时，角色进入“气血浮动”；超过承载则必须选择停手、降低效力或承受经脉伤。界面只显示“从容、浮动、透支”，不要求玩家心算。

### 4.5 境界压制与破阶

境界差不直接让低境界角色无法点击按钮，而是同时改变效力与险势：

| 境界差 | 低境界者的正面对抗 |
| --- | --- |
| 同境 | 正常结算 |
| 低一境 | 直接伤害效力降低一档；承受对方完整攻击时伤势提高一档 |
| 低两境 | 无破阶条件时直接攻击为零效力；高承诺失败可直接形成致命伤 |
| 低三境及以上 | 不作为可正面取胜的战斗；目标改为逃离、拖延、谈判、救人或启动预设机关 |

玩家可以获得“破阶优势”：

- 已验证的招式弱点；
- 正好克制的功法或兵器；
- 敌人已有的部位重伤、毒性或内息紊乱；
- 对自己功法极有利的地形；
- 成功伏击、多人合击或提前布置的机关；
- 敌人必须保护某物、无法全力出手的任务约束。

每项有效优势只为对应行动抵消一层境界差。抵消的是“这一次如何破局”，不是把玩家整场临时升到更高境界。

## 5. 一回合如何进行

每回合固定分为七步，界面不必逐步弹窗，但规则结算顺序必须稳定。

### 5.1 先算把握、效力与险势

每个行动必须分别给出三个结论：

1. **把握**：这次动作能否按预想执行；
2. **效力**：即使做成，能对目标和战局造成多大改变；
3. **险势**：若被敌人反制，玩家会承担多严重的后果。

#### 把握

底层使用确定性差值，不显示随机命中率：

```text
行动值 = 主属性
       + floor(辅属性 / 2)
       + 武学熟练
       + 攻守之势
       + 破绽与情境
       + 同伴协助
       - 部位伤势
       - 透支影响

把握差 = 行动值 - 目标对抗值
```

武学熟练修正为：入门 `0`、熟练 `+1`、精通 `+2`、突破 `+3`。只持有秘籍或只知道名称不能使用正式招式。

| 把握差 | 结果 | 战术含义 |
| --- | --- | --- |
| `3+` | 上成 | 完成目的，并可从当前招式允许的优势效果中选择一项 |
| `0～2` | 做成 | 完成行动的标准结果 |
| `-2～-1` | 苦成 | 达成主要目的，但承受当前险势对应的代价或降低一档效力 |
| `-3` 以下 | 失手 | 未达成目的，敌人意图兑现或战局恶化 |

#### 效力

效力分为“无效、有限、标准、显著、终结”五档：

```text
效力 = 招式基础效力
     - 未抵消的境界差
     + 针对性克制
     + 武器或功法强度
     + 破阶优势
     + 环境适配
```

高把握不等于高效力。未入门高手可能准确把钢针射中聚气武者，却只能逼其偏头；若先以毒扰乱内息、看破换气停顿，再用春风针取穴，才可能得到标准甚至显著效果。

#### 险势

险势分为“从容、有险、危急”：

- 从容：失败只失去机会、位置或一件小资源；
- 有险：失败会失势、受轻中伤、同伴受威胁或目标推进；
- 危急：失败会受重伤、被俘、失去关键人物，或进入明确致死条件。

境界更高的敌人、失衡落脚、高承诺招式、已有重伤和未看破后手都会提高险势。掩体、同伴保护、已确认情报和克制功法可以降低险势。

行动按钮因此显示为：

```text
春风针·封腕
把握：苦成｜效力：标准｜险势：有险
悟性 3/3 · 身法 1/2 · 春风针入门
做成：封住持刀手；代价：你会被左袖短刃擦伤
```

### 5.2 敌人露势

敌人根据性格、武学、伤势和当前目的生成意图。玩家至少能看到最危险的一项表面动作。

示例：

> 王卓右肩微沉，刀锋却贴在腿侧。他在等你护住上路，再从袖中打出第二件东西。

### 5.3 玩家读势

系统根据观察、悟性、已知情报、武学和环境显示不同深度的信息：

- 只看见动作；
- 判断攻击范围和目标；
- 看穿佯攻；
- 发现后手；
- 找到可以反用的破绽。

已看破的事实进入 `knownFacts`。对同一招再次交锋时，不要求玩家重复花一回合观察。

### 5.4 玩家定策

玩家从当前可用行动中选择一项主要行动；部分低承诺动作可作为附带动作。每个按钮必须显示：

- 想达到什么；
- 需要什么条件；
- 会消耗什么；
- 最主要的风险；
- 可能改变哪项局势。

### 5.5 同时对招

敌我行动按“检查行动权限 → 计算把握 → 计算效力 → 确定险势 → 应用境界压制 → 结算优势效果与代价”统一处理，而不是简单轮流扣血。

### 5.6 留下后果

依次处理：

1. 位置和出口变化；
2. 攻守之势变化；
3. 破绽生成或消失；
4. 伤势、失血、毒性和心神状态；
5. 物品、同伴、环境和任务变化。

### 5.7 判断结束

先检查目的是否达成，再检查撤离、制伏、被俘和死亡。若战斗继续，则生成下一轮意图。

## 6. 空间：不用棋盘也要有位置

### 6.1 距离

距离只设四档：

| 距离 | 典型行为 |
| --- | --- |
| 贴身 | 擒拿、短刃、封穴；长兵器难以展开 |
| 近距 | 刀剑、拳掌、短距离挪步 |
| 中距 | 钢针、长杆、飞石、冲刺 |
| 远距 | 弓弩、追逐、撤退和寻找掩体 |

招式不直接写“射程 2”，而写允许距离和改变距离的结果。

### 6.2 落脚

`footing` 表示当前能否稳定发力：

- 稳固：可以完整运劲；
- 受限：泥地、狭巷、船舱、拥挤人群；
- 失衡：被逼到水边、踩空、被勾住兵器；
- 倒地：只能使用少量应急行动。

海桩等武学可以把水边“受限”转为“稳固”，这比单纯增加伤害更能体现武学特色。

### 6.3 掩体、出口与控制权

场景至少提供一种可利用环境和一个出口：

- 灯火可以被扑灭；
- 桌案可以阻挡直线暗器；
- 柳树可以隐藏同伴；
- 船索可以绊人或放船；
- 狭门一次只能通过一人；
- 铜锣若被敌人控制，会召来援兵。

控制关键位置不是装饰。它应改变可用行动、敌人意图或结束条件。

## 7. 攻守之势与破绽

### 7.1 攻守之势

`momentum` 取值如下：

| 数值 | 名称 | 含义 |
| --- | --- | --- |
| `-2` | 受制 | 下一次高承诺行动极易被截断 |
| `-1` | 失势 | 只能稳住、冒险反击或寻找出口 |
| `0` | 相持 | 双方都能执行正常行动 |
| `1` | 得势 | 可以逼位、连续压迫或安全观察 |
| `2` | 压制 | 可尝试制伏、夺械或决定性一击 |

攻守之势每场战斗重新计算，不带出战斗，也不能无限累积。强力终结动作通常需要“得势/压制 + 对应破绽”，避免起手秒杀，也避免靠磨血收尾。

### 7.2 破绽

破绽是有来源、有时限、可被特定行动利用的条件：

```js
{
  id: "exposed-wrist",
  targetId: "wang-zhuo",
  source: "failed-sleeve-dart",
  expiresAfterRound: 3,
  tags: ["hand", "disarm", "acupoint"],
  revealed: true
}
```

常见破绽包括：

- 手腕外露：可封穴或夺械；
- 重心前倾：可借力推入水中；
- 换气停顿：可打断心法；
- 视线被遮：可救人或撤退；
- 同伴被牵制：敌人不能兼顾出口；
- 杀意锁定主角：被保护者可自行离场。

破绽应由玩家行为制造，不能只靠随机出现。

## 8. 敌人意图与看破层级

每个敌方意图包含三层信息：

```js
{
  actorId: "wang-zhuo",
  telegraph: "右肩抬起，刀锋指向你的面门",
  actionId: "high-feint-low-dart",
  targetId: "player",
  danger: "severe",
  layers: {
    surface: "上路挥刀",
    technique: "逼你抬手护面",
    followUp: "袖箭取腿，封住退路"
  },
  confidence: "suspected"
}
```

信息分三级开放：

1. **露势**：所有玩家都能看见表面动作和大致危险；
2. **识招**：属性、武学或一次亲历后看见攻击目标、距离和主要后果；
3. **破招**：结合情报、观察和环境，看见后手及可制造的破绽。

错误判断必须来自敌人的欺骗能力或玩家掌握的信息不足，不使用毫无提示的随机反转。界面用“看准”“推测”“未明”标示可靠度。

## 9. 玩家行动模型

所有行动使用同一结构：

```js
{
  id: "spring-needle-seal-wrist",
  label: "春风针·封腕",
  category: "technique",
  target: "enemy",
  skillId: "spring_rain_needles",
  masteryRequired: "entered",
  approaches: [
    {
      id: "precise",
      label: "看准穴位再发针",
      primaryAttribute: "insight",
      secondaryAttribute: "agility",
      opposedDefense: "initiative"
    },
    {
      id: "fast",
      label: "抢在拔刀前出针",
      primaryAttribute: "agility",
      secondaryAttribute: "insight",
      opposedDefense: "initiative"
    }
  ],
  requires: {
    range: ["near", "middle"],
    momentumAtLeast: 1,
    openingTags: ["hand", "acupoint"],
    usableBodyParts: ["right-arm"]
  },
  costs: { needle: 1 },
  load: 0,
  commitment: "medium",
  baseEffect: "standard",
  effectTags: ["acupoint", "precision", "nonlethal"],
  counters: ["hard-cover", "deflect-projectile"],
  results: ["disable-weapon-hand", "capture-window"],
  superiorResults: ["disarm", "keep-momentum"],
  risks: ["lose-momentum-on-failure"]
}
```

### 9.1 行动类别

| 类别 | 作用 |
| --- | --- |
| 观察 | 看清后手、武学、出口或机关；会让出部分主动权 |
| 身法 | 改变距离、落脚、掩体和出口控制 |
| 防守 | 接架、闪避、护人、卸力，为下一回合稳住局势 |
| 招式 | 攻击、封穴、夺械、打断、压制或制造破绽 |
| 物品 | 暗器、药物、绳索、火折、信物等 |
| 环境 | 灭灯、断索、翻桌、入水、关门、敲锣 |
| 同伴 | 请求掩护、夹击、救人、递物或撤离 |
| 言语 | 威慑、拖延、揭破身份、动摇立场或诱导目标 |
| 离场 | 撤退、投降、放船、带人突围或假意被俘 |

### 9.2 承诺程度

- 低承诺：观察、试探、短步，不易遭到重罚，收益也有限；
- 中承诺：正常招式、护人、使用环境，失败会失势或负轻伤；
- 高承诺：绝招、夺械、救下必死者、强行突围，成功可结束阶段，失败会产生重伤或致死条件。

高风险按钮必须提前说明主要代价，不用模糊的“试试看”。

### 9.3 不显示命中率

界面不显示百分比命中率。行动结果由已知条件决定，并展示为：

- 稳妥：当前条件足够，主要结果确定；
- 有险：能达成目的，但将承担已知代价；
- 冒险：仍有一项关键条件未知；
- 必死：已亲历并确认的直接死亡路线。

如内容需要不确定性，应从敌人未揭示意图、伤势恶化或场景变化产生，而不是暗骰让同样条件得到任意结果。

### 9.4 同一招允许不同属性做法

属性不应固化为“力道只能攻击、悟性只能观察”。一式武学可以提供两到三种合理做法，但每种做法的风险、效力和对抗门不同。

以《打鱼杆法》的“缠腕”为例：

| 做法 | 主／辅属性 | 对抗门 | 特点 |
| --- | --- | --- | --- |
| 快线抢腕 | 身法／悟性 | 机先 | 抢先控制，失败容易被近身 |
| 借势拖拽 | 悟性／力道 | 护架 | 需要敌人前冲的破绽，成功可令其失衡 |
| 强拉夺刀 | 力道／根骨 | 护架 | 不要求复杂判断，但遇到高境界护体时效力下降明显 |

这样高力道角色、灵巧角色和善于识招的角色都能使用同一门杆法，却不会得到完全相同的按钮与结果。

### 9.5 逆天改命在战斗中的规则

战斗外仍可自由重分已经拥有的五维点数。进入敌我已经互相出手的状态后，当前分配记为 `combatAllocation`：

- 重分不是额外消耗命灯或永久资源；
- 但调整呼吸、站位和发力方法需要一个“改命换势”行动；
- 在得势或有掩体时使用，攻守之势回到相持；
- 在失势时强行使用，敌人的当前意图照常兑现，通常属于危急险势；
- 入场时生成的福缘机会不随重分刷新；
- 已经产生的伤势与负荷不会因为把点数移到根骨而消失，只改变后续承受和治疗条件。

这保留“为眼前难题重分属性”的独特玩法，同时避免每点一个战斗按钮就无代价地自动换成最优五维。

## 10. 武学必须改变行动规则

武学不以“攻击力 +10%”为主要差异，而要改变玩家能看见、能承受和能完成的事情。属性代表使用者，境界代表力量层次，武学本身必须提供具体的规则身份。

### 10.1 武学类别在战斗中的职责

| 类别 | 进入结算的位置 | 例子 |
| --- | --- | --- |
| 心法 | 负荷恢复、属性替代、特定环境效力和越阶条件 | 鱼跃龙门诀在水势中提供破阶优势 |
| 桩功 | 承载、落脚、伤势容忍和防御门 | 海桩稳住机先，枯木桩稳住定元 |
| 招式 | 提供主动行动、对抗门、基础效力和优势结果 | 春风针封穴，打鱼杆法缠腕 |
| 轻功 | 先手、距离、追逃和出口 | 踏水九连环跨越水面出口 |
| 奇术 | 改变意图、杀意、部位或结束条件 | 飞星定穴允许活捉，止杀诀改变杀意后果 |
| 毒功 | 以潜伏状态攻击定元，制造破阶条件 | 盘蛇毒经令高境界敌人内息紊乱 |

### 10.2 掌握度不能只是加值

掌握度既影响把握，也逐级开放规则：

| 掌握状态 | 战斗作用 |
| --- | --- |
| 已知 | 只知道名称与来历，可能帮助识别敌人使用 |
| 持卷 | 可研读，不能在实战中使用正式招式 |
| 入门 | 解锁基础招式；熟练修正 `0`；高压下容易只有苦成 |
| 熟练 | 熟练修正 `+1`；解锁第二种属性做法或一个优势结果 |
| 精通 | 熟练修正 `+2`；可以忽略一项常见限制或形成稳定克制 |
| 突破 | 熟练修正 `+3`；改变距离、境界、环境或结束条件中的一条规则 |

掌握度的提高不得只写成更高修正。每升一档至少增加下列一项：

- 新做法；
- 新目标部位；
- 新优势结果；
- 更低负荷；
- 一项克制；
- 一种非杀戮结束方式；
- 一个可以抵消境界差的限定条件。

### 10.3 功法协同

多门功法不是把所有数值相加，而是组成一条“准备 → 出手 → 承受 → 收尾”的链：

```text
鱼跃龙门诀看懂水势
→ 海桩在湿滑河岸维持稳固
→ 打鱼杆法制造手腕破绽
→ 春风针封穴完成制伏
```

协同成立时只在具体一步提供效果，例如海桩不能增加春风针在旱地的把握，鱼跃龙门诀也不能让所有招式永久视为高一境界。

### 10.4 春风针

定位：中近距离观察、封穴与精确终结。

- 入门：以悟性／身法封住已经露出的手腕、腿弯或肩井；
- 熟练：可以在“精准”和“抢先”两种属性做法间选择，并在上成时保住攻守之势；
- 精通：看破换气后可攻击定元，而非只对抗机先；
- 突破：面对高一境界者时，“已确认穴位破绽”可作为一项破阶优势；
- 得势且有破绽：封穴制伏，不必杀人；
- 高承诺：致命出针，基础效力提高一档，但产生杀人、证据与关系后果；
- 限制：钢针数量、手臂伤势、遮挡和贴身压迫。

### 10.5 鱼跃龙门诀与打鱼杆法

定位：控制距离、借力改位和水边作战。

- 心法入门：水中身法相关行动降低一档险势；
- 心法熟练：水边首次失势时可以借流回到相持；
- 心法突破：战胜高境界敌人后推进，同时在逆流、水下或船战中提供一项破阶优势；
- 杆法入门：钩住兵器或衣袖，改变距离；
- 杆法熟练：可以选择快线、借势或强拉三种属性做法；
- 借敌人前冲之力使其失衡；
- 在水边夺取落脚和出口，并把环境优势传给下一式；
- 拉回同伴或关键物品；
- 面对重兵器时不硬拼，以缠、引、卸改变攻守之势。

### 10.6 海桩

定位：水势、湿滑地面和推挤中的稳定。

- 将水边受限落脚视为稳固；
- 被推、拉、浪涌影响时少失一档攻守之势；
- 有效根骨参与承载，海桩熟练时水边再增加一点承载；
- 可以在浅水中完成他人无法稳定使用的招式；
- 不能免除溺水、重伤或水下闭气需求。

### 10.7 枯木桩

定位：忍痛、护身与伤后反击。

- 轻伤不会立刻中断动作；
- 可暂时压住失血或毒性一轮；
- 毒与内伤首先对抗由根骨和枯木桩形成的定元；
- 重伤时仍能完成一次护人或撤离动作；
- 代价是战后伤势可能加重，不能把受伤变成免费收益。

后续猿公棍等武学也按同一原则设计：至少增加一种新行动、改变一种场景条件，并提供一种独特的结束方式。

### 10.8 两个完整结算示例

#### 春风针夜战：同样五点属性，三种打法

刀客尚未显露左袖短刃时，玩家拥有《春风化雨针》入门和五点可调属性：

| 临战分配 | 能稳定做到 | 明显短板 | 形成的路线 |
| --- | --- | --- | --- |
| 悟性 `5` | 观察时直接看穿虚招；精准发针对机先有较高把握 | 身法为零，被贴身后很难换位 | 先读势，再用手腕破绽封穴 |
| 身法 `3`、悟性 `2` | 能抢先灭灯、绕位或用快针打断拔刀 | 守神不足，未必看懂左袖后手 | 先改变位置；若没有死亡见闻，快攻仍属有险 |
| 力道 `3`、根骨 `2` | 可翻桌架刀、强行撞开出口，受创后仍有撤退余地 | 针法把握和识招都弱 | 不求制伏，换一次带伤突围 |

武学掌握和境界继续改变同一场战斗：

- 只有秘籍、尚未入门：不能使用“封腕”，只能把钢针当普通暗器；
- 春风针熟练：上成时可选择“夺下短刃”或“封穴后保持得势”；
- 未入门：被短刃完整刺中通常直接形成重伤；
- 锻体且枯木桩熟练：同样受击可把后果降为受创，但会积累负荷；
- 锻体且海桩熟练：雨地换位不再视为受限落脚，可以走不同的绕后路线。

因此玩家不是因为“有针”就得到固定答案，而是人物卡真正改变能看见什么、能执行什么、能承受什么以及最后能带走什么。

#### 锻体对聚气：高把握不等于能破防

陈司命以锻体境、悟性和春风针准确命中王卓的手腕，但王卓若为聚气境，双方相差一境：

1. 没有准备时，封腕把握可能为“做成”，但效力从标准降为有限，只能令其出刀稍慢；
2. 若已看破左手换气停顿，得到“穴位破绽”，抵消一层境界差，封腕恢复标准效力；
3. 若又在河岸以鱼跃龙门诀借水、海桩稳身、杆法缠住手腕，行动可达到显著效力并制造制伏窗口；
4. 若玩家只把力道堆高正面硬刺，命中并不自动穿透内劲，失败险势反而因境界差升到危急。

这里的越阶胜利来自“属性适配 + 功法协同 + 已知弱点 + 地形”，而不是低概率暴击或隐藏战力比较。

## 11. 伤势与身体功能

### 11.1 伤势结构

```js
{
  id: "knife-cut-left-arm",
  type: "cut",
  bodyPart: "left-arm",
  severity: 2,
  bleeding: 1,
  pain: 1,
  infectionRisk: 1,
  tags: ["grip-weakened", "needs-bandage"],
  source: "temple-knife-fighter",
  treated: false
}
```

### 11.2 部位影响

| 部位 | 典型影响 |
| --- | --- |
| 头颈 | 观察失真、眩晕、失声或快速致死 |
| 手臂 | 持械、发针、攀爬、护人受限 |
| 躯干 | 运劲、呼吸、承受冲击和持续行动受限 |
| 腿脚 | 移动距离、稳定落脚和撤退受限 |
| 经脉 | 心法、爆发招式和恢复受限 |

### 11.3 严重度

| 等级 | 状态 | 规则后果 |
| --- | --- | --- |
| 1 | 轻伤 | 提醒与轻微限制，简单处理后可继续 |
| 2 | 受创 | 禁用部分行动或提高对应行动风险 |
| 3 | 重伤 | 持续恶化，需要撤离、同伴或紧急医治 |
| 4 | 致命 | 进入明确倒计时，若不解除则死亡 |

伤势不是另一根血条。一次精准钢针可以直接造成“持刀手失用”，一次胸腹重击也可能让角色仍未死亡却无法继续护人。

### 11.4 战后处理

战斗结算后必须给出伤势去向：

- 当场包扎：止血但不治愈；
- 运功压制：换取赶路时间，之后可能反噬；
- 求医：消耗钱、时间或人情；
- 同伴照料：改变关系并暴露秘密；
- 放任恶化：进入感染、残损或新的奇遇条件。

伤势必须进入旅行、修炼、谈判和下一场战斗，直到被真实处理。

## 12. 毒、心神与持续状态

毒物至少包含：

```js
{
  id: "black-water-paralysis",
  latentRounds: 1,
  intensity: 2,
  symptoms: ["numb-fingers", "slowed-breath"],
  progression: ["grip-loss", "unable-to-move"],
  suppressBy: ["medicine", "deadwood-breath"],
  cureBy: ["matching-antidote"]
}
```

毒性以症状和发作阶段提示，玩家观察得越深，越能判断剩余时间和对症方法。

心神状态包括恐惧、杀意压迫、魅惑、执念和威吓。它们改变可用行动、可靠度或风险，例如“恐惧时无法选择高承诺逼近”，但不能直接夺走所有选择。玩家始终至少保留稳住、观察、求助或撤离中的一项。

## 13. 同伴参战

同伴不是第二个需要玩家逐招操作的角色。每回合玩家只为同伴指定一个意图：

- 护住自己；
- 牵制某人；
- 保护目标；
- 控制出口；
- 准备救援；
- 立即撤离。

同伴是否执行及执行深度由以下条件决定：

- 信任和关系；
- 是否理解玩家的计划；
- 是否触碰其底线；
- 自身伤势和武学；
- 玩家是否兑现过承诺。

高信任不是数值增伤，而是让同伴愿意承担风险、配合假动作或相信看似荒唐的命令。低信任同伴可能拒绝送死，但不能无提示地随机背叛。

同伴受伤、杀人、被放弃或被保护都会写回关系与后续剧情。

## 14. 多名敌人

多人战不让每个杂兵都拥有完整回合。敌人按战术角色组成一个威胁队列：

| 角色 | 功能 |
| --- | --- |
| 突击 | 直接逼近并制造伤势 |
| 封路 | 控制出口、船只或狭门 |
| 掠阵 | 等待玩家失势后补刀 |
| 暗器 | 迫使玩家寻找掩体或分心 |
| 投毒 | 推动持续倒计时 |
| 传讯 | 召来援手或启动机关 |

每轮突出一个主要危险和至多两个次要威胁。玩家的行动可以打断某个角色、改变队形，或让两个敌人的目的彼此冲突。

清理弱敌应通过一次成功的范围控制、威慑、断后或首领崩溃完成，避免逐个消耗长血条。

## 15. 首领阶段

首领转阶段必须由规则或剧情变化触发，不只依赖剩余气血。

常见触发方式：

- 身份或武学被看破；
- 关键机关被夺取；
- 同伴撤离或入场；
- 战场从巷口转到河岸；
- 首领第一次负伤后改用禁招；
- 玩家毁掉其任务目标，使其从灭口转为逃命。

### 王卓两阶段战示例

#### 第一阶段：柳巷尾随

眼前目的：护住燕惊鸿，确认跟踪者是谁。

- 王卓不急着杀人，先试探玩家是否拿到账册；
- 玩家可借柳影观察、分开诱敌或让燕惊鸿先走；
- 看破袖箭后获得“左手后手”事实；
- 逼王卓失势、主动退到河岸或燕惊鸿被截住时进入第二阶段。

#### 第二阶段：河岸截命

眼前目的根据前一阶段变化：

- 若燕惊鸿已离开：玩家可撤退、制伏或追问幕后者；
- 若燕惊鸿仍在场：必须同时处理她与出口；
- 若袖箭未被看破：王卓保留一次隐藏致伤后手；
- 若玩家掌握鱼跃龙门诀与海桩：可借水边夺位，将其逼入浅水；
- 若选择杀死王卓：快速断线，但失去活口并改变龙青鱼态度；
- 若制伏：需要压制之势、手腕破绽和同伴看守；
- 若夺取令牌放他离开：可尾随进入帮会据点，但敌方会提高戒备。

同一战斗因此同时验证心法、环境、同伴、情报和长期路线，而不是只验证战力。

## 16. 战斗结束与长期后果

统一的 `outcome.type` 包括：

- `objective-complete`：任务完成，无需继续交锋；
- `enemy-killed`：敌人死亡；
- `enemy-subdued`：敌人被制伏或俘虏；
- `enemy-routed`：敌人逃走或被逼退；
- `player-escaped`：玩家带着当前成果离场；
- `player-captured`：进入俘虏剧情；
- `mutual-injury`：双方带伤中止；
- `player-dead`：满足致死条件，进入命灯流程。

结算至少写回：

```js
{
  result,
  objectives,
  wounds,
  consumedItems,
  gainedItems,
  relationshipChanges,
  learnedFacts,
  witnesses,
  deaths,
  factionConsequences,
  nextScene
}
```

杀死、制伏和放走同一敌人必须产生不同后果：

- 杀死：立即消除威胁，但制造尸体、目击、心性和关系问题；
- 制伏：难度最高，可审问和交换，但要处理看守与逃脱；
- 放走：保留尾随、传假消息或长线关系，也可能让敌方提前备战。

## 17. 命灯、死亡与死因记忆

### 17.1 检查点

重大交锋前建立因果节点，记录进入战斗前的业务状态。节点不能放在已经承担伤害之后，避免状态重复结算。

### 17.2 真正死亡

只有出现以下情况之一才触发死亡：

- 致命伤倒计时归零；
- 玩家选择已经明确标注的致死行动；
- 场景规则明确无生还条件；
- 两盏命灯均已熄灭后的最终死亡。

负伤、昏迷、被俘和任务失败都不是死亡。

### 17.3 回照保留内容

熄灭一盏命灯后，回到最近因果节点，并保留：

- 直接死因；
- 亲眼看见的敌人招式与后手；
- 已确认的场景规则；
- 玩家经历过的关键对话和身份信息。

不保留已经消耗的战斗奖励、伤势、缴获和关系结果。已知事实会改变下一次战斗的意图展示和行动条件，但不会直接增加伤害。

### 17.4 防止反复送死刷收益

- 同一死因只首次生成新的死因见闻；
- 已知必死行动在只剩一盏命灯时隐藏或禁用；
- 重复看破的招式不再次给予奖励；
- 回照后的优势来自新选择，不来自叠加永久数值。

## 18. 手机界面结构

战斗页保持单列，信息顺序固定：

1. 场景标题与一句眼前困境；
2. 当前主要目的；
3. 双方武境与玩家当前临战五维；
4. 最危险的敌人意图；
5. 距离、落脚、攻守之势与气血负荷；
6. 玩家与同伴的关键伤势；
7. 三至六个当前行动，每项显示把握、效力、险势和参与结算的属性／功法；
8. 最近一轮结果；
9. 可折叠的已知事实、功法协同和更早战报。

建议示意：

```text
河岸截命 · 第二轮
护住燕惊鸿，并找到离开河岸的路

王卓：刀锋压向你，左袖仍贴着肋下
推测：正面是虚招，袖中后手未明

你：锻体｜悟性 3 · 身法 2｜春风针熟练
王卓：聚气｜高你一境
近距｜湿滑｜失势｜气血从容
你：左臂刀伤（发针受限）
燕惊鸿：退路被封

[海桩接刀] 把握：做成｜效力：标准｜险势：有险
[钓线缠腕] 把握：苦成｜效力：标准｜险势：有险
[春风针封左腕] 把握：做成｜效力：有限｜险势：危急
[翻入河中撤离] 把握：做成｜效力：标准｜险势：有险
```

界面不使用传统红蓝血条。敌我状态用“从容、戒备、失势、负伤、重伤、濒死”等可读词语表达。

数字键 `1`～`9` 继续对应当前可用行动，禁用按钮必须解释缺少的条件。

## 20. 数值与节奏边界

- 普通交锋以 `2～5` 轮结束；
- 首领战以 `4～7` 轮和 `2～3` 个阶段为上限；
- 每轮展示 `3～6` 个有意义的行动；
- 每场至少有一种非杀戮解法和一种撤离或失败底线；
- 首次观察可以花费主动权，已确认事实永久免除重复观察；
- 同一种最优行动不能连续解决所有意图；
- 任一行动只读取一个主属性、一个辅属性和一项直接相关的熟练修正，禁止同一能力重复计入；
- 境界差不加入所有行动值，只改变权限、定元、效力、负荷和后果严重度；
- 属性重分必须产生新的临战长短板，不能自动替玩家选出当前最优分配；
- 伤势数量保持少而清晰，同一部位同类轻伤优先合并或升级；
- 不用敌人血量膨胀延长战斗，用阶段、目的和规则变化增加深度；
- 强敌可以让玩家无法正面获胜，但必须保留拖延、欺骗、撤离或利用环境的可能。

## 21. 单场战斗编写清单

新增一场战斗前必须回答：

1. 玩家为什么现在必须出手？
2. 不杀敌也能达成的主要目的是什么？
3. 敌人真正想要什么，而不只是“杀死玩家”？
4. 第一轮玩家能自然看见什么危险？
5. 这一战分别让哪项五维、哪个武境特征和哪门已有功法发挥作用？
6. 哪个后手需要观察、亲历或旧情报才能看破？
7. 场景中至少哪一件东西可以改变战局？
8. 同一招能否根据两种合理属性做法产生不同打法？
9. 功法掌握提高一档后具体增加什么规则，而不只是数值？
10. 如何制造破绽，如何把破绽转化为制伏或终结？
11. 若敌人高一境或两境，玩家需要哪些破阶优势？
12. 负伤、撤退、被俘、制伏和杀死分别进入哪里？
13. 同伴或关系如何改变选择，而不是只提供伤害？
14. 死亡会留下哪条具体见闻？
15. 这场战斗改变了哪条后续剧情或势力状态？

若只能回答“敌人血量归零”，该战斗尚未达到制作标准。

## 22. 测试矩阵

### 22.1 纯规则测试

- 相同状态与行动得到可重复结算；
- 同一招在不同五维分配下产生不同把握、可用做法或险势；
- 主属性、辅属性和熟练修正各只计入一次；
- 只有秘籍而未入门时不能使用正式招式；
- 入门、熟练、精通和突破分别开放约定的规则能力；
- 同属性同武学下，未入门与锻体的承载、效力和伤势后果不同；
- 高一境使正面对抗效力下降，高两境在无破阶条件时为零效力；
- 弱点、克制功法和有利环境分别只能抵消其声明的一层境界差；
- 高把握但低效力的行动能成功命中，却不能错误地造成制伏或重伤；
- 福缘机会按入场值生成，临战重分不会重复刷新；
- 战中重分属性会消耗换势机会并正确保留已有伤势与负荷；
- 距离不满足时不能使用对应招式；
- 伤臂正确限制持械和发针；
- 破绽过期后不能执行对应终结动作；
- 攻守之势不超出 `-2～2`；
- 观察可揭示后手，已知事实不重复收费；
- 非致死失败不消耗命灯；
- 死亡回照只消耗一盏灯且不重复结算物品；
- 一盏灯时已确认必死行动不再出现；
- 同伴拒绝必须由关系或底线确定，不受随机影响；
- 击杀、制伏、逃离分别写回不同结果；
- 所有规则返回对象均可 JSON 序列化。

### 22.2 浏览器完整流程

- 春风针夜战原有分支和结果保持不变；
- 至少三种临战属性分配能在春风针夜战得到不同有效路线；
- 未入门和锻体人物面对同一刀招时显示不同后果；
- 每个战斗行动显示实际参与的属性、武学掌握、把握、效力和险势；
- 敌人意图、目标、武境、位置、伤势和行动在手机首屏可读；
- 禁用行动明确显示缺失条件；
- 数字键可触发当前行动；
- 一次死亡后正确回到交锋前节点并显示新见闻；
- 王卓战可完成护人撤退、制伏和杀死三类结果；
- 同伴伤势与关系能进入战后场景；
- `390×844` 和 `1280×720` 无横向溢出；
- 页面无运行异常，动态姓名经过 `escapeHtml()`。

- 加入首领阶段、隐藏后手和活捉条件；
- 让鱼跃龙门诀、海桩和春风针各有独特解法；
- 将不同结局写回龙青鱼、燕惊鸿和帮会路线。

完成信号：至少支持护人撤退、借水制伏、致命击杀三种完整路线，且结果进入下一场景。

### C3：连续据点战

- 加入多名敌人的战术角色；
- 加入毒物、警戒和援兵；
- 让伤势、物品和同伴状态跨遭遇保留；
- 支持夺取暗号、关闭机关和接管据点机制；
- 支持不杀、强攻和潜入暴露后的应急路线。

完成信号：帮会清剿不依赖逐个扣血，玩家能通过战场目的和机制完成整段据点流程。

## 24. C1 完成定义

第一轮通用战斗系统只有同时满足以下条件才算完成：

- 春风针夜战已经使用通用规则，原有剧情结果不减少；
- 五维分别改变主动做法与被动承受，不存在万能主属性；
- 武学掌握同时影响把握与规则权限，不只是按钮开关；
- 武境改变承载、效力和后果严重度，不作为所有检定的统一加值；
- 高境界敌人必须能被情报、克制、伤势和地形组成的破阶条件针对；
- 同一行动分别显示把握、效力、险势及其能力来源；
- 逆天改命能在临战中重分已有属性，但会真实改变战机；
- 敌人意图至少包含露势、识招和破招三层；
- 距离、落脚、攻守之势和破绽真实改变行动；
- 至少五个身体部位与四档伤势能限制对应行为；
- 击杀、制伏、撤离、负伤和死亡是不同的规则结果；
- 死亡回照保留死因见闻，但不重复保留奖励；
- 武学提供新行动、场景优势或结束方式，而非只加数值；
- 规则层可独立测试并保持 JSON 可序列化；
- 手机界面能在行动前说明目的、条件和主要风险；
- 规则测试与完整浏览器流程通过，文档与实际状态一致。
