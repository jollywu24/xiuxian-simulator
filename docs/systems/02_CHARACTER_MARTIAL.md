# SYS-02 人物成长与武学系统

## 1. 系统目标

把五维、潜能、医术进度和几门固定武学扩展为可长期成长的武道系统，同时保持“能力改变行动深度”，避免退化为堆数值自动胜利。

## 2. 当前基础

当前已经支持：

- 五维与已有属性重分；
- 出身、初心和固定债务；
- 潜能消耗与秘籍入门；
- 《鱼跃龙门诀》的水行判定；
- 《青青册》《五禽戏》和《打鱼杆法》；
- 一次五禽属性增长；
- 有效悟性和首次炼丹门槛。

主要缺口：

- 没有统一武学目录与招式数据；
- 武学“拥有”和“掌握”区分不足；
- 没有锻体内部阶段、突破条件和失败后果；
- 多门心法、桩功、招式之间没有冲突与协同；
- 内功目前只有场景被动，尚未形成聚气境后的真气资源与招式催动；
- 训练只有加进度，缺少方法、师承、环境和身体负荷；
- 后续十余门武学无法继续用独立布尔字段维护。

## 3. 成长层级

人物成长分为五层：

1. 属性：力道、根骨、身法、悟性、福缘；
2. 武境：未入门、锻体、聚气、通脉、宗师；
3. 学识：医术、炼丹、采集、钓鱼、毒术等；
4. 武学：心法、桩功、招式、轻功、奇术；
5. 身体与心性特征：宝鱼气血、钢筋铁骨、杀意、净魂等。

原著炼体一至四重只映射为本项目“锻体”内部进度，不新增第二套公开境界。

## 4. 属性事实来源

建议拆分：

```js
attributes: {
  base: { strength: 0, constitution: 0, agility: 0, insight: 0, fortune: 0 },
  earned: { strength: 1, constitution: 0, agility: 0, insight: 1, fortune: 0 },
  allocation: { strength: 0, constitution: 0, agility: 0, insight: 5, fortune: 0 }
}
```

- `base`来自人物建立；
- `earned`来自五禽、宝鱼和长期修炼；
- `allocation`是逆天改命当前分配；
- 有效值由身体状态、武学、环境和伤势修正后计算；
- 任何系统不得直接缓存有效值到存档。

战斗中不得把五维合成单一“战斗力”。每个行动只读取一项对应属性；属性、功法熟练、境界差、优势／劣势和伤势共同进入唯一行动值。具体规则见 [SYS-03 简明战斗、伤势与死亡系统](03_COMBAT_INJURY_DEATH.md)。

## 5. 武学数据模型

```js
{
  id: "spring_rain_needles",
  name: "春风化雨针",
  type: "technique",
  grade: "yellow",
  tags: ["needle", "medical", "ranged", "lethal"],
  source: "cao_qing",
  prerequisites: [],
  mastery: { level: 1, progress: 0 },
  moves: ["seal_acupoint", "stop_bleeding", "pierce_vital"],
  combatRules: {
    attribute: "insight",
    range: "middle",
    masteryModifier: 0,
    commonMove: "seal_wrist",
    specialMove: "subdue_acupoint",
    passive: "observe_meridian_advantage"
  },
  qiRules: null,
  passives: [],
  conflicts: []
}
```

武学必须区分：

- 已知：知道名称和来源；
- 持有秘籍：可以研读但尚未入门；
- 入门：至少能使用一式；
- 熟练：可以改变行动深度；
- 精通：解锁被动或组合；
- 突破：品阶或规则发生变化，第一版不作为额外战斗熟练档位。

战斗掌握修正统一为入门 `0`、熟练 `+1`、精通 `+2`。每门功法在战斗中最多提供一个常用动作、一个条件特殊动作和一个被动特点；第一版不增加大成、化境等额外档位。

存档版本5已经为`p0.activeMartial`落地根基、招式和桩功三个当前运用位置。春风化雨针以熟练状态取得，在下一场夜战立即提供封腕、看破后封穴和穿喉；选择桩功后同步写入当前桩功位置。

## 6. 武学类别

| 类别 | 主要作用 | 当前与后续代表 |
| --- | --- | --- |
| 心法／内功 | 提供长期根基；聚气后决定真气上限、恢复和催动方向 | 鱼跃龙门诀 |
| 桩功 | 塑造身体方向和锻体突破 | 神农枯木桩、沧澜定海桩、金刚斗猿桩 |
| 招式 | 战斗或场景中的主动动作 | 打鱼杆法、春风化雨针 |
| 轻功 | 旅行、追逐、潜入和战斗位置 | 踏水九连环 |
| 奇术 | 改变特殊规则 | 五禽戏、飞星定穴法、止杀诀 |
| 毒功 | 以毒素、耐性和身体负荷换力量 | 盘蛇毒经、毒桩 |
| 心神法 | 抵抗或影响意志 | 冰心净魂、浩然相关能力 |

## 7. 内功、真气与招式催动

### 7.1 核心定位

内功不是另一套法术列表，而是人物当前运转的武道根基。玩家可以学会多门内功，但同时只运转一门主内功；它决定：

- 真气上限；
- 战斗内外的恢复方式；
- 哪些招式可以催动；
- 催动后偏向伤害、卸力、换距、点穴、压伤或隐匿；
- 对应场景中的长期被动。

真气相当于有限的高阶施展资源，招式催动与《博德之门3》的升环施法有相似作用：玩家仍使用熟悉的同一招，但投入更多资源后获得更深的效果。本项目不复制分级法术位，也不设置一阶、二阶、三阶真气次数。

### 7.2 解锁时机

| 武境 | 内功与真气表现 |
| --- | --- |
| 未入门 | 不能主动运转真气 |
| 锻体 | 心法只提供呼吸、身体和场景被动，不显示真气条 |
| 聚气 | 解锁真气池与招式催动 |
| 通脉 | 开放少量深度催动、经脉攻击和隔空运劲 |
| 宗师 | 真气可以影响多人、远距目标或一片场景 |

真气第一次出现必须与玩家达到聚气境的剧情和教学同时发生，不能在开局人物页提前摆出一条空资源。

### 7.3 真气池

目标规则：

```text
真气上限 =
  3
  + 内功熟练修正
  + floor(根骨 ÷ 3)

最终上限不超过6
```

| 内功掌握 | 上限修正 |
| --- | --- |
| 入门 | `0` |
| 熟练 | `+1` |
| 精通 | `+2` |

- 真气是跨战斗保存的当前状态，不在每场战斗开始时自动补满；
- 安全休息、完整吐纳、特定丹药或内功规则可以恢复；
- 战斗中的“吐纳”通常消耗一次行动、恢复一点真气，并允许敌招照常推进；
- 特定内功可以通过受击、换距、临水、成功招架等方式恢复，但每轮至多触发一次；
- 普通消耗品不能廉价补满真气，避免把内功变成喝药循环。

### 7.4 常式与催动

一个允许催动的招式最多提供以下层级：

| 层级 | 消耗 | 作用 |
| --- | --- | --- |
| 常式 | 真气 `0` | 招式的稳定基础用途 |
| 催动 | 真气 `1` | 获得一次清楚的质变 |
| 深度催动 | 真气 `2` | 只给标志性招式，并要求境界、熟练或特定条件 |

大部分招式只有“常式／催动”两档。深度催动不作为每门武学的标配。

示例：

```text
雁翎刀·横截

常式｜行动2｜真气0
伤害6～8

催劲｜行动2｜真气1
伤害8～10，忽略一点减伤

贯劲｜行动2｜真气2
伤害8～10，忽略一点减伤并造成失衡
需要：聚气境、刀法熟练
```

催动应优先产生质变：

| 招式类型 | 常见催动变化 |
| --- | --- |
| 刀剑 | 忽略减伤、震开兵器、扩大已有破绽 |
| 拳掌 | 击退、截脉或造成内在伤势 |
| 针法 | 从封腕深入为封穴 |
| 长兵 | 从缠兵深入为夺械或拉回同伴 |
| 身法 | 无视一次追击、跨越额外身位或获得临时防御 |
| 防御 | 获得临时减伤、替同伴承受或卸去冲击 |
| 压伤 | 暂时忽略一处伤势，战后仍需治疗 |

只有伤害数字不同、使用时机完全相同的招式不应拆成多个按钮；应当合并为同一招式的催动层级或熟练成长。

### 7.5 宽招式库，窄临战选择

玩家可以学会很多武学，但一场战斗中频繁使用的应当只有少数招路：

1. 一个兵器常用招式；
2. 一个当前主修武学；
3. 一个防御或换距手段；
4. 一个真气催动方向；
5. 一个决胜手段；
6. 当前场景临时产生的特殊行动。

战斗页面仍只推荐三项最相关行动，其余收入“全部手段”。真气催动在原行动卡中切换并即时更新消耗、伤害和效果，不生成一排名称相近的重复按钮。

### 7.6 内功差异

不同内功决定同一点真气可以把招式推向哪里：

| 内功方向 | 催动倾向 |
| --- | --- |
| 鱼跃龙门诀 | 换距、借水卸力、逆流恢复和水路脱身 |
| 枯木类内功 | 护体、压伤、抗毒和濒死支撑 |
| 刚猛内功 | 伤害、击退和忽略减伤 |
| 阴柔内功 | 点穴、缠劲和延迟发作 |
| 敛息内功 | 隐藏催动、假死和反击 |

内功差异必须改变行动或恢复规则，不允许只表现为“真气上限多一点”。

### 7.7 资源命名

当前运行时把每轮三点行动额度称为“气机”。正式加入真气时，玩家界面将其改称“行动”：

```text
行动：本轮还能做几件事
真气：还能催动几次高阶变化
```

内部兼容字段可以继续迁移旧名称，但玩家界面不得同时出现“气机”和“真气”两条相近资源。

## 8. 修炼行动

修炼不再统一为“消耗潜能加进度”。每次修炼由以下因素决定：

- 方法：独练、师父指点、实战、观摩、药浴、奇珍；
- 时间：时段或连续天数；
- 资源：潜能、饱腹、药材、银钱、关系；
- 环境：水边、丹房、猴洞、静室；
- 身体：伤势、疲劳、毒性和负荷；
- 风险：走火、旧伤、暴露、错误领悟；
- 结果：进度、招式、属性、特征或突破条件。

同一天重复同一练法应递减收益并增加透支风险。

## 9. 桩功选择与冲突

P0首先支持二选一：

### 神农枯木桩

- 强化恢复、耐毒、药性吸收和濒死支撑；
- 与医术、毒术和春风化雨针协同；
- 代价是爆发和追击较弱。

### 沧澜定海桩

- 强化水中稳定、气血循环、抗冲击和心法协同；
- 与鱼跃龙门诀、打鱼杆法和踏水轻功协同；
- 代价是离水环境提升较慢。

后续加入金刚、止杀和毒桩时，角色可以兼修，但必须承担：

- 每日修炼时段竞争；
- 身体负荷上限；
- 相冲特征；
- 师父或势力态度；
- 突破时的路线取舍。

## 10. 武境突破

突破不是经验条自动升级。统一要求：

- 身体进度；
- 一门达到要求的桩功；
- 至少一项实战或生死见闻；
- 对应资源或环境；
- 身体无阻塞性重伤；
- 玩家主动确认风险。

突破结果可为：

- 稳定突破；
- 带伤突破；
- 失败但看见缺口；
- 走火入魔；
- 致命失败。

## 11. 招式与场景兑现

招式不能只在战斗页出现：

| 能力 | 战斗外用途 |
| --- | --- |
| 春风化雨针 | 止血、封穴、诊断、唤醒 |
| 打鱼杆法 | 打捞、探路、绊倒、触发远处机关 |
| 鱼跃龙门诀 | 逆流、闭气、辨水势、稳定药性 |
| 飞星定穴 | 治疗、制止失控者、秘密审问 |
| 踏水九连环 | 赶路、逃离、潜入、抢救落水者 |
| 止杀诀 | 控制杀意、使用七杀刀、识别凶性影响 |

每门新能力必须在内容包中声明首次兑现节点，校验器检查其是否存在。

## 13. P0实施顺序

1. 统一武学目录和存档结构；
2. 迁移现有五门能力；
3. 增加招式与被动；
4. 实现春风化雨针的医治和战斗动作；
5. 实现拜师与两套桩功；
6. 实现锻体起步条件板和突破；
7. 把八月十五神猿动作写成金刚路线伏笔，而非立即发放完整武学。

真气不回填到已经完成的P0锻体流程。第一次玩家聚气时再按“当前内功状态→真气池→三种催动用途→一场立即验证战斗”的顺序实现，首批只需要催劲、护体和爆发身法。

## 14. 测试矩阵

- 逆天改命只能重分已有点数；
- 伤势修正有效属性但不污染基础属性；
- 持有秘籍不等于可以使用招式；
- 春风化雨针可止血，也可造成致命穿刺；
- 桩功二选一后提供不同条件和行动；
- 同日重复训练收益递减并提高负荷；
- 锻体突破缺任一条件时说明具体缺口；
- 回照恢复武学进度，但保留已经亲历的失败见闻；
- 旧存档中的现有能力完整迁移。
- 锻体角色不显示真气，聚气后才建立真气池；
- 常式不消耗真气，催动和深度催动分别消耗一或两点；
- 真气不足时保留常式，只把催动条件置灰；
- 同一招式切换催动后仍使用同一次固定因果判定；
- 真气不会在每场战斗开始时自动补满；
- 玩家界面不同时显示“气机”和“真气”两条相近资源。

## 15. 完成标准

玩家能从“曹青传针”连续走到“拜师选桩并进入锻体”，两种桩功至少各改变一个战斗行动、一个非战斗行动和一个突破条件，才算P0完成。

真气纵切只有在玩家达到聚气后，同一常用招式能够在常式、催动之间切换，内功改变至少一种恢复或催动规则，并在下一场战斗中让玩家亲手决定“现在爆发还是保留真气”，才算完成。
