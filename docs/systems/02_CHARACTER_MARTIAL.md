## 1. 系统定位

武学系统不是收集图鉴，也不是把几十个同质技能塞进战斗快捷栏。它要持续回答四个问题：

1. **我学会了什么？**
2. **我现在带着哪几门本事？**
3. **这些本事在眼前局面里能做什么？**
4. **我要把有限阅历投给哪门武学，让它产生新的规则？**

武学的核心体验是：

> 从人物和事件中得到一门本事，在武学页看懂它的用途与成长方向，把它带在身上，并在一至两个场景内亲手改变战斗、调查、旅行或人物关系。

系统必须同时服务三层体验：

- **叙事层**：师承、来路、恩怨和使用后果；
- **决策层**：有限携带位、阅历投入、兵器条件和临场取舍；
- **表现层**：明确数值、解锁节点、动作反馈和武侠化结果描述。

### 1.1 设计原则

1. **少而有用**：每门武学至少改变一种行动规则，不以大量换皮技能填数。
2. **宽学习、窄携带**：可以学很多，临战只能带少数，形成清楚打法。
3. **品阶与修为分离**：品阶代表传承上限，修为代表玩家掌握程度。
4. **主动与被动并存**：武学不只增加按钮，也会改变距离、代价、伤势或剧情条件。
5. **一套战斗公式**：武学、属性、境界和装备接入同一判定，不另建“内功战斗”。
6. **所有数字可解释**：界面显示最终结果，点击后能追溯每一项来源。
7. **失败也能推进**：研习不随机失败；战斗失手由固定因果骰推进局面。
8. **能力尽快兑现**：获得新武学后，最多两个场景内必须出现一次主动使用机会。

### 1.2 第一版不做

- 不做职业、门派职业树或固定配装模板；
- 不做随机洗词条、强化成功率、武学耐久或秘籍抽卡；
- 不做十余层技能树和大量百分比乘区；
- 不做“第一式、第二式、第三式哪里亮了点哪里”的固定连招队列；
- 不做独立法术命中、法术防御、法术位或第二套生命条；
- 不让福缘稳定增加命中或伤害；
- 不允许读档刷新研习结果、突破结果或战斗骰点；
- 不把“潜能、修为、熟练、境界、品阶”混成同一个成长数字。

### 1.3 《烟雨江湖》拆解后的正式采用项

参考拆解只用于确认结构，不复制原作武学名称、门派、数值或长期运营方式。以下决定已经成为本系统正式规则：

| 参考结构 | 本项目采用方式 | 当前落地 |
| --- | --- | --- |
| 套路、内功、轻功正交分工 | 改为招式、心法、轻功，并保留独立锻体 | 四类目录与六个携带位已运行 |
| 一本武学逐步解锁招式 | 造诣解锁少量主动／被动节点，战斗动作直接读取节点 | 战斗动作支持`martialNodeId`门禁 |
| 武学来自人物与事件 | 每门可学武学必须登记传承来源、首次兑现局面与玩家为此承担的关系／事件后果 | 目录校验会拒绝缺来源或首次兑现的条目 |
| 轻功同时改变地图 | 每门轻功至少改变一条追逐、脱身或路线，不允许只有身法常驻加值 | 已进入目录校验；首门轻功随正文来源制作 |
| 主动与被动共同构成武学 | 节点改变行动、条件、距离、伤势、资源或结果，不只增加百分比 | 当前针法、心法和桩功已按节点拆分 |
| 属性影响招式 | 招式显式声明属性，界面和检定展示最终依据 | 已接入统一战斗公式 |
| 指定配套联动 | 每门最多一个强配套；未配套仍可独立使用 | 首个样板为“行波定海” |
| 一套路一内功一轻功 | 改为一心法、三招式、一轻功、一锻体 | 已运行 |
| 高低品阶纵向替换 | 品阶决定规则上限，低品阶依靠低消耗、环境与场外用途长期保值 | 打鱼杆法是首个粗浅样板 |
| 使用与领悟推动成长 | 每个场景第一次实际兑现可提高修为，稳定ID保证幂等 | 战斗、紫金河水路、王五试杆已接入 |

明确不采用的部分仍包括：十重三境、突破等待、六类累计修为、固定武学资质、真元再折算内力点、有损传功、门派贡献日常、通用精进点和以数百本同质武学填量。

## 2. 统一术语

### 2.1 玩家可见术语

| 术语 | 定义 | 不等于 |
| --- | --- | --- |
| 武学 | 可以学习、研习、携带并产生规则的完整传承 | 单件装备、一次性剧情技巧 |
| 心法 | 调息、运劲与真气运转之法 | “根基”“内功”两个并列大类 |
| 招式 | 用兵器或身体主动完成的攻防手段 | 所有武学的统称 |
| 轻功 | 换位、追逐、脱身和越障之法 | 单纯增加身法数值 |
| 锻体 | 桩功、导引、横练等塑造身体的法门 | 人物武境“锻体”本身 |
| 品阶 | 武学先天的传承层级与规则上限 | 玩家练得有多熟 |
| 修为 | 当前掌握阶段内的进度，范围为0～100 | 人物境界 |
| 造诣 | 未入门、入门、熟练、精通、圆满五档 | 品阶 |
| 阅历 | 用于研习武学的通用成长资源 | 人物等级、战斗经验条 |
| 携带 | 当前已准备、能在突发战斗中立即调用 | 已经学会 |
| 主动 | 玩家选择后消耗行动或其他资源的招式节点 | 自动触发加成 |
| 被动 | 条件满足时自动改变规则的武学节点 | 永久无条件加属性 |
| 催动 | 达到聚气后，为同一动作投入真气获得更深效果 | 另一条重复招式 |

### 2.2 废弃或收束术语

以下词不再作为顶层分类：

- **根基、内功**：统一归入“心法”；
- **桩功、导引、横练**：作为“锻体”的标签或子型；
- **奇术、毒功、心神法**：按实际用途归入四类，并通过标签表达；
- **远手**：统一写“远程”；
- **防守**：统一写“防御”；
- **护身**：统一写“减伤”；
- **气机**：玩家资源统一写“真气”；
- **潜能**：目标界面与通用武学养成统一写“阅历”。

“近距／中距／远距”表示战场距离；“近战／远程”表示攻击类型，二者不得混用。

## 3. 武学分类

顶层分类固定为四类：

| 分类 | 核心职责 | 常见节点 |
| --- | --- | --- |
| 心法 | 呼吸、恢复、真气上限、催动方向、特殊环境运转 | 调息被动、真气恢复、催动规则 |
| 招式 | 伤害、控制、救治、缴械、点穴和兵器运用 | 主动招式、命中被动、处决条件 |
| 轻功 | 移动、追逐、撤离、跨越地形和临时防御 | 换位动作、脱身被动、地形规则 |
| 锻体 | 气血、减伤、伤势承受、抗毒、姿态和武境突破 | 身体被动、防御动作、突破条件 |

### 3.1 招式子类型

只有“招式”提供二级筛选：

| 子类型 | 典型玩法 |
| --- | --- |
| 剑法 | 招架、拆招、精准、连续压制 |
| 刀法 | 伤害、破势、压迫、扩大伤口 |
| 拳掌 | 贴身、擒拿、截脉、击退 |
| 枪棍 | 中距控位、扫击、缠兵、护人 |
| 暗器 | 中远距、点穴、追击、状态施加 |

界面可提供“全部”作为筛选入口，但“全部”不是一种武学。

### 3.2 非顶层标签

标签只用于条件、检索和联动，不占用新的分类栏：

```text
兵器：剑、刀、拳掌、枪棍、暗器
体术：桩功、导引、横练
用途：医术、毒术、点穴、卸力、护人、追踪、潜行
环境：临水、雨夜、狭巷、高处、暗处
传承：曹青、白栀云、漕帮、药王谷
性质：刚猛、阴柔、灵巧、沉稳、险绝
```

同一武学可以拥有多个标签。例如《春风化雨针》是“招式·暗器”，同时拥有“医术、点穴、远程、白栀云传承”等标签。

## 4. 品阶系统

武学品阶固定为：

> 粗浅 → 寻常 → 上乘 → 绝学 → 镇派

### 4.1 品阶职责

品阶代表：

- 传承的完整程度；
- 能承载多少独特规则；
- 能否支持真气催动或深度催动；
- 对人物、势力和江湖身份的价值；
- 达到圆满后仍可继续演化的上限。

品阶不直接代表：

- 当前一定比低品阶伤害高；
- 获得后无需研习就能使用；
- 每升一阶统一增加命中、伤害和防御；
- 高品阶在所有局面都优于低品阶。

一门圆满的粗浅杆法，可以在水边和长兵控距上胜过一门刚入门的上乘刀法。

### 4.2 各品阶内容预算

| 品阶 | 设计定位 | 完整节点预算 | 催动上限 |
| --- | --- | --- | --- |
| 粗浅 | 生计、乡野、基础防身 | 2～3个 | 通常无催动，或仅一个简单催动 |
| 寻常 | 完整可用的江湖传承 | 3～4个 | 可有常式／催动 |
| 上乘 | 能形成明确打法的名家武学 | 4～5个 | 至少一个标志性催动 |
| 绝学 | 改变常规行动规则的稀有传承 | 5～6个 | 可有一个深度催动 |
| 镇派 | 与势力身份、传承责任绑定的核心法门 | 6个左右 | 可以改变资源循环，但必须有代价 |

节点预算不是要求把格子填满。一个强而清楚的被动，胜过三个只有数字差异的主动按钮。

### 4.3 品阶视觉

品阶颜色同时作用于：

- 武学名称；
- 武学图标底框；
- 品阶文字；
- 详情页顶部装饰线；
- 携带槽边框。

修为进度条始终使用统一的中性颜色，不随品阶变化。品阶必须同时写文字，不能只靠颜色辨认。

具体色值由界面令牌统一管理，武学页不得自行维护第二套颜色表。

### 4.4 品阶晋升

普通研习只提高造诣，不提高品阶。品阶晋升必须来自武学自身写明的事件：

- 补全残卷；
- 得到正统传承；
- 战胜符合条件的强敌；
- 在特定环境完成领悟；
- 解决传承人物的因果；
- 以另一门武学补足缺失规则。

《鱼跃龙门诀》的“鱼跃龙门”允许在真实越境胜利后触发晋升条件板，是首个品阶晋升样板。晋升必须改变至少一项水路、换距、恢复或催动规则，不能只改颜色。

## 5. 拥有、掌握与携带

一门武学有四个相互独立的状态层：

| 状态层 | 含义 | 玩家可做 |
| --- | --- | --- |
| 见闻 | 知道名称、来路或部分效果 | 调查、追问、寻找传承 |
| 传承 | 持有秘籍、口诀或师父许可 | 查看入门条件、开始研习 |
| 掌握 | 已达到入门及以上造诣 | 用于叙事知识与准备 |
| 携带 | 当前六个武学位之一正在运用 | 在突发战斗中立即提供主动与被动 |

### 5.1 已学不等于已携带

- 玩家可以掌握任意数量武学；
- 只有携带中的武学向战斗动作栏提供主动与被动；
- 已掌握但未携带的武学，仍可用于医理、辨认、谈判、追查等“知识已经存在”的剧情判断；
- 突发战斗开始后不能无代价更换携带；
- 有充分准备时间的场景，允许在入场前调整携带；
- 战斗中临时换法只有特殊剧情或武学规则才能做到。

### 5.2 永久所得

武学事件已经取得的永久结果不会因卸下而消失，例如：

- 五禽戏第一次完整演练取得的一点可重分属性；
- 品阶晋升后写入人物的传承身份；
- 从生死实战中获得的破绽见闻；
- 因师承建立的人物关系和势力权限。

武学被动和动作必须携带才生效；已经发生的人生结果不回退。

## 6. 造诣与修为

造诣固定为五档：

> 未入门 → 入门 → 熟练 → 精通 → 圆满

每一档内部拥有0～100修为。达到100后，完成该门武学写明的突破条件，才能进入下一档。

### 6.1 各档职责

| 造诣 | 战斗熟练修正 | 主要意义 |
| --- | --- | --- |
| 未入门 | 不可用 | 只能阅读传承与查看入门条件 |
| 入门 | `+0` | 解锁核心主动或核心被动 |
| 熟练 | `+1` | 解锁第一项打法变化 |
| 精通 | `+2` | 解锁组合、催动或规则被动 |
| 圆满 | `+2` | 不再堆通用命中，改为标志性规则或品阶晋升资格 |

圆满不提供`+3`通用修正，以免武学熟练压过属性、装备、伤势和场景条件。

### 6.2 通用研习

第一版采用确定性成长：

```text
研习一次：阅历 -40，当前修为 +10
修为达到100：停止获得进度，等待突破
```

同一按钮不进行随机成功率判定。玩家支付资源后必须得到明确进度。

### 6.3 突破消耗

| 目标造诣 | 阅历消耗 | 额外要求 |
| --- | ---: | --- |
| 入门 | 80 | 满足武学入门条件 |
| 熟练 | 80 | 当前修为100，至少实际使用一次 |
| 精通 | 120 | 当前修为100，完成一项对应领悟 |
| 圆满 | 200 | 当前修为100，完成标志性人物或局面条件 |

这些数字是第一版统一调优基线，不随品阶乘倍。高品阶的难度来自传承条件、领悟事件和使用门槛，而不是把研习按钮价格简单乘五。

### 6.4 研习增益来源

通用按钮是保底成长，内容奖励可以提高效率：

| 来源 | 效果边界 |
| --- | --- |
| 师父指点 | 一次性修为`+20`或直接满足一项领悟条件 |
| 首次实战兑现 | 每场遭遇每门武学至多修为`+10` |
| 特定环境 | 允许研习，或让一次研习额外`+10` |
| 残卷／注解 | 降低一次突破的阅历消耗，或揭示隐藏节点 |
| 生死见闻 | 满足精通／圆满条件，不直接无限加进度 |
| 相合武学 | 开放新领悟，不提供可反复叠加的百分比经验 |

重复攻击无威胁目标、反复进出同一场景或读档重做同一固定因果节点，不能重复领取首次实战修为。

### 6.5 阅历来源

阅历来自“真正形成经验”的行为：

- 完成事件并承担结果；
- 首次看破敌招或解决新的战斗局面；
- 师父指点与人物传承；
- 长途旅行、调查或百艺实践中的新见闻；
- 重要奇遇；
- 章末按实际经历结算。

普通重复战斗不给可刷取的阅历。第一版不设置人物总等级，阅历只决定玩家能把哪些已有传承练深。

### 6.6 旧资源字段迁移

版本7已经完成玩家术语迁移：

1. 玩家可见名称统一为“阅历”；
2. 旧存档余额按`1:1`迁入`martial.experience`，不会吞掉已有资源；
3. 顶层`potential`暂时作为旧剧情处理器的兼容镜像，保存、读取与武学操作时保持双向一致；
4. 新武学规则只读取`martial.experience`，不再直接依赖`potential`；
5. 《青青册》、医术和炼丹等非武学成长继续使用各自进度、材料与事件条件；
6. 既有原作事件数值保持不变，界面只显示一个“阅历”余额，不并列显示旧称。

## 7. 携带系统

武学携带位固定为六个：

| 携带位 | 数量 | 作用 |
| --- | ---: | --- |
| 心法 | 1 | 当前运转的心法与真气方向 |
| 招式 | 3 | 临战主要主动手段 |
| 轻功 | 1 | 换位、追逐和脱身 |
| 锻体 | 1 | 当前身体法门与防御方向 |

### 7.1 携带规则

- 只能携带已经入门的武学；
- 同一武学不能重复占位；
- 心法、轻功、锻体只能进入对应唯一位置；
- 招式可进入任意一个招式位；
- 兵器要求不满足时仍可携带，但相关主动动作不可用；
- 携带变化立即更新人物摘要和行动预览，不直接恢复气血或真气；
- 卸下心法不会清空当前真气，但在重新携带可运转心法前不能主动催动；
- 双手兵器、装备和武学携带是两套状态，不互相偷偷替换。

### 7.2 按钮状态

| 当前状态 | 主按钮 |
| --- | --- |
| 已选武学正在携带 | 卸下 |
| 未携带且有兼容空位 | 携带 |
| 未携带且兼容位置已满 | 替换 |
| 尚未入门 | 研习／查看条件，不显示携带 |

点击“替换”后：

1. 中央只高亮兼容位置；
2. 玩家点击具体位置确认；
3. 面板预览将失去和获得的动作、被动；
4. 再次确认后才替换；
5. 不允许自动覆盖第一个招式位。

### 7.3 战斗开始时

战斗动作来源包括：

- 装备提供的基础动作；
- 六个携带位解锁的主动动作；
- 携带武学的被动和催动；
- 场景物件与人物关系产生的临时动作；
- 当前见闻看破后开放的特殊行动。

默认只推荐三项最适合当前意图、距离和条件的动作，其余收入“其余手段”。携带六门武学不等于同时显示十余个按钮。

## 8. 主动、被动与解锁节点

每门武学由少量、可解释的节点构成：

```text
核心节点：定义这门武学最基本的用途
变化节点：让同一用途在条件、距离或结果上走得更深
被动节点：改变资源、伤势、位置或情报规则
标志节点：精通或圆满后形成这门武学的独特身份
```

### 8.1 节点解锁基线

| 造诣 | 推荐解锁 |
| --- | --- |
| 入门 | 一个核心主动，或一个核心被动 |
| 熟练 | 一个变化节点 |
| 精通 | 一个组合、催动或规则被动 |
| 圆满 | 一个标志节点或品阶晋升条件 |

不是每门武学都要在每档解锁一个主动。锻体和心法应以被动、资源与场景规则为主。

### 8.2 主动动作规格

每个主动节点必须至少声明：

```js
{
  id: "seal_wrist",
  name: "封腕",
  kind: "active",
  actionCost: 2,
  attribute: "insight",
  attackType: "ranged",
  range: ["middle", "far"],
  weaponRequirement: ["needle"],
  difficulty: 0,
  damage: { min: 6, max: 9 },
  ignoreReduction: 1,
  results: {
    great: "封穴并保留完整活口",
    success: "截断持械手",
    costly: "得手但暴露距离或承受反击",
    failure: "未封住穴位，敌招继续"
  }
}
```

### 8.3 被动规格

每个被动必须说明触发、作用、频率和反馈：

```js
{
  id: "observe_meridians",
  name: "观脉",
  kind: "passive",
  trigger: "首次观察有经脉或伤势的目标",
  effect: "揭示一项可封穴部位，并让对应行动获得有利",
  limit: "每名目标一次",
  feedback: "你从呼吸与肩腕的细颤里看见了行气缺口。"
}
```

禁止使用“略微提高”“大幅增强”等无法验证的描述。界面必须给出具体数值或明确规则。

### 8.4 一招多用

标志性招式应优先同时拥有战斗和非战斗用途：

| 武学 | 战斗用途 | 非战斗用途 |
| --- | --- | --- |
| 春风化雨针 | 封腕、封穴、穿喉 | 止血、诊脉、救醒 |
| 打鱼杆法 | 缠兵、扫腿、控距 | 打捞、探路、触发远物 |
| 鱼跃龙门诀 | 临水换距、借流卸力 | 闭气、逆流、辨水势 |
| 五禽戏 | 稳定伤势、身体姿态 | 调养、承药、长期属性 |

如果一门新武学只能提供“伤害比旧招高二点”，就还没有达到内容制作标准。

## 9. 四类武学详细规则

### 9.1 心法

心法决定人物怎样呼吸、运劲和使用真气。同一时间只运转一门。

#### 锻体及以下

- 不显示真气条；
- 不提供真气数值；
- 只提供呼吸、身体、环境和叙事被动；
- 聚气相关节点显示锁定提示“尚未聚气”；
- 允许心法参与水路、闭气、炼药观察等合理场景。

#### 聚气及以上

- 解锁真气上限和当前真气；
- 决定真气恢复方式；
- 决定允许哪些招式催动；
- 可以提供一个吐纳或运气动作；
- 不建立独立法术列表。

#### 心法详情模板

右侧只显示：

1. 名称、品阶、类别、当前造诣；
2. 当前运转效果；
3. 锻体阶段的场景与身体被动；
4. 聚气后真气上限、恢复条件和催动方向；
5. 四档节点；
6. 修为进度、研习与携带操作；
7. 尚未聚气时的锁定说明。

### 9.2 招式

招式是战斗主动选择的主要来源，但每门只保留少量有差异的动作。

招式详情优先显示：

```text
当前伤害
基础命中
行动消耗
距离
穿透／控制
未满足的兵器条件
```

招式可以指定力道、身法、根骨或悟性作为行动属性，不按兵器门类强制绑定唯一属性。福缘不作为常态命中属性。

#### 兵器条件

- 条件满足：不显示任何提示；
- 条件不满足：只显示赤色提示，例如“需要：剑”；
- 未满足时可以携带、研习和查看；
- 战斗中对应动作置灰，点击可查看缺口；
- 徒手招式明确写“无需兵器”，不借此重复堆说明。

### 9.3 轻功

轻功不是“身法永久加二”，而是对空间和追逐规则的控制。

轻功详情优先显示：

- 可移动节点数；
- 行动消耗；
- 是否无视贴身追击；
- 使用后的临时防御；
- 可跨越的地形；
- 雨、泥、水面、狭巷等限制；
- 战斗外旅行、潜入和救援用途。

首批轻功动作只需覆盖：

1. 低成本换位；
2. 一次脱离追击；
3. 一个场景越障；
4. 一个精通后的标志规则。

### 9.4 锻体

锻体包含桩功、导引和横练，负责身体承载与武境突破。

锻体详情优先显示：

- 最大气血变化；
- 常驻或条件减伤；
- 伤势抗性与可压制伤势；
- 抗毒、承药或恢复规则；
- 当前身体被动；
- 对人物武境突破的条件贡献。

“锻体武学”和“人物达到锻体境”必须始终分开显示。例如：

```text
人物境界：锻体一重
当前锻体：《神农枯木桩》· 熟练
```

桩功不是顶层标签页。它只在锻体详情和筛选标签中出现。

## 10. 真气与催动

### 10.1 解锁时机

| 人物武境 | 心法与真气表现 |
| --- | --- |
| 未入门 | 无法主动运转真气 |
| 锻体 | 心法提供呼吸、身体和场景被动；不显示真气条 |
| 聚气 | 建立真气池，解锁常式／催动 |
| 通脉 | 少量招式开放深度催动与经脉规则 |
| 宗师 | 真气可以影响多人、远距目标或局部场景 |

### 10.2 真气池基线

达到聚气后：

```text
真气上限 =
  3
  + 心法造诣修正
  + floor(根骨 ÷ 3)

第一阶段上限不超过6
```

| 心法造诣 | 上限修正 |
| --- | ---: |
| 入门 | 0 |
| 熟练 | +1 |
| 精通／圆满 | +2 |

真气跨战斗保存，不在每场战斗开始时自动补满。

### 10.3 催动层级

| 层级 | 真气 | 设计边界 |
| --- | ---: | --- |
| 常式 | 0 | 稳定完成招式基础用途 |
| 催动 | 1 | 取得一个明确质变 |
| 深度催动 | 2 | 仅标志性招式拥有，并要求境界或造诣 |

催动和常式是同一个动作：

- 共用同一枚固定因果骰；
- 不生成重复动作卡；
- 切换后即时更新伤害、消耗、距离和结果；
- 真气不足时保留常式，只把催动置灰；
- 主要强化通常只选伤害、忽略减伤、控制、换位、护人之一。

首批催动用途固定为：

1. **催劲**：增加伤害、扩大破绽或忽略一点减伤；
2. **运气护体**：获得一次或一轮临时减伤；
3. **爆发身法**：无视一次追击、额外换位或获得临时防御。

### 10.4 恢复

- 安全休息、完整吐纳、特定丹药或心法条件恢复真气；
- 战斗中吐纳通常消耗行动，敌方意图仍继续；
- 心法可以在受击、临水、成功招架等特定条件恢复，但每轮至多一次；
- 普通消耗品不能廉价补满真气；
- 敌人使用同一资源规则，蓄气和催动必须提前暴露意图。

## 11. 武学、属性、境界与装备

四套系统分别负责不同问题：

| 系统 | 回答的问题 | 主要进入战斗的位置 |
| --- | --- | --- |
| 属性 | 这个人擅长怎样行动 | 行动修正、防御、伤害小幅成长、气血 |
| 武学 | 他会用什么方法 | 动作、熟练修正、招式威力、特殊规则 |
| 境界 | 身体和内息达到什么层次 | 境界差、气血、伤害加值、高武权限 |
| 装备 | 手中与身上有什么 | 兵器伤害、距离、持握、减伤、装备动作 |

### 11.1 五维在武学中的职责

| 属性 | 常见武学用途 |
| --- | --- |
| 力道 | 重击、压制、长兵发力、破门、击退 |
| 根骨 | 气血、锻体承载、护体、抗毒、真气上限 |
| 身法 | 换位、闪避、轻兵、暗器、追逐 |
| 悟性 | 拆招、点穴、医针、复杂心法和领悟条件 |
| 福缘 | 奇遇、偶然发现和少数因果改写，不提供稳定战斗加值 |

每个动作只读取一项主属性。不能让一招同时吃力道、身法、悟性三项加值。

### 11.2 无职业结构

第一版不建立“战士、盗贼、法师”职业。玩家打法由以下组合自然形成：

```text
五维倾向
+ 当前装备
+ 六门携带武学
+ 人物境界
+ 伤势和见闻
+ 当前场景
```

属性重分应通过明确人物、代价和安全地点完成，不保留“命灯随时洗点”的战斗工具化设计。

## 12. 统一战斗公式

武学必须使用[SYS-09](09_EQUIPMENT_COMBAT_FORMULA.md)的唯一公式。

### 12.1 行动判定

```text
行动修正 =
  行动属性
  + 武学熟练
  + 境界差
  + 有利／不利
  - 相关伤势
  + 动作特殊修正

行动总值 = 固定因果骰1D10 + 行动修正
```

非攻击目标：

```text
目标值 = 4 + 行动难度
```

攻击、擒拿、点穴和缴械目标：

```text
命中目标 = 4 + 行动难度 + 目标防御
```

### 12.2 伤害

```text
伤害下限／上限 =
  武器伤害下限／上限
  + 招式威力
  + floor(威力属性 ÷ 2)
  + 境界伤害加值
  + 本次催动伤害加值
```

同一枚因果骰同时决定命中与伤害档位：

| 结果 | 伤害取值 |
| --- | --- |
| 大成 | 上限 |
| 得手 | 上下限向上取整的平均值 |
| 得手有损 | 下限，并承受预告代价 |
| 失手 | 0，除非动作明确有擦伤或环境余波 |

最终伤害：

```text
有效减伤 = max(0, 常驻减伤 - 穿透)

最终伤害 =
  档位伤害为0时取0；
  否则 max(1, 档位伤害 - 有效减伤 - 本次临时减伤)
```

### 12.3 武学详情中的简化数值

武学管理页默认只显示玩家做决定需要的最终值：

```text
当前伤害：6～9
基础命中：+5
行动：2
距离：中距／远距
忽略减伤：1
```

点击“查看依据”后才展开：

```text
基础命中 +5
= 悟性3 + 熟练1 + 银针1

伤害6～9
= 银针2～4 + 招式威力2 + 悟性折算1 + 锻体境1
```

武学页不显示目标防御、现场有利／不利和伤势后的最终命中，因为这些必须进入具体战斗后才能确定。

### 12.4 可用性顺序

动作进入战斗推荐区前依次检查：

1. 武学已入门；
2. 武学已经携带；
3. 当前兵器满足；
4. 当前距离满足；
5. 行动点足够；
6. 催动时真气足够；
7. 目标和场景满足；
8. 伤势没有完全禁用动作。

不可用动作保留在“其余手段”中并明确缺口；重复死亡选择等另有剧情规则限制的内容除外。

## 13. 非战斗使用

武学不是只在战斗地图里生效。

### 13.1 三类非战斗判定

| 类型 | 是否要求携带 | 示例 |
| --- | --- | --- |
| 知识判断 | 否，只要已掌握 | 认出针孔、看懂桩架、辨认行气错误 |
| 突发行动 | 是 | 突然封穴、立刻追人、塌桥时救人 |
| 有准备行动 | 可在入场前调整 | 夜探前换轻功、炼药前运转心法 |

这一规则避免“我明明学过却突然失忆”，也保留携带位的战略意义。

### 13.2 条件展示

相关选项直接写：

```text
[春风化雨针·熟练] 先封住她腕脉
[鱼跃龙门诀] 潜入第三段河湾
[需要：已携带轻功] 越墙截住送信人
```

条件满足时显示来源；不满足时以赤色或灰色显示缺口。点击条件可以查看：

- 来自哪门武学；
- 当前造诣；
- 为什么在此处生效；
- 可能改变的结果；
- 尚未满足的兵器、距离、关系或见闻。

### 13.3 首次兑现

每门武学数据必须声明`firstPayoff`：

```js
firstPayoff: {
  withinScenes: 2,
  nodeId: "first_needle_ambush",
  mode: "combat_and_rescue"
}
```

内容校验器至少检查：

- 获得节点可达；
- 首次兑现节点可达；
- 两者之间不超过两个主要场景；
- 兑现不是只有一句被动文案；
- 至少有一个按钮或战斗动作让玩家主动使用。

### 14.3 打鱼杆法

建议节点：

| --- | --- |

| 精通 | 缠竿夺械：在得手时改变敌方兵器 |
| 圆满 | 不设必需节点；可通过人物或水路事件补全传承 |

### 14.4 五禽戏与两门桩功

- 《五禽戏》统一归入锻体，不再作为“奇术”；
- 神农枯木桩和沧澜定海桩统一归入锻体·桩功；
- 玩家只能携带一门锻体，但永久属性和已完成突破不回退；
- 两门桩功必须各自改变至少一个战斗行动、一个非战斗行动和一个突破条件。

### 14.5 三条卸力法

白栀云传授的“护经、沉胯、送力回桩”不建立一门独立武学。它属于武学心得：

```text
作用：在闭门试势、封刀或护人时开放一项变化节点
```

心得用于补强已有武学，避免列表被零散技巧淹没。

“基础拳架、断水刀、飞星定穴法、小周天吐纳、枯木养生功、玄龟藏息法、大江归海经”等名称仅用于界面构图示意。在剧情、目录和存档中出现前，必须另行完成来源、人物、规则和首次兑现设计。

## 15. 武学界面

武学页为全屏界面，沿用人物页和行囊页的纸墨、暗金、青灰视觉语言。结构固定为左、中、右三栏。

1672×941视觉标尺固定为：

- 左栏31.4%，展示“所学武学”、一级分类、招式子类型和传承列表；
- 中栏36%，复用陈司命雨夜立绘，并把一心法、一锻体、三招式、一轻功六个等大位置环绕人物排列；
- 右栏32.6%，展示武学身份、修为、当前效用、领悟节点与养成操作；
- 背景使用`web/assets/martial/martial-screen-backdrop.webp`，圆形徽记使用`martial-emblem-atlas.webp`；美术资源不得包含玩家文本，文字与状态仍由HTML实时渲染。

### 15.1 顶部

顶部只承担全局导航与资源：

- 人物；
- 行囊；
- 武学（当前选中）；
- 当前阅历；
- 当前银两；
- 返回。

不在顶部重复显示境界、气血、修为总量等与本次决策无关的信息。银两与行囊、人物页保持同一资源条格式，用于跨界面确认当前江湖资源。

### 15.2 左栏：我学会了什么

左栏包含：

1. 四个一级分类：心法／招式／轻功／锻体；
2. 仅在招式分类下出现：全部／剑法／刀法／拳掌／枪棍／暗器；
3. 当前分类名称；
4. 约五条武学列表；
5. 超出五条时的细滚动条和底部渐隐提示。

每条列表只显示：

- 图标；
- 名称；
- 品阶与子类型；
- 很小的携带标识。

左栏不显示：

- 修为数字；
- 修为进度条；
- 阅历消耗；
- 已解锁节点全文；
- “已携带”大标签；
- 伤害、命中、距离等重复详情。

### 15.3 中栏：我携带了什么

中央固定显示六个等尺寸位置：

```text
心法 ×1
招式 ×3
轻功 ×1
锻体 ×1
```

每个位置只显示图标、名称和品阶底框。所有位置大小一致、对齐一致、左右间距一致，不让招式位或心法位被拉伸。

点击位置：

- 选中其中武学；
- 右侧打开该武学详情；
- 不立即卸下；
- 替换模式下用于确认具体目标位。

### 15.4 右栏：它有什么用，怎么变强

所有会重复的信息只保留在右栏一处：

- 名称、品阶、类别；
- 当前造诣；
- 当前修为进度；
- 分类专属数值；
- 主动／被动节点；
- 下一节点；
- 研习按钮；
- 突破条件；
- 携带／替换／卸下按钮。

右栏顺序固定：

1. 身份：名称、品阶、分类；
2. 成长概览：当前造诣与统一修为条；
3. 判断：当前主要用途与本分类最重要的三至五项；
4. 节点：已解锁、下一节点、远期节点；
5. 成长操作：阅历消耗与突破条件；
6. 操作：研习、突破、携带状态。

### 15.5 四类右栏差异

| 分类 | 必须优先显示 | 不显示 |
| --- | --- | --- |
| 心法 | 当前运转、呼吸被动、真气规则、催动方向 | 锻体阶段的空真气条 |
| 招式 | 伤害、基础命中、行动、距离、穿透／控制 | 已满足的兵器条件 |
| 轻功 | 移动、行动、脱离、临时防御、地形限制 | 伪造的伤害值 |
| 锻体 | 气血、减伤、伤势抗性、身体被动、突破贡献 | 兵器命中和距离 |

### 15.6 交互

- 点击武学条目只选中，不改变携带；
- 点击主动／被动节点可展开详细说明；
- 点击伤害或命中可展开公式依据；
- 点击空白处关闭节点详情，不退出武学页；
- 手机横屏保持三栏；
- 手机竖屏按“分类与列表 → 携带位 → 详情”纵向排列；
- 所有主要操作都必须能点击完成，不依赖悬停；
- 数字键1～9可以触发当前可用的研习、突破、携带和节点详情。

### 15.7 文本和颜色

- 品阶色：名称、品阶和底框；
- 金色：重要规则和可执行主操作；
- 青色：已满足条件、已解锁节点；
- 赤色：兵器缺失、风险和不可逆代价；
- 灰色：不可用节点与次要说明；
- 修为条：固定中性色；
- 不可用按钮除了置灰，还必须写出原因。

## 19. 内容生产规范

新增一门武学前必须填写：

1. 名称与来源人物；
2. 顶层分类和必要子类型；
3. 品阶与为什么是这个品阶；
4. 核心玩法一句话；
5. 入门条件；
6. 四档造诣节点；
7. 主动动作完整数值；
8. 被动的触发、效果、频率和反馈；
9. 兵器与距离条件；
10. 至少一个非战斗用途；
11. 首次兑现节点；
12. 与现有武学的差异；
13. 师承、势力或人物后果；
14. 测试用例。

### 19.1 一句话检验

一门武学必须能用一句玩家语言说明：

```text
《春风化雨针》让我在中远距封穴，也让我在病榻前止血救人。
《打鱼杆法》伤害不高，却能在中距缠兵，并在水边探路打捞。
《神农枯木桩》让我带伤不乱，代价是没有定海桩的临水控位。
```

说不出差异时，不应进入制作。

### 19.2 数值预算

- 同造诣的常用主动，行动消耗通常为1～2；
- 单个普通被动通常只改变一个规则；
- 常态命中修正来源不超过五项；
- 一次催动只给一个主要强化；
- 圆满优先解锁规则，不继续堆通用命中；
- 低品阶依靠低门槛和特殊场景保留价值；
- 新武学不得让旧武学在所有维度同时失效；
- 一场普通战斗中玩家反复使用两至四种手段属于合理体验。

## 20. 测试矩阵

### 20.1 分类与目录

- 所有武学只属于心法、招式、轻功、锻体之一；
- 只有招式具有剑法、刀法、拳掌、枪棍、暗器子类型；
- 桩功、导引、横练只作为锻体标签；
- 品阶只能使用粗浅、寻常、上乘、绝学、镇派；
- 效果图示意名称不会自动进入剧情目录。
- 每门可学武学必须声明临阵所长、传承来源、首次兑现和至少一项场外用途；
- 轻功若没有改变追逐、脱身或路线，目录校验必须失败；
- 配套武学只能指向一门有效传承，不能指向自身。

### 20.2 研习与突破

- 研习消耗40阅历并增加10修为；
- 修为达到100后不会溢出；
- 突破缺任一条件时逐项说明；
- 研习与突破没有随机失败；
- 品阶不会为通用研习增加隐藏倍率；
- 首次实战奖励不能通过读档重复领取；
- 同一武学在同一场景更换动作不会重复增加修为；
- 实际用过的节点会留下`node:{nodeId}`记录，旧档已有首次使用记录不会丢失；
- 圆满不再增加第三点通用熟练修正。

### 20.3 携带

- 心法、轻功、锻体各只能携带一门；
- 招式可携带三门；
- 有空位显示“携带”，满位显示“替换”；
- 替换必须选择具体位置并二次确认；
- 点击条目或携带位不会立即穿卸；
- 未满足兵器条件仍可携带，但主动动作置灰；
- 已学未携带武学仍能参与合理的知识判断；
- 永久属性不会因卸下武学消失。

### 20.4 战斗

- 武学熟练修正正确进入唯一行动公式；
- 战斗动作绑定具体领悟节点后，节点未解锁时保留动作并明确显示“需要领悟”；
- 当前伤害由武器、招式、属性、境界和催动推导；
- 管理页的基础命中不错误加入具体敌人防御；
- 近距／中距／远距和近战／远程不混用；
- 大成、得手、得手有损、失手正确取伤害档位；
- 常式和催动共用固定因果骰；
- 锻体角色不显示真气；
- 聚气角色真气跨战斗保存；
- 真气不足只禁用催动，不禁用常式；
- 敌人真气催动有公开意图和资源约束。
- “行波定海”只在鱼跃龙门诀与定海桩同时携带时生效；拆开后两门武学仍可单独使用；

### 20.5 叙事

- 新武学在一至两个场景内出现首次主动兑现；
- 武学的战斗外用途由按钮或条件产生实际结果；
- 获得、研习、突破和首次使用均幂等；
- 武学来源人物、势力和事件可追溯；
- 首次兑现、重复使用和修为增加会紧随行动结果写入叙事信息流；
- 关键选项直接显示相关武学与造诣；
- 玩家界面不显示内部ID、旧分类或产品术语。

### 20.6 界面

- 左栏可见约五项并有滚动提示；
- 左栏不重复修为、伤害和大号携带标签；
- 中央六格尺寸与间距一致；
- 1272×660一类中等横屏必须保留三排携带位的明确间隔，不得因按宽度放大而纵向相贴；
- 六格内的圆形武学徽记统一占槽宽72%；图集本身的透明留边应在徽记内部补偿，不得叠加第二层缩小圆框；
- 右栏能分别正确渲染四种分类模板；
- 尚未获得对应传承时，左栏使用印记、标题和一句世界内提示，右栏沿用详情页首部与分隔线结构；禁止回退到硬边空框或大号单字占位；
- 品阶名、名称和底框使用同一品质色；
- 修为条始终使用统一颜色；
- 已满足兵器条件不显示，无条件时赤字提示；
- 844×390横屏可以完成研习、突破和替换；
- 390×844竖屏没有横向溢出；
- 关闭详情、返回和数字键可用；
- 颜色不是品阶和可用性的唯一表达。

## 22. 完成定义

完整武学系统必须同时满足：

- 玩家可学多门武学，并用六个携带位形成临战方案；
- 四类武学在详情、用途和战斗行为上明显不同；
- 品阶、造诣、修为、境界和阅历职责不混淆；
- 武学与属性、装备、境界共用唯一战斗公式；
- 四类右侧详情正确显示各自最重要的信息；
- 新武学在一至两个场景内获得主动兑现；
- 已学未携带仍保留合理知识，突发行动仍受携带限制；
- 锻体阶段不显示真气，聚气后才教学并开放催动；
- 当前六门可获得武学、金刚斗猿桩伏笔和既有存档无损迁移；
- 桌面、手机横屏和手机竖屏完成交互回归；
- 规则测试、内容校验与完整浏览器流程通过；
- 文档、运行时、测试和玩家可见术语保持一致。

达到以上条件后，玩家面对武学页时应能立即说清：

> 我现在运转哪门心法，带着哪三门招式，靠什么轻功进退，又用哪门锻体扛住代价；下一笔阅历投下去，会让我多出什么真正可用的本事。
