# SYS-02 人物成长与武学系统

## 1. 系统目标

把五维、潜能、医术进度和几门固定武学扩展为可长期成长的武道系统，同时保持“能力改变行动深度”，避免退化为堆数值自动胜利。

## 2. 当前基础

当前已经支持：

- 五维与已有属性重分；
- 出身、初心和固定债务；
- 潜能消耗与秘籍入门；
- 《鱼跃龙门诀》的水行判定；
- 《青青册》《五禽戏》和《打鱼杆法》；
- 一次五禽属性增长；
- 有效悟性和首次炼丹门槛。

主要缺口：

- 没有统一武学目录与招式数据；
- 武学“拥有”和“掌握”区分不足；
- 没有锻体内部阶段、突破条件和失败后果；
- 多门心法、桩功、招式之间没有冲突与协同；
- 训练只有加进度，缺少方法、师承、环境和身体负荷；
- 后续十余门武学无法继续用独立布尔字段维护。

## 3. 成长层级

人物成长分为五层：

1. 属性：力道、根骨、身法、悟性、福缘；
2. 武境：未入门、锻体、聚气、通脉、宗师；
3. 学识：医术、炼丹、采集、钓鱼、毒术等；
4. 武学：心法、桩功、招式、轻功、奇术；
5. 身体与心性特征：宝鱼气血、钢筋铁骨、杀意、净魂等。

原著炼体一至四重只映射为本项目“锻体”内部进度，不新增第二套公开境界。

## 4. 属性事实来源

建议拆分：

```js
attributes: {
  base: { strength: 0, root: 0, agility: 0, insight: 0, fortune: 0 },
  earned: { strength: 1, root: 0, agility: 0, insight: 1, fortune: 0 },
  allocation: { strength: 0, root: 0, agility: 0, insight: 5, fortune: 0 }
}
```

- `base`来自人物建立；
- `earned`来自五禽、宝鱼和长期修炼；
- `allocation`是逆天改命当前分配；
- 有效值由身体状态、武学、环境和伤势修正后计算；
- 任何系统不得直接缓存有效值到存档。

## 5. 武学数据模型

```js
{
  id: "spring_rain_needles",
  name: "春风化雨针",
  type: "technique",
  grade: "yellow",
  tags: ["needle", "medical", "ranged", "lethal"],
  source: "cao_qing",
  prerequisites: [],
  mastery: { level: 1, progress: 0 },
  moves: ["seal_acupoint", "stop_bleeding", "pierce_vital"],
  passives: [],
  conflicts: []
}
```

武学必须区分：

- 已知：知道名称和来源；
- 持有秘籍：可以研读但尚未入门；
- 入门：至少能使用一式；
- 熟练：可以改变行动深度；
- 精通：解锁被动或组合；
- 突破：品阶或规则发生变化。

## 6. 武学类别

| 类别 | 主要作用 | 当前与后续代表 |
| --- | --- | --- |
| 心法 | 提供长期根基和判定修正 | 鱼跃龙门诀 |
| 桩功 | 塑造身体方向和锻体突破 | 神农枯木桩、沧澜定海桩、金刚斗猿桩 |
| 招式 | 战斗或场景中的主动动作 | 打鱼杆法、春风化雨针 |
| 轻功 | 旅行、追逐、潜入和战斗位置 | 踏水九连环 |
| 奇术 | 改变特殊规则 | 五禽戏、飞星定穴法、止杀诀 |
| 毒功 | 以毒素、耐性和身体负荷换力量 | 盘蛇毒经、毒桩 |
| 心神法 | 抵抗或影响意志 | 冰心净魂、浩然相关能力 |

## 7. 修炼行动

修炼不再统一为“消耗潜能加进度”。每次修炼由以下因素决定：

- 方法：独练、师父指点、实战、观摩、药浴、奇珍；
- 时间：时段或连续天数；
- 资源：潜能、饱腹、药材、银钱、关系；
- 环境：水边、丹房、猴洞、静室；
- 身体：伤势、疲劳、毒性和负荷；
- 风险：走火、旧伤、暴露、错误领悟；
- 结果：进度、招式、属性、特征或突破条件。

同一天重复同一练法应递减收益并增加透支风险。

## 8. 桩功选择与冲突

P0首先支持二选一：

### 神农枯木桩

- 强化恢复、耐毒、药性吸收和濒死支撑；
- 与医术、毒术和春风化雨针协同；
- 代价是爆发和追击较弱。

### 沧澜定海桩

- 强化水中稳定、气血循环、抗冲击和心法协同；
- 与鱼跃龙门诀、打鱼杆法和踏水轻功协同；
- 代价是离水环境提升较慢。

后续加入金刚、止杀和毒桩时，角色可以兼修，但必须承担：

- 每日修炼时段竞争；
- 身体负荷上限；
- 相冲特征；
- 师父或势力态度；
- 突破时的路线取舍。

## 9. 武境突破

突破不是经验条自动升级。统一要求：

- 身体进度；
- 一门达到要求的桩功；
- 至少一项实战或生死见闻；
- 对应资源或环境；
- 身体无阻塞性重伤；
- 玩家主动确认风险。

突破结果可为：

- 稳定突破；
- 带伤突破；
- 失败但看见缺口；
- 走火入魔；
- 致命失败。

## 10. 招式与场景兑现

招式不能只在战斗页出现：

| 能力 | 战斗外用途 |
| --- | --- |
| 春风化雨针 | 止血、封穴、诊断、唤醒 |
| 打鱼杆法 | 打捞、探路、绊倒、触发远处机关 |
| 鱼跃龙门诀 | 逆流、闭气、辨水势、稳定药性 |
| 飞星定穴 | 治疗、制止失控者、秘密审问 |
| 踏水九连环 | 赶路、逃离、潜入、抢救落水者 |
| 止杀诀 | 控制杀意、使用七杀刀、识别凶性影响 |

每门新能力必须在内容包中声明首次兑现节点，校验器检查其是否存在。

## 12. P0实施顺序

1. 统一武学目录和存档结构；
2. 迁移现有五门能力；
3. 增加招式与被动；
4. 实现春风化雨针的医治和战斗动作；
5. 实现拜师与两套桩功；
6. 实现锻体起步条件板和突破；
7. 把八月十五神猿动作写成金刚路线伏笔，而非立即发放完整武学。

## 13. 测试矩阵

- 逆天改命只能重分已有点数；
- 伤势修正有效属性但不污染基础属性；
- 持有秘籍不等于可以使用招式；
- 春风化雨针可止血，也可造成致命穿刺；
- 桩功二选一后提供不同条件和行动；
- 同日重复训练收益递减并提高负荷；
- 锻体突破缺任一条件时说明具体缺口；
- 回照恢复武学进度，但保留已经亲历的失败见闻；
- 旧存档中的现有能力完整迁移。

## 14. 完成标准

玩家能从“曹青传针”连续走到“拜师选桩并进入锻体”，两种桩功至少各改变一个战斗行动、一个非战斗行动和一个突破条件，才算P0完成。
