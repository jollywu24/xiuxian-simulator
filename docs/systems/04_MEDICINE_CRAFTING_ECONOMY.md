# SYS-04 医术、炼丹、毒术、物品与经济系统

## 1. 系统目标

把《青青册》等级和首炉回春丹扩展成一套可玩的“诊断—取材—处理—配方—使用—后果”系统，并为后续毒术、奇珍、装备、银钱和交易提供统一物品事实来源。

## 2. 当前基础与缺口

已有：

- 医术、炼丹、采集、钓鱼等级和进度；
- 潜能门槛；
- 回春丹火候选择、品质和失败重试；
- 六枚丹药、银柳木竿、十两银子等剧情物件；
- 宝鱼和草药的固定奖励。

缺口：

- 物品散落为多个字段，没有统一目录和数量；
- 丹方没有材料、步骤、器具和药性；
- 医术不能主动诊断病例；
- 药材没有来源、品质、部位和保存；
- 毒没有剂量、发作和解毒；
- 银钱与渠道只用于单次剧情；
- 装备和奇珍没有使用、损耗和关系归属。

## 3. 统一物品目录

```js
{
  id: "return_spring_pill_low",
  name: "下品回春丹",
  category: "medicine",
  quality: 1,
  tags: ["stop_bleeding", "restore_qi"],
  stackable: true,
  value: { base: 300, currency: "cash" },
  effects: [/* 使用效果 */],
  provenance: true
}
```

库存使用：

```js
inventory: {
  items: { return_spring_pill_low: 6 },
  unique: [/* 血书、玉佩、特殊兵器 */],
  currency: { cash: 10000 },
  capacity: 20
}
```

不模拟每件衣物重量。容量只限制药材、器具和大件，剧情信物不占普通格位。

## 4. 物品来源与归属

关键物品记录：

- 来源人物或地点；
- 获得日期；
- 是否偷取、借用、受赠或购买；
- 是否被NPC知道；
- 是否涉及债务或证据；
- 是否可消耗、转赠或丢失。

同一瓶药因来源不同可以引发不同关系和势力后果。

## 5. 医术病例

病例包含：

```js
{
  id: "bai_zhiyun_deviation",
  symptoms: [/* 可见症状 */],
  hiddenCauses: [/* 病因 */],
  dangerClock: 4,
  examinationActions: [/* 问、望、切、试 */],
  treatments: [/* 稳定、治愈、冒险方案 */],
  contraindications: [/* 错药和禁忌 */]
}
```

诊断流程：

1. 看见症状；
2. 选择检查；
3. 获得见闻；
4. 形成推测；
5. 用第二种证据确证；
6. 选择稳定、根治或高风险治疗；
7. 处理复发和关系后果。

医术等级提高观察深度和容错，不直接弹出标准答案。

## 6. 药材模型

药材至少包含：

- 名称与部位；
- 药性标签；
- 品质；
- 新鲜度；
- 采集地点与季节；
- 炮制状态；
- 毒性或相冲；
- 可替代材料。

P0只制作紫龙换血丹所需材料、回春丹材料和常用止血／稳脉药，不建立百种无用草药。

## 7. 配方与制作

```js
{
  id: "purple_dragon_blood_pill",
  category: "alchemy",
  ingredients: [/* 数量、品质和替代 */],
  tools: ["medicine_stove"],
  steps: ["prepare", "extract", "change_fire", "seal"],
  checks: [/* 医术、炼丹、心法 */],
  outputs: [/* 品质结果 */],
  failures: [/* 废丹、毒丹、爆炉 */]
}
```

制作至少允许：

- 严格照方；
- 用替代材料；
- 追求品质；
- 保留特殊药性；
- 中途停炉；
- 失败产物再利用。

## 8. 品质

品质不只提高数值：

| 品质 | 作用 |
| --- | --- |
| 废品 | 可能留有毒性或材料回收价值 |
| 下品 | 完成基础效果，副作用明显 |
| 中品 | 效果稳定，副作用降低 |
| 上品 | 可改变治疗或突破路线 |
| 特殊变体 | 保留某种药性，开启独特用途 |

P0只需废品、下品和中品，后续丹药提纯时再开放上品与变体。

## 9. 毒术

毒物统一记录：

- 入口：口服、吸入、伤口、接触；
- 剂量；
- 潜伏；
- 症状阶段；
- 可检测方式；
- 压制与解毒；
- 耐性增长；
- 物品、针法和桩功的使用方式。

医术可以辨毒和救人，毒术可以控制剂量和利用症状。两者共享知识但保留道德与关系后果。

## 10. 银钱与渠道

经济系统只服务选择，不模拟市场经营。

渠道类型：

- 普通店铺：稳定、品类有限；
- 沈家：需要权限与人情；
- 曹青旧关系：药材专业但会留下记录；
- 王五水路：宝鱼和河产；
- 黑市：稀有但有欺诈和势力风险；
- 官面缴获：需要燕惊鸿或公文；
- 帮会渠道：价格受声望和警戒影响。

价格由基础价、稀缺、关系、违法性和世界状态计算，不做每日随机波动。

## 11. P0三夫人闭环

1. 通过症状发现病危倒计时；
2. 医术检查区分外伤、中毒和走火；
3. 查到紫龙换血丹方案；
4. 选择向沈家、曹青或黑市找材料；
5. 炮制并炼丹；
6. 决定先稳脉还是直接换血；
7. 春风化雨针参与封穴；
8. 产生命救活、留下后患、治疗失败或错过四类结果；
9. 记录药材债、救命债和丹方掌握。

## 14. 测试矩阵

- 库存不可出现负数量；
- 关键物品记录来源且不能重复领取；
- 同一症状在不同医术下显示不同信息；
- 错误诊断不会被系统自动纠正；
- 替代药材会改变品质或副作用；
- 中途停炉保留合理失败产物；
- 毒的潜伏和发作按时间推进；
- 伤势可被对应药物治疗而不是全量恢复；
- 黑市价格和风险受关系、戒严影响；
- 版本3中的六枚回春丹和十两银子正确迁移。

## 15. 完成标准

P0完成要求三夫人病例能够在不改核心代码的情况下配置至少四种结局；玩家必须真实取得材料、炼出丹药并选择治疗时机，而不是满足等级后直接治愈。
