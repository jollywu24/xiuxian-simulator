# S0 视觉与资产契约

范围 A05。采用原创绘本式 2D 江南场景、斜向俯视、人物精灵、局部光影与克制特效。定标工作台固定 1600×900 逻辑画布，保持 16:9；主界面场景与叙事约 2:1。场景不旋转；S1 镜头跟随和遮挡由地图模块实现。美术目标是清晰空间、可辨人物、动作有因果反馈，不以单张高精度背景替代整体质量。

色板：墨青 #132c2c、灰绿 #929d92、暖金 #c9b17b、朱印 #93483b。背景控制饱和度，角色外轮廓保留亮暗分离；危险同时用形状和文本表达。材质采用石板、白墙、深瓦、木柱与银杏叶，避免高反光塑料感。

已制作：青河渡口底图一张；四名角色共用的 4列×4行透明动作样板图集一张；程序化剑光、棍击、暗器与治疗反馈；昼、灯夜、烟雨三个环境预览。角色图集每列一个人物，每行站立、迈步A、迈步B、出手。当前单朝向、步行插值、招式姿势为质量探索，**不是首发全部方向动作已经量产**。护院复用样板外观，只用于战斗可读性评估。

导入契约：底图PNG RGB，人物PNG RGBA；底图完整保留来源；角色裁切归一到 160×200，脚底锚点 (80,180)，运行画面显示约90×112逻辑像素；真实图集1254×1254，裁切元数据在 renderer.loadAtlas，按宽度比例计算。正式量产须将其抽为独立 manifest，并固定相同画布、脚底、武器伸出边界与命中时刻。不得把样板中逐行裁切值扩散成不同角色的临时补丁。
