# S0 产品与世界规则定稿

版本：2026-09-17；范围 A01、A02、A03。以下为目标规则，工作台只实现战斗定标子集。

**定位：以大曜江湖为舞台的 PC 单机武侠沙盒 RPG。玩家操控陈司命，通过探索、武学、结交与门派身份解决局面；四人回合战斗承担武力解法，关系与制度提供其他解法，事件后果改变回访时的江湖。**

目标玩家是愿意读对白、研究队伍、主动找路和承担选择后果的武侠 RPG 玩家。首小时应经历一次自主选路、一次能力兑现、一次有代价的失败和一次回访反馈。参考《大侠立志传》的行动自由、《烟雨江湖》的区域内容密度、《逸剑风云决》的场景层次与武学表现；不复制专有人物、美术、台词和剧情。

体验支柱：一件事有至少两种成立的解法；武学兼有战斗和探索用途；同伴有利益与行为边界；世界变化有来源、有预警、能回访。主循环为获得线索→选择手段→付出资源或关系代价→获得能力或权限→进入新地区→回访旧关系。探索、叙事和战斗相互兑现，避免内容变成待清空的标记。

平台冻结为 Windows 10/11 x64、键鼠、离线单人、买断本体，简体中文首发。手柄与其他语言须单独通过预算变更；移动和主机为 S4，浏览器横屏保留为研发试玩兼容面。无强制账号、联网经济、抽卡、体力、日常签到和多人同步。Steam 是发行目标，商店、SDK、云存档和税务等留给 W 阶段，不在 S0 假称完成集成。旧网页版本继续作为旧版运行。

目标验证档位（测试目标，不是已公布最低配置）：低档 i5-8250U/UHD620/8GB/SSD，1080p 低画质 30fps；推荐档 Ryzen5 3600/GTX1650 4GB/16GB/SSD，1080p 标准 60fps。必须实测后才能公布配置。首发 20–30 小时为内容节奏目标，不是当前可玩时长。

| 行为 | 冻结规则 | 事前提示与后果 | 异常／退路 |
| --- | --- | --- | --- |
| 攻击 | 普通成年江湖人物允许敌对行动；儿童、纯背景人物和受保护的关键人物不提供致死攻击 | 区分切磋与攻击，展示阵营、目击和可能死亡；不可逆攻击二次确认 | 保护对象说明为何不能攻击，提供质问、挑战或任务解法 |
| 战败 | 常规冲突进入受伤、损失或被捕；明确致命事件才死亡 | 入场前标示切磋／危险／致命；受伤改变行动成本 | 非致命失败推进；死亡回到最近有效记录，不写坏档 |
| NPC 死亡 | 普通命名人物允许死亡，保护名单由内容表明确 | 对话、商店、任务同步关闭或转移 | 每个依赖必须有遗物、继任者、替代线索或明确失败结算 |
| 偷取与潜入 | 物品保留所有者与唯一 ID；成功不等于无人知情 | 提示禁区、物主和风险；目击者才产生第一手记忆 | 犯罪记录按地域传播；未被目击也保留失物事件，不能瞬间全世界通缉 |
| 治安 | 轻罪可赔偿，重罪触发追捕、拒绝服务和通行限制 | 账单展示处罚来源、金额与解除方式 | 必有投案、赔偿、服役或躲避后续任务中的一种可玩出口 |
| 拜师 | 同时一个正式门派；外门关系可并存 | 资格、介绍人、考核、禁忌、传授承诺明确 | 不满足条件给可达的替代准备路线 |
| 退门 | 保留已学知识；撤销身份、服务和未完成门派任务权限 | 展示关闭任务与关系影响；镇派授权单独规定 | 不删除背包、不清空人物；再次入门需明确补偿条件 |
| 任务中断 | 未接、进行、完成、失败、关闭互斥；奖励键仅结算一次 | 限时只从告知后计时；地图／日志显示失效原因 | 提前拿物、目标入队、跨区、死亡和迟到均有显式分支 |
| 时间 | 沿用十二时辰、每时辰八刻；菜单与阅读暂停 | 耗时行动提交前显示刻数 | 战斗结束统一结算一次，禁止动画推进第二套时间 |
| 同伴离队 | 四人含主角；离队保留人物状态、归属和重逢地点 | 招募满员须先指定替换；明确装备去向 | 剧情强制离队有预警，不能默默吞唯一任务物 |

禁止用无限程序化任务填充内容指标。世界演化采用有因果来源的有限事件状态；离屏批量结算，不在首发承诺全社会逐帧模拟。以上目标尚未在 S0 全量实现，后续交付对应 C–N 模块。
