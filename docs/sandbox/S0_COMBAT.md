# S0 战斗与队伍定标

范围 A04。决定：**四人队伍、四向方格、阵营轮流回合**。稀疏节点仅保留在工作台作比较，不成为第二套正式模式。

实作场地为 10×7 格，3 个阻挡格；4 名队员对 3 名护院。每名队员每轮 3 AP；一次移动每经过 3 格消耗 1 AP（向上取整），不允许穿过活体占位；伤害和治疗技能耗 2 AP，守势耗 1 AP；手动交还回合后敌方依距离和可达性行动，存活队员恢复 AP。左侧 x≤1 为撤退区，胜、负、撤退只推进世界 1 刻。切磋不永久死亡。

| 对照 | 四向方格（采用） | 稀疏节点（不采用） |
| --- | --- | --- |
| 移动选择 | 每格明确；堵路与侧翼可由地形解释 | 仅 13 个锚点；部分视觉空地不能落脚 |
| 距离 | 曼哈顿步长，路径成本可预览 | 锚点边同样按步长计费，容易产生一步跨多格的感知差异 |
| 四人占位 | 可让路、卡口、保护后排 | 锚点占位更容易封锁主要连接 |
| 内容制作 | 统一导航格＋碰撞，场景美术可独立细化 | 每张地图需维护额外锚点与连接 |
| 结论依据 | 可运行灰盒、路径与占位测试、实际键鼠操作 | 同规则可切换演示；未做外部玩家研究，不报告偏好比例 |

比较入口：展开工作台底部，切换“空间规则”。两方案使用同一队员、地图、AP、伤害公式和随机种子。节点样板不代表已验证连续空间碰撞，不能复用为正式通行规则。

伤害调用原 `character-system.mjs` 的 calculateDamageRange、damageForTier、applyDamageReduction；固定因果调用 rollCausalDie。不得再维护独立公式。每个动作先 inspectAction 查询再 applyCommand 提交，拒绝时原状态不变。预览与结算共用射程、阻挡和费用判断。

操作：点击人物／数字 1–4 选人；点击地面或方向键移动；点击招式再点目标；交还回合；左侧撤退。当前英雄剑、同伴棍、暗器与治疗只是职责样板，S1 再扩展装配与构筑。缺失方向动作、击退、完整装备、真气、状态叠加、剧情战果都不算 S0 已完成。

S1 必须补齐：行动费用悬停预览、连续移动合并、敌方意图、动画时序阻断与跳过、战场入出场、技能范围数据化、首战引导。验收先检查选择能否改变结果，再扩展数量。
