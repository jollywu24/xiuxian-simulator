# 《武道》高武江湖设计文档

> 一个能看见奇遇条件、却仍要用有限命灯亲手支付代价的无名少年，在高武江湖中寻找自己的第一条路。

当前已实现剧情的时间线、分支后果、人物弧光、信息揭示顺序与后续伏笔，统一参见 [《大曜江湖》完整剧情线参考](STORY_BIBLE.md)。

从当前首章扩展到完整游戏所需的系统、依赖和制作顺序，统一参见 [《大曜江湖》完整游戏系统路线图](SYSTEM_ROADMAP.md) 及其拆分的[系统制作文档](systems/README.md)。

战斗的信息公开、身体状态、死亡学习、位置环境、图文呈现与长期后果，统一参见 [《武道》战斗系统参考与转化](COMBAT_DESIGN_REFERENCE.md)。

三种出身、独立开场、破庙汇流与沈家入口的现行规格，统一参见 [《三出身与独立序章系统》](systems/11_ORIGIN_PROLOGUES.md)。当前网页已经提供世家旁支、市井子弟、身世成谜三条入口，并在曹青丹房前稳定汇流。

## 1. 第一版产品定义

第一版只发生在武道世界“大曜”，不设置现实身份、现实同步、论坛、武道局或其他玩家。主角从“世家旁支、市井子弟、身世成谜”三种来处之一开始，在十五至二十五分钟的独立序章后进入金陵城外破庙，完成求生、固定奇遇、人物奇遇、死亡回照和心法初试，继而以不同身份进入沈家丹房，把已经获得的心法、命灯和线索用于一场新的死局。

核心循环为：

> 了解眼前处境 → 建立人物与债务 → 看见奇遇条件 → 支付时间、资源、关系或命灯 → 获得武学与门路 → 立刻用新能力打开新的道路。

第一版要证明三件事：

1. 高武世界可以通过场景和人物逐层进入，而不是靠名词列表解释；
2. “逆天改命”改变条件信息和行动方案，而不是自动发奖励；
3. 每次获得武学、信物或关系后，短时间内都有可操作的兑现机会。

## 2. 明确边界

### 2.1 必须存在

- 一个自洽的高武王朝与江湖秩序；
- 人物建立、出身所得与江湖牵连；
- 五维属性、命格、两盏命灯；
- 固定奇遇与人物奇遇；
- 可选择、可错过、可死亡的事件；
- NPC 关系与势力入口；
- 武学获得和同世界内的即时应用；
- 三条能继续扩展的江湖去路。

### 2.2 第一版不做

- 现代或现实世界；
- 两个世界之间的能力同步；
- 论坛、排行榜与新人登记；
- 其他玩家、多人竞争或交易；
- 自由格子战棋、随机装备海、耐久强化和大地图自由移动；
- 大量门派、境界和历史名词一次性灌输。

NPC、门派、世家、帮会和朝廷机构属于世界本身，不属于“其他玩家”。

## 3. 高武世界结构

第一版使用原创世界“大曜”。对《一世之尊》前期只参考四种体验：低位人物入场、地方秩序层次分明、顶级武力作为遥远天花板、每个事件同时牵动个人与势力。不得照搬其人物、门派、榜单、轮回空间、境界名称或具体剧情。

| 层级 | 表面职责 | 对主角的实际影响 | 第一版呈现方式 |
| --- | --- | --- | --- |
| 朝廷 | 守城、驿路、律法 | 城内规矩可借，城外保护有限 | 世界入场与金陵官道 |
| 山门 | 传承武学、占据山场 | 决定正统武学来源和身份门槛 | 作为远景，不展开具体门派 |
| 世家 | 守土、经商、掌握地方关系 | 信物能开门，差事也可能是死局 | 沈字铜钱与沈家丹房 |
| 帮会 | 控制水路、码头和生计 | 人情与权争会改变一整条路线 | 龙青鱼与漕帮 |
| 游侠、市井 | 送信、护运、买卖情报 | 主角早期行动和生存的主要空间 | 破庙、官道、金陵外城 |

武道层级只在需要时解释：

1. 未入门：普通人的气血水平；
2. 锻体：正式熬炼筋骨，可修招式；
3. 聚气：内息成流，超出凡俗技艺；
4. 通脉：气走周天，可隔空发劲、踏水疾行；
5. 宗师：精神与天地相合，一人足以镇住一方势力。

开场只明确“未入门”和第一步“锻体”。聚气通过青衣妇人的死亡预见自然出现，通脉和宗师只作为世界武力上限。

## 4. 渐进式入场

### 第一层：世界

开场只回答三个问题：

- 大曜朝廷管什么；
- 山门、世家与帮会为何能影响普通人的生活；
- 强者能强到什么程度，而主角目前有多弱。

### 第二层：人物建立

人物建立不只选择数值，还选择社会位置和第一段亲历：

- 世家旁支：从沈家西偏院领受雨夜取匣差事，有沈家的姓氏与有限外院权限，也受家法、名声和内宅调用约束；
- 市井子弟：从秦淮外港鱼市接下红绳油布包差事，熟悉物价、黑话、后门和底层人情，却没有正式担保；
- 身世成谜：从破庙冷醒，持有半块玉佩与血书，更容易触及身世隐秘，也更容易引来追查。

初心决定角色为何继续行动，并在人物对话中提供不同立场。

### 第三层：事件

三种开场先用地点、任务和人物态度解释玩家处于江湖哪一层，再让角色以不同理由抵达破庙。破庙不再是必须按顺序点完的选项链，而是第一个完整局面：庙前、大殿与庙后三块区域可以自由切换，十二个对象可以直接查看；观察和区域切换免费，救火、拆物、清路与深入调查会推进八刻局面时间，雨势、脚步与来人按状态自动发生。玩家不可能无代价清空所有内容，前半场改变过的火堆、破窗、柴堆、香架、暗墙与塌墙还会在后半场再次提供用途。对象的完整描述与动作位于右侧当前上下文，浅观察不写入历史；角色自由移动继续暂缓。

这一局面已经接入：

- 乌沉药匣的完整、检查、拆封与遗失状态；
- 三种出身对同一对象的不同知识和行动；
- 脚夫的生死、信息和救治代价；
- 龙青鱼对玩家此前行为的见证；
- 追兵危机中战斗、撤离、藏匣与环境利用；
- 见闻、关系、资源和地点状态在离场后的立即回响。

三条序章只在曹青取血前汇入同一主线：

- 世家旁支回府复命，经旁支试用被安排到丹房；
- 市井子弟从货门或铜钱进入沈家，因送药差事被曹青留下；
- 身世成谜持沈字铜钱谋差，四项普通差事落选后进入丹房。

汇流后仍保留出身见闻、地点权限、人物联系人和开场悬念，不得把独立序章清零成几句特殊台词。

## 5. 角色与成长系统

### 5.1 五维

| 属性 | 主要用途 |
| --- | --- |
| 根骨 | 气血、武学承载、部分奇遇限制 |
| 悟性 | 参悟、识破武学与突破瓶颈 |
| 身法 | 移动、潜入、闪避与轻功 |
| 力道 | 体力、负重、外功和环境互动 |
| 福缘 | 偶发人物、宝物与隐藏分支 |

旧版“破庙洗点后敲墙”的教程已经从新旅程撤销。初始属性在人物建立的属性步骤分配；后续若保留洗点，将通过世界内人物或设施实现，不再把临时重分作为第一场景唯一解法。“逆天改命”的剧情意义需要随破庙完整垂直切片另行重做，半块玉佩只保留为“身世成谜”的人物线索。

### 5.2 命灯

人物初始有两盏命灯：

- 熄灭一盏：保留死亡前记忆，回到最近因果节点；
- 两灯皆灭：本次人生终结；
- 已确认会死亡的重复选项在只剩一盏时隐藏，避免误触终结当前流程。

命灯是武道世界内的命格规则，不连接另一个世界。

### 5.3 阅历与武学

阅历代表可用于学习、参悟和突破的积累。所有武学统一分为心法、招式、轻功、锻体，并拥有粗浅、寻常、上乘、绝学、镇派五档品阶，以及未入门、入门、熟练、精通、圆满五档造诣。每档造诣内部有0～100修为；通用研习固定消耗四十阅历并增加十点修为，满百后按真实使用、领悟或人物事件突破，不掷随机成功率。

玩家可以学会多门武学，但突发战斗只读取六个携带位：一门心法、三门招式、一门轻功和一门锻体。已学未携带仍保留合理的知识与长期所得；需要立即运转的主动、身体被动和临战招路必须处于携带状态。兵器不合不会遗忘招式，但对应行动会明确显示“需要：剑／枪棍／针”等缺口。

鱼跃龙门诀是第一门可用心法，提供：

- 水中身法、耐力和闭气；
- 水意武学的悟性与根骨判定；
- 越境取胜后晋升品级的长期可能。

获得后立即面对赶往沈家的路途：顺紫金河游往东湖可以避开漫长官道，在饥饿耗尽体力前抵达；沿官道步行较安全，却会错过沈家当日收人的时辰。

## 6. 奇遇系统

### 6.1 固定奇遇

| 奇遇 | 条件 | 所得 | 当前可执行性 |
| --- | --- | --- | --- |
| 梁下抓痕 | 首夜只能看见新旧抓痕与金褐细毛 | 未揭示 | 只能记录征兆 |
| 神秘贡品 | 首夜只能确认山桃新鲜且来者熟悉漏雨处 | 未揭示 | 只能记录征兆 |
| 乌沉药匣 | 探清暗墙夹层 | 药匣、货路见闻与追兵局面 | 可完成，但属于主线局面而非隐藏奖励 |

固定奇遇属于地点，条件稳定，但首夜不显示完整条件、完成率或隐藏奖励。属性和准备只能改变玩家亲手完成行动的方式，不自动结算奇遇。

### 6.2 人物奇遇

人物奇遇的条件会被关系和此前选择改变。青衣妇人的身份在追兵危机落定前保持隐藏；她没有受伤，也不是追兵的逃亡目标，而是循乌沉药匣与货路痕迹来到破庙。追兵寻找的是药匣和见过交割的活口。

玩家可见结果包括：

- 把痕迹摆给她：已有行为越可信，越能提高信任；
- 先问来意：知道她循匣而来，并在等追者露面；
- 守住药匣：提高戒心，但不直接截断后续；
- 暗火倒架、塌墙撤离、柴堆藏匣与守门迎敌：形成不同追兵、药匣与伤势结果。

危机落定后，龙青鱼按信任、戒心和人情形成离散关系位置，留下阅历、临安入口和鱼跃龙门诀；不再用单场夜话直接固定为红颜知己或莫逆之交。

### 6.3 沈家丹房死局

本段按原作第十二至十八章的顺序重组为可操作事件，删除此前原创的沈砚秋、伏脉藤、封炉和三选一奖励。

1. 主角借鱼跃龙门诀顺紫金河抵达东湖沈家，以沈字铜钱得到一次谋差机会。
2. 管事依次列出护院、苦力、跑堂和账房的门槛。主角因为力量、根骨、敏捷、悟性和基础武学不足，四项皆不合格，只能进入无人愿去的曹青丹房。
3. 命格显示曹青本名庞不凡，是药王谷叛徒，并显示血灵丹经、毒师传承及曹青好感二十、四十、六十、八十的门槛。
4. 曹青强取一碗血。反抗与拒绝都会死亡；顺从则永久失去一点根骨并继续留在丹房。
5. 取血后可以休息或继续观察。休息会被判定无用，观察才进入炼丹盘问。玩家可把玉佩三点尽数改到悟性；鱼跃龙门诀在水炼相关观察中再提供两点有效悟性。
6. 三道盘问依次检验火候变化、丹砂水炼药序和求学动机。前两题答错会死；最后若直言想学炼丹会引起曹青杀心，回答“只想活命”才把好感推至二十。
7. 固定所得为一百八十阅历、炼丹进度六成一和《青青册》，不再提供虚构的三选一。
8. 医书第一层要求悟性三并消耗八十五阅历。次日完成辨药、尝味、诊脉考校后，曹青好感升至三十并传下五禽戏。五禽戏是调养身体的养生法，不会令主角立即突破锻体。

改编仅保留人物、事件、数值门槛与因果顺序，所有玩家文本使用原创转述，不复制小说正文长段落。

### 6.4 丹房日常与沈家密会

取得《五禽戏》后不再直接结算，而是进入每日三个时段的起居循环。

| 行动 | 当日代价 | 长期结果 |
| --- | --- | --- |
| 研读《青青册》 | 体力一、饱腹一、时段一 | 医术进度十七 |
| 练习《五禽戏》 | 体力一、饱腹一、时段一 | 五禽进度十四 |
| 整理丹房并旁观 | 体力一、饱腹一、时段一 | 丹理进度五 |
| 去灶房吃饭 | 时段一 | 体力一、饱腹三 |
| 闭门小睡 | 饱腹一、时段一 | 体力二 |

体力或饱腹降到零会死亡，并在仍有命灯时回到当日第一个时段；当只剩一盏命灯时，界面会禁用明确造成透支的行动。

《五禽戏》入门要求医术一级、悟性三和五百阅历。第一次完整演练后，从虎、熊、鹤、猿、鹿五戏中选择一点永久属性；该点以及之后宝鱼所得都纳入“逆天改命”可以重分的属性总数。原作路线选择猿戏，悟性增加一点。

第一日结算后，曹青带主角进入沈家密会。密会同时承担三个作用：

1. 让主角从丹房后院看见沈家真正的权力结构；
2. 揭示金龙会四堂回岛和三个月后的百舸争流；
3. 让曹青宣布离开沈家、由主角代为传递药材与差事。

沈福赠送十两银子后，原作路线为收下再向曹青如实交代。该选择把曹青好感从三十推到三十九，并建立此后找护院学钓鱼、进灶房取饵的沈福门路。

### 6.5 医术二级、黄金钱鳘与首炉炼丹

迁到东门药铺后，《青青册》先须通过日常研读达到十七进度，再消耗一百六十六阅历提升到二级。医术二级让主角看出：曹青要求返回沈家取药草的差事，是准备紫金河奇遇的时间窗口。

钓鱼条件板包含：

- 路边挖蚯蚓；
- 以逆天改命在杂货铺挑出银柳木竿，得到五十阅历；
- 由沈福引见走船护院，消耗五十阅历学会钓鱼一级；
- 从沈家灶房取得竹叶青和面团；
- 已掌握《鱼跃龙门诀》，能够游到第三段河湾。

紫金河先钓到普通鲫鱼，再遇见身份尚未揭示的摆渡老翁。玩家集中福缘后才令黄金钱鳘上钩。硬拽会被拖入深水，割线会失去本周奇遇，沿岸溜鱼并接受老翁指点才会合力擒鱼。

分食宝鱼使王五好感达到六十，取得五百阅历和一点力道，并开放《打鱼杆法》。杆法需要力道三、悟性二；《鱼跃龙门诀》参与水行悟性判定。玩家须再用逆天改命把已有属性集中到力道，才能把宝鱼气血转化为真正掌握的基础武学。

晚归后如实向曹青说明并演示杆法，好感越过四十。曹青依原作顺序两次指点《五禽戏》、一次指点《青青册》，随后正式传授回春丹。此时五禽所得一点与宝鱼所得一点令可调属性总数达到五；全部重分到悟性，再由《鱼跃龙门诀》增加两点，形成有效悟性七。

首次炼丹提供真实火候选择。错误会烧坏一炉药材并在次日重试，不消耗命灯；正确复现曹青的全部步骤，固定得到六枚下品回春丹、炼丹二级十二进度、《百丹注解》和“三种新丹换真正武功”的承诺。

### 6.6 三夫人病危与紫龙换血丹

首炉炼丹成功后，沈府夜召把已有医术和炼丹能力带入第一次完整病例。玩家不能直接看见病因，必须在四刻病势内通过望诊、切脉或索要练功残页取得见闻；呼吸错乱与经脉逆行互相印证后，才能确认是强练残缺功法所致。

紫龙换血丹需要紫鳞草、血藤芯和定脉砂。药材可以由曹青情分、白栀云的沈家权限或六两银子取得，分别改变信任、戒心和库存。炼制区分稳定、躁烈与焦结；治疗区分先封穴再服丹、直接服丹与放弃。完整救治使白栀云同时产生情分、信任和救命债，并传下既可封穴止血、也可穿喉制敌的《春风化雨针》。

### 6.7 雨夜战斗、拜师选桩与锻体突破

取得针法后立刻进入东门长街夜战。战斗状态包含轮次、距离、双方境界、当前武学、敌人意图、虚招、暗处短刃和伤势。每项行动只读取一项五维和至多一门武学，再由境界差、一次有利／不利和相关伤势形成行动修正；真正仍有不确定性的行动再掷一枚固定因果骰。相同存档、相同战况和相同行动的骰点不变，读取旧进度不能刷点数；改变属性、武学、见闻、伤势或战场状态后，新的因果键才会产生新结果。

夜战判定分为大成、得手、得手有损与失手。大成观察会抢得下一手先机，大成制伏、击杀或脱身会保住完整活口、左袖凭证或隐蔽退路，并直接提高后续盘问、搜查或追踪的胜算；得手有损会完成目标但留下部位伤势；普通失手推进到新的距离、伤势和敌人意图，不自动读档。第一轮观察、灭灯或先伤手腕会改变第二轮；看破左袖藏刀后可制伏、杀死或逃离。贸然只盯右手或在重伤下连续抢穴仍可能死亡，并把地点、死因、检定结果、左袖见闻和回照节点写入死劫履历。只剩一盏命灯时，明确必死行动不再出现。

夜战不是在结算页结束。制伏、杀死和脱身分别通过活口、尸身和雨痕进入追查；玩家补齐被确认的目标、回报暗语、鱼鳞铜签和丑时交接地点后，可以发送假消息接管旧渠道、改写接头地点、优先保护白栀云或磨平铜签隐藏结果。该回报链是为验证“受袭—识局—借局”加入的原创系统性改编，不冒充原著既有事实。

后续战斗统一使用“敌招 → 战局 → 选择 → 预测 → 兑现 → 余波”。敌招先公开主要目标和已知后手；多敌人使用横向单位栏，当前交锋展开完整信息，其他单位只显示小气血和简化意图；场景显示人物位置、出口与可选环境对象；默认只显示三项最相关行动，其余招式、身法、物品与退路进入“全部手段”。按钮在行动前说明胜算、主要依据、预计气血／位置变化与风险；结算事件驱动短段落、伤害飘字、状态笔触、轨迹和气血延迟扣除；重要战斗最终必须把伤势、关系、活口、证据、势力警戒或路线变化带回剧情。玩家最大气血为十二加根骨两倍及境界加成，既有伤势降低入场气血；自身归零进入命灯死局，击杀令敌方归零，制伏保留一点。气血用于公开换伤压力，不取代战斗目的。疲劳、士气与架势只在特定战斗中转化为“失衡”“喘息”“胆怯”“受困”等临时标签，不新增更多全局数值条。

独立演武采用比单次选项更有空间感的回合结构。我方阶段每轮获得三点“行动”，所有观察、武学、环境和换位共用这三点，不另设主行动、附赠行动与反应；玩家可以连续花完，也可以提前“收势迎敌”。敌方阶段按单位栏上的一、二、三顺序逐个兑现已公开意图，刀客会沿节点逼近或贴身出刀，弩手先瞄准再放箭，头目会蓄势、封锁矮墙或催刀合围。雨巷使用六个离散身位节点而非自由棋盘，移动一段通常消耗一点行动，脱离贴身额外消耗一点；节点同时决定贴身、近距、中距、远距、遮挡和翻墙条件。这样保留“先见后应”的清晰度，也取得利用空间造优的选择压力，但不要求玩家在手机上操作格子战棋。

后续将六节点直接合入左侧场景：人物、敌人、出口、环境对象和已知敌招覆盖在同一幅战场插画上；点击只选择对象，右侧确认动作后才结算。底层仍是五至九个离散节点，不制作自由格子、像素寻路和朝向系统。初版边界与待讨论问题见 [SYS-10 战场地图系统](systems/10_BATTLEFIELD_MAP.md)。

人物属性、装备和战斗已使用同一套公式：固定因果骰只掷一次，五维中的本次主属性、武学熟练、境界差、有利／不利和相关伤势形成行动修正；直接攻击还要面对目标防御。命中后由武器伤害、威力属性、境界、招式威力和本次催劲生成伤害区间，再按大成／得手／得手有损取上限／均值／下限，最后扣除减伤并处理穿透。玩家与敌人共用公式。

取得内功后显示跨战斗保存的真气池。真气用于催劲，后续随聚气剧情补护体和爆发身法；催动在原招式内形成变体，沿用常式同一枚固定因果骰，推荐区不会同时摆出两个版本，不建立分级法术位或独立法术栏。人物页已接入九个装备槽、二十四格装备行囊和十六件手工装备；换装后伤害、防御、减伤、气血或真气会立即重算。

夜战结果被曹青用于决定师徒关系。入门后从神农枯木桩与沧澜定海桩中二选一：前者擅长带伤和纳药，后者擅长水边定身与行气。首次站桩消耗一百二十阅历，锻体突破再消耗二百阅历，并检查桩功、伤势和真实生死见闻。成功后境界变为锻体一重。

### 6.8 八月十五、返回旧地图与灵猴遗迹

连续日历推进到八月十四。玩家必须在八月十五窗口内返回破庙：紫金河水路最快，官道会迟到，山路会产生腿伤，停留休整则永久错过。定海桩让水路抵达时保持气血平稳，枯木桩减轻山路伤势。

准时抵达会发现供桌贡品来自檐上灵猴。分享山桃、留下银钱或强取青果决定猴群情分、信任与敌意；猴儿酒可分享、当场炼体或全部带走。只有非敌对关系才会开放庙后猴道与神猿水洞。水洞内可安全记录挥棒残势，或亲身模仿并承担肩伤。完成后破庙从开局地点转为可长期返回的关系与传承入口。

## 7. 当前完整流程

`landing → characterDraft → appearance → 三出身独立序章 → templeWake（三地区／十二对象／八刻局面／药匣／脚夫）→ templeLady（行为反馈）→ templeCrisis（追兵多解法）→ templeDeparture（结果持久化）→ mindArt → roadTrial → roadResult → ending → shenArrival → shenJobs → caoArrival → ... → m4JourneyEnd`

`fateSight`、`allocation`、`templeTasks`、`originTempleTask`与旧龙青鱼连续对话仍可作为旧档迁移标识，但新旅程不再进入这些旧版破庙门槛。版本13会把仍在旧破庙流程中的存档汇入新探索或新来客局面；已经离开破庙的旧档不倒退。

支路：

- 正面守门会依据力道与根骨留下轻伤或中伤，不再因普通答错直接死亡；
- 撤离、藏匣和环境利用会分别改变药匣归属、追兵去向与人物态度；
- 紫金河水路可及时抵达沈家，官道路线会错过当日时辰；
- 结尾可记录沈家、破庙贡品或临安漕帮作为下一程；
- 选择沈家且持有沈字铜钱时可继续进入丹房；
- 取血时反抗或拒绝，以及炼丹盘问答错，都会进入 `shenDeath`；仍有命灯时回到曹青开口取血之前；
- 选择休息会安全结束沈家差事，却永久错过曹青传承；
- 正确完成三问后，奖励按《青青册》到五禽戏的固定次序推进；
- 丹房日常透支会进入 `shenDeath`，回照时恢复到当日开始；
- 沈福银子隐瞒、放弃钓鱼、割断宝鱼线、独吞宝鱼或向曹青隐瞒晚归都会形成不同的提前收束；
- 首炉炼丹选错火候进入 `alchemyFailure`，次日保留记忆和能力重新尝试，不消耗命灯。
- 三夫人夜召可拒绝；误诊、焦丹、错误救治或主动撤手会进入 `p0Missed`，永久失去白栀云与针法后续；
- 春风针夜战和强行锻体可进入 `p0Death`；仍有命灯时保留死因见闻并回到各自最近节点；
- 夜战可杀死、制伏或逃离，拜师也可拒绝；这些结果会留在后续状态而不是只替换文本；
- 八月十五走官道或延误会错过灵猴，强取青果会令猴群敌对；水路和山路按已选桩功产生不同结果。
- 曹青离场时只能保留一项临别帮助，药库、日常指点和师父担保不能同时继续；
- 钱匣至少查清两处疑点才能处置，设局需要三处；上交需要白栀云关系或曹青短札；
- 追踪选择读取对应五维和既有心法、桩功、杆法、回报渠道或人物信任；失手不会退回选择页，而会带着残页、警觉或轻伤抵达旧宅；
- 旧宅只能优先取得七杀刀痕、收货活证或白栀云支援之一；
- 沈福可被控制、揭发交人、放走或杀死，四条路线都会真实关闭、收紧或替换至少一条沈家门路；
- 白栀云授武需要救命关系与七杀物证，取得后三条卸力法会在下一场闭门试势立刻作用于现有桩功或封刀判断；
- 章末江湖留痕只汇总已经发生的事实，每句保留来源，不另造结果。

首炉炼丹以前形成两组成果：

## 9. 界面与叙事规则

- 信息层级参考《极乐迪斯科》的场景与对话分工，但不复制其美术：桌面和手机横屏由左侧场景承担空间、人物和热点，右侧单一叙事栏承担旁白、条件、结果和行动；
- 右侧叙事栏是一卷连续发生的记录：点击后，所选行动先转成“你”的紧凑记录，结果旁白分段接续，未选或新出现的行动再排到“接下来”之下；旧文只向上推移而不整页替换，最新行动停在右栏约四分之一高度作为阅读锚点；进入新场景时自动定位到“眼下”，玩家仍可向上回看先前经过；
- 火势、饥饿、伤势等即时变化优先在左侧场景以约一秒的有色飘字反馈，顶部状态同步落到最终值；右栏只叙述因果，不重复显示同一组数值变化；
- 每个属性、武学、关系、见闻或资源相关选项，都在选项内直接显示判定来源与简要条件；点击条件行可展开判定说明和当前依据，不另开脱离语境的规则面板；
- 选择颜色承担稳定语义：普通行动使用青色，重要且会改变路线的选择使用金色，明确高风险行动使用赤色，条件不足的行动保留在原位并使用可读灰色；颜色之外同时保留“重要选择”“高风险”“条件未满足”等文字标签；
- 人物、行囊、武学和见闻不再常驻左右两列，而是收进左下角四个独立入口；四者互相排斥，叙事经过直接留在右侧卷轴，见闻只保存玩家已经掌握的人与事；
- 行囊页不沿用叙事双栏：桌面与横屏完整覆盖设备视口，顶部保留人物／行囊／武学、银两与返回；左侧约三分之二用于六类图标、当前分类名、已用容量和六列四行物品格，右侧用于选中物品详情与使用；MVP竖屏只显示横置提示；
- 分类入口只显示图标，由无障碍名称说明全部、丹药、材料、兵具、信物和线索；格内不写物品名，只显示物品图、品质色底边与右下角堆叠数量，品质颜色不另设图例；物品来源不在行囊重复展示；
- 行囊容量固定为二十四格，堆叠数量不额外占格；同一物品跨旧字段和统一物品状态时先按稳定ID去重；只有带实际消耗效果的道具出现使用按钮，条件不足时按钮置灰并以世界内文字说明原因；
- 行囊美术不从效果图裁取带界面的局部：背景、十六件物品与回春丹详情图为独立生成资源，分页图标、银锭、宣纸选中态和空格纹样为可缩放资源；物品在全部分类中使用固定陈列顺序，确保同一批道具不会随来源字段改变位置；
- 武学页使用固定比例左／中／右三栏：左侧31.4%显示当前分类与可滚动传承，中间36%以人物立绘为中心环绕六个等大携带位，右侧32.6%按心法、招式、轻功、锻体分别显示修为、当前用途、数值、节点与养成操作；招式提供剑法、刀法、拳掌、枪棍、暗器二级筛选，已满足的兵器条件不重复占位，未满足时以赤字直接说明；
- 右侧行动按数字键顺序显示编号，使阅读、触控和键盘选择指向同一组选项；
- MVP手机竖屏只显示横置提示，不承担玩法布局；横屏以1672×941效果图为固定外层视觉标尺等比缩放，维持约三分之二场景、三分之一叙事、68像素顶栏、76像素行动框和左下羊皮纸入口的比例；超宽屏使用黑色侧边留空，不拉伸字号或间距；
- 左侧场景原画不是16:9整屏壁纸，而是为叙事栏让位后的独立舞台资产。横屏目标窗口约为1114×873，比例约1.28:1；破庙及其同地点人物变体统一使用1280×1000的5:4母版、居中覆盖，关键物件必须同时留在安全区内，目标分辨率下不得出现有意义的横向裁切；
- 破庙、紫金河、沈家侧门和丹房使用同一套“2D场景—可查看物件—人物站位—文字行动”结构；场景图先建立空间，文字继续承担动机、判断和后果；
- 场景物件读取真实状态：余火、暗墙所得、取血木碗、丹理进度与人物身份会随亲历变化，不把热点做成另一套奖励按钮；热点使用原始场景图坐标，并按实际背景缩放与裁切换算屏幕位置，禁止针对单一分辨率另写目测坐标；再次点击同一热点或点击场景空白处，必须同时关闭“所见”、连线和选中光环；
- 行路图只显示已经亲历、持有信物或经关系得知的地点；未知去处以雨幕等世界内表达保留，不提前展示攻略；
- 2D层不要求自由走动。玩家点击物件和人物查看处境，再从下方行动卡决定做法，以控制手机操作和内容制作成本；
- 玩家可见文本只属于世界、人物卡、场景、条件、选择、结果或资源变化；
- 新名词第一次出现时，由当前场景、人物或物品自然解释；
- 不显示开发阶段、测试、原型、构筑、自动保存等产品词汇；
- 不把旁白当玩法，关键发现必须来自选择、条件、资源或关系变化；
- 龙青鱼身份在夜话结束前保持隐藏；
- 成人情节只保留人物动机和选择压力，不展示露骨内容；
- 关键选择必须改变资源、命灯、关系、线索或后续入口；
- 桌面与手机都必须显示明确可操作项，不允许横向溢出。
