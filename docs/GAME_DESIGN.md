# 《武道》破庙奇遇设计文档

> 一款“看见所有奇遇条件，却必须用仅有的两条命亲手拿到它们”的武侠文字冒险。

## 1. 改编目标

当前可玩版以小说《文字武侠：开局破庙夜会帮主夫人》前十章为剧情基线，重现以下核心体验：

1. 现实中的普通人获得无法解释、无法卸载的文字游戏；
2. 选择高风险身世与专属命格后，以极弱人物进入真实江湖；
3. 看见正常玩家无法得知的奇遇条件，但仍要支付时间、体力、关系或死亡代价；
4. 在破庙从固定环境奇遇过渡到不可预测的人物奇遇；
5. 游戏收获同步现实，武道局随之进入主角生活；
6. 主角必须隐藏最珍贵的能力，同时利用它领先其他玩家。

游戏不复制章节正文。事件顺序、人物关系和规则取自原作公开章节，具体场景文案均重新组织为可交互叙事。

## 2. 原作前十章与游戏映射

| 原作节点 | 可玩场景 | 玩家操作 |
| --- | --- | --- |
| 陈玄在宿舍发现《武道》 | 现实开场 | 点开陌生图标，理解两界前提 |
| 选择身世、外观、五维、初心和命格 | 人物建档 | 选择身世、初心和江湖姓名，确认人物卡 |
| 专属命格“逆天改命” | 命格揭示 | 接受五维归零，获得奇遇条件视野 |
| 金陵城外破庙醒来 | 生存场景 | 拨火、找山桃、解除饥饿 |
| 三项固定奇遇 | 条件板 | 重分玉佩加成，完成旅人遗物与沈氏承诺，记下神秘贡品条件 |
| 游戏疲劳进入现实、发现论坛 | 现实论坛 | 得知两条命、现实同步、武道局与势力争夺 |
| 青衣妇人偶然进入破庙 | 人物奇遇 | 利用命格预见死亡、离开和后续关系分支 |
| 因爱成恨、破庙夜话 | 连续对话危机 | 在求生、利用和真诚倾听之间选择 |
| 龙青鱼留下心法 | 奇遇结算 | 获得关系、潜能、重逢入口与鱼跃龙门诀 |
| 心法同步现实、武道局登门 | 现实兑现 | 水下闭气验证能力，决定登记到什么程度 |

## 3. 双重身份

### 3.1 现实身份

- 姓名：陈玄；
- 处境：江海大学学生，暑假独自留校；
- 背景：父母早逝，有基本生活保障，熟悉游戏但不是武者；
- 初始认知：认为《武道》只是来历不明的小程序；
- 第一阶段转折：身体出现与游戏一致的疲劳、饥饿和心法效果。

### 3.2 武道身份

- 默认姓名：陈司命，允许玩家改名；
- 默认主线路线：身世成谜、求道者；
- 年龄：十六；
- 境界：无；
- 命数：二；
- 关键物：半块家传玉佩、一封指向金龙会万鲤堂孙不离的血书；
- 专属命格：逆天改命。

四种身世和五种初心均可选择，但当前完整剧情入口以“身世成谜”最贴近原作。其他身世能进入破庙，却没有玉佩的三点装备加成，完成沈氏承诺会消耗更多时间与山桃。

## 4. 逆天改命

命格同时提供两个规则级能力：

1. 随时重新分配当前已经拥有的五维属性；
2. 显示场景与人物的全部奇遇、条件、可能结局和品级。

代价是五维基础属性归零。它不能凭空创造属性，也不会自动完成条件。

因此破庙墙体不是“拥有命格便自动打开”，而是：

- 身世成谜提供的玉佩临时增加根骨、力道、身法各一点；
- 玩家可以把三点全部转为力道；
- 力道三能以更短时间完成敲墙，并保留山桃；
- 保持均衡或转为福缘仍可敲墙，但会支付额外时间和食物。

## 5. 奇遇系统

### 5.1 固定奇遇

固定奇遇属于地点，只出现一次，条件稳定：

| 奇遇 | 条件 | 所得 | 当前状态 |
| --- | --- | --- | --- |
| 旅人遗物 | 篝火只余一刻钟时，以供桌旧布添火 | 东郊残图、干粮、潜能 | 可完成 |
| 沈氏承诺 | 敲击东北墙体一千次 | 沈字铜钱、沈家入口、潜能 | 可完成 |
| 神秘贡品 | 晴日初一或十五、辰时、根骨不高于二 | 未知地级奖励 | 只能记录条件 |

### 5.2 偶发人物奇遇

人物奇遇不是“救一个身份不明的伤者”。龙青鱼进入破庙时没有受伤，也没有被追兵追赶。她是因为丈夫陆连山变心而独自离开漕帮，处于愤怒、失望且极危险的状态。

逆天改命显示每个回答的结果：

- 反唇相讥：先天以下死亡；
- 沉默避让：安全，但永远失去后续；
- 否认乞丐身份：进入“因爱成恨”；
- 宁死不屈：死亡；
- 暂时顺从：看清她真正痛恨的对象；
- 利用她的失意攀附：条件不足时死亡；
- 拒绝成为报复工具：进入破庙夜话。

成人情节只保留其戏剧功能——她试图利用陌生人报复丈夫，玩家选择利用、拒绝或倾听——不展示露骨内容。

## 6. 死亡与命数

人物初始有两条命：

- 第一次死亡：现实仍然存活，武道人物可返回，已知结局保留；
- 第二次死亡：现实死亡；
- 达到后天境界后可增加一次复活机会，当前流程尚未达到。

可玩版允许玩家主动尝试一次命格已经标明的死亡选择，用一条命验证规则。剩余一条命时隐藏明确会死亡的重复选项，避免误触直接结束试玩。

## 7. 龙青鱼与鱼跃龙门诀

龙青鱼并非单次奖励容器。她拥有：

- 身份：漕帮帮主夫人；
- 关系：陆连山的妻子，因对方贪权变心而离开；
- 当前需求：在没有帮派身份约束的地方倾诉并重新确认自我；
- 危险：情绪失控时足以随手杀死无境界人物；
- 后续入口：临安“重逢”奇遇。

破庙夜话根据回应增加不同好感。主线路线达到“莫逆之交”后获得：

- 潜能一千五百；
- 龙青鱼关系；
- 临安重逢入口；
- 黄级心法“鱼跃龙门诀”。

心法包含水下身法与闭气、水意武学判定提升、越境击杀后晋升三个规则效果。第一项必须立刻在现实盥洗间得到亲手验证。

## 8. 武道局选择

于可心与林毅登门后，玩家选择登记范围：

| 选择 | 收益 | 风险 |
| --- | --- | --- |
| 只登记心法 | 保留逆天改命秘密 | 武道局继续调查第一夜便获得心法的原因 |
| 承认部分奇遇征兆 | 获得一次官方保护与情报交换 | 进入高潜力新人关注名单 |
| 公开逆天改命 | 资深玩家立即提供保护 | 可能被要求优先为组织寻找奇遇 |

它把“隐藏金手指”转为实际策略，而不是只存在于旁白中。

## 9. 后续剧情入口

当前结尾同时留下三条可扩展路线：

1. 沈字铜钱打开金陵沈家，进入丹房差事与毒师传承；
2. 等到初一或十五回破庙，触发神秘贡品；
3. 前往临安寻找龙青鱼，触发重逢奇遇。

后续章节应继续遵循“条件可见、代价亲付、收获同步现实”的闭环。

## 10. 界面与叙事规则

- 开场先交代现实身份与异常设备，再进入人物创建；
- 新名词首次出现时由界面、论坛或人物自然解释；
- 龙青鱼身份在夜话结束前保持隐藏；
- 玩家界面不得出现 Demo、P0/P1/P2、原型、测试、构筑、自动保存等产品词汇；
- 小说内容使用原创转述，不逐段复制原文；
- 桌面与手机均需显示明确可操作项，重要结果不能只藏在长段旁白里；
- 所有关键选择必须有即时后果或后续状态变化。
