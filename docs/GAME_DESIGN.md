# 《太虚命盘》（暂定名）游戏设计文档

> 一款“先死明白，再逆天改命”的修仙人生模拟 Roguelite

> **当前浏览器 Demo 落地说明：** 为形成可从捏人玩到正式结局的闭环，Demo 将七年事件链压缩为第三月矿难、第一年旧档案、第五年祭阵准备和第七年黑日四个现实锚点，并实现四种轻量构筑、三种正式结局与一次二周目继承。它验证完整结构，但不等同于下述 10～15 小时正式版内容规模。

## 0. 本版结论

本项目不再制作“大而全”的宗门经营模拟器。

玩家不盖房、不排班、不维护几十种材料，也不从炼气一路刷到合道。宗门只是一个七年后必然覆灭的小社会；玩家真正玩的，是一次次进入可能的未来，亲自经历失败，把一项成果带回现实，再利用情报改写下一次死亡。

核心体验可以用一个场景检验：

> 第一次，玩家在宗门晚宴上中毒，被蒙面人杀死。
>
> 第二次，玩家提前盯住水井，发现下毒者也是被胁迫的受害者。
>
> 第三次，玩家故意让毒酒送上桌，借假死跟踪接头人，第一次摸到灭门真相。

如果游戏不能持续产生这种“原来如此——这次我换个办法”的冲动，其他修仙系统都没有制作价值。

## 1. 一句话概念

玩家创建一名七年后必死于灭门之劫的小宗弟子。借助残破的“太虚命盘”，玩家可以反复模拟自己的未来人生，并在每次死亡后，从道行、确证、词条抽取中只能选择一项，逐步拆掉导致灭门的因果链。

### 1.1 玩家幻想

玩家应当持续获得四种感受：

- 我不是靠读档蒙对答案，而是用上一条命换来了这一局的优势。
- 一个早期不起眼的人名、日期或物品，会在后来的模拟中突然产生意义。
- 同一个事件会因玩家的词条构筑、关系和准备不同，出现完全不同的破法。
- 最终破局不是等级碾压，而是我已看懂这场劫难如何运转。

### 1.2 三个核心动词

1. **试命**：为自建主角选择目标和准备，进入一条可亲自游玩的未来。
2. **带回**：模拟结束后，只保留一项最重要的成果。
3. **改命**：在现实中花费时间采取行动，让已知未来发生偏转。

### 1.3 明确不做

- 不做自由铺砖式宗门建设。
- 不做弟子日常排班和生产流水线。
- 不做开放世界清问号。
- 不做数百种材料、丹方和装备的仓库管理。
- 不做八大境界的漫长刷数值流程。
- 不做随机事件拼盘；关键事件都属于可追查的因果链。
- 不让模拟只是一段自动播放的文字日志。

### 1.4 模拟器流的核心爽点

模拟器流真正吸引人的不是“系统弹窗”，而是玩家用低成本试错换来信息、力量和命运主动权。以下爽点必须转化为实际操作与即时反馈：

| 爽点 | 网文中的满足感 | 本项目的玩法落地 | 玩家必须感受到的瞬间 |
| --- | --- | --- | --- |
| 放胆试错 | 反正是模拟，敢走现实中不敢走的绝路 | 模拟死亡不损永久进度；允许试毒、卧底、越级挑战和故意入局 | “这一命我就专门去看陷阱后面有什么。” |
| 死亡破题 | 每次死都比上一世更接近答案 | 首次死法必须揭示一条可行动信息，并标出仍未知的上一层原因 | “原来不是毒死的，是中毒后被指定的人补刀。” |
| 先知降维 | 提前知道日期、口令和背叛者，回到现实精准拆局 | 固定时间线、确证系统、提前埋伏和规则级战斗优势 | 对手刚准备出手，玩家已经站在正确位置等他 |
| 一生压缩 | 几段文字跨过十年，只保留命运转折 | 长期行动与事件跳时压缩无决策阶段，一次模拟只保留关键场景 | 20 分钟内从外门弟子走到一次完整死亡与结算 |
| 结算开奖 | 看评价、选奖励、赌稀有词条 | 确定道行、确定情报与未知词条互斥；词池和保底可预判 | 明知情报有用，仍想赌一次紫色“替命”词条 |
| 多世成型 | 每一世留下一点东西，最终拼成独有流派 | 先天词条固定底色，后天词条按行为抽取并形成联动 | 曾经为了活命获得的毒抗，后来成为主动试毒的核心能力 |
| 救回必死之人 | 上一世的遗憾，在这一世被亲手改写 | 记录 NPC 原定死期；救回后改变其日程、关系和后续事件 | 上次死在眼前的人，这次活着参加了下一年议事 |
| 从被摆布到掌局 | 开局处处晚一步，后期利用整个时间线设局 | 因果链逐层公开，终局方案由多条早期选择共同组成 | 最终劫难仍按时到来，但祭品、阵眼和伏兵都已被玩家换掉 |

爽点落地有一条硬规则：**模拟里获得的重要成果，回到现实后必须尽快有机会兑现。** 如果玩家拿到口令、抗性或死亡情报，却要再等半小时才能使用，爽点已经失效。

### 1.5 跑团式开场与世界内界面

新玩家不能在首页同时接收产品类型、系统说明、未来事件和核心人物名单。开场按跑团主持人带团的顺序逐步揭示：

1. **世界与处境**：大虞由朝廷和仙门共治；归尘门是照夜山上的小宗门；外门弟子最靠近仙途，也最无足轻重。
2. **人物入籍**：姓名、称谓、凡俗出身与玉牌印色都写在宗门名牒上。
3. **照骨验身**：先天词条由山门照骨镜映出，避免角色尚未接触太虚命盘便使用命盘能力。
4. **人物卡确认**：集中展示身份、境界、持有物、凡俗牵挂和三枚先天命签。
5. **首个可选事件**：入门第三日，藏经阁西墙异响；玩家选择循迹、谨慎查验或按门规报告。
6. **命盘异象**：进入祖师洞并触盘后，才揭示七年黑日、命火和模拟规则。

界面必须保持世界内表达。游戏中不得出现 `Demo`、`P0/P1/P2`、原型、测试、构筑、二周目、自动存档、菜单、养成等开发或产品词汇。它们分别以法门、前世遗痕、命盘记录、现实锚点等叙事内概念呈现。新名词首次出现必须由场景、人物或物件自然解释；尚未亲历或得知的时间线节点保持隐藏。

### 1.6 奇遇：先遇其人，再知其名

奇遇不是随机弹窗或一次性奖励。每条奇遇都应包含“自然触发 → 身份遮蔽 → 压力抉择 → 身份揭示 → 即时所得 → 长期回响”六个环节，并至少改变一个后续可操作场景。

当前开场奇遇发生在入山前夜的无名破庙。主角先遇到一名遭追杀的重伤妇人，只能从伤势、衣着、武器和庙外追兵判断处境；作出藏人、救治或问价的选择后，才知道对方是掌控白石镇水路的霜河帮主母柳照影。三条路线分别留下：

| 处置 | 即时所得 | 长期因果 | 首次模拟中的兑现 |
| --- | --- | --- | --- |
| 掩去血迹、引走追兵 | 霜河暗纹 | 柳照影欠一次不问缘由的人情，夺权者可能追查假足迹 | 拦下水路脚夫，追查无印水桶 |
| 止血并辨认箭毒 | 锁息丹 | 柳照影更信任医者身份，记住主角的救命手法 | 拖慢毒发，亲自尝井水并看清补杀结构 |
| 先问代价再提供庇护 | 夜渡名帖 | 双方形成必须结清的交易关系 | 查白石镇暗货，连接乌舌草、夜船与宗门旧印 |

出身与先天命签用于加深同一选择，而不是把普通选择锁死。例如药农之子救人时可辨出乌舌草，流亡猎户藏人时能伪造更可信的雨夜足迹，商队遗孤问价时能多换到一条消息。奇遇所得必须进入人物侧栏的“奇缘簿”，并在 10 分钟内提供一次亲手兑现的机会。

## 2. 故事前提：七年后的黑日

故事发生在小宗门“归尘门”。开局第三天，玩家误入封闭的祖师洞，触碰一块残破命盘，瞬间经历了一段未来：

> 太虚七年，黑日悬山。归尘门护山阵反转，门中上下无一生还。

玩家醒来时，现实只过去一息。

公开说法是七年后敌宗来袭；随着模拟深入，玩家会逐步发现：归尘门建宗时便是一座延寿祭阵。每隔六十年，它会吞掉门中修士，为沉睡的开山祖师续命。敌宗、叛徒、矿难与失窃都不是孤立事件，而是祭阵启动前依次倒下的保险。

玩家的目标不是简单击败一个魔头，而是决定：

- 谁值得被救；
- 哪段真相应当公开；
- 是否还要保留这个建立在牺牲上的宗门；
- 自己愿意为终结轮回付出什么。

## 3. 玩家身份：唯一的自建主角

开局由玩家创建唯一主角，包括姓名、性别表达、外观和凡俗出身。无论现实还是模拟，玩家从头到尾只直接控制这名角色；不会切换成同门、长老或敌人，也不会在主角死亡后接管现成 NPC。

主角固定以“归尘门新入门的外门抄经弟子”开始，以保证关键事件拥有稳定入口。凡俗出身提供少量初始对话与技能倾向，例如药农之子、落第书生、流亡猎户或商队遗孤，但不替代随机词条。

身份低、战力弱，使主角能够接触外门、库房和山下市镇，却很难直接说服掌门。成长不仅是提高战力，也包括让原本不会相信主角的人愿意提供权限、证词或同行帮助。

### 3.1 开局随机词条

捏人完成后，命盘生成三组随机“先天词条”，每组二选一：

1. **根骨组**：灵根、体质或身体缺陷；
2. **才性组**：学习方式、感知、社交或技艺倾向；
3. **因果组**：强力优势与固定代价并存的命运特征。

玩家最终获得 3 枚先天词条。每组必定包含一个稳定选项和一个改变路线的高波动选项，不会同时给出两个纯负面词条；同一开局最多出现一枚金色词条，也不会生成使主线无法推进的互斥组合。

标准模式允许免费重抽整组一次；重抽后必须从新结果中选择，避免无限刷新完美开局。自定模式可开放无限重抽，并明确标记为自定规则。

| 先天词条 | 类型 | 主要效果 | 代价或路线变化 |
| --- | --- | --- | --- |
| 烬火灵根 | 根骨·蓝 | 火属功法领悟更快，可感知异常热源 | 寒毒伤势更难恢复 |
| 百草舌 | 才性·蓝 | 可从气味与药渣识别常见药毒 | 首次接触未知毒物时发作更快 |
| 过目不忘 | 才性·紫 | 首次见到的文书自动记录关键字 | 心神创伤更难随模拟结束淡去 |
| 旧伤复发 | 根骨·灰 | 开局伤势上限降低 | 解锁医馆、旧军营和追查身世的特殊路线 |
| 命犯孤辰 | 因果·紫 | 单独行动时隐匿和悟性提高 | 核心关系达到“生死之交”前存在上限 |
| 天厌早慧 | 因果·金 | 开局额外掌握一项基础术法 | 初始天妒提高，幕后者更早注意主角 |

词条稀有度表示规则影响范围，不保证高稀有度无条件更强。负面词条必须同时提供特殊路线或结算词池，不能只是降低数值。

3 枚先天词条永久生效、不能被普通结算替换。它们必须在开局 30 分钟内至少各出现一次可感知影响，让随机开局不只是角色页上的百分比。

### 3.2 核心同伴

其他人物是拥有自主行动的同伴、阻力或情报源，不是可切换主角。

| 核心人物 | 能提供的帮助 | 独占线索 | 不会轻易跨越的底线 |
| --- | --- | --- | --- |
| 裴照雪，首席弟子 | 剑术支援、内门担保 | 护山阵与掌门议事 | 不接受无证据地污蔑师门 |
| 闻青禾，丹房弟子 | 医治、毒理、黑市渠道 | 丹房账册与历代尸骨 | 不会放弃寻找失踪兄长 |
| 宋无咎，宗门执事 | 调档、审讯、调动杂役 | 建宗旧档与长老隐情 | 会优先维持宗门稳定 |
| 阿厌，被俘魔修 | 潜行、禁术、敌方语言 | 敌宗营地与山外暗线 | 不会为了归尘门牺牲自由 |

玩家通过建立信任、交换利益或掌握确证，让他们同行或在别处同时行动。秘密只能通过主角亲自调查、听取证词、截获记录或与同伴共同经历获得，不能切换视角免费读取。

## 4. 核心循环

一次完整循环约 20～40 分钟：

1. 在现实时间线上选择当前最想解决的问题。
2. 为自建主角选择本次调查目标和带入准备。
3. 消耗命火，进入从当前现实锚点开始的模拟未来。
4. 在地图上行动、修炼、交涉、调查和战斗。
5. 因死亡、主动收束或到达命盘极限而结束模拟。
6. 查看完整死因与结算，从道行、确证、词条抽取中只选一项。
7. 在现实中利用成果采取行动；行动消耗真实日期。
8. 世界时间线产生偏转，新机会与新危险出现。
9. 建立新锚点，开始下一轮试命。

核心闭环不是“刷到足够强”，而是：

> 遭遇未知死亡 → 找到直接原因 → 带回针对性成果 → 越过旧死法 → 死于更深一层的问题。

### 4.1 单轮情绪曲线

每轮体验按“惊—悟—赌—爽—悬”组织：

1. **惊**：遭遇一项不知道规则的危机。
2. **悟**：死亡或调查让玩家看懂其中一个关键环节。
3. **赌**：在确定成果与随机词条之间做结算选择。
4. **爽**：回到现实，用上一世成果精准改变原事件。
5. **悬**：旧死法被越过，但更深层原因随之暴露。

推荐节奏：

- 已经完全掌握的旧内容在 1～3 分钟内快速处理；
- 每次模拟至少提供一个此前未知的危险、人物动机或可利用规则；
- 从结算返回现实后，5 分钟内出现至少一个使用新成果的机会；
- 旧事件成功改写后，3 分钟内给出新的问题，避免高潮后只剩整理菜单。

所谓“先知爽”必须由玩家亲自完成准备和执行。系统不能因为持有确证就自动播放胜利结果。

### 4.2 单周目的掌控升级

爽感必须随周目从“逃命”升级到“设局”：

| 阶段 | 玩家状态 | 典型行为 |
| --- | --- | --- |
| 前 2 次模拟 | 只想活过眼前死法 | 查毒、逃跑、记住凶手特征 |
| 第 3～6 次模拟 | 开始利用未来获利和救人 | 提前取走物品、截断交易、救下原定死者 |
| 第 7～12 次模拟 | 主动让危险以有利方式发生 | 放出假阵图、故意留下诱饵、借敌人破坏祭阵 |
| 终局前 | 同时安排多条因果链 | 调换阵眼、安排撤离、诱导两方在指定日期交战 |

后期不能只是把前期玩法换成更大的数值。玩家的权限、情报网络和可同时推动的计划必须真实增加，让“我已经从棋子变成下棋的人”成为系统层面的变化。

## 5. 一次模拟具体怎么玩

### 5.1 入盘准备

每次模拟始终控制自建主角。入盘前只做两个决定：

1. **执念**：本次优先调查谁、保护谁或取得什么；它决定跳时时优先保留哪些事件。
2. **准备**：携带一件现实中真实拥有的物品，或将一条已确证情报设为本轮行动依据。

开局先天词条和当前装备的后天词条会完整进入模拟，不额外随机临时主角。界面在入盘前列出哪些词条可能影响当前目标，但不直接泄露隐藏解法。

### 5.2 地图行动

世界采用 6～9 个地点节点，不做连续开放地图。首章包含：

- 归尘门外院；
- 内门与议事堂；
- 丹房；
- 乌铜矿；
- 山下白石镇；
- 被封闭的祖师洞。

一次行动消耗数个时辰到数月。玩家会在三种尺度间切换：

- **短场景**：潜入、对话、调查或战斗，5～10 分钟内完成。
- **长期行动**：闭关、养伤、学习、经营关系，直接推进数周或数月。
- **事件跳时**：若期间没有相关变化，直接跳到下一项已知或未知关键事件。

时间跳过前必须显示会错过的已知窗口，例如：

> 闭关四十日。期间“闻青禾下山购药”将发生；你可能无法介入。

### 5.3 关键场景

模拟中的关键场景必须至少提供两种解法，来源包括：

- 主角的出身、词条和关系；
- 已带入的确证；
- 功法、医术、潜行或战斗能力；
- 上一次模拟发现的环境细节；
- 愿意承受的伤势、暴露或关系代价。

不使用“魅力 63，检定成功”作为主要表现。玩家应当知道特殊选项为什么出现，例如：

> 你认出药渣中有乌舌草。只有丹房负责夜班的人能接触此物。

### 5.4 模拟深度

启动模拟消耗 1 点命火。每跨过一个年度节点，玩家可以：

- 立即收束并结算；
- 再消耗 1 点命火，继续向更远未来推进。

越深的模拟越可能摸到灭门真相，也越容易因为前期的小偏差进入陌生未来。玩家不应每次都无脑模拟到死亡；“现在带着可靠成果离开”也是重要选择。

### 5.5 死亡

模拟死亡不读档、不扣永久属性，直接进入结算。

死亡界面回答四个问题：

1. 直接死因是什么？
2. 哪个更早的行为让它成为可能？
3. 本次首次确认了什么？
4. 下一次有哪些已知的回避方向？

死因回溯只使用本次亲历、观察或已经确证的事实；尚未看见的幕后环节继续标为未知，不由系统免费揭谜。第一次死于某种机制时必须产生可行动的新信息。重复相同路径、相同死法只给极少收益，系统会明确提示“此段命途已无新意”。

### 5.6 单次模拟的爽点配额

一段 15～35 分钟的正常模拟至少应当包含：

- 1 次由玩家主动承担的高风险试探；
- 1 条能改变下一轮行动的新信息；
- 1 次词条、关系或旧情报带来的特殊破法；
- 1 个值得在结算时放弃其他奖励去保留的成果；
- 1 个旧问题解决后暴露的新钩子。

这不是要求机械地每轮发五次奖励，而是防止模拟退化成“点击闭关十年，看一段死亡日志”。连续两个长期行动之间必须出现一次会改变路线的玩家决策。

## 6. 结算：拿确定答案，还是抽一枚词条

每次模拟结束提供三种互斥结算。玩家只能选择一种，选择“词条抽取”就必须放弃本轮已经看得见的道行与确证奖励。

| 结算 | 获得内容 | 确定性 | 主要代价 |
| --- | --- | --- | --- |
| 道行 | 一项本轮实际练成的境界进度、功法熟练或身体抗性 | 选择前完全可见 | 直接带回力量，提高天妒 |
| 确证 | 一条日期、身份、口令、配方位置或事件因果 | 选择前完全可见 | 不增加战力，且可能随时间线偏转而过期 |
| 词条抽取 | 从本轮行为生成的词池中随机抽取，再选一枚后天词条 | 词池标签和保底可见，具体候选未知 | 放弃短期答案；强词条启用时提高天妒 |

结算不会凭空补齐三个奖励：本轮没有实际修炼出新理解，道行选项就会锁定；没有发现新事实，确证选项也会锁定；没有形成有效行为标签，则只能得到最低规格词池。毫无进展的模拟可能没有值得带回的成果。

例如玩家第一次死于晚宴毒杀后，结算显示：

- **道行：灵息逆转**——保留模拟中练成的运气法，可压制毒素三回合并强行迎战。
- **确证：酉时换水**——确认下毒时间和入口，可在现实中提前蹲守。
- **词条抽取：丙等**——放弃上述成果，从“中毒、观察、求生”词池抽三选一。

道行和确证能直接针对眼前死法；抽词条则押注长期构筑。新手教学中的首次词池至少包含一个能影响晚宴的候选，之后不保证抽到立刻解决当前事件的答案。

### 6.1 词池由这一生如何活出来决定

词条不是从全局奖池盲抽。本次模拟中产生的有效行为会给结算添加标签：

- 识破或承受多种毒物，加入“毒理、抗性”词族；
- 多次保护同伴且承担实际损失，加入“守护、替命”词族；
- 利用口令、伪装和假证突破封锁，加入“欺诈、潜行”词族；
- 首次看破阵法运行，加入“阵理、灵视”词族；
- 只被火烧死而没有观察、抵抗或利用火焰，不会凭空获得火系词条。

首次晚宴结算可能抽到：

| 后天词条 | 效果 | 来源要求 |
| --- | --- | --- |
| 毒息迟滞·蓝 | 新毒首次发作延迟一个行动阶段 | 中毒后仍完成一次有效行动 |
| 临危静观·蓝 | 濒死时额外看清一项可观察细节 | 在低伤势状态主动调查 |
| 草木辨性·白 | 接触药材时显示其一项主要药性 | 本轮实际检查过药渣或药材 |
| 护命执念·紫 | 为同伴承受致命伤时保留一线生机 | 至少一次主动替人承担死亡风险 |

重复相同路线会快速降低结算新意，不能靠在同一口井前反复中毒刷满抗性。

### 6.2 评价决定抽取规格

评价来源为首次活过关键事件、确认事实、改变核心人物命运、完成特殊破局，以及在有价值节点主动收束。单纯多活几年、重复杀敌或反复练功不会稳定提高评价。

| 评价 | 抽取规格 | 品质规则 |
| --- | --- | --- |
| 丁 | 2 抽 1 | 以白色为主，可能出现带路线补偿的灰色缺陷 |
| 丙 | 3 抽 1 | 至少一枚蓝色候选 |
| 乙 | 3 抽 1 | 至少两枚蓝色，紫色概率明显提高 |
| 甲 | 4 抽 1 | 至少一枚紫色，小概率出现金色因果词条 |

稀有度代表规则强度和适用范围，不代表无脑更优。紫色、金色词条往往附带天妒、关系或伤势代价。

### 6.3 先天与后天词条槽

- 3 枚开局先天词条永久生效，不占后天槽。
- 抽取的词条进入“命痕册”，不会因暂时不用而销毁。
- 主角最多同时启用 5 枚后天词条，只能在现实锚点更换。
- 高影响词条拥有“命重”；启用时增加天妒，卸下后不再继续增加。
- 同名低阶词条再次出现时，可选择升阶而非新增一枚；重复路线的收益仍受新意衰减限制。

后天词条优先改变规则和行动选项，不堆叠小百分比。至少一半词条应与另一词条、功法或确证形成可读联动：

- **百草舌 + 毒息迟滞**：解锁“以身试毒”，可故意服毒并追踪完整药性变化。
- **过目不忘 + 临危静观**：模拟死亡时多保留一个亲眼看见的细节，但增加心神负担。
- **命犯孤辰 + 藏踪术**：单独潜入时可越过一层守卫，同时更难呼叫同伴救援。

获得词条后立即显示一到两个可能联动的模糊提示，不要求玩家查攻略猜隐藏配方。真正的构筑爽点应当是“我发现这两段失败留下的东西能拼起来”，而不是背词条表。

这一上限要求玩家围绕当前问题组装构筑，例如调查矿难时换上灵视与毒抗，准备最终攻山时改为护命与破阵，而不是把所有永久增益同时堆在身上。

### 6.4 天妒与偏差

- **天妒**针对玩家带回并启用“不属于现实的力量”。越高，幕后力量越早察觉命盘持有者。
- **偏差**代表现实已远离原始未来。越高，旧情报可信度越低，也会出现原时间线不存在的机会。

这两项不是惩罚条，而是阻止玩家无限刷模拟的变化引擎。玩家可以依靠道行和高命重词条强行破局，但必须面对提前苏醒的祖师；也可以主要依靠确证，维持更稳定的未来。

## 7. 固定时间线与因果链

开局世界不是随机生成的。重要人物在没有干预时会按固定动机行动，关键事件拥有明确日期、前置与后果。

| 原始时间 | 表面事件 | 深层作用 | 初始可见度 |
| --- | --- | --- | --- |
| 第七日 | 晚宴投毒 | 清除看见祖师洞异象的杂役 | 玩家第一次模拟可见 |
| 第三月 | 乌铜矿坍塌 | 取出祭阵缺失的“日核” | 仅知道矿难传闻 |
| 第一年冬 | 闻青禾失踪 | 她查到历代弟子尸骨被炼成阵材 | 初始未知 |
| 第二年夏 | 外门分裂 | 有人伪造账册，引导弟子投奔敌宗 | 初始未知 |
| 第三年冬 | 阵图失窃 | 宋无咎故意放走偷图者，试图借敌宗毁阵 | 只知道“出现叛徒” |
| 第五年秋 | 赤霞宗攻山 | 对方误以为山下封着飞升遗宝 | 初始只知敌宗威胁 |
| 第七年蚀日 | 护山阵反转 | 开山祖师收割全门寿元并苏醒 | 只见到灭门结果 |

### 7.1 情报状态

时间线上的信息分三种：

- **传闻**：模拟中听到，可能错误；玩家知道，但不能直接说服现实人物。
- **确证**：通过结算带回或在现实查实，可用于行动和交涉。
- **过期确证**：曾经正确，但因偏差扩大已不再可靠，界面标明最后有效锚点。

玩家可以记住所有见过的内容，但角色要在现实中合理利用信息，必须拥有证据、身份或足够信任。这样既尊重玩家记忆，也避免主角凭空宣布幕后真相。

### 7.2 偏转不是完全随机

现实改变后，NPC 仍按其动机寻找新办法：

- 玩家阻止下毒，幕后者可能改为制造意外，而不是凭空放弃灭口。
- 玩家提前封矿，缺钱的宗门会寻找其他财源，可能更早接受敌宗交易。
- 玩家公开旧尸骨，裴照雪会质疑宗门；依赖宗门庇护的弟子则可能指责玩家造谣。

系统改变的是“人物如何继续实现目标”，不是简单把旧事件换成随机新事件。

## 8. 现实层：把答案真正落地

现实不是安全菜单。玩家要亲自执行从模拟中带回的方案，并承担时间和关系后果。

现实行动包括：

- 查实一条模拟情报；
- 提前准备物品、埋伏或撤离路线；
- 说服一名同门改变日程；
- 公开、隐瞒或伪造证据；
- 深化一段同伴关系，争取对方同行或配合；
- 亲自进入已经准备好的关键事件。

所有行动显示耗时和即将关闭的事件窗口。玩家不可能救下所有人、调查所有线索并同时修炼。

### 8.1 预知兑现

当玩家利用上一世成果改变已知事件时，游戏要明确承认这是一次“预知兑现”：

- 对话中说出尚未公开的口令，对方会产生具体反应，而不是只显示“好感 +5”；
- 提前站到伏击点，短暂叠显上一世自己在这里被杀的残影；
- 敌人准备使用已知杀招时，界面标出其与命盘记录吻合，随后仍由玩家亲自破解；
- 救回上一世死亡的 NPC 时，对照更新其原定死期、现实日程和后续关系，不把结果压缩成奖励弹窗。

若抽到的词条不适用于当前危机，5 分钟内也要安排一次低风险试用机会，让玩家先感受到它改变了什么；这不等于免费解决眼前问题。

同一种表现不能频繁重复。轻量事件用时间线盖章和一句角色反馈即可，重大改命才使用完整镜头。NPC 可以震惊、怀疑或恐惧，但不会无条件崇拜主角；精准预知带来的社会后果同样是玩法。

### 8.2 命火

命火是启动和延长模拟的稀缺资源，不可通过重复战斗刷取。

主要来源：

- 初始获得 3 点；
- 在现实中首次改变一个既定死亡，获得 1 点；
- 首次让一名核心人物主动相信灭门预警，获得 1 点；
- 解决一段重大因果链，获得 1～2 点；
- 主动接受一项不可逆损失，偶尔可回收其中的命数。

玩家通常能完成 12～18 次有价值的模拟，而不是无限读取未来。

### 8.3 现实死亡

模拟死亡是学习，现实死亡是失败。

若自建主角在现实死亡，本周目结束，不会切换成任何 NPC 续玩。普通存档仍存在，游戏不会把铁人模式设为默认；高难度模式可限制现实层存档，但不改变主角唯一性。

这让玩家敢在模拟中试错，却会认真准备现实中的同一场危机。

## 9. 修炼与人物构筑

修炼服务于破局，不单独构成数十小时的刷取游戏。

### 9.1 境界

首发只使用四个大阶段：凡胎、炼气、筑基、金丹。

境界提供新的行动规则，而不只是属性倍率：

- **凡胎**：依赖道具、身份与环境，正面战斗危险。
- **炼气**：可使用术法，并感知基础灵气痕迹。
- **筑基**：选择不可逆道基，获得一种改变场景规则的能力。
- **金丹**：足以正面介入终局，但会被祭阵优先锁定。

七年内正常修炼通常只能到筑基。想达到金丹，必须从深层模拟带回道行，或用高命重后天词条拼出危险构筑，因此强大本身就是一条代价路线。

### 9.2 角色配置

自建主角只维护：

- 1 个根基特性；
- 1 部主修功法；
- 4 个主动术法；
- 1 个反应术法；
- 3 枚固定先天词条；
- 最多 5 枚启用中的后天词条；
- 伤势、关系和当前执念。

没有头盔、护肩、戒指等十几个装备格。法宝最多携带两件，每件应当改变打法或开启路线。

### 9.3 成长来源

- 在模拟中实际使用并领悟；
- 师承、偷学或交换；
- 通过“道行”结算带回；
- 因重大经历改变根基；
- 解析敌人的术法和弱点。

闭关只能消耗时间巩固已有能力，不能替代冒险和信息获取。

## 10. 战斗：让情报真正值钱

战斗采用快速回合制，单场普通战斗控制在 60～120 秒。

### 10.1 基础规则

- 玩家只控制自建主角，最多携带两名同伴。
- 同伴根据性格和战前优先级自主行动；玩家可请求集火、保护或撤退，但不能逐技能接管。
- 敌方下回合意图默认只显示模糊类别。
- 每回合选择一个主动术法，并可预留一个反应术法。
- 核心状态只有真气、伤势和破绽。
- 术法围绕制造破绽、利用环境、保护同伴和撤退展开。

### 10.2 情报改变战斗

同一敌人第一次可能近乎不可战胜；获得情报后，战斗规则会真实变化：

- 确认对方口令，可让一名守卫离场；
- 知道法宝蓄力征兆后，完整显示其致命招式意图；
- 提前破坏阵眼，敌方开场失去护盾；
- 带来对应解药，中毒从永久伤势变为可控倒计时；
- 查明敌人只想夺物，可以用假货达成不战而退。

玩家的爽点应当是“我知道你下一步要做什么”，而不是单纯高十级。

已经在同等或更弱条件下稳定获胜的普通战斗可以快速结算，避免每次模拟重复操作。

## 11. 前 30 分钟体验

### 0～5 分钟：捏人、抽词条、看见结局

- 玩家创建唯一主角，选择外观与凡俗出身。
- 命盘随机生成三组先天词条，玩家完成三次二选一。
- 主角完成入门后的普通抄经任务，在祖师洞触碰命盘，看见七年后黑日灭门。
- 回到现实，命盘提示可模拟到“第七日”；至少一枚开局词条立即提供特殊观察或对话。

对应爽点：随机开局带来的构筑期待，以及“我已经看见自己结局”的强钩子。

### 5～13 分钟：第一次死亡

- 玩家进入第一次模拟，可自由调查、练功或社交。
- 第七日晚宴，全门外院饮下有毒井水。
- 玩家行动受限，蒙面人入院灭口。
- 无论具体选择如何，普通新手大概率死亡；细心玩家可以多确认一项线索，但不能直接解决全部问题。

死亡界面明确显示：

> 直接死因：失去行动能力后被短刃刺中心脉。
>
> 已知前因：毒来自晚宴井水，酉时前仍无异常。
>
> 新问题：蒙面人为何只搜查接触过祖师洞的杂役？

对应爽点：死亡没有白费，死因从“我中毒了”推进到“有人按名单灭口”。

### 13～18 分钟：第一次结算

- 道行：灵息逆转；
- 确证：酉时换水；
- 词条抽取：丙等，从“中毒、观察、求生”词池抽三选一。

界面预览道行和确证的明确用途，并展示词条池标签、抽取数量与品质保底，但不提前展示具体词条。

对应爽点：拿眼前答案还是赌长期词条的结算纠结。

### 18～25 分钟：现实第一次改命

- 选择确证：提前蹲守，抓到下毒杂役，并发现其家人被扣押。
- 选择道行：假装中毒，在袭击中反杀一人，取得敌方腰牌。
- 选择词条：根据抽到的“毒息迟滞”“临危静观”或“草木辨性”，分别获得拖延毒发、观察凶手或追查药材的路线。

教学词池保证至少有一个能影响晚宴的候选，但词条路线通常比确定性奖励更绕，换来的是可长期装备的构筑能力。

对应爽点：先知反制第一次兑现；NPC 对主角提前蹲守、假装中毒或准确辨药产生不同反应。

### 25～30 分钟：第二次未来变了

- 玩家再次模拟，晚宴不再是必死点。
- 时间快速推进到第三月乌铜矿任务。
- 玩家第一次感受到：旧情报仍有价值，但未来已经不是原样。
- 试玩在矿井深处出现“日核”异象时结束，留下明确的新目标。

对应爽点：旧死法已被踩在脚下，但玩家发现晚宴只是更大因果链的第一环。

前 30 分钟只教授捏人、开局随机词条、模拟死亡、三类结算、现实改命和时间偏转。境界突破、后天词条换装、天妒与复杂战斗随后逐步开放。

## 12. 胜负与结局

### 12.1 正式失败

满足任一条件则本周目失败：

- 自建主角在现实死亡；
- 第七年蚀日完成收割，且主角未达成任何撤离或破局结局；
- 命盘被开山祖师夺回并彻底封闭。

同门死亡、宗门解散或敌宗占山都不是自动失败。

### 12.2 三个主要结局

| 结局 | 达成方式 | 代价与含义 |
| --- | --- | --- |
| 携火离山 | 提前撤出核心人物和典籍，放弃山门 | 最容易生还，但祭阵秘密可能继续害人 |
| 斩祖散门 | 公开真相、瓦解祭阵、击杀或封回祖师 | 归尘门名誉与制度一并终结，众人获得新生活 |
| 夺盘续世 | 玩家控制祭阵，把收割转嫁给敌人或其他生命 | 获得最强力量，也成为下一轮劫难的制造者 |

另设一个困难隐藏结局，但不在核心原型阶段制作。隐藏结局必须来自对系统的深度利用，而不是收齐一百件藏品。

## 13. 内容规模

### 13.1 90 分钟核心原型

原型只验证模拟器循环，不制作完整宗门：

- 1 名自建且唯一可控的主角；
- 2 名不可切换的核心 NPC；
- 2 个现实锚点；
- 第七日晚宴与第三月矿难两个事件；
- 4 个地点；
- 12 个关键场景；
- 3 场短战斗；
- 12 枚开局先天词条；
- 6 个确定性结算成果与 9 枚可抽取后天词条；
- 晚宴至少 3 种破法，矿难至少 2 种进入方式；
- 1 条可视化时间线。

### 13.2 最小可发行版本

- 1 名自建主角与 4 名核心 NPC；
- 7 年现实时间线；
- 12～18 次有价值的模拟；
- 18 个主因果事件，约 70 个支撑场景；
- 6 个公开地点与 3 个隐藏地点；
- 4 个境界、12 部主修功法、约 30 个术法；
- 24 枚开局先天词条、45 枚可抽取后天词条；
- 3 个主要结局；
- 10～15 小时单周目。

首发目标是一次完整、紧凑、能被玩家复盘的破局体验，不假装提供无限沙盒。若核心循环成立，再增加第二套灭门剧本，而不是先把第一套内容程序化稀释。

## 14. 界面与信息设计

### 14.1 捏人与开局词条

捏人界面先完成外观和出身，再进入先天词条抽取。三组候选同时展示完整效果、代价和能影响的玩法标签，不使用需要逐张跳过的抽卡演出，也不存在付费重抽。

选择完成后生成一张“初命笺”，把外观、出身和 3 枚先天词条汇总在同一页，确认后才正式建立世界种子。

### 14.2 命盘界面

命盘是主界面之一，展示：

- 当前现实锚点；
- 已经历的模拟分支；
- 每次死亡位置与直接死因；
- 已知未来事件及可信度；
- 哪些成果从哪条命途带回；
- 当前先天词条、已装备后天词条与命痕册；
- 当前天妒与偏差将影响什么。

时间线默认只显示玩家真正知道的内容，不展示空白问号海洋。

### 14.3 现实与模拟必须一眼可辨

- 现实使用暖色实纸质感，模拟使用冷色墨迹与边缘裂纹。
- 屏幕常驻“现实”或“第 N 次模拟”标识。
- 模拟中所有不可带回的物品带有虚影边框。
- 任何将推进现实时间的按钮必须二次显示耗时和错过窗口。

### 14.4 死亡与结算界面

死亡不播放冗长失败动画。先显示死因，再按时间顺序回放三到五个关键前因，最后进入三类结算。

结算选项不只写数值，而要预览用途：

> “酉时换水”可用于：提前蹲守水井；说服闻青禾验毒；在晚宴前更换水源。

词条抽取按钮必须先展示本轮评价、词池标签、抽取数量与品质保底，并明确提示“选择后将放弃道行与确证”。确认后才播放短促抽取演出：候选依次显现，稀有词条用独特题记和音效强化期待，但整段不超过 8 秒且可跳过。表现目标是一次有代价的命运结算，不模拟商业抽卡界面。

## 15. 原型验证标准

核心原型只有在以下问题大多回答“是”时才继续扩充：

- 玩家第一次死亡是否发生在 13 分钟以内？
- 三枚开局词条是否都在前 30 分钟产生过一次可感知影响？
- 死亡后，玩家能否立即说出下一次想改变的动作？
- 每一种首次死亡是否都提供了至少一条可行动的新信息？
- 第二次模拟是否在 5 分钟内让玩家因旧情报获得明显优势？
- 从结算回到现实后，玩家是否在 5 分钟内使用了新成果？
- 三个结算选项是否至少有两个让玩家认真犹豫？
- 玩家是否愿意为了获取情报，主动选择一条战力更弱的路线？
- 玩家是否理解抽取词条意味着放弃本轮确定答案？
- 首次抽到的后天词条是否改变了玩家下一次的行动或构筑？
- 玩家能否在 60 分钟后复述“晚宴投毒为何发生”，而不只记住奖励？
- 玩家能否主动讲出一次“因为我提前知道，所以这次赢了”的具体场面？
- 不看教程文本，玩家是否理解模拟死亡与现实死亡的区别？
- 重复同一段内容时，是否有足够的跳过与快速结算能力？

建议记录：

- 每次死亡到再次启动模拟的间隔；
- 结算完成到首次使用新成果的时间；
- 旧死法被越过到新问题出现的时间；
- 道行、确证、词条抽取的选择比例；
- 各开局词条的选择率、重抽率和首个触发时间；
- 玩家重复相同死法的次数；
- 首次主动收束而非等死的时间；
- 每次模拟中新场景、快速结算场景与纯跳时所占比例；
- 玩家在现实中因错过窗口而后悔的次数；
- 首次主动更换后天词条构筑的时间。

## 16. 主要风险与处理

| 风险 | 表现 | 处理原则 |
| --- | --- | --- |
| 重复感 | 每次都要重走相同前期 | 已通场景快速结算；允许从稳定节点跳时；重复路线降低收益 |
| 攻略化 | 查时间表后只剩标准答案 | 人物按动机应变；偏差使旧确证逐步过期；每个事件至少两种代价不同的解法 |
| 文字日志化 | 玩家只看模拟结果 | 关键发现必须来自可操作场景；自动文字只压缩无决策时间 |
| 爽点兑现过晚 | 带回成果后长时间整理菜单或等待日期 | 现实层 5 分钟内提供使用机会；不能立即使用时在结算前明确提示 |
| 无限刷强度 | 反复带回修为后碾压一切 | 命火有限；道行提高天妒；七年内正常成长设上限 |
| 刷词条取代破局 | 玩家重复低风险路线，只追求高稀有度 | 词池绑定有效行为；重复路线降低评价；抽词条必须放弃确定成果 |
| 开局反复重抽 | 玩家在捏人界面刷金色词条而不进游戏 | 标准模式只允许整组重抽一次；高稀有度附带实际代价 |
| 情报无用 | 知道未来却只能继续打 | 情报必须改变入口、敌人数量、对话或战斗规则 |
| 同伴工具化 | NPC 只是给线索和战斗加成 | 每名核心人物有自己的日程、底线和拒绝条件，玩家不能切换控制绕过它们 |
| 先知反馈浮夸 | 所有人无条件震惊并崇拜主角 | 角色根据证据、立场和性格产生怀疑、利用或恐惧；重大改命才强化演出 |
| 真相一次性 | 知道谜底后无法重玩 | 首发不强求无限重玩；后续优先新增完整灾劫剧本 |

## 17. 制作顺序

### P0：证明“死了还想马上再来”

- 自建主角与三组开局随机词条；
- 第一次模拟与晚宴死亡；
- 死因回溯；
- 道行、确证、词条抽取三类结算；
- 基于本轮行为生成词池并抽三选一；
- 三种现实破法；
- 一次带前世残影和 NPC 反应的“预知兑现”；
- 第二次模拟的时间线偏转；
- 快速跳过已知内容。

### P1：证明情报比数值更有趣

- 乌铜矿难；
- 一套短回合战斗；
- 传闻、确证、过期确证；
- 天妒与偏差；
- 至少两组能改变行动选项的词条联动；
- 第一条完整同伴任务线，NPC 全程不可切换控制。

### P2：扩展成完整游戏

- 四名核心 NPC 与各自的关系路线；
- 七年事件链；
- 三个结局；
- 完整修炼构筑；
- 完整先天、后天词条库与换装规则；
- 自建主角现实死亡与周目失败；
- 第二周目变化。

P0 未被试玩验证前，不制作宗门建设、炼器、交易、世界势力模拟或高境界内容。

## 18. 参考作品的结构拆解

本项目只借鉴结构，不复制人物、世界观和具体桥段：

| 参考方向 | 转化为本项目的规则 |
| --- | --- |
| 可亲自经历的模拟副本 | 模拟必须包含探索、交涉或战斗，不能只是日志 |
| 消耗资源后模拟、结算三选一 | 命火有限；确定道行、确定情报与随机词条只能选一 |
| 模拟获利、现实兑现 | 结算后 5 分钟内提供一次使用新成果的机会，并由玩家亲自执行 |
| 固定未来与信息差成长 | 关键事件有日期；情报是永久进度的一部分 |
| 家族或群体目标 | 玩家只控制自建主角，通过关系和同行影响自主 NPC |
| 随机天赋与流派构筑 | 开局随机先天词条；结算词池由本轮实际行为生成 |
| 多世积累与有限带回 | 每条命只能留下确定成果或抽取一个词条，死亡因此有价值 |

## 19. 设计底线

后续任何功能都必须至少强化以下一项：

1. 让第一次死亡更意外但可理解；
2. 让第二次尝试因旧情报明显不同；
3. 让结算选择更难取舍；
4. 让现实偏转产生合理的新后果；
5. 让同一事件因词条构筑、同伴关系或准备不同而出现新破法。

若一项功能只是让玩家更忙、数值更大或菜单更多，应当删除。

本项目的最终检验不是“像不像一个完整修仙世界”，而是：

> 玩家死后，会不会盯着刚得到的线索说——再来一次，这次我知道该找谁了。
