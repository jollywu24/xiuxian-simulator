# 《武道》高武江湖设计文档

> 一个能看见奇遇条件、却仍要用有限命灯亲手支付代价的无名少年，在高武江湖中寻找自己的第一条路。

## 1. 第一版产品定义

第一版只发生在武道世界“大曜”，不设置现实身份、现实同步、论坛、武道局或其他玩家。主角从金陵城外破庙醒来，完成车卡、求生、固定奇遇、人物奇遇、死亡回照和心法初试，继而持旧诺进入沈家丹房，把已经获得的心法、命灯和线索用于一场新的死局。

核心循环为：

> 了解眼前处境 → 建立人物与债务 → 看见奇遇条件 → 支付时间、资源、关系或命灯 → 获得武学与门路 → 立刻用新能力打开新的道路。

第一版要证明三件事：

1. 高武世界可以通过场景和人物逐层进入，而不是靠名词列表解释；
2. “逆天改命”改变条件信息和行动方案，而不是自动发奖励；
3. 每次获得武学、信物或关系后，短时间内都有可操作的兑现机会。

## 2. 明确边界

### 2.1 必须存在

- 一个自洽的高武王朝与江湖秩序；
- 人物车卡、出身所得与出身债务；
- 五维属性、命格、两盏命灯；
- 固定奇遇与人物奇遇；
- 可选择、可错过、可死亡的事件；
- NPC 关系与势力入口；
- 武学获得和同世界内的即时应用；
- 三条能继续扩展的江湖去路。

### 2.2 第一版不做

- 现代或现实世界；
- 两个世界之间的能力同步；
- 论坛、排行榜与新人登记；
- 其他玩家、多人竞争或交易；
- 完整战斗、装备掉落和大地图自由移动；
- 大量门派、境界和历史名词一次性灌输。

NPC、门派、世家、帮会和朝廷机构属于世界本身，不属于“其他玩家”。

## 3. 高武世界结构

第一版使用原创世界“大曜”。对《一世之尊》前期只参考四种体验：低位人物入场、地方秩序层次分明、顶级武力作为遥远天花板、每个事件同时牵动个人与势力。不得照搬其人物、门派、榜单、轮回空间、境界名称或具体剧情。

| 层级 | 表面职责 | 对主角的实际影响 | 第一版呈现方式 |
| --- | --- | --- | --- |
| 朝廷 | 守城、驿路、律法 | 城内规矩可借，城外保护有限 | 世界入场与金陵官道 |
| 山门 | 传承武学、占据山场 | 决定正统武学来源和身份门槛 | 作为远景，不展开具体门派 |
| 世家 | 守土、经商、掌握地方关系 | 信物能开门，差事也可能是死局 | 沈字铜钱与沈家丹房 |
| 帮会 | 控制水路、码头和生计 | 人情与权争会改变一整条路线 | 龙青鱼与漕帮 |
| 游侠、市井 | 送信、护运、买卖情报 | 主角早期行动和生存的主要空间 | 破庙、官道、金陵外城 |

武道层级只在需要时解释：

1. 未入门：普通人的气血水平；
2. 锻体：正式熬炼筋骨，可修招式；
3. 聚气：内息成流，超出凡俗技艺；
4. 通脉：气走周天，可隔空发劲、踏水疾行；
5. 宗师：精神与天地相合，一人足以镇住一方势力。

开场只明确“未入门”和第一步“锻体”。聚气通过青衣妇人的死亡预见自然出现，通脉和宗师只作为世界武力上限。

## 4. 渐进式入场

### 第一层：世界

开场只回答三个问题：

- 大曜朝廷管什么；
- 山门、世家与帮会为何能影响普通人的生活；
- 强者能强到什么程度，而主角目前有多弱。

### 第二层：人物车卡

车卡不只选择数值，还选择社会位置：

- 世家旁支：有拳谱和银钱，也欠宗族差事；
- 寒门子弟：有市井见闻，无人庇护；
- 身世成谜：有玉佩与血书，也会被人循线追查；
- 江湖遗孤：有生存经验，名门初见时更戒备。

初心决定角色为何继续行动，并在人物对话中提供不同立场。

### 第三层：事件

破庙先让角色处理寒冷与饥饿，再逐步引入：

- 玉佩和五维重分；
- 固定奇遇及其条件；
- 沈家信物代表的世家门路；
- 龙青鱼代表的帮会权力与人物关系；
- 心法改变行动规则的实际效果。

## 5. 角色与成长系统

### 5.1 五维

| 属性 | 主要用途 |
| --- | --- |
| 根骨 | 气血、武学承载、部分奇遇限制 |
| 悟性 | 参悟、识破武学与突破瓶颈 |
| 身法 | 移动、潜入、闪避与轻功 |
| 力道 | 体力、负重、外功和环境互动 |
| 福缘 | 偶发人物、宝物与隐藏分支 |

“逆天改命”令基础五维归零，但允许重新分配装备和武学提供的数值。破庙中的玉佩提供三点，因此力道三能更快完成敲墙，均衡或福缘路线则支付更多时间和食物。

### 5.2 命灯

人物初始有两盏命灯：

- 熄灭一盏：保留死亡前记忆，回到最近因果节点；
- 两灯皆灭：本次人生终结；
- 已确认会死亡的重复选项在只剩一盏时隐藏，避免误触终结当前流程。

命灯是武道世界内的命格规则，不连接另一个世界。

### 5.3 潜能与武学

潜能代表可用于学习、参悟和突破的积累。第一版只记录潜能，不展开完整消耗树。

鱼跃龙门诀是第一门可用心法，提供：

- 水中身法、耐力和闭气；
- 水意武学的悟性与根骨判定；
- 越境取胜后晋升品级的长期可能。

获得后立即面对赶往沈家的路途：顺紫金河游往东湖可以避开漫长官道，在饥饿耗尽体力前抵达；沿官道步行较安全，却会错过沈家当日收人的时辰。

## 6. 奇遇系统

### 6.1 固定奇遇

| 奇遇 | 条件 | 所得 | 当前可执行性 |
| --- | --- | --- | --- |
| 旅人遗物 | 篝火将灭时用供桌旧布添火 | 东郊残图、干粮、潜能 | 可完成 |
| 沈氏承诺 | 敲击东北墙体一千次 | 沈字铜钱、沈家门路、潜能 | 可完成 |
| 神秘贡品 | 晴日初一或十五、辰时、根骨不高于二 | 未知地级奖励 | 只能记录条件 |

固定奇遇属于地点，条件稳定，可以通过准备和属性重分解决。

### 6.2 人物奇遇

人物奇遇的条件会被性格、关系和此前选择改变。青衣妇人的身份在夜话结束前保持隐藏；她没有受伤，也没有被追兵追赶，而是因丈夫陆连山变心独自离开漕帮。

玩家可见结果包括：

- 反唇相讥：死亡；
- 沉默避让：安全，但永失后续；
- 否认乞丐身份：进入因爱成恨；
- 暂时顺从：继续听出真正矛盾；
- 利用她的失意：条件不足时死亡；
- 拒绝成为报复工具：进入破庙夜话。

主线路线根据夜话回应形成红颜知己或莫逆之交，获得潜能、临安重逢入口和鱼跃龙门诀。

### 6.3 沈家丹房死局

本段按原作第十二至十八章的顺序重组为可操作事件，删除此前原创的沈砚秋、伏脉藤、封炉和三选一奖励。

1. 主角借鱼跃龙门诀顺紫金河抵达东湖沈家，以沈字铜钱得到一次谋差机会。
2. 管事依次列出护院、苦力、跑堂和账房的门槛。主角因为力量、根骨、敏捷、悟性和基础武学不足，四项皆不合格，只能进入无人愿去的曹青丹房。
3. 命格显示曹青本名庞不凡，是药王谷叛徒，并显示血灵丹经、毒师传承及曹青好感二十、四十、六十、八十的门槛。
4. 曹青强取一碗血。反抗与拒绝都会死亡；顺从则永久失去一点根骨并继续留在丹房。
5. 取血后可以休息或继续观察。休息会被判定无用，观察才进入炼丹盘问。玩家可把玉佩三点尽数改到悟性；鱼跃龙门诀在水炼相关观察中再提供两点有效悟性。
6. 三道盘问依次检验火候变化、丹砂水炼药序和求学动机。前两题答错会死；最后若直言想学炼丹会引起曹青杀心，回答“只想活命”才把好感推至二十。
7. 固定所得为一百八十潜能、炼丹进度六成一和《青青册》，不再提供虚构的三选一。
8. 医书第一层要求悟性三并消耗八十五潜能。次日完成辨药、尝味、诊脉考校后，曹青好感升至三十并传下五禽戏。五禽戏是调养身体的养生法，不会令主角立即突破锻体。

改编仅保留人物、事件、数值门槛与因果顺序，所有玩家文本使用原创转述，不复制小说正文长段落。

## 7. 当前完整流程

`landing → worldIntro → characterDraft → vow → destiny → characterSheet → templeWake → fateSight → allocation → templeTasks → ladyArrival → ladyPressure → ladyTest → nightTalk → encounterReward → mindArt → roadTrial → roadResult → ending → shenArrival → shenJobs → caoArrival → caoFate → bloodDemand → danObservation → caoExamFire → caoExamIngredients → caoExamMotive → qingQingReward → qingQingStudy → fiveAnimalReward → shenChapterEnding`

支路：

- 危险回答进入 `gameDeath`，熄灭一盏命灯后回到 `ladyArrival`；
- 沉默避让进入 `quietDeparture`，安全结束今夜但永久错过龙青鱼路线；
- 紫金河水路可及时抵达沈家，官道路线会错过当日时辰；
- 结尾可记录沈家、破庙贡品或临安漕帮作为下一程；
- 选择沈家且持有沈字铜钱时可继续进入丹房；
- 取血时反抗或拒绝，以及炼丹盘问答错，都会进入 `shenDeath`；仍有命灯时回到曹青开口取血之前；
- 选择休息会安全结束沈家差事，却永久错过曹青传承；
- 正确完成三问后，奖励按《青青册》到五禽戏的固定次序推进。

## 8. 后续内容优先级

沈家丹房完成后，最适合沿三条原作因果继续：

1. 以五禽戏和《青青册》继续积累根骨与医术，而不是直接跨境；
2. 继续提高曹青好感，逐级接近血灵丹经和毒师传承；
3. 处理金龙会孙不离追索半块玉佩的血书旧债，或在初一晴日重返破庙。

后续仍需保持单一武道世界和单人叙事，并让本段取得的医术、炼丹进度、五禽戏与曹青好感在下一场景中改变行动条件。

## 9. 界面与叙事规则

- 玩家可见文本只属于世界、人物卡、场景、条件、选择、结果或资源变化；
- 新名词第一次出现时，由当前场景、人物或物品自然解释；
- 不显示开发阶段、测试、原型、构筑、自动保存等产品词汇；
- 不把旁白当玩法，关键发现必须来自选择、条件、资源或关系变化；
- 龙青鱼身份在夜话结束前保持隐藏；
- 成人情节只保留人物动机和选择压力，不展示露骨内容；
- 关键选择必须改变资源、命灯、关系、线索或后续入口；
- 桌面与手机都必须显示明确可操作项，不允许横向溢出。
