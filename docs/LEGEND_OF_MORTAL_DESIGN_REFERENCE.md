# 《活侠传》系统设计拆解与《大曜江湖》适配参考

> 文档用途：作为后续人物塑造、门派日常、因果随机、关系分支、失败叙事、决斗与长线重玩设计的参考，不作为剧情、人物、台词或数值仿写依据。
>
> 核对日期：2026-07-20。
>
> 资料口径：产品骨架优先采用 Steam 官方商店页、官方更新公告与开发团队专访；战斗指令和玩家理解成本使用社区资料交叉核对。文中的“设计判断”“风险”和“适配建议”均为本项目推断。
>
> 版本边界：截至核对日，官方仍在更新剧情与机制，并已预告 2026 年 9 月 15 日的后续内容。本文只拆解已经稳定可辨认的设计骨架，不把尚未发布内容当作现状。

## 1. 结论先行

《活侠传》最值得研究的不是“养成加骰子”，而是它让四类系统共同参与人物书写：

```mermaid
flowchart LR
    A[门派日常与有限行动] --> B[武学、性格、心相与关系变化]
    B --> C[事件读取长期状态]
    C --> D[玩家选择意图]
    D --> E[天命与条件决定具体遭遇]
    E --> F[成功、代价、错过或死亡]
    F --> G[人物与门派记住结果]
    G --> A
```

它真正建立的是：

> **玩家不是先捏好一个赵活，再去观看剧情；玩家在日常、选择、意外和失败中，逐渐把这个赵活活成某种人。**

对《大曜江湖》最有价值的七项启发是：

1. **低位身份本身就是玩法。** 主角的困难来自没有资格、没有人脉、没有实力，而非单纯敌人等级高。
2. **日常行动必须同时塑造能力和关系。** 扫地、炼丹、练武、帮忙不只是刷数值，也是在决定主角把时间交给谁。
3. **人格应当由行为留下，而不是在车卡上一次选完。** 性格可以改变对白、关系、事件入口和战斗策略。
4. **随机结果应生成故事，而不只是判定成功。** 好骰、坏骰和极端结果都要有作者写过的后续。
5. **失败也必须是内容。** 死法、错过、误会与不完美结局只有被认真书写，随机性才不会只像惩罚。
6. **关系要在危机时兑现。** 好感不是商店折扣；真正的回报是某个人在关键时刻相信、包庇、救援或背叛玩家。
7. **战斗中的语言也是行动。** “嘴攻”的价值不在搞笑，而在把人物立场、旧事和性格带入战斗回合。

不应直接照搬的部分：

- 让骰子替玩家决定道德立场、感情对象或重大路线；
- 大量条件隐藏，却不给玩家说明缺少什么；
- 为看少量新剧情重复很长的固定养成流程；
- 用命运点和读档补救本来就缺乏控制感的随机；
- 性格数值名称抽象、增减来源零碎，导致玩家只能查攻略；
- 门派规模、债务等数值存在，却没有足够的世界反馈；
- 决斗动作形成表面克制，实际因意图不透明而退化为固定最优解。

一句话归纳：

> **学习它如何让一段人生成为角色卡；不要让骰子、隐藏条件和重复劳动夺走玩家对这段人生的署名权。**

## 2. 可核对的产品骨架

官方资料将《活侠传》描述为单人角色扮演游戏：玩家扮演唐门中资质、外貌和地位都不占优势的外姓弟子，在衰败门派中练武、打杂、经营关系并面对江湖危机。官方明确强调天命、门派养成、动态人格、回合制决斗和大规模战役。

| 层面 | 可核对事实 | 设计意义 |
| --- | --- | --- |
| 主角身份 | 无主角光环的唐门底层外姓弟子 | 成长首先是从“无人看重”变成“有人愿意把事托付给你” |
| 门派生活 | 炼丹、毒术、锻造、杂务、师长关系、门派政策与规模 | 养成行为与故事场所统一，不需要独立训练副本 |
| 人格 | 决策、行动和天命会改变人物特质 | 角色卡是历程结果，而不是静态初始答案 |
| 事件 | 大量分支读取性格、关系、地点、时间与既有选择 | 同一事件可以承认玩家此前过的生活 |
| 天命 | 随机结果参与故事分岔，后续加入更多选择与重骰空间 | 偶然性制造个人经历，但必须给玩家保留方向控制 |
| 决斗 | 回合制、猜拳式动作关系、武学和人格影响战术 | 战斗承担人物表达，不只承担数值验收 |
| 战役 | 大规模冲突强调闪避、存活和群体处境 | 个人武力边界通过玩法而非旁白表现 |
| 失败 | 多种死亡与结局，死亡可转化为后续周目的命运资源 | 坏结果被包装成经历，而非简单读档提示 |
| 传奇 | 一轮经历最终被编成个人传奇 | 分散状态在结尾重新获得叙事意义 |

这套骨架的关键并不是系统数量，而是系统之间的相互读取：

```text
这次帮谁做事
→ 改变能力、性格、心相、关系或门派状态
→ 某场事件出现不同对白、不同权重或不同人物
→ 结果又改变之后谁还在、谁相信你、唐门是什么样子
→ 结局把这些零散因果整理为“你这一生做过什么”
```

## 3. 低位主角：把“弱”拆成可改变的社会条件

### 3.1 赵活的弱不只是一组低属性

《活侠传》的开局压力同时来自：

- 武功不足；
- 外貌不受欢迎；
- 外姓弟子身份低；
- 门派正在衰败；
- 强者和名门子弟拥有更自然的江湖位置；
- 很多灾祸不会因为他是主角就绕开。

所以玩家追求的第一层爽感不是“打出一万伤害”，而是：

> **一个本来不配坐上桌的人，终于让别人不能再把他当作可以随手舍弃的杂鱼。**

### 3.2 低位感为何成立

低位必须通过具体互动呈现：

| 低位来源 | 只写在设定里的弱表现 | 可玩的弱表现 |
| --- | --- | --- |
| 身份低 | 旁白说你是杂役 | 不能进内堂，只能从杂务、侧门或熟人取得入口 |
| 实力弱 | 敌人境界很高 | 正面打会死，但能躲、拖、求援、查弱点或改变战场 |
| 人缘差 | 人物说不喜欢你 | 关键证词没人信，受伤无人照看，礼物也不能直接买通 |
| 门派弱 | 大家说唐门衰败 | 缺钱、缺人、政策分歧和外敌压力改变可用行动 |
| 名声低 | 面板为零 | 事件结束后功劳被夺，死亡无人追查 |

### 3.3 对《大曜江湖》的适配

陈司命已经拥有类似的低位基础：无名、无门路、无合适差事，被迫进入丹房。后续不需要再降低属性，而应持续改变他的“办事资格”：

```text
破庙陌生人
→ 持沈字铜钱的求门者
→ 曹青丹房里可用的杂役
→ 知道药王谷旧事的人
→ 能替沈家处理病局的人
→ 掌握夜袭回报链的危险知情者
```

每次身份变化至少应兑现三件事：

1. 一个人改口；
2. 一个地点或行动开放；
3. 一种新的风险出现。

这样成长才是“社会位置变化”，而不只是境界提升。

## 4. 门派养成：用有限时间写出归属

### 4.1 日常循环的真实作用

门派养成表面上是分配行动次数，实际同时完成五件事：

1. 建立唐门的空间与生活感；
2. 让玩家认识师长、同门和劳动分工；
3. 累积武学、钱财、物品和技艺；
4. 通过重复接触生成关系；
5. 让“是否为唐门留下”不再只是结尾的一次按钮。

玩家之所以可能在危机时保护唐门，不是因为任务栏写着“守卫门派”，而是因为此前许多天都在这里练功、打杂、受气、被照顾和认识人。

### 4.2 有效的行动经济

一项合格的日常行动至少应在以下三层中改变两层：

| 层级 | 例子 |
| --- | --- |
| 即时收益 | 潜能、钱、体力、饱腹、伤势、材料 |
| 人物收益 | 曹青信任、王五关系、白栀云态度、同门评价 |
| 世界收益 | 新传闻、职位、政策倾向、事件时间窗、门派处境 |

若日常行动只给固定经验，它会迅速变成玩家为看剧情必须支付的重复劳动。

### 4.3 选择必须产生机会成本

好的行动次数不是体力条，而是人生取舍：

```text
这天去练武
→ 战力更强
→ 但没帮曹青取药
→ 关系增长变慢
→ 也错过紫金河出现的短暂窗口
```

玩家不是在算“哪项收益率最高”，而是在回答：

> **这一天，我愿意把时间交给谁、哪门本事和哪种未来？**

### 4.4 对当前沈家日常的改造方向

现有沈家日常已经有时段、体力、饱腹和五种行动，下一步不该增加第六、第七种资源，而应增强交叉后果：

- 取药：医术增长之外，也听见药房对三夫人用药的议论；
- 守炉：炼丹增长之外，让曹青愿意透露一段过去；
- 练五禽：身体改善之外，被沈家护院看见并改变评价；
- 帮沈福：获得门路，但占用曹青交代的差事时间；
- 休息：恢复稳定，同时明确错过了哪扇只开一日的门。

一日最多保留一个真正需要权衡的冲突。过多窗口叠加会把生活感变成排程攻略。

## 5. 人格系统：行为留下的“你是谁”

### 5.1 人格不是阵营九宫格

开发团队明确提到，性情、道德、修养、学问等数值不仅触发事件，还会改变同一段对白；官方商店页也强调人格特质会影响人际关系、剧情和决斗策略。

这意味着人格系统有三种用途：

1. **反映行为**：玩家长期怎样做事；
2. **改变表达**：同一意图会怎样说出来；
3. **产生后果**：谁更愿意接近或提防这样的主角。

它不是传统善恶值，因为“直率、世故、守礼、好学”等并不天然等于强弱或善恶。

### 5.2 人格系统最成功的地方

普通属性回答“能不能做到”，人格回答“你会怎样做、别人怎么看”：

| 状态 | 主要问题 |
| --- | --- |
| 力量／悟性／医术 | 是否具备完成行动的能力 |
| 性格倾向 | 会以怎样的语气、手段和代价完成 |
| 关系 | 对方是否愿意相信、容忍或配合 |
| 心相 | 此刻是否有精力把本事发挥出来 |
| 天命 | 世界是否出现意料之外的偏转 |

### 5.3 最大问题：数值语义不透明

人格轴一旦名称过于抽象，会出现三种理解成本：

- 玩家不知道数值两端分别代表什么人；
- 不知道某个日常动作为什么改变道德或处世；
- 只有看攻略才知道某段剧情需要哪组组合。

如果玩家为了攻略人物而机械刷“高道德、低处世”，人格就从角色扮演退化为隐藏钥匙。

### 5.4 《大曜江湖》不应复制四根人格数值条

当前项目更适合使用“行为痕迹＋少量倾向”的轻量结构：

```text
稳定倾向：求道、护人、藏锋、借势
行为痕迹：守诺、记仇、冒险试药、留活口、借制度办事
人物印象：曹青认为你能守秘密；燕惊鸿认为你敢承担；沈福认为你懂规矩
```

设计原则：

- 倾向由三次以上同类行为形成，不因一个玩笑突然翻转；
- 选项中直接显示会强化哪种倾向；
- 关键路线不只读一条抽象数值，而读行为证据；
- 人物可以对同一行为有不同解释；
- 倾向优先改变表达和行动深度，不轻易封死主线。

例如同样“逼问俘虏”：

| 主角留下的行为痕迹 | 表现与结果 |
| --- | --- |
| 多次留活口 | 先以生路换口供，俘虏更愿意相信承诺 |
| 多次藏锋 | 制造同伴已经招供的假象，降低警觉 |
| 多次护人 | 把威胁集中在保护对象上，更快问出危险时辰 |
| 多次借势 | 故意放出半真消息，让俘虏带回错误情报 |

这比“仁义达到 60，特殊选项亮起”更像人物在行动。

## 6. 心相：让情绪进入规则，但不要变成情绪税

### 6.1 心相的系统位置

从现有公开资料和官方更新可确认，心相会参与日常收益、事件触发或天命加成。它把“今天状态如何”放进养成规则，使人物不再永远以满效率执行计划。

心相与体力的区别应当是：

| 状态 | 回答的问题 |
| --- | --- |
| 体力 | 还能不能继续做 |
| 心相 | 愿不愿、稳不稳、能不能把本事完整发挥 |

### 6.2 它能制造的好体验

- 连续受挫后，人物的表现真的变差；
- 被理解、休息或完成心愿后，行动质量恢复；
- 某些冲动决定只会在低落或亢奋时出现；
- 情绪不只写在旁白里，而会改变玩家计划。

### 6.3 它容易变成的坏体验

- 玩家每几回合必须做一次固定恢复动作；
- 低心相只表现为所有收益减少；
- 想看剧情必须先刷到阈值；
- 情绪恢复被商品化为消耗品最优解。

### 6.4 对本项目的建议

第一版不增加持续波动的“心相数值”。使用少量、有来源、有期限的心境状态即可：

- `心神安定`：下一次观察或针术不受伤势劣势；
- `惊魂未定`：可看见危险意图，但主动进攻承受劣势；
- `受人所托`：保护特定人物时得到关系驱动的行动；
- `前世余悸`：命灯回照后看见死因，但面对同一杀招有心理压力。

每个状态必须：

1. 写明来源；
2. 写明影响哪些行动；
3. 写明何时消失；
4. 同时提供限制与新的叙事选项，而非只有减益。

## 7. 关系系统：把日常好感延迟到危机兑现

### 7.1 好感的意义不在数值增长

关系系统真正有效的时刻通常不是“好感＋1”，而是：

- 某人愿意说出本来不该告诉你的事；
- 某人替你证明身份；
- 某人错误地相信你，因此受到伤害；
- 某人在门派立场和私人感情之间做出选择；
- 某人因过去的相处，在结局战中出现或缺席。

这形成一个延迟回路：

```mermaid
flowchart LR
    A[日常相处] --> B[具体共同经历]
    B --> C[形成信任、亏欠、敬畏或怨恨]
    C --> D[危机读取关系与旧事]
    D --> E[援助、包庇、误会、牺牲或背叛]
    E --> F[关系获得新的含义]
```

### 7.2 单一好感的局限

单一好感无法区分：

- 喜欢你但不信任你；
- 尊敬你但不愿亲近；
- 欠你的命却反对你的立场；
- 害怕你，因此暂时服从。

当前项目已有信任、亲近、敬畏、亏欠等多维关系，比照搬单一星级更合适。接下来应强化的不是维度数量，而是“关键时刻自动兑现”。

### 7.3 关系兑现模板

每名核心人物至少准备四个时刻：

| 阶段 | 必须回答 |
| --- | --- |
| 初识 | 他为什么暂时容忍玩家？ |
| 共事 | 哪件具体行动改变了看法？ |
| 冲突 | 在什么情况下会牺牲、欺骗或拒绝玩家？ |
| 兑现 | 哪个危机中会因旧关系改变原定行动？ |

例如曹青不应只在四十好感传授丹方；后续还应读取：

- 玩家是否守过他的秘密；
- 是否在取血后仍选择观察；
- 是否把《青青册》只当升级材料；
- 是否在沈家与曹青利益冲突时站过队。

最终得到的可能不是“更高好感奖励”，而是曹青在必须弃卒时迟疑一次，或者提前把退路交给玩家。

## 8. 天命与安科：随机要写故事，不要替玩家表态

### 8.1 设计来源

开发团队专访明确说明，《活侠传》深受“安科”式互动叙事影响：作者先准备若干有权重的结果，再由骰子决定实际展开；即使出现低概率的极端走向，也要尊重结果继续写下去。

它与传统技能检定的区别是：

```text
传统检定：我尝试开锁 → 成功或失败

安科分岔：我决定去后山 →
  常见：遇见同门
  少见：撞见仇家
  极少：意外卷入足以改变人生的事件
```

前者判定能力，后者生成遭遇。

### 8.2 随机性为何会成为爽点

1. 玩家不能完全预演自己的人生；
2. 极端结果会形成“只有我遇到”的谈资；
3. 作者被迫认真书写坏结果和小概率结果；
4. 多周目不只是在另选按钮，也可能出现完全不同的插曲；
5. 传奇文本能把偶然重新解释为人生的一部分。

### 8.3 随机性为何会引发强烈反感

开发团队后来公开承认，过度随机和锁存档影响体验，并增加自由选择、重骰和更灵活的存档。问题不在玩家“不能接受失败”，而在随机越过了以下边界：

| 适合随机 | 不适合随机代替玩家 |
| --- | --- |
| 今天遇见谁 | 是否背叛师门 |
| 敌人临场用了哪招 | 是否爱上某人 |
| 行动完成得有多漂亮 | 是否接受明确屈辱 |
| 意外付出何种代价 | 已知条件下仍强制做出蠢事 |
| 小概率的插曲 | 已经充分准备后完全抹除准备价值 |

### 8.4 《大曜江湖》的因果骰边界

当前项目的固定因果骰方向正确，应明确为：

> **玩家决定做什么，属性和准备决定有多大把握，因果骰决定过程的质量与意外代价。**

建议固定四档：

| 档位 | 叙事职责 | 不应发生 |
| --- | --- | --- |
| 大成 | 不仅完成意图，还保住额外人证、退路或主动权 | 平白发放与行动无关的大奖 |
| 得手 | 完成核心意图 | 偷换玩家真正想做的事 |
| 得手有损 | 完成意图，但受伤、暴露、欠债或失去时机 | 把所有代价都写成扣血 |
| 失手 | 产生新局面、被反制或需要换方案 | 删除故事并只提示读档 |

### 8.5 随机结果的透明度

选择前至少显示：

```text
【针术·悟性】封住左袖杀招
把握：较高
有利：已见过左袖起手、春风针熟练
不利：右臂受伤
最坏可见后果：失手后敌人立刻近身
```

选择后显示：

```text
因果 6 + 针术 2 + 破绽 2 - 伤势 1 = 9
结果：得手
```

固定种子保证同一状态、同一行动不能靠反复读档刷新骰点；改变准备、对象或做法，才会改变因果。这比给无限重骰更能保护选择意义。

## 9. 失败与死亡：坏结果必须有作者待遇

### 9.1 大量死法的真正价值

《活侠传》为不同失败准备大量具体死法，并让死亡参与后续命运资源。它最重要的贡献不是“死得好笑”，而是承认：

> **一条没有成为大侠的人生，也值得被完整描述。**

失败若有独特原因、人物反应和传奇记录，就不再只是系统弹窗。

### 9.2 三种失败层级

| 失败层 | 结果 | 适合用途 |
| --- | --- | --- |
| 局部失手 | 本次行动失败，但场景继续 | 战斗、说服、调查 |
| 路线错过 | 人活着，但某人离开或窗口关闭 | 关系、奇遇、门派事件 |
| 人生终结 | 死亡或不可逆结局 | 明确高危行动、长期因果总爆发 |

如果所有失败都死亡，玩家会习惯读档；如果所有失败都能无损继续，选择又没有压力。

### 9.3 失败内容的最低标准

每个关键失败至少留下两项：

- 新见闻或死因；
- 关系变化；
- 世界事件继续发展；
- 伤势、身份或物证变化；
- 新的补救入口；
- 可写入个人传奇的一句结论。

当前命灯系统只应回照明确死亡，不应变成万能撤销。错过、误会、关系破裂和代价成功应留在世界里，才能形成这一轮独有的经历。

## 10. “传奇”结算：把状态重新翻译成人生

多数 RPG 的结算只列出：等级、装备、击杀、成就。《活侠传》的“传奇”思路更接近把过程编成一部属于这一轮的书。

其作用有三层：

1. **回收零散因果**：早期小选择在结尾重新出现；
2. **赋予失败意义**：不完美人生仍然有可述说的主题；
3. **鼓励重玩**：玩家想看的不是不同数值，而是另一种自己。

### 对《大曜江湖》的适配

本项目可以在每章收势时生成“江湖留痕”，不必等完整结局：

```text
沈家丹房一月

你以一碗血换来容身之地，认出了水炼之法，替三夫人续过一命。
曹青开始把你当作能守住炉火的人，却仍没有把退路告诉你。
雨巷刀客活着落入你手中；从此有人知道，沈家的杂役不只是杂役。
```

生成时只读取已发生事实，不虚构玩家未见内容。点击每一句可展开对应事件、关系和物证来源。

## 11. 高密度事件图：同一段文本承认过去

### 11.1 事件图的力量

官方更新日志反复出现以下条件修正：人物是否同行、心上人是谁、是否变心、掌门是否健在、人物位于何处、关系和时间是否满足。这说明系统不是按单线任务推进，而是让文本读取大量世界状态。

理想体验是：

> **玩家发现游戏记得一件自己都快忘了的小事。**

### 11.2 事件图的成本

每增加一个长期状态，潜在组合都会扩张：

```text
人物在不在 × 是否受伤 × 与玩家关系 × 门派立场 × 时间 × 前置事件结果
```

这会带来：

- 条件互斥却没有说明；
- 人物已经离开仍在场；
- 对白假设与玩家经历冲突；
- 新支线改坏旧路线；
- 测试组合远超内容团队承受范围。

### 11.3 本项目的控制办法

每个事件最多区分三层状态：

1. **入口条件**：事件会不会发生；
2. **核心变体**：最多三种真正改变冲突的版本；
3. **回声文本**：用一两句承认其他小状态，不另开完整支线。

例如燕惊鸿到来：

```text
入口条件：玩家完成雨巷追查

核心变体：
- 有完整活口与鱼鳞铜签
- 只有尸证或残缺口供
- 放走刀客但成功跟踪

回声文本：
- 是否带伤
- 是否曾护住白栀云
- 曹青是否信任玩家
```

这样能获得“世界记得我”的感觉，又不把每个布尔值扩成一条新主线。

## 12. 武学与成长：秘籍应改变人物与行动，不只加伤害

### 12.1 成长的多出口

《活侠传》的秘籍、日常、人格与战斗互相连接。武学既提供属性与招式，也可能影响嘴攻、性格或事件表现。其优点是“练什么”参与人物塑造。

### 12.2 常见风险

- 秘籍数量增加后，大多数只剩数值差异；
- 玩家为特定结局照表修炼，不再按角色选择；
- 成长点被分散在太多属性、技能和被动上；
- 战斗只有少数固定动作，许多秘籍无法形成可见玩法变化。

### 12.3 当前项目的适配原则

每门核心武学至少改变两层：

| 武学 | 战斗内改变 | 战斗外改变 |
| --- | --- | --- |
| 鱼跃龙门诀 | 调整身法、气息或脱身路线 | 水路赶路、涉水、观察水势 |
| 春风化雨针 | 封招、救治、点穴 | 诊断、止痛、识穴、保住证人 |
| 五禽戏 | 提升身体承受与桩功表现 | 赶路、劳作、恢复、模仿禽兽动作 |
| 打鱼杆法 | 控距、借力、挑落 | 钓鱼、取物、操舟、识别水上发力 |

秘籍数量可以少，但玩家应很快在剧情中亲手用到新能力。

---

## 13. 决斗系统：叙事概念强，博弈信息不足

### 13.1 基础结构

公开资料将决斗概括为以猜拳关系为底的回合制，常见动作包括：

- 嘴攻；
- 近身攻击；
- 防守；
- 暗器；
- 绝招。

不同动作消耗或积累气，并形成克制关系；武学、人格和相关能力会改变效果。

### 13.2 它最有价值的地方

决斗没有把剧情人物变成一个静默血条。尤其嘴攻能：

- 让双方在战斗中继续表明立场；
- 使旧怨、秘密和人格成为招式；
- 动摇对手、激怒对手或积累气势；
- 用插科打诨缓解重复回合；
- 让“不善武但会说话”拥有战斗参与方式。

### 13.3 它最明显的问题

猜拳式系统必须让玩家能够推断对手，否则只是蒙答案。社区反馈集中在：

- 敌方意图不够稳定可读；
- 克制成功与实际收益不对等；
- 少数动作在多数场合形成固定最优解；
- 秘籍很多，但回合动作仍然重复；
- 嘴攻的叙事很鲜活，数值决策却未必同样有深度。

这说明：

> **动作之间存在克制，不等于玩家正在博弈；只有对手意图可观察、可记忆、可诱导时，克制才会成为策略。**

### 13.4 对当前战斗系统的直接启发

本项目已经采用敌人意图、破绽、固定因果骰和少量行动，应该继续保持，不改成五键猜拳。最值得加入的是“战斗中的人物行动”：

```text
【旧事·鱼鳞铜签】说出交接暗语
效果：刀客意识到回报链已经泄露，下回合从补刀改为抢签。
条件：已取得暗语；刀客尚未重伤失控。
风险：若未掌握交接时辰，对方会判断你只知道一半。
```

嘴攻不应作为无条件的“精神伤害”，而应读取：

- 玩家知道什么；
- 对手在乎什么；
- 双方是什么关系；
- 当前战斗目标是什么。

它改变敌人意图、士气、援军、撤退或投降条件，效果要比扣一格血更具体。

## 14. 大规模战役：个人强弱必须服从战场目标

官方将大规模战斗与单挑分开：主角需要面对大量敌人和投射物，重点不只是击倒所有人，而是生存并参与群体战局。这种模式传达了一个重要的高武边界：

> **一名高手可以改变局部，却不该把军阵当作排队送死的血包。**

### 14.1 战役与决斗应该问不同问题

| 模式 | 核心问题 |
| --- | --- |
| 决斗 | 我能否读懂并压制眼前这个人？ |
| 战役 | 在混乱、时间与人数压力下，我能否完成目标并活着离开？ |

### 14.2 本项目未来的战役形式

不需要制作弹幕或即时群战，可以采用“战场路线＋连续事件”：

```text
守侧门
  ├─ 护送伤者退入丹房
  ├─ 截断传令者
  ├─ 借药烟封住窄巷
  └─ 放弃侧门，保住证人与账册
```

每轮显示：

- 当前战场目标；
- 两到三个敌方意图；
- 哪条路线将在下一轮失守；
- 玩家只能亲自处理其中一处；
- 同伴关系和此前准备决定其余地点能否撑住。

这样能表现“一人不能包办战场”，也能让日常积累的人脉在大冲突中兑现。

---

## 15. 门派规模与债务：有数值不等于有系统

开发团队在专访中提到，门派规模与债务原本有更多设想，现有作用相对有限。这个反例非常重要：

```text
玩家不断投入资源
→ 面板数字变化
→ 场景、人物、行动和危机没有明显变化
→ 玩家发现投入主要用于触发少数条件
→ 系统退化为隐藏门票
```

一个组织数值要成立，每跨过重要阶段至少改变：

1. 场景可见状态；
2. 可用人物或差事；
3. 对外势力的反应；
4. 危机中的实际承受能力。

《大曜江湖》第一版不应增加“沈家繁荣度”“丹房规模”“漕帮势力值”等总量条。若需要表现组织变化，用少量明确事实：

- 药库已被沈福控制；
- 曹青仍掌握丹房钥匙；
- 两名护院愿意听玩家调度；
- 王卓的回报链已经被改写。

事实比抽象数值更容易在剧情和战斗中兑现。

## 16. 多周目与命运点：减少重复，不要奖励重复

### 16.1 多周目的正当目标

多周目系统只应解决三件事：

- 更快进入未见分支；
- 让失败经历产生新的理解或起点；
- 允许玩家有意识地扮演另一种人。

《活侠传》把死法、结局和命运资源相连，并在发售后补充二周目继承与存档便利，说明重玩体验需要主动降低重复成本。

### 16.2 不适合本项目的部分

《大曜江湖》的命灯发生在同一条人生内，不应增加局外命运货币，更不应要求玩家收集死法来提高开局属性。否则会产生冲突：

- 故事说死亡可怕；
- 系统却鼓励主动刷死法；
- 玩家不再试图活下去，而在完成图鉴。

### 16.3 命灯的正确定位

命灯只提供：

1. 对死因的完整记忆；
2. 回到最近因果节点；
3. 因见过死亡而改变风险信息；
4. 某些只有死过才知道的敌人意图。

它不提供：

- 无限重骰；
- 任意撤销关系后果；
- 跨周目属性膨胀；
- 自动打开正确选项。

---

## 17. 叙事界面：系统反馈必须像故事的一部分

《活侠传》的核心资产是人物对白与旁白。系统数值若独立堆在角色面板，会割裂文字；若完全隐藏，又会让玩家不知道行为为何产生结果。

当前项目的右侧叙事栏可以采用三层表达：

### 第一层：故事发生了什么

```text
曹青把药杵放回案上，没有问你为何记得这味药，只把药柜第二层的钥匙推来半寸。
```

### 第二层：状态为何改变

```text
【曹青·信任】+1　你没有当众说破他的试探
【门路】丹房药柜第二层
```

### 第三层：这会改变什么

点击状态展开：

```text
曹青开始让你独自取用寻常药材。
若要接触紫龙丹主药，仍需他亲口许可或取得药库账册。
```

既保留文学感，也让玩家理解系统。不可只显示“道德－1、处世＋2”而不解释人物为什么这样看。

---

## 18. 《活侠传》最强的系统设计

### 18.1 系统共同写人物

能力、性格、关系、偶然和失败不是五个独立面板，而是都能改变赵活如何说话、遇见谁和成为什么人。

### 18.2 门派先成为生活，再成为立场

玩家是否守门，不是结尾临时选阵营，而是此前无数日常形成的情感结果。

### 18.3 坏结果被认真创作

极端失败、意外死亡和不完美人生拥有独立文本，随机才有叙事资格。

### 18.4 人物对白进入战斗

嘴攻让战斗继续塑造人物，没有把剧情和战斗切成两个互不相干的模式。

### 18.5 结局回收整轮经历

个人传奇把分散事件组织成“这一轮的我”，使重玩目标从清单转为另一种人生。

---

## 19. 《活侠传》最需要警惕的问题

### 19.1 随机越权

当骰子决定本应属于玩家的价值判断时，玩家不是经历命运，而是被系统代演。

### 19.2 隐藏条件爆炸

条件越密，越需要信息透明、稳定 ID、自动化校验和有限核心变体；否则文本越多，连续性错误越多。

### 19.3 重复养成阻挡内容

如果新分支前面有数小时相同排程，多周目不是发现，而是通勤。

### 19.4 抽象人格数值难以理解

道德、性情、修养、处世若缺乏清楚语义，会让角色扮演变成阈值工程。

### 19.5 系统承诺没有世界兑现

门派规模、债务或某些养成值如果只改变少数条件，玩家会停止相信系统。

### 19.6 猜拳不等于策略

没有稳定意图、观察和诱导时，克制链只是在按钮之间隐藏胜率。

---

## 20. 采用／改造／舍弃清单

| 《活侠传》设计 | 本项目处理 | 原因 |
| --- | --- | --- |
| 底层弱者开局 | 采用 | 与陈司命无名求道、沈家杂役身份高度一致 |
| 门派日常行动 | 改造 | 保留有限时间与人物交集，减少重复刷取 |
| 行为改变人格 | 采用 | 用行为痕迹和少量倾向代替四根抽象数值条 |
| 心相 | 轻量改造 | 使用有来源和期限的心境状态，不做持续恢复税 |
| 多维人物关系 | 采用 | 关系必须在危机中自动兑现 |
| 安科式随机遭遇 | 谨慎采用 | 只随机遭遇和结果质量，不随机重大立场 |
| 命运点重骰 | 舍弃 | 固定因果骰更能阻止 SL 刷点 |
| 多种独特死法 | 改造 | 死亡必须给见闻和新风险信息，不鼓励刷图鉴 |
| 传奇结算 | 采用 | 每章生成可追溯的江湖留痕 |
| 猜拳决斗 | 舍弃 | 当前意图制与条件行动更适合文字界面 |
| 嘴攻 | 深度改造 | 改为读取秘密、关系和立场的战斗行动 |
| 弹幕式战役 | 舍弃表现、采用目标 | 用路线、倒计时与同伴兑现表现大战 |
| 门派规模／债务数值 | 暂不采用 | 第一版缺少足够反馈出口 |
| 大量隐藏事件条件 | 舍弃 | 核心条件应在调查后可见，避免攻略依赖 |
| 二周目属性继承 | 暂不采用 | 当前是一条命灯人生，不做局外成长 |

## 21. 当前项目最高价值的三项落地

### P1：把“嘴攻”改造成战斗中的人物与情报行动

不增加通用嘴攻数值。先在雨巷刀客与王卓两战各加入一项条件语言行动：

```text
行动由来：玩家掌握了什么秘密或旧事
行动对象：对手真正担心什么
即时效果：改变敌人下一回合意图
长期效果：决定是否留口供、暴露情报或激化关系
```

验收标准：语言行动不直接扣血；必须改变敌人意图、投降条件、援军或战后证据中的至少一项。

### P2：让沈家日常写出人格与关系

不增加新日常按钮。为现有五种行动补充：

- 一项会留下的行为痕迹；
- 一名会因此改变看法的人；
- 一次后续事件里的回声；
- 一个明确错过的机会。

验收标准：三夫人病局或夜袭开始前，至少两次直接承认玩家此前如何过日子。

### P3：制作章末“江湖留痕”

在沈家章节收势时，依据稳定状态生成五至八句个人经历：

- 如何进入沈家；
- 与曹青形成何种关系；
- 学会什么并怎样首次使用；
- 三夫人是否得救；
- 雨巷留下活口、尸证还是追踪线；
- 玩家现在被谁视作何种人。

验收标准：每句都可追溯到真实状态；不同选择至少生成三组明显不同的章末主题；不泄露未见剧情。

> 这三项是本参考文档的优先建议，不自动替代 `SYSTEM_ROADMAP.md` 的既定优先级。进入实现前，应结合下一段剧情选择最短验证路径。

## 24. 最终设计原则

从《活侠传》中最值得保留的，不是低概率死法、数十种属性或庞大文本量，而是这个判断：

> **角色扮演不是在开局回答“我是谁”，而是让游戏在几十次行动之后，仍然记得我是怎样成为这个人的。**

对《大曜江湖》而言，后续设计应依次保证：

1. 玩家先决定意图；
2. 过去的行动真实改变眼前条件；
3. 随机只制造过程和代价，不夺走立场；
4. 失败产生新的故事状态；
5. 关系在危机时采取行动；
6. 武学在战斗外也能被亲手使用；
7. 章节结束时，把零散状态重新翻译为这一段人生。

理想结果不是玩家说“我把属性刷对了”，而是：

> **“这是我在沈家活过的那一个月。另一个选择，也许会活成另一个人。”**
