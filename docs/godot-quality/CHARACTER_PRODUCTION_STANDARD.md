# 主角与NPC制作规范 v3

生效：2026-09-24。按用户最新要求：**不限定角色生产方式，以动作连续、人物好看为准；先验证小样再选管线。** 取代v2的“必须同rig渲染”和后续“必须逐帧AI生成”。运行时仍为2D人物。

## 1. 造型与画面

叶无尘保持同一身份：年轻剑客、黑高束发/发带、白交领、蓝灰外衣、棕腰带、黑护腕短靴，3.5–4头身。右手单剑、左腰剑鞘；不得直接镜像非对称造型。已有turnaround与idle风格图是未批准候选，不能标为用户已确认。

主验收1080p站立约100–112px，720p约67–75px；必须与整屏共同确认，不能仅放大看脸。相机初始约35°俯视，与绘制/源渲染透视共同冻结。

## 2. 先验证管线，后批量生产

2026-09-24 三轮整图步行失败后，用户选择“保留当前造型，改用可控骨骼动画验证”。当前执行路线为修改真实三维母版、约束脚部接地及武器轨迹、离线输出完整二维帧；不恢复纸偶。仅先做 S/SE 静止、S 步行、SE 直刺小样，合格后再扩展。此选择不是对旧低模或新样本的美术批准。

允许完整动作图集生成后切片/像素修订、整体人物独立帧生成、精细三维角色骨骼动画预渲染。按最少返工评估已有候选，选一种能通过连续动作验收的主管线，记录采用原因与真实来源。

小样最少覆盖：S/SE各一张静止关键帧、S完整8帧步行、SE完整12帧直刺。在正常游戏尺寸和连续循环下检验造型/步幅/持剑/接地/攻击起收势，然后扩至P2的48帧槽。不要求同时尝试三条管线，不盲目生成全部192帧。

不恢复已被用户否定的纸偶肢体拼接，不使用旧Canvas人物；现有被拒低模不是强制母版。AI序列不得虚称同rig渲染。图集排版只做完整帧打包，不是身体拼接。

合格源头为唯一权威母版，续作修改该母版。每次生成/修订登记输入参考、提示词/工具、输出、选择理由、拒收缺陷与可重放加工；缺失历史记录如实标缺失。

## 3. 固定运行合同

|字段|要求|
|---|---|
|画布|160×128 RGBA，所有动作一致|
|脚锚|(80,112)，不按bbox自动居中|
|站立源身体高度|约80逻辑像素，具体比例随P1/P2共同冻结|
|方向顺序|N、NE、E、SE、S、SW、W、NW|
|安全边|剑、头发、衣摆、靴底距格边至少4px|
|导入|无损PNG，最近邻基准，禁自动3D有损压缩；mipmap另行实机A/B|
|引擎|Sprite3D/AnimatedSprite3D，固定pixel_size与脚点，深度测试、受光|
|动作|idle4、walk8、thrust12，每方向同帧数；NPC固定朝向idle4/pour8|
|事件|脚接地、起手/命中/收势；命中每轮仅一次|

P2只S/SE共48槽，P3主角全8向192槽；本轮无run/hurt。帧区域、持续时间、脚点、武器手、关键武器锚点和事件写入统一动画描述。缺方向、缺帧或未验收时明确为候选，不能以复制/镜像旧角色填满数量。

源文件级人工修整可调整姿态和像素簇，必须可追溯；禁止逐帧缩放、逐帧bbox对齐、运行时偏移修错。步行的接地脚可自然交替，脚锚代表角色地面根坐标，不强迫每只脚始终重叠。

## 4. 光照与边缘

保持弱方向性固有明暗；引擎接受场景光与阴影。检查日光→檐下，不能用unshaded逃避融合。无合格法线输出不声称已具备配对法线；避免源图重明暗与引擎重复照明。

黑/白/灰底检查透明毛边、游离像素与邻帧碎片。调色板24–48色仅作工作目标，不以颜色数证明质量。像素化和下采样之后重新审视五官色簇、肩袖、手剑连接、双脚轮廓和剑尖。

## 5. 验收与当前候选

自动检查尺寸、Alpha、安全边、完整引用、方向/时长/事件和固定比例。人工检查原尺寸连续动画、逐帧与整数放大；自动通过不代表人物通过。

拒收：缩放/分裂、跨格、晃动、跳手、多肢、缺方向、明显滑步、姿态体积漂移、脸部糊团。相同问题三轮无改善记录对照并请求评审；不改变标准放行。

已有hero-v2的AI候选与低模/纸偶试验均未通过P2。P1只使用一张静止身份尺寸试片，明确不是动画或正式角色。旧上传角色与旧默认测试入口保留，不进入新的正式验收结果。
