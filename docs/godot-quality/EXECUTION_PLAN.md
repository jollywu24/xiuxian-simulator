# 《武道》Godot 一屏可玩场景重制计划 v2

生效：2026-09-24。用户已要求实施，且后续明确：**角色不限定生产方式，以人物好看、动作连续为准；先验证小样再选管线。** 本文件取代旧 v1 计划的生产方式、阶段及范围。历史缺陷、证据和用户源资产保留，不视为当前验收通过。

## 1. 唯一目标与边界

在正常游戏尺寸下制作完整的临水茶铺与渡口。人物比例、服饰与动作以武侠可读性为先，空间层次、构图与光影参考《八方旅人2》。使用 Windows x86_64、Godot Forward+、标准 GDScript、固定镜头、3D 环境和运行时 2D 人物。

一屏内容：茶铺、石路、河岸、短木桥、码头、一艘船、一棵柳树、主角、茶铺 NPC、练剑木桩。可行走、过桥、对话、码头观察、练剑，有声音和反馈。不增加完整战斗、成长、背包、昼夜、跑步、受伤、旧系统迁移或网页导出。

工程：`godot/linshui-quality/`；源资产：`art_source/linshui-quality/v1/`。不修改旧网页、旧 tests、存档或 Pages，不购买收费素材，不删除用户资源，不推送或上线。保留工作区已有修改，沿用292文件保护基线；不得用新基线掩盖差异。

## 2. 构图合同

1920×1080 主验收，1280×720 兼验。固定斜俯视正交镜头，初始约35°，P1确认后冻结。主角站立在1080p约100–112像素，所有动作同一世界比例，不按动作缩放。

左后方茶铺和可走入檐下；中景石路串联出生点、茶铺、木桩和桥；右侧河道、桥、码头与船呈现岸壁/水位/桥面高差。柳树作近景，远岸收束；画面不露孤立平台和空白背景。前景不能长期遮没玩家；所有交互点可辨识且可达。

固定暖侧光、冷环境补光；先关闭DOF/Glow验收结构。必须检验接地、进出檐下受光、桥下空间和水岸交界。可以克制润色，但不能以模糊、泛光或植物遮盖资产问题。

## 3. 生产与运行合同

角色具体规范见 [CHARACTER_PRODUCTION_STANDARD.md](CHARACTER_PRODUCTION_STANDARD.md)。不限定逐帧AI、动作图集或精细三维预渲染；先以连续动画小样选路线。禁止默认回到已拒收的肢体拼接、旧Canvas人物或不合格低模。已有未批准图仅作候选，不伪称用户已批准。

主角八向 idle4/walk8/thrust12，共192槽；NPC固定工作方向idle4/pour8。图集160×128、脚锚(80,112)、4px安全边、固定比例，动作事件单次命中。不逐帧bbox居中、运行时缩放/平移修错。打包不改变作者帧的造型。缺帧不得用旧图或占位填满后报告完成。

环境Blender母版→GLB→包装场景；纹理、来源、许可、导出与生成记录可追溯，已合格资产在原母版续作。NPC、船、柳树与木桩有对应动态/反馈。音频包括水、风叶、不同地面脚步、交谈和受击。

运行控制与显示分离；WASD/点击移动、E交互、空格练剑、Esc暂停。对话锁移动攻击；攻击锁位移并拒绝重复按键重启。碰撞、导航、点击地面和视觉高程一致，交互验证距离/朝向。验证场景与最终入口分离，完整场景验收后才切默认入口。

## 4. 阶段质量门

|阶段|交付|放行|
|---|---|---|
|P0|实际入口/资产/工具审计，哈希复核，规范与状态统一|记录真实，不将文件存在算通过|
|P1|整屏灰盒、真实行走、桥/码头高差、檐下、正常尺寸人物试片、双分辨率引擎截图|路线结构通过；**用户确认构图与角色大小**|
|P2|完整构图内精制茶铺立面/屋檐、石路、岸水接缝；S/SE 48动作槽与受光连续实机|**用户确认画面与动作方向**；无分裂/变焦/滑步/碎片|
|P3|其余方向、NPC、全屏环境、动效全部补齐|无正式占位；逐资产逐方向检查|
|P4|移动→茶铺交谈→渡桥→码头观察→木桩练剑，UI、声音、暂停重置|从启动起可连续操作，无调试依赖|

每轮检查真实输出并记录具体缺陷；同类三轮无改善提交对照，停止无依据重复。工具、额度、授权阻塞只阻止依赖部分，不用占位替代放行。历史429并不证明当前仍限额；不得无依据承诺可生成或额度充足。

## 5. 验收与交付

- 原尺寸1080p/720p：头脸区域、衣层、剑手、双脚、方向可辨；八向身份不漂移。
- 待机不摇摆；步行接地自然；攻击无分裂、跨格、变焦、跳手、邻帧残片或重启。连续播放与逐帧检查分别留证。
- 地面/墙/桥/船/角色细节密度统一；无悬浮、强重复接缝、纹理闪烁或遮挡穿帮。
- 实际物理走完茶铺→檐下→桥→对岸→码头→木桩→茶铺；河水/屋顶/不可达点击被拒绝。键盘不穿墙落水。
- 对话、倒茶、练剑、暂停、重置可反复执行，命中只发一次。
- 1080p Release包，本机GPU预热30秒后采样120秒：平均≥60FPS，P95≤20ms；报告硬件、帧耗时分位、卡顿、显存和资源规模。
- 90秒以上连续真实操作录屏；离线Movie Maker不证明实时性能。
- 交付工程、Windows包、独立帧/图集/元数据、编辑母版、GLB/材质/贴图、生成和许可记录、截图、录屏、测试与未完成项。
- 自动检查与视觉评审分别记录；没有实际用户视觉确认，不宣称商业参照完成度。
