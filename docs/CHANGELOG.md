# 《武道》重要变更

本文只记录已经交付的玩家能力或工程能力。设计原因见 `DECISION_LOG.md`，未来计划见 `SYSTEM_ROADMAP.md`。

## 2026-08-06

### 人物建立页统一为明亮水墨视觉

- 出身页按确认效果改为雾白绢纸、青玉交互和旧金描边；三张卡默认选中世家旁支，未选中卡不再显示详细经历，确认后再进入容貌；
- 三幅出身原画重新统一为十六岁上下的青年身量，并分别保留族宅偏院、秦淮鱼市和东郊驿路的生活环境，不使用预设主角正脸；
- 容貌页沿用同一视觉语言，重新绘制浅墨江南庭院；前景石板从画面底部连续延伸到人物脚下，水面退到远景与两侧，人物以接触阴影明确站在地面；
- 当前容貌预览继续使用已验收的静态`rig-v2`合成，没有把尚未完成授权与编辑器验证的Spine纵切带入网页；
- 新增人物建立美术构建脚本、四张正式WebP、资源契约测试、合成验收图和三视口浏览器回归断言。

## 2026-08-05

### 建立男女 Spine 待机动画预制纵切

- 按官方Spine 4.2骨骼、插槽、皮肤、附件与网格形变结构建立男女共用待机纵切；灰衣男身／女身共享九骨骼和六秒`idle`动画，不为每种体貌复制循环帧；
- 眨眼使用两次非等间隔闭眼附件切换，闭眼局部经过近景开／闭眼对照，身体、发型、服装和姿势继续来自已经验收的完整人物母版；
- 呼吸与衣摆变化写入同一人物网格的局部形变时间轴，并生成本地动态预演图；静态WebP仍是正式网页的唯一运行资源和失败降级；
- 新增可重建图集、Atlas和Spine JSON的脚本及契约测试，验证男女皮肤、骨骼、闭眼时间点、形变幅度和资源尺寸；
- 当前机器没有Spine编辑器，也未确认可公开分发的Spine Professional许可；本纵切使用的网格形变不能由Essential保存或导出。官方运行时没有进入网页、提交或Pages；纵切只能称为可导入预制，待许可和匹配版本编辑器就绪后再完成官方运行时验证。

### 撤回错位纸娃娃并按同源母版重做

- 复核上一版九十六格矩阵后确认其并未通过视觉验收：底图为空、衣服携带另一副完整身体、帽子并非同头型派生，且部分透明资源带有色块污染；此前“组合已经验收”的说明错误，相关运行选项和发布资源已经撤回；
- 男女各重新锁定一张完整人物母版，再以该母版为输入派生靛蓝行衣和旧布额巾；灰衣／靛蓝行衣保持身份、姿势、头身比例和手脚基准，发带使用同一头型的头部变体，不再用独立帽图猜位置；
- 正式 `rig-v2` 只包含六张实际通过的运行资源；其它容貌类别仍保留状态和界面位置，但在同源部件完成前只有默认项，不再用伪组件填满数量；
- 组合图改为八张可辨识大格，逐格检查头身、领口、肩线、手脚、发带、颈部接缝与透明边缘；自动测试只证明文件契约，不再代替人工美术判断；
- 行为准则新增视觉验收门禁：组合图必须以原尺寸人工检查，发现结构错位时禁止发布并回到共同母版重做。

## 2026-08-04

### 容貌合成改用槽位与遮罩方案

- 在项目行为准则中加入“成熟方案优先门禁”：涉及通用系统、交互范式和资产管线时，先查已发行游戏、官方规范或活跃开源实现，记录采用／舍弃理由，再开始设计与编码；
- 容貌管线采用Picrew的复合部件与冲突规则、Spine的插槽与绘制顺序、Universal LPC的共同画布纪律；不引入其服务、编辑器、运行时或第三方素材；
- 旧版把独立生成部件直接叠放的实现退出运行目录，现行纵切只保留经过共同母版验收的双体貌、两组发式、两套服装、两种脸型和三种帽态；
- 人物预览与人物页共用原生Canvas合成器；帽子为前后发提供同一遮罩，全部图层先在离屏画布完成，加载失败时不会留下半个人物；
- 已删除旧纸娃娃按单件装备和男女体貌分别写`top`、`width`的偏移补丁；结构问题只允许在共同母版、插槽或遮罩中修正；
- 当日曾新增九十六组跨体貌、帽子、前发、后发、衣服和脸型的组合图；该图随后被确认只验证了渲染和尺寸、没有通过视觉对位，并于2026-08-05随错位资源一并撤回。

### 容貌组件对位修正

- 修正`1280×660`等中等高度横屏下体貌按钮压住“前发”选项的问题，五排左右组件改用独立短横屏锚点；浏览器回归现在直接检查身份区、第一排、第五排和确认按钮之间不得相交；
- 男女面部母版重新归一到人物中轴，脸型层不再夹带头发或矩形颈部补片，眼睛、眉毛、鼻子和嘴巴改为只有笔触明暗的透明细节层，不再携带椭圆肤色底片；
- 生产校验新增面部中心偏差和五官肤色底片检测，男女面部源母版随脚本保存在`scripts/assets/appearance/`，以后重建不再依赖临时生成目录；

### 容貌页视觉还原与默认组件合成

- 容貌页按确认稿改为暗色雨后江南庭院、人物居中、顶部帽子与左右各五项镜像环绕，桌面和手机横屏均保留完整操作；
- 中央人物不再使用包含完整脸、发型和服装的单张立绘。运行时改为透明锚点叠加当前脸型、五官、前后发、服装、帽子与装饰，所有层共享`1024×1536`画布和稳定顺序；
- 男女两套目录的十一类部件已经全部替换为手绘透明位图：共计一百五十八件可见组件和两个透明锚点，不再回退到旧SVG图集或只为默认项准备位图；
- 美术生产先用八套完整人物确定体型、脸部、发式、布料与配色，再分别制作无帽发式母版和无头饰服装母版后拆层；组件在统一面部中心、脚底线、光向和笔触下制作，任意混搭不会切回另一种画风；
- 新旅程的十一项外观部件全部从编号“1”开始；帽子、脸饰和后背的一号代表“无”，其余每一项都只替换自己的透明层；
- 发布资源契约升级，规则测试会核验全部一百六十个运行资源存在，浏览器回归会确认默认八层位图和切换后的女性前发真实加载，避免发布时漏图。

## 2026-08-03

### 十一类容貌与装备外观解耦

- 容貌页由整脸、发式、肤色三项预设升级为帽子、前发、后发、眼睛、眉毛、嘴巴、鼻子、脸型、脸饰、后背外观和服装十一类独立选择；
- 十一项控件固定为顶部一项、左右各五项，左右同行等宽、等高、等距并镜像对齐；中央只保留人物预览，手机横屏继续完整显示，竖屏改为人物在上、两列选项在下；
- 新增男女透明人物底像与共同部件图集，切换体貌和任一部件立即更新预览，整组随机会同时轮换十一类外观；
- 装备与人物外观彻底解耦：人物页继续显示创建时选定的服装，装备、替换和卸下只改变装备槽、派生数值、动作与叙事权限；
- 存档升级为版本10，版本2至8补齐安全默认组合，版本9的整脸、发式和肤色迁移为对应的新部件，不倒退剧情或人物建立流程；
- 正篇浏览器回归新增十一项控件数量、人物中轴、控件等尺寸、左右逐行镜像、男女底像和部件切换检查；三出身流程全部经过新版容貌页继续抵达破庙。

## 2026-07-31

### 容貌创建与正式美术资源

- 人物建立流程由出身选择继续进入全屏容貌页，姓名正式移入该步骤；出身完成、容貌当前、天赋与属性待定在同一进度条中显示；
- 新增男身／女身、六套面容、五套短发式、五档自然肤色、姓名轮换与整组随机，所有选择都有可序列化状态并会随存档恢复；
- 面容、发式与肤色收束为三条左右预设切换栏，不拆眼眉鼻嘴、不增加滑杆，也不在容貌页混入服装选择；
- 新增江南晨雾庭院底图、十二面容图集、男女各五幅人物立像及对应发式缩略图；网页只加载拆分后的正式资源，不直接加载设计效果图；
- 人物页开始使用共用纸娃娃合成：容貌立像作为底图，蓑雨兜帽、江行斗笠、乌鳞短甲和沈府护腕作为独立透明装备层；换装只替换对应层，装备详情二次确认与战斗数值规则保持不变；
- 新增纸娃娃纯规则测试与浏览器换装回归，确认查看详情不会提前换装、替换冠帽不会重画人物底像、卸下后对应外观层消失；
- 存档升级为版本9，版本2至8都会补齐安全的默认容貌；浏览器回归新增1672×941、844×390和390×844容貌页检查以及男女／发式切换；
- 当前“确认容貌”继续承接原有初心与开场纵切；天赋和独立属性页仍属待制作内容，不把进度条方向描述为已上线功能。

## 2026-07-30

### 出身选择页视觉还原

- 出身选择页改为雾白青灰的三卡并列构图，顶部显示出身、容貌、天赋、属性四步方向，当前只点亮出身；
- 三张卡均使用开场生活地点的正式场景资源，场景、名称和完整经历描述在同一卡片内，不显示主角立绘、姓名输入、初始物品或未来任务；
- 默认选中市井子弟，选中态使用深青说明底、暖金边与菱形标记，底部只保留“选定出身”；
- 增加1672×941设计标尺、844×390手机横屏与390×844手机竖屏截图回归，横屏三张卡及描述必须同时可见。

### 武学节点与实际使用

- 正式采用《烟雨江湖》拆解中适合本项目的武学结构：四类正交分工、少量节点解锁、人物传承、场外兑现、低品阶保值和有限配套；明确继续舍弃十重等待、隐藏累计修为、二次内力换算与门派日常；
- 武学目录新增临阵所长、传承来源和首次兑现契约，目录测试会拦截缺少来源、首次使用或场外用途的新武学；
- 战斗动作开始读取具体领悟节点，未达到造诣时动作保留并显示缺少的领悟，不再让详情页节点只承担说明文字；
- 玩家第一次在某场战斗、旅行或训练中实际使用一门武学时，自动留下稳定记录并增加十点修为；同场重复出招不会重复领取；
- 武学页会标明节点是否已经在局中用过，并显示首次实证与配套状态；
- 鱼跃龙门诀与沧澜定海桩形成首个非强制配套“行波定海”，同时携带时强化水边立足，拆开后仍可独立使用。

## 2026-07-28

### 三出身与独立序章

- 新旅程改为世家旁支、市井子弟、身世成谜三种来处，选择页使用三张匿名环境牌面，不提前替主角决定容貌，也不提前泄露族宅属于沈家；
- 世家旁支从城南西偏院接下封药木匣差事，市井子弟从秦淮鱼市接下红绳油布包跑腿，二者各有四个独立前置节点与一段破庙任务；
- 开场差事支持普通成功、带代价成功和失手继续，分别写入物品、见闻、门路、联系人、银钱、暴露与后续入门身份；
- 三种来处在破庙共同觉醒三点重分，经龙青鱼与紫金河汇流，再分别以回府复命、货门交割和沈字铜钱进入曹青丹房；
- 沈家密会后新增旁谱缺名、鱼市催信、血书旧字三项个人事件，来处痕迹进入首章结算；
- 存档升级为版本8，旧`clan`、`common`、`street`、`mystery`自动映射，已经离开破庙的旧档不会倒退重做序章；
- 新增三出身规则测试、西偏院与秦淮鱼市场景、三张出身牌面，以及独立浏览器回归流程。

### 发布与质量保障

- 增加可同时在本地和 GitHub Actions 运行的统一 Web 验证工作流；

- 增加发布资源唯一契约、运行时资源扫描、统一缓存版本、工作流门禁和调试接口契约测试；

- 建立 `PROJECT_CONTEXT.md`、`TESTING.md`、`DEBUGGING.md`、`RELEASE.md`、`DECISION_LOG.md`、`CHANGELOG.md` 与现行系统文档的职责边界。
