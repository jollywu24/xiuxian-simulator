# 《武道》重要变更

本文只记录已经交付的玩家能力或工程能力。设计原因见 `DECISION_LOG.md`，未来计划见 `SYSTEM_ROADMAP.md`。

## 2026-07-28

### 发布与质量保障

- 增加可同时在本地和 GitHub Actions 运行的统一 Web 验证工作流；
- 浏览器回归改为自动启动静态服务器、无头 Chrome／Edge、随机调试端口和临时用户目录；
- 正篇与独立战斗两套 CDP 深流程可通过 `npm run test:browser` 连续执行；
- 增加发布资源存在性、统一缓存版本、工作流门禁和调试接口契约测试；
- Pages 发布产物写入短提交号，部署完成后在线验证页面、版本与关键资源；
- 增加仅在 `?debug=1` 下开放的 `window.WudaoDebug` 状态快照与受控状态接口；
- 建立 `PROJECT_CONTEXT.md`、`DECISION_LOG.md`、`CHANGELOG.md` 与现行系统文档的职责边界。
