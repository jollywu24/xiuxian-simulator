# 《武道》存档架构

## 1. 当前结论

存档已经拆成两层：

1. **游戏状态层**：继续使用可迁移的JSON状态，当前内容版本为`version: 7`；
2. **平台存储层**：浏览器使用本地键值存储，未来桌面版使用用户目录中的文件。

剧情、战斗、人物、装备和武学代码只关心JSON状态，不直接决定文件放在哪里。这样网页发布、桌面封装和Steam Cloud可以共用同一份状态结构与迁移规则。

## 2. 浏览器端

现有主键`wudao-high-martial-v1`保持不变，因此旧手机和旧浏览器里的版本2～7进度无需导出即可继续。

浏览器端使用四条记录：

| 记录 | 用途 |
| --- | --- |
| `wudao-high-martial-v1` | 当前主档原始JSON |
| `wudao-high-martial-v1-checksum` | 主档FNV-1a校验值 |
| `wudao-high-martial-v1-backup` | 上一次有效主档 |
| `wudao-high-martial-v1-backup-checksum` | 备份档校验值 |

写入顺序：

1. 在内存中解析并校验新JSON；
2. 只有旧主档仍然有效时，才把它轮换成备份；
3. 移除旧校验值；
4. 写入新主档；
5. 写入新校验值。

读取顺序：

1. 校验并读取主档；
2. 主档截断、JSON损坏、校验不一致或版本不受支持时读取备份；
3. 备份有效则自动提升为主档并补写校验值；
4. 两份都无效时不覆盖原记录，由游戏进入新旅程入口。

没有校验值的旧存档被视为兼容存档；首次产生新进度后自动进入主档＋备份档机制。

## 3. 桌面文件端

`desktop/save-file-store.mjs`提供不依赖Electron的文件存档器。桌面外壳只需把安全的用户存档目录传入，并通过预加载桥接暴露三个白名单动作：

- `readSaveSlot(slot)`；
- `writeSaveSlot(slot, raw)`；
- `clearSaveSlot(slot)`。

第一版文件：

```text
<userData>/saves/
├─ save-1.json
└─ save-1.bak
```

临时写入使用同目录`.save-1.tmp`，成功替换后不保留。

每次文件写入执行：

1. 拒绝无法解析或结构错误的新状态；
2. 将新内容写入临时文件；
3. 刷新文件句柄，避免只停留在进程缓存；
4. 有效旧主档先原子替换到`.bak`；
5. 新主档再由临时文件替换；
6. 写入串行排队，避免连续点击使旧状态晚于新状态落盘。

主档损坏时读取`.bak`，恢复成功后立即重建`save-1.json`。损坏主档绝不能反向覆盖有效备份。

## 4. Steam Cloud边界

Steam Cloud首版只同步：

- `save-1.json`；
- `save-1.bak`。

不同步临时文件、日志、截图和缓存。设置项后续独立放入`settings.json`，避免云端画质或窗口模式覆盖另一台设备。

云冲突解决尚未实现。接入Steam前必须为存档补充：

- 稳定的`saveId`；
- `updatedAt`；
- 累计游玩时间；
- 当前章节与地点摘要；
- 桌面端冲突选择界面。

不能只用文件修改时间静默选择新档，因为系统时钟与云端同步顺序都可能不可靠。

## 5. 版本与兼容

存储方式和内容版本分开演进：

- 内容字段变化才提升状态`version`；
- 增加备份、校验或换用文件，不提升状态`version`；
- 旧内容先迁移到当前结构，再由平台层写回；
- 迁移或写入失败时保留原始主档和备份，不用空状态覆盖。

当前支持读取版本2、3、4、5、6、7，并统一迁移至版本7。

## 6. 验证要求

自动测试必须覆盖：

- 旧浏览器存档无校验值仍可读取；
- 第二次写入会保留第一次有效状态；
- 主档JSON截断会恢复备份并重建主档；
- 校验值不一致会恢复备份；
- 无效新状态不会覆盖有效旧档；
- 清除旅程会同时移除主档、备份和校验记录；
- 桌面文件主档、备份、临时替换与串行写入；
- 版本2～6迁移到版本7；
- 浏览器完整终章进度损坏后仍能从备份恢复。

实现对应：

- `web/save-core.mjs`：校验、解析与主备选择纯规则；
- `web/save-storage.mjs`：浏览器存储和桌面桥接适配；
- `desktop/save-file-store.mjs`：桌面原子文件存档；
- `tests/save-system.test.mjs`：主备、损坏恢复与文件写入测试；
- `scripts/cdp-smoke.mjs`：真实浏览器终章坏档恢复检查。
