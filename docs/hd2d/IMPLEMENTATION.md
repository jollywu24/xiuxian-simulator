# 临水镇 HD-2D 实现与验收

本次以用户提供的 `Wudao_HD2D_Jiangnan_Demo_Implementation_v1.md` 为主，采用《渡口旧账》及 1 对 2 仓院战斗。另一份 `HD2D_Jiangnan_Town_Demo_Implementation_Plan.md` 的《错封的药箱》和可选切磋不混入本条任务。

## 独立接入

入口是 `web/demos/jiangnan-hd2d/index.html`，随现有 `web/` 静态发布，不替换首页、S0 工作台或演武场。纯规则、导航、状态和存档不依赖 DOM。方案明确授权 Three.js，本切片将 0.186.0 核心及 MIT 许可证完整放在本地 vendor 内，无 CDN 运行依赖，无构建步骤。保留独立版本目录是为了让切片可单独搬运与回滚。

主角叶无尘与《渡口旧账》是方案中的原创验证故事，不属于原小说后续改编，也不改写陈司命正篇。战斗数值采用这份方案明确列出的确定性公式，限定在独立切片，不修改正篇统一战斗引擎。

## 已实现

- 真实 XZ 三维关卡、Y 向上、固定窄视场跟随镜头；室外两岸、木桥、低码头、茶摊、仓院以及客栈四桌、柜台、货架、楼梯与二层回廊。
- 桥面与导航共享正弦高程；水区不可走；半米 A* 网格、角色半径、对角穿墙检查、分段碰撞检查及可达交互锚点。门口、柜台均经过路线测试。
- 原创可编辑像素人物：48×72 源画布、四方向、四步行帧、独立出剑图；MeshLambertMaterial 接收光照、alphaTest 写深度并投射裁切阴影。角色不是全屏像素滤镜。
- 曲面青瓦、灰墙、木构、桌椅、杯碗、货箱、木车、船、岸草、柳树；程序化石纹、木纹与瓦纹。重复箱体和圆柱合批，草叶采用实例化。
- 太阳与天空光、室内局部灯、日照／晚照；512×512 平面反射每八帧更新，独立深度纹理驱动轻景深。低画质关闭景深、反射刷新和动态阴影，保留接触脚影并降低渲染分辨率。所有 UI 在后处理之外。
- WASD／方向键、Shift、地面点击寻路、点击人物走近交谈、E 交互、触屏方向键、地图导航；对话时阻止移动、Tab 焦点限制、Esc 收起。
- 两条证据、客栈核号、仓院交锋、取回镖箱、回客栈交付。收取额外谢礼或退回谢礼分别改变铜钱、关系与后续对话。交易与伤药真实生效，交付幂等。
- 8×6 战场、三格移动、近身普攻、两格流水剑、守势与药品；敌人自动走位并依次行动；失败返回桥头，调查保留。
- 独立 `wudao-jiangnan-hd2d-v1` 行录，版本与字段校验、坐标修复、导入导出、损坏档保留、写入异常反馈。战中重载回安全检查点。
- 原创 Web Audio 水声、脚步与短击音，默认静音；后台暂停。没有使用外部音乐或游戏音效。

## 文件职责

| 文件 | 职责 |
|---|---|
| `src/world.mjs` | 场景锚点、高程、碰撞、A* 与交互距离 |
| `src/rules.mjs` | 任务、背包、确定性战斗、存档验证 |
| `src/art.mjs` | 可重建纹理、角色四向序列、受光人物网格 |
| `src/render.mjs` | 三维建筑、实例化、灯光、平面反射与深度景深 |
| `src/main.mjs` | 固定步长循环、输入、DOM 界面、存档与音频 |
| `tests/hd2d.test.mjs` | 全部锚点可达、穿水限制、战斗、奖励与存档 |
| `scripts/cdp-hd2d.mjs` | 正常操作的通关、购买、三尺寸截图、重载与运行异常 |

`?debug=1` 才提供 `window.__jiangnan` 只读快照、性能数据、投影坐标以及与地图相同的寻路命令，不提供注入任务结果或瞬移接口。浏览器回归实际沿路行走并点击战斗格子，不直接写完成档。

## 验证方法

```bash
npm run serve
# 使用服务输出的端口，进入 /demos/jiangnan-hd2d/
node --test tests/hd2d.test.mjs
npm run verify:quick
# 本地 HTTP 8080 + Chrome CDP 9225
node scripts/cdp-hd2d.mjs 9225
npm run verify
```

截图和性能记录默认输出 `/tmp/wudao-hd2d-evidence/`，可用 `HD2D_EVIDENCE_DIR` 指定目录；临时证据不进入 Git。

## 当前质量边界

这是可运行的首版 HD-2D 切片。模块化几何和原创程序像素稿已经进入运行，但不能据此声称达到参考图或商业游戏的最终美术完成度。尚未完成方案所列 Blender GLB 资产生产、逐帧人工精修的完整八方向动作与生活动作、正式音效资产、连续录像、目标显卡 60 FPS／移动设备 30 FPS 验收和 15–25 分钟玩家体验测时。

当前 NPC 有固定职能与状态回应，未制作跑堂送餐、搬货往返等日程动画；屋顶和近墙通过独立室内剖面呈现，尚未制作分组屋顶渐隐。反射为固定频率的低分辨率平面反射，不包含折射和水下几何。景深轻且有中景清晰区，不以强虚化替代美术制作。手机竖屏提供紧凑布局与触控，推荐横屏。

软件渲染环境的真实帧耗时包含 SwiftShader 和截图开销，只可用于复现问题；不得写成真实 GPU 性能达标。所有性能数字以实际报告为准。
