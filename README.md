# 《武道》高武江湖可玩版

一款从金陵城外破庙起步、以文字和状态为核心的浏览器高武叙事RPG。第一版只讲大曜武道世界：山门传武、世家守土、帮会争夺水陆生计，强者足以改变一州格局，而主角只是一个尚未锻体的十六岁少年。

剧情保留《文字武侠：开局破庙夜会帮主夫人》的破庙奇遇、逆天改命、龙青鱼和鱼跃龙门诀，并重新组织成纯武道世界内的可玩流程。没有现实世界、现实同步、论坛、武道局或其他玩家。

本项目使用原创转述与交互改编，没有复制小说章节正文。原作：我想下海，[番茄小说作品页](https://fanqienovel.com/keyword/7572253)。世界结构仅参考《一世之尊》前期“低位人物进入层次分明的高武江湖”的体验，不使用其专有人物、势力、境界或剧情。

## 手机在线试玩

[打开《武道》高武江湖](https://jollywu24.github.io/xiuxian-simulator/)

支持手机竖屏与横屏、触控、数字键选择和本地进度保存。`main` 分支更新后由 GitHub Pages 自动发布。

## 当前流程

- 集中式江湖界面：桌面与手机横屏把场景放在左侧，右侧叙事卷轴连续收纳故事旁白、人物对话、玩家选择记录与当前行动；重要选择以金色强调，危险选择以赤色警示，未满足条件的选项明确置灰；
- 条件化选择：属性、武学、关系、见闻和资源门槛直接写在选项内，每项都可展开查看判定依据与当前缺口；人物与行录收进边缘随身册，竖屏则按场景、叙事、选择顺序阅读；
- 2D场景与行路图：破庙、紫金河、沈家侧门和丹房会随剧情显形；点击火堆、暗墙、道路或人物可查看当前状态，地图只展示已经知道的地点；
- 世界入场：大曜朝廷、山门、世家、帮会与高阶武者的关系；
- 人物车卡：四种出身、五种初心、姓名、债务与初始所得；
- 唯一命格“逆天改命”：五维归零，但可重分装备加成并看见奇遇条件；
- 双灯照命：第一次死亡保留记忆并回到最近因果节点，两灯皆灭则此生终结；
- 金陵破庙：饥饿、篝火、山桃、旅人遗物、沈氏承诺与暂时无法触发的神秘贡品；
- 青衣来客：身份延迟揭示、死亡预见、拒绝奇遇与连续关系选择；
- 龙青鱼夜话：根据回应建立不同关系，主线路线获得鱼跃龙门诀；
- 紫金河初试：新心法让主角走水路抢在饥饿耗尽体力前抵达沈家；
- 三条去路：金陵沈家、初一破庙、临安漕帮；
- 沈家求职：持沈字铜钱进侧门，却因根骨太差无法胜任护院、苦力、跑堂或账房，只能被送去曹青丹房当药童；
- 曹青死局：看见药王谷叛徒、血灵丹经与毒师传承三项奇遇，面对取血、偷学和三道盘问；
- 固定成长：把玉佩三点尽数改到悟性，观察炼丹并答出火候、药序与真正动机，得到一百八十潜能和《青青册》；
- 五禽戏：花八十五潜能学成医书第一层，通过次日辨药、尝味、诊脉考校后取得养生法；秘籍不会自动变成能力，仍须满足医术、悟性和五百潜能门槛后选择一戏入门；
- 丹房日常：一天三个时段，研读、练功、旁观、吃饭和休息分别改变体力、饱腹与成长进度，透支会触发命灯回照；
- 沈家密会：跟随曹青看见金龙会四堂、百舸争流和东门药铺门路，并处理沈福赠送的十两银子；
- 医术二级：先把《青青册》读出实际进度，再花一百六十六潜能突破，识别返回沈家取药草正是钓鱼窗口；
- 紫金河奇遇：亲手凑齐蚯蚓、鱼竿、钓鱼一级、酒与面团，以鱼跃龙门诀抵达钓点，遇见王五并合力擒下黄金钱鳘；
- 打鱼杆法：分食宝鱼把王五好感推到六十，取得一点力道、五百潜能与基础杆法，再用新武学推动曹青好感越过四十；
- 首次炼丹：重分五点已有属性到悟性，以鱼跃龙门诀补足水火判定；炼丹失败会烧坏药材并在次日重试，成功固定得到六枚下品回春丹、《百丹注解》和曹青的武功承诺；
- 三夫人病危：以望诊和切脉确认经脉逆行，从曹青、沈家秘库或鬼市取得三味药，亲手炼制紫龙换血丹；救治步骤和丹药品质共同决定白栀云是否脱险以及情分、信任、救命债和戒心；
- 春风化雨针：救人后立即取得医针与杀针，在东门长街的多回合夜战中读取双方境界、当前武学和敌人意图；危险行动使用固定因果骰，同一战况反复读取仍是同一点数，只有改变属性、武学、伤势、见闻或战场状态才能改变结果；
- 四档战果：大成会保住完整活口、凭证或退路并影响后续追查，得手正常完成目标，得手有损会带伤推进，失手则进入新的战况；只有撞入明确死局或连续严重失手才会触发命灯；
- 借局反制：制伏、杀死或脱身分别开放盘问活口、搜查尸身或追踪雨痕；补齐目标、暗语、鱼鳞铜签和交接时辰后，可以发送假回报、改写接头地点、优先保护白栀云或毁去渠道；
- 死劫履历：真正死亡会记录地点、死因、见闻与回照节点；贸然抢攻带回左袖藏刀的记忆，下一次入场会直接改变敌人意图和行动胜算；
- 拜师锻体：根据夜战结果接受曹青问徒，从神农枯木桩和沧澜定海桩中择一，花费潜能修炼并突破到锻体一重；
- 八月十五：按日期重返开局破庙，官道、山路、水路和延误产生不同到达时间与伤势；按对灵猴的馈赠、交易或强取结果分配猴儿酒，最后打开水洞并取得神猿残势线索。

“沈家丹房—东门药铺—紫金河—首炉炼丹”按公开章节第十二至二十九章的事件顺序改编；“三夫人病危—第一次杀人—拜师选桩—八月十五灵猴遗迹”按第三十至五十四章的因果顺序改编。项目保留关键事件和人物关系，以原创转述与可交互分支呈现，不复制正文长段落。详细目标与验收条件见 [`GOAL.md`](GOAL.md)。

## 本地启动

无需安装第三方依赖：

```bash
npm run serve
```

打开 `http://127.0.0.1:8080/`。

### 金陵雨巷战局

战斗模块可以通过 `http://127.0.0.1:8080/combat.html` 独立进入。该入口直接读取现有夜战规则，并以雨巷场景承载三名敌方单位、当前交锋、敌招顺序和灯笼／檐柱／矮墙热点。默认只显示三项情境行动，更多招式、身法、物品与退路收进“全部手段”；行动后会播放破绽、银针轨迹、伤害飘字和气血延迟扣除。命盘仍可调整五维、境界、针法、伤势、死中见闻与固定因果。

[手机打开战斗演武](https://jollywu24.github.io/xiuxian-simulator/combat-lab/combat.html)

已有调试浏览器运行在 `9225` 端口时，可执行 `npm run smoke:combat` 检查桌面、手机竖屏、手机横屏、单位切换、环境选择、全部手段、飘字、死亡和回照流程。

## 验证

```bash
npm test
npm run validate:content
```

当前共有83项规则测试。内容校验会检查三个篇章、26个事件节点、坏跳转、重复目录ID和首次能力兑现距离。

浏览器完整流程脚本位于 `scripts/cdp-smoke.mjs`。它覆盖世界入场、人物车卡、固定奇遇、一次死亡回照、龙青鱼主线、沈家求职、曹青死局、丹房日常、钓鱼与首炉六丹，并继续走完三夫人诊断救治、固定因果骰参与的春风针夜战、一次随机失手继续推进、雨中追查、假回报反制、拜师选桩、锻体突破、八月十五赶路、灵猴关系和神猿水洞；同时检查版本2／3／4迁移到版本5、终章恢复、1280×720桌面、390×844竖屏、844×390横屏和页面运行异常。
