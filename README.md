# 《武道》高武江湖可玩版

一款从金陵城外破庙起步的浏览器文字冒险。第一版只讲大曜武道世界：山门传武、世家守土、帮会争夺水陆生计，强者足以改变一州格局，而主角只是一个尚未锻体的十六岁少年。

剧情保留《文字武侠：开局破庙夜会帮主夫人》的破庙奇遇、逆天改命、龙青鱼和鱼跃龙门诀，并重新组织成纯武道世界内的可玩流程。没有现实世界、现实同步、论坛、武道局或其他玩家。

本项目使用原创转述与交互改编，没有复制小说章节正文。原作：我想下海，[番茄小说作品页](https://fanqienovel.com/keyword/7572253)。世界结构仅参考《一世之尊》前期“低位人物进入层次分明的高武江湖”的体验，不使用其专有人物、势力、境界或剧情。

## 手机在线试玩

[打开《武道》高武江湖](https://jollywu24.github.io/xiuxian-simulator/)

支持手机竖屏、触控、数字键选择和本地进度保存。`main` 分支更新后由 GitHub Pages 自动发布。

## 当前流程

- 世界入场：大曜朝廷、山门、世家、帮会与高阶武者的关系；
- 人物车卡：四种出身、五种初心、姓名、债务与初始所得；
- 唯一命格“逆天改命”：五维归零，但可重分装备加成并看见奇遇条件；
- 双灯照命：第一次死亡保留记忆并回到最近因果节点，两灯皆灭则此生终结；
- 金陵破庙：饥饿、篝火、山桃、旅人遗物、沈氏承诺与暂时无法触发的神秘贡品；
- 青衣来客：身份延迟揭示、死亡预见、拒绝奇遇与连续关系选择；
- 龙青鱼夜话：根据回应建立不同关系，主线路线获得鱼跃龙门诀；
- 黑水涧初试：新心法立即改变可走的道路，并能发现沈家丹房线索；
- 三条去路：金陵沈家、初一破庙、临安漕帮；
- 沈家丹房：用沈字铜钱进入世家药路，在有限时间内查药、查水或查门；
- 丹房死局：可以援引家规封炉、运转心法改风，或主动赴死后假毒反抓；
- 三向成长：选择《五禽桩》踏入锻体、服洗髓散补根骨，或取得青木药牌打开长期门路，并在离开沈家前立刻用所得处理丹房余波。

“沈家丹房死局”依据已出现的沈字铜钱与丹房线索原创扩展，不声称还原未经核对的小说后续章节。

## 本地启动

无需安装第三方依赖：

```bash
npm run serve
```

打开 `http://127.0.0.1:8080/`。

## 验证

```bash
npm test
```

浏览器完整流程脚本位于 `scripts/cdp-smoke.mjs`。它覆盖世界入场、人物车卡、固定奇遇、一次死亡回照、龙青鱼主线、黑水涧武学初试、沈家丹房调查与破局、锻体奖励、存档以及桌面和手机横向溢出检查。

## 主要文件

- `web/index.html`：网页入口；
- `web/wudao-core.mjs`：世界、人物、属性、命灯、奇遇、关系、心法与沈家死局纯规则；
- `web/wudao-app.mjs`：状态机、场景、存档与交互；
- `web/styles.css`：江湖冷墨、死亡暗红、奇遇玄金视觉；
- `tests/wudao.test.mjs`：当前路线核心规则测试；
- `scripts/cdp-smoke.mjs`：完整浏览器流程；
- `docs/GAME_DESIGN.md`：世界结构、系统边界与后续内容设计。

`web/app.mjs`、`web/game-core.mjs` 与 `tests/core.test.mjs` 保留上一版规则作为迁移参考，不再由网页入口加载。
