# 《武道》破庙奇遇可玩版

基于网络小说《文字武侠：开局破庙夜会帮主夫人》前十章剧情结构改编的浏览器文字冒险。

玩家以现实中的陈玄进入神秘文字游戏《武道》，创建江湖人物陈司命，在金陵城外的无名破庙寻找只会出现一次的奇遇。游戏中的武功、属性和死亡都会影响现实。

本项目使用原创转述与交互改编，没有复制小说章节正文。原作：我想下海，[番茄小说作品页](https://fanqienovel.com/keyword/7572253)。

## 手机在线试玩

[打开《武道》破庙奇遇](https://jollywu24.github.io/xiuxian-simulator/)

支持手机竖屏、触控、数字键选择和本地进度保存。`main` 分支更新后由 GitHub Pages 自动发布。

## 当前流程

- 现实开场：江海大学暑假宿舍，陌生的《武道》图标自动出现；
- 人物建档：四种身世、五种初心、江湖姓名与完整人物卡；
- 专属命格“逆天改命”：五维归零，但可重分装备加成并看见全部奇遇条件；
- 金陵破庙：饥饿、篝火、山桃、旅人遗物、沈氏承诺与暂时无法触发的神秘贡品；
- 现实论坛：两条命、武功同步现实、武道局和民间势力争夺新人；
- 偶发奇遇：不提前公开身份的青衣妇人，以及能够预见死亡和关系结局的连续选择；
- 龙青鱼夜话：根据回应建立不同关系，主线路线获得地级奇遇结局；
- 鱼跃龙门诀：三项规则级心法能力，并在现实中亲手验证水下闭气；
- 武道局登门：于可心、林毅询问登记情况，玩家在保护与自由之间选择；
- 后续入口：金陵沈家丹房、初一十五神秘贡品、临安重逢。

## 本地启动

无需安装第三方依赖：

```bash
npm run serve
```

打开 `http://127.0.0.1:8080/`。

## 验证

```bash
npm test
```

浏览器完整流程脚本位于 `scripts/cdp-smoke.mjs`。它覆盖人物创建、固定奇遇、一次死亡回溯、龙青鱼主线、现实同步、武道局选择、存档以及桌面/手机横向溢出检查。

## 主要文件

- `web/index.html`：网页入口；
- `web/wudao-core.mjs`：人物、属性、奇遇、关系、心法与武道局纯规则；
- `web/wudao-app.mjs`：状态机、场景、存档与交互；
- `web/styles.css`：现实暖纸、武道冷墨、死亡暗红、奇遇玄金视觉；
- `tests/wudao.test.mjs`：小说路线核心规则测试；
- `scripts/cdp-smoke.mjs`：完整浏览器流程；
- `docs/GAME_DESIGN.md`：剧情映射与玩法设计。

`web/app.mjs`、`web/game-core.mjs` 与 `tests/core.test.mjs` 保留上一版规则作为迁移参考，不再由网页入口加载。
