# 《武道》高武江湖可玩版

一款从金陵城外破庙起步、以文字和状态为核心的浏览器高武叙事RPG。第一版只讲大曜武道世界：山门传武、世家守土、帮会争夺水陆生计，强者足以改变一州格局，而主角只是一个尚未锻体的十六岁少年。

剧情保留《文字武侠：开局破庙夜会帮主夫人》的破庙奇遇、逆天改命、龙青鱼和鱼跃龙门诀，并重新组织成纯武道世界内的可玩流程。没有现实世界、现实同步、论坛、武道局或其他玩家。

本项目使用原创转述与交互改编，没有复制小说章节正文。原作：我想下海，[番茄小说作品页](https://fanqienovel.com/keyword/7572253)。世界结构仅参考《一世之尊》前期“低位人物进入层次分明的高武江湖”的体验，不使用其专有人物、势力、境界或剧情。

## 手机在线试玩

[打开《武道》高武江湖](https://jollywu24.github.io/xiuxian-simulator/)

支持手机竖屏与横屏、触控、数字键选择和本地进度保存。`main` 分支更新后由 GitHub Pages 自动发布。

战斗模块在 `codex/combat-lab` 分支持续开发，发布流程会把它挂到独立的[东门雨夜演武入口](https://jollywu24.github.io/xiuxian-simulator/combat-lab/combat.html)，不会替换正式根页面。

## 当前流程

- 集中式江湖界面：桌面与手机横屏把场景放在左侧，右侧叙事卷轴连续收纳故事旁白、人物对话、玩家选择记录与当前行动；选择落定后会转成“你”的行文记录，结果紧随其后，旧文上推而不换页；重要选择以金色强调，危险选择以赤色警示，未满足条件的选项明确置灰；
- 条件化选择：属性、武学、关系、见闻和资源门槛直接写在选项内，每项都可展开查看判定依据与当前缺口；人物、行囊与武学是左下角三个独立入口，竖屏则按场景、叙事、选择顺序阅读；
- 全屏行囊：从场景进入独立行囊页，以图标切换全部、丹药、材料、兵具、信物和线索；1672×941下按确认稿的68像素顶栏、1080／592分区、六列四行格位与回春丹详情逐项对齐；左侧显示已用容量、品质底边与右下角数量，右侧只显示当前物品名称、品质、类型、持有上限、说明和效用；银两常驻顶部，能实际消耗的物品才出现使用按钮；
- 全屏人物与装备：人物页按1672×941确认稿重做；左侧显示小号姓名、出身、境界、气血、真气、五维、防御、减伤、伤势和只露名称的特性，不显示命灯或潜能；中间以新陈司命立绘为中心配置九个等大装备槽，近战／远程武器槽下直接显示伤害；右侧是二十四格装备行囊，支持品质底框、兵刃／衣甲／佩饰筛选、条件校验、点击穿戴和点击卸下；

- 雨夜入场：点击开始后直接在金陵东郊破庙冷醒，先从余火、饥饿和随身物认识世界与人物；火势、饥饿与查明行囊在左侧场景以短暂飘字反馈，顶部只保留最终状态；开场旁白和行动结果采用克制的武侠说书口吻；横屏严格使用1672×941视觉标尺等比缩放，保留约三分之二场景、三分之一叙事和三个大号单行行动；

### 完整战斗系统

战斗模块可以通过 `http://127.0.0.1:8080/combat.html` 独立进入，并可在金陵雨巷与东湖王卓战之间切换；正篇春风针夜战和锻体后的柳巷／东湖连续战也已接入同一会话接口。我方每轮有三点行动，移动、识招、武学、同伴、疗伤、环境和撤离使用同一行动协议；有内功时可投入跨战斗保存的真气催动原招式，常式与催动沿用同一枚固定因果骰，推荐区不会重复摆出两个版本。收势后敌方按公开意图自动依次移动、攻击、施毒、增援或撤走。

攻击行动统一使用“固定1D10＋单项属性＋武学熟练＋境界差＋有利／不利－伤势”对抗“4＋行动难度＋目标防御”；命中后，武器、威力属性、境界、招式和真气共同生成伤害区间，大成／得手／得手有损分别取上限／均值／下限，再由减伤与穿透结算实际失血。玩家和敌人共用这套公式，换装后的伤害、防御和减伤会立即进入下一次战斗。

雨巷保留三敌人、六节点、灯笼／檐柱／矮墙和杀／擒／逃纵切；刀客有十八点气血，必须先看破杀招并压到九点以下才能制伏或取命。王卓战新增柳巷尾随与东湖河岸两个阶段：柳巷只显示身份线索、同行去向与警觉，不把尾随伪装成血条战；东湖包含燕惊鸿关系协作、锻体对聚气越阶、王卓锁链刀、毒刃夹击、持续蛇毒、第二轮援弩、松动船索机关、解毒与致命伤止血。首领可生擒、击杀、放线追踪或护送同伴撤离；结束后统一输出伤势、人物关系、证据、敌方警戒、敌人生死和持续毒伤。雨巷结局还能直接承接柳巷，命灯、伤势、见闻、关系、证据和警戒不会重置。

界面默认只显示三项去重后的情境行动，同时预告身位和若此刻收势将承受的后果；更多手段收进抽屉或折叠区。同伴、毒伤、致命伤、证据与警戒直接显示为可聚焦状态，桌面、手机竖屏和横屏使用同一规则状态。正篇夜战结束后仍进入原有搜尸／盘问／追踪与后续成长，旧夜战存档会在继续时自动迁入新会话。

[手机打开战斗演武](https://jollywu24.github.io/xiuxian-simulator/combat.html)

已有调试浏览器运行在 `9225` 端口时，可执行 `npm run smoke:combat` 检查桌面、手机竖屏、手机横屏、雨巷完整流程、柳巷转场、同伴协作、河岸多敌、援弩、致命伤处理、环境热点、死亡和回照流程。
