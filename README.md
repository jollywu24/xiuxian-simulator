# 《武道》高武江湖可玩版

一款从金陵城外破庙起步、以文字和状态为核心的浏览器高武叙事RPG。第一版只讲大曜武道世界：山门传武、世家守土、帮会争夺水陆生计，强者足以改变一州格局，而主角只是一个尚未锻体的十六岁少年。

剧情保留《文字武侠：开局破庙夜会帮主夫人》的破庙奇遇、逆天改命、龙青鱼和鱼跃龙门诀，并重新组织成纯武道世界内的可玩流程。没有现实世界、现实同步、论坛、武道局或其他玩家。

本项目使用原创转述与交互改编，没有复制小说章节正文。原作：我想下海，[番茄小说作品页](https://fanqienovel.com/keyword/7572253)。世界结构仅参考《一世之尊》前期“低位人物进入层次分明的高武江湖”的体验，不使用其专有人物、势力、境界或剧情。

## 手机在线试玩

[打开《武道》高武江湖](https://jollywu24.github.io/xiuxian-simulator/)

支持手机竖屏与横屏、触控、数字键选择和本地进度保存。`main` 分支更新后会先通过规则、内容和自启动浏览器回归，再由 GitHub Pages 自动发布；部署完成后继续检查线上构建号、资源契约和真实浏览器启动。

战斗模块在 `codex/combat-lab` 分支持续开发，发布流程会把它挂到独立的[东门雨夜演武入口](https://jollywu24.github.io/xiuxian-simulator/combat-lab/combat.html)，不会替换正式根页面。

## 当前流程

- 三种来处：新旅程从世家旁支、市井子弟、身世成谜三者中选择；选择页只展示当下可知的生活痕迹，不提前替主角决定容貌，也不提前泄露族宅属于沈家。世家旁支从西偏院接下封药木匣差事，市井子弟从秦淮鱼市接下红绳包跑腿，身世成谜仍从破庙冷醒；三条路在破庙汇流，又分别以回府复命、货门交割和沈字铜钱进入沈家；
- 容貌与命名：选定出身后进入独立全屏容貌页，可填写姓名、切换男身／女身，并用规律的“顶部一项＋左右各五项”浏览帽子、前发、后发、眼睛、眉毛、嘴巴、鼻子、脸型、脸饰、后背外观和服装；当前实际开放男女两张完整人物母版、同姿势派生的灰衣短打／靛蓝行衣，以及同头型派生的无头饰／旧布额巾，其它类别暂时只有默认项。六张正式资源统一到固定画布后由 Canvas 合成，八种组合已经用可辨识大格人工检查；上一版衣服、身体和帽子不属于同一人物的九十六格资源已经撤回，旧档无效编号会回到安全默认；
- 出身长期回响：来处会写入随身物、银钱与口粮、联系人、见闻、权限、暴露和差事状态；普通成功、带代价成功与失手都可继续。曹青丹房会读取开场留下的药气、腰牌或血书旧字，沈家密会后分别触发旁谱缺名、鱼市催信和血书旧字事件；
- 集中式江湖界面：桌面与手机横屏把场景放在左侧，右侧叙事卷轴连续收纳故事旁白、人物对话、玩家选择记录与当前行动；选择落定后会转成“你”的行文记录，结果紧随其后，旧文上推而不换页；重要选择以金色强调，危险选择以赤色警示，未满足条件的选项明确置灰；
- 条件化选择：属性、武学、关系、见闻和资源门槛直接写在选项内，每项都可展开查看判定依据与当前缺口；人物、行囊与武学是左下角三个独立入口，竖屏则按场景、叙事、选择顺序阅读；
- 全屏行囊：从场景进入独立行囊页，以图标切换全部、丹药、材料、兵具、信物和线索；1672×941下按确认稿的68像素顶栏、1080／592分区、六列四行格位与回春丹详情逐项对齐；左侧显示已用容量、品质底边与右下角数量，右侧只显示当前物品名称、品质、类型、持有上限、说明和效用；银两常驻顶部，能实际消耗的物品才出现使用按钮；
- 全屏人物与装备：人物页按1672×941确认稿重做；左侧显示小号姓名、出身、境界、气血、真气、五维、防御、减伤、伤势和只露名称的特性，不显示命灯或阅历，人物／关系／百艺以连续竖排纸签切换；中间人物始终读取创建时选定的十一类容貌，装备不会替换服装或人物外观；九个装备槽等大，近战／远程武器槽下直接显示伤害；右侧是二十四格装备行囊，支持品质底框和兵刃／衣甲／佩饰筛选；点击任何装备只打开详情浮层，必须再点击装备、替换或卸下按钮才会改变状态；
- 完整武学系统：全屏武学页按效果图还原为31.4%所学列表、36%人物与六个等大携带位、32.6%详情，使用专用暗纹背景、陈司命立绘和九枚圆形武学徽记；心法、招式、轻功、锻体使用统一目录，招式可按剑法、刀法、拳掌、枪棍和暗器筛选，武学品阶固定为粗浅、寻常、上乘、绝学、镇派；研习固定消耗四十阅历并增加十点修为，满百后按真实使用、领悟与人物事件突破；已学武学不会因卸下而遗忘，但突发战斗只读取携带中的一心法、三招式、一轻功和一锻体，兵器不合时直接显示条件缺口；

### 完整战斗系统

战斗模块可以通过 `http://127.0.0.1:8080/combat.html` 独立进入，并可在金陵雨巷与东湖王卓战之间切换；正篇春风针夜战和锻体后的柳巷／东湖连续战也已接入同一会话接口。我方每轮有三点行动，移动、识招、武学、同伴、疗伤、环境和撤离使用同一行动协议；有内功时可投入跨战斗保存的真气催动原招式，常式与催动沿用同一枚固定因果骰，推荐区不会重复摆出两个版本。收势后敌方按公开意图自动依次移动、攻击、施毒、增援或撤走。

攻击行动统一使用“固定1D10＋单项属性＋武学熟练＋境界差＋有利／不利－伤势”对抗“4＋行动难度＋目标防御”；命中后，武器、威力属性、境界、招式和真气共同生成伤害区间，大成／得手／得手有损分别取上限／均值／下限，再由减伤与穿透结算实际失血。玩家和敌人共用这套公式，换装后的伤害、防御和减伤会立即进入下一次战斗。

雨巷保留三敌人、六节点、灯笼／檐柱／矮墙和杀／擒／逃纵切；刀客有十八点气血，必须先看破杀招并压到九点以下才能制伏或取命。王卓战新增柳巷尾随与东湖河岸两个阶段：柳巷只显示身份线索、同行去向与警觉，不把尾随伪装成血条战；东湖包含燕惊鸿关系协作、锻体对聚气越阶、王卓锁链刀、毒刃夹击、持续蛇毒、第二轮援弩、松动船索机关、解毒与致命伤止血。首领可生擒、击杀、放线追踪或护送同伴撤离；结束后统一输出伤势、人物关系、证据、敌方警戒、敌人生死和持续毒伤。雨巷结局还能直接承接柳巷，命灯、伤势、见闻、关系、证据和警戒不会重置。

界面默认只显示三项去重后的情境行动，同时预告身位和若此刻收势将承受的后果；更多手段收进抽屉或折叠区。同伴、毒伤、致命伤、证据与警戒直接显示为可聚焦状态，桌面、手机竖屏和横屏使用同一规则状态。正篇夜战结束后仍进入原有搜尸／盘问／追踪与后续成长，旧夜战存档会在继续时自动迁入新会话。

[手机打开战斗演武](https://jollywu24.github.io/xiuxian-simulator/combat.html)

执行 `npm run smoke:combat` 会自行启动本地服务和无头 Chrome／Edge，检查桌面、手机竖屏、手机横屏、雨巷完整流程、柳巷转场、同伴协作、河岸多敌、援弩、致命伤处理、环境热点、死亡和回照流程，无需提前打开调试浏览器。

## 验证

```bash
npm run verify
```

完整质量门禁依次执行语法检查、纯规则与迁移测试、内容校验、发布资源契约，以及正篇／三出身／战斗三套自启动浏览器回归。浏览器脚本会自行托管页面、寻找Chrome或Edge、分配端口并清理临时目录。局部命令、覆盖矩阵和失败定位见[`docs/TESTING.md`](docs/TESTING.md)；浏览器存档和坏档恢复边界见[`docs/SAVE_ARCHITECTURE.md`](docs/SAVE_ARCHITECTURE.md)。

统一启动器位于`scripts/run-browser-regression.mjs`。Pages部署前运行同一套完整门禁；部署后再读取统一资源契约检查线上构建号、MIME与字节数，并自动启动浏览器进入三出身选择，证明真实线上JavaScript已经启动。发布闭环见[`docs/RELEASE.md`](docs/RELEASE.md)，调试状态协议见[`docs/DEBUGGING.md`](docs/DEBUGGING.md)。

## 主要文件

- `web/index.html`：网页入口；
- `web/wudao-core.mjs`：世界、人物、属性、命灯、日常起居、奇遇、关系、心法、钓鱼与炼丹纯规则；
- `web/origin-core.mjs`：三种出身、独立序章、任务成败、旧ID迁移、破庙反馈与第一章个人事件纯规则；
- `web/appearance-core.mjs`：十一类容貌状态、同源人物／服装／头部变体、默认值、旧档回落与正式资源映射；
- `web/inventory-core.mjs`：行囊分类、容量、物品目录、品质、使用条件与银两显示纯规则；
- `web/character-system.mjs`：人物派生属性、九个装备槽、二十四格装备行囊、品质、穿戴条件、伤害区间、防御、减伤与真气纯规则；
- `web/martial-system.mjs`：武学目录、品阶、造诣、修为、突破、六个携带位、兵器条件、战斗映射与旧存档迁移纯规则；
- `web/wudao-p0-core.mjs`：通用条件与效果、病例、物品、关系、战斗、伤势、桩功、突破、时间和灵猴规则；
- `web/content/p0/`：第三十至五十四章的目录与事件节点；
- `web/wudao-p1-core.mjs`：曹青离场、钱匣来源、追踪、联系人结局、白栀云授武与江湖留痕纯规则；
- `web/content/p1/`：第五十五至六十八章第一条可玩闭环的局面盒、解法矩阵、节点和证据目录；
- `web/save-core.mjs`：存档校验、解析与主备恢复纯规则；
- `web/save-storage.mjs`：浏览器主备存储与桌面桥接适配；
- `desktop/save-file-store.mjs`：未来桌面外壳使用的原子文件存档器；
- `web/wudao-app.mjs`：状态机、场景、存档与交互；
- `web/wudao-scenes.mjs`：2D场景物件、人物站位和已知路线视图；
- `web/combat-engine.mjs`：通用回合、行动判定、敌方队列、状态、伤势、回照和战后总账纯规则；
- `web/combat-encounters.mjs`：王卓双阶段首领战、敌人意图、环境与结局数据；
- `web/combat-lab-core.mjs`：雨巷旧规则与通用引擎的统一入口适配层；
- `web/combat-lab.mjs`：双战局界面、同伴／状态聚焦、行动反馈与连续战役交互；
- `web/assets/scenes/`：破庙、紫金河、沈家侧门和丹房场景背景；
- `web/assets/origins/`：西偏院、秦淮鱼市与三张匿名出身牌面；
- `web/assets/inventory/`：生成式行囊背景、十六件统一画风物品、回春丹详情图，以及分页、银锭、宣纸与空格纹样；
- `web/assets/character/`、`web/assets/equipment/`：人物纸偶立绘与十六件统一画风装备图集；
- `web/styles.css`：江湖冷墨、死亡暗红、场景热点与手机路线视觉；
- `tests/wudao.test.mjs`：当前路线核心规则测试；
