# 《太虚命盘》可玩 Demo

`xiuxian-simulator` / 修仙模拟器 Demo

一段约 35～50 分钟、从捏人推进至第七年黑日终局的完整浏览器 Demo，验证“试命 → 带回 → 改命”以及“情报比单纯数值更能改变规则”的核心循环。

## 手机在线试玩

[打开《太虚命盘》完整网页版](https://jollywu24.github.io/xiuxian-simulator/)

支持手机竖屏、触控操作和自动存档；`main` 更新后会通过 GitHub Pages 自动重新发布。

当前可体验内容：

- 跑团式开场：先了解大虞与归尘门，再填写入籍名牒、照骨验身并确认人物卡；
- 原创“雨夜破庙”奇缘：先判断陌生伤者与追兵，再揭开霜河帮主母身份；藏人、救治、问价三种处置会留下不同信物与长期因果；
- 奇缘信物不是收藏文本：霜河暗纹、锁息丹或夜渡名帖会各自解锁第一次模拟中的专属调查行动；
- 藏经阁异响作为第一个可选择事件，触碰祖师洞命盘后才逐步揭示模拟规则；
- 唯一自建主角：姓名、称谓、外观印色、凡俗出身；
- 根骨、才性、因果三组随机先天词条，每组二选一，可整组重抽一次；
- 第一次模拟中的调查、关系、修炼与高风险试探；
- 晚宴毒杀、死亡因果回溯；
- 道行、确证、按行为生成词池的后天词条抽取；
- 三种不同的现实破局与“预知兑现”；
- 第二次模拟快速越过旧死法，进入完整乌铜矿因果事件；
- 传闻、确证、过期确证三档情报可信度；
- 正井、排水道与词条联动风井等不同入矿路线；
- 可观察敌方意图、用确证反制的短回合战斗；
- 天妒与偏差对敌方准备和情报可靠性的实际影响；
- 闻青禾、裴照雪的证据门槛、拒绝条件与自主行动；
- 矿底成果带回现实后的即时兑现与路径复盘；
- 第一年建宗旧档、第五年祭阵争夺与第七年黑日的压缩七年因果链；
- 裴照雪、闻青禾、宋无咎、阿厌四名拥有动机、线索与底线的核心人物；
- 观命、拆阵、潜行、关系四种规则级构筑方向；
- 现实死亡、最近现实锚点重试与 v1/v2→v3 存档迁移；
- “携火离山”“斩祖散门”“夺盘续世”三个正式结局；
- 结局命痕继承及真实可玩的二周目早期变化；
- 本地自动存档、现实死亡重试、改选第一次结算。

## 启动

无需安装第三方依赖：

```bash
npm run serve
```

然后打开：

```text
http://127.0.0.1:8080/
```

如需固定随机结果，使用：

```text
http://127.0.0.1:8080/?seed=balance-42
```

## 验证

核心随机与结算池测试：

```bash
npm test
```

完整浏览器冒烟脚本位于 `scripts/cdp-smoke.mjs`，会验证 P0 三条结算路线、P1 矿难，以及 P2 现实死亡、七年危机、三个结局、旧存档迁移和二周目继承。它需要一个开启远程调试端口的本地 Chrome：

```bash
google-chrome --headless --no-sandbox --remote-debugging-port=9225 \
  --user-data-dir=/tmp/taixu-demo-chrome \
  "http://127.0.0.1:8080/?seed=balance-42"

node scripts/cdp-smoke.mjs 9225
```

## 文件

- `web/index.html`：页面入口；
- `web/styles.css`：现实暖纸、模拟冷墨、死亡暗红、结算玄金四套视觉状态；
- `web/game-core.mjs`：可复现随机、奇遇、词条、情报、NPC、构筑、战斗、终局和周目继承规则；
- `web/app.mjs`：场景状态机、v1/v2→v3 存档迁移与完整 P0/P1/P2 Demo 流程；
- `tests/core.test.mjs`：无依赖核心测试；
- `docs/GAME_DESIGN.md`：完整游戏设计。
