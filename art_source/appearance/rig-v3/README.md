# 容貌半身母版 v3

本目录保存四套同标尺容貌母版的色键源图：男身两套、女身两套。

四张母版统一遵守：

- 角色年龄约十九至二十二岁，保留少年侠客／初入江湖青年的气质，不使用儿童脸比例；
- 视角、头部尺度、肩线、腰线、双手位置和光向一致；
- 人物从头顶展示到大腿上段，不包含膝盖、脚、地面或投影；
- 画风为干净的矿物色手绘与克制墨线，四套分别使用黛蓝金、赭红黑、松绿银和月白玄红，不使用统一灰破脏污、写实摄影或3D渲染；
- 源图只使用纯洋红色键背景，构建后网页加载透明WebP；
- 四套是完整验证过的容貌组合，不拆出未经验证的独立五官部件。

`concept-lineup-v2.png`是四人年龄、服装结构、身份色与记忆点的共同母版；四张`*-chroma.png`必须以它为身份依据派生，不能各自重新设计。

构建脚本会把每张源图按可见人物高度的同一比例截到大腿上段，再统一头顶与中轴。源图下缘长短不得通过网页CSS逐张修正。

构建命令：

```bash
python scripts/build-appearance-rig-v3.py
```

运行资源输出到`web/assets/appearance/rig-v3/`，组合验收图输出到`docs/assets/appearance-rig-v3-matrix.webp`。
