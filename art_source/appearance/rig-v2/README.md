# 容貌母版 v2

本目录保存纸娃娃运行资源的透明母版。所有母版遵守同一条规则：先锁定完整人物，再从同一人物派生衣服和头饰；禁止把独立生成的局部直接拼到人物上。

当前纵切只开放：

- 男、女各一张完整内衬母版；
- 同姿势派生的一套靛蓝外衣；
- 同头型派生的一条武人发带；
- 未从母版派生并通过视觉检查的五官、发型和大型帽子暂不开放。

源文件命名：

- `male-base.png`、`female-base.png`：完整母版；
- `*-outfit-indigo.png`：同一人物的完整外衣母版；
- `*-headband.png`：同一人物的完整发带母版。

正式网页不直接加载本目录，而是加载构建脚本输出到 `web/assets/appearance/rig-v2/` 的 WebP。
