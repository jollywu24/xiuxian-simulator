# 容貌固定锚点源管线 v5

本目录保存容貌纸娃娃 v5 的新增源母版。运行时不会直接加载这里的 PNG；`scripts/build-appearance-rig-v5.py`会结合已验收的`rig-v3`男女母版与`rig-v4`第二套衣装，生成`web/assets/appearance/rig-v5-psd/`中的正式 WebP 图层。

## 用途与结构

- 画布统一为`1024×1536`，人物中轴固定在`x=512`；
- 衣服允许改变颈部以下的姿势与轮廓，但不能携带自己的头脸进入最终合成；
- 构建时先输出两套衣装底像，再用固定遮罩导出同一头脸及四种前发／后发组合；
- 脸型、眼睛、眉毛、鼻子和嘴巴只在各自固定脸部区域生成替换片；
- 帽子、脸饰和后背物使用全画布透明层与固定插槽；
- 浏览器只做正常 Alpha 合成，不为任何编号追加位置、缩放或裁切补丁。

## 来源、作者与许可

- `ebony-guan-chroma.png`由 OpenAI 内置图像生成工具于 2026-08-07 生成，提示词要求单独绘制一顶黑漆旧金武侠小冠，置于纯洋红键色背景，不含人物、头发、文字、界面或阴影；
- 男女人物身份母版来自本项目`art_source/appearance/rig-v3/`，第二套衣装源来自`art_source/appearance/rig-v4/`；其来源和公开分发权记录见各自 README；
- 本目录不含第三方游戏素材。生成资产作为本项目自有美术源使用，可随项目公开分发；成熟游戏与工具只用于结构研究，不复制其素材。

## 构建

```bash
python scripts/build-appearance-rig-v5.py
```

输出：

- `web/assets/appearance/rig-v5-psd/`：男女各十四张、合计二十八张正式运行资源；
- `docs/assets/appearance-rig-v5-psd-matrix.webp`：男女各四组的人工组合验收图。

## 人工验收

逐格核对以下项目，任一失败都不得发布：

- 换衣后头顶、脸中心、五官、下颌与颈部不漂移；
- 前发和后发变化不改写五官，衣服变化不改写头脸；
- 五官替换没有第二张脸、重影、矩形补片或肤色断层；
- 帽子与头发保持清楚的遮挡关系，后背物位于人物后方；
- 男女两套衣装有结构差异，且所有资源透明边缘无洋红残色；
- `1280×720`与`844×390`中，帽子控制条不遮挡人物头顶。
