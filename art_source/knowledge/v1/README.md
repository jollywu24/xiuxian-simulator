## 用途

这组母版用于见闻全屏页的首章条目缩略图与详情主图：乌沉药匣、破庙山桃、龙青鱼、紫金河夜船、东郊脚夫遇袭。

## 来源与许可

- 作者／来源：2026-08-07 由 OpenAI 内置图像生成工具按项目提示生成；
- 第三方素材：无；
- 公开分发：项目可将裁切后的输出随网页公开分发；
- 参考图 `docs/assets/references/见闻.jpg` 只用于界面层级参考，没有被裁切或拼入运行资源。

最终提示共同约束为：大曜高武江湖、原创中国水墨设色游戏插画、5:4 横幅、纸张肌理、克制半写实、无文字、无标志、无水印。五张图分别描绘乌木药匣、新鲜山桃、雨中青衣女侠、无灯夜船与受伤脚夫。

## 画布与锚点

- 母版：生成工具原始 PNG；
- 发布输出：`1000×800`、sRGB、WebP quality 88；
- 主要对象保持在画面中央 15%—85% 安全区，列表使用 `object-fit: cover`，详情使用同一图的宽幅裁切；
- 龙青鱼插画只能在姓名与身份已经揭示后显示。
