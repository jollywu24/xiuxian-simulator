# Inventory art v1

本目录保存行囊十六件物品的 `4×4` 无文字源图集。网页不直接加载本目录；当前运行时使用 `web/assets/inventory/` 下已经裁切并验收的独立物品图。

## 来源与用途

- 源文件：`inventory-items-atlas.png`；
- 画面内容：十六件同一画风的物品静物，不包含玩家文字、边框或数量；
- 当前用途：作为现有独立物品图的权威构图与画风来源；
- 公开分发：运行时只分发裁切后的物品图，本源图集不进入 Pages；
- 第三方运行时：无。

后续重建必须保持四列四行的稳定顺序，并逐项核对透明边缘、主体完整性、相邻格污染和小尺寸辨识度。没有完成可重复裁切脚本前，不得用本图集批量覆盖已经上线的独立物品图。
