# 雨夜世界材质与几何

用途：Three.js 破庙、宅院、丹房、街巷地面与木建筑共用材质。作者/来源：本次任务通过 OpenAI imagegen 原创生成，未使用第三方照片或受许可限制的游戏资产。可按生成服务条款与用户授权用于本项目分发；不声称具有第三方素材独占权。

母版为 1254×1254 PNG；输出 1024×1024 WebP。UV 原点以 Three.js 标准 UV 为准，无角色锚点。石材和木材为独立平铺材质，不是从场景效果图裁切。平铺是生成目标，边界并非数学意义上的周期保证；运行中按小块石板/木构件使用并以接缝分隔。

生成规格：
- stone-source-v1.png：旧灰蓝石板、细裂纹、少量苔藓，正交平视表面、均匀漫射照明、无物体/透视/投影/文字/边框，克制手绘写实。
- timber-source-v1.png：深红褐旧木、竖向木纹、磨损红漆，相同正交照明和无物体约束。

导出：`python scripts/build-world3d-assets.py`。
输出：`web/assets/world3d/temple-stone-v1.webp` 与 `temple-timber-v1.webp`。

人工检查：母版纹理已检查，无文字、物件或透视畸变；浏览器中实际平铺、曝光和移动端清晰度需按交付验证范围区分。

建筑、瓦顶、草木、河道、器物与角色为 `web/world3d-models.mjs` 中可重建的原创程序化网格。使用固定随机种子、米制坐标、Y 轴向上，人物脚底为原点。步态由肩/髋分组驱动，不依赖 Spine 或外部骨骼资产。身体轮廓为风格化表现，原容貌与装备系统仍由既有角色面板承载。
